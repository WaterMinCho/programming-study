## 문제 설명

마을 물통마다 담긴 물의 양이 정수로 적혀 있습니다. 관리인은 물이 가장 많이 담긴 물통부터 쓰려고 합니다.

물통의 양을 담은 배열 nums가 주어질 때, 가장 큰 값을 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(nums: list[int]) -> int:
```

```javascript
function solution(nums) {}
```

## 제한사항

- 1 ≤ nums의 길이 ≤ 20,000
- nums의 원소는 -1,000 이상 1,000 이하인 정수입니다.

## 입출력 예

| nums | result |
|---|---|
| [3, 9, 4] | 9 |
| [-5, -2, -8] | -2 |
| [6] | 6 |

## 입출력 예 설명

- 예 1: 3, 9, 4 가운데 가장 큰 값은 9입니다.
- 예 2: 모두 음수이고 그 가운데 가장 큰 값은 -2입니다.
- 예 3: 물통이 하나라 그 양 6이 답입니다.
