## 문제 설명

마을 관리인은 물통 가운데 k개를 골라 축제에 쓰려고 합니다. 물이 많이 담긴 물통부터 고르면 모은 물이 가장 많아집니다.

물통의 양을 담은 배열 nums와 정수 k가 주어질 때, 물통 k개를 골라 얻을 수 있는 물의 양의 합 가운데 가장 큰 값을 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(nums: list[int], k: int) -> int:
```

```javascript
function solution(nums, k) {}
```

## 제한사항

- 1 ≤ nums의 길이 ≤ 20,000
- nums의 원소는 -1,000 이상 1,000 이하인 정수입니다.
- 1 ≤ k ≤ nums의 길이

## 입출력 예

| nums | k | result |
|---|---|---|
| [3, 1, 4, 1, 5] | 2 | 9 |
| [-1, -2, -3] | 2 | -3 |
| [2, 7] | 2 | 9 |

## 입출력 예 설명

- 예 1: 가장 큰 두 값 5와 4를 더해 9입니다.
- 예 2: 모두 음수라도 두 개를 골라야 하므로 -1과 -2를 더해 -3입니다.
- 예 3: 물통 두 개를 모두 골라 2 + 7 = 9입니다.
