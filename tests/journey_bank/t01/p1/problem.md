## 문제 설명

마을 물통마다 담긴 물의 양이 정수로 적혀 있습니다. 양수는 채운 양이고 음수는 새어 나간 양입니다.

물통의 양을 담은 배열 nums가 주어질 때, 모든 물통의 양을 더한 값을 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(nums: list[int]) -> int:
```

```javascript
function solution(nums) {}
```

## 제한사항

- 1 ≤ nums의 길이 ≤ 20,000
- nums의 원소는 -1,000 이상 1,000 이하인 정수입니다.

## 입출력 예

| nums | result |
|---|---|
| [1, 2, 3] | 6 |
| [5, -2] | 3 |
| [7] | 7 |

## 입출력 예 설명

- 예 1: 1 + 2 + 3 = 6입니다.
- 예 2: 5 + (-2) = 3입니다.
- 예 3: 물통이 하나라 그 양 7이 답입니다.
