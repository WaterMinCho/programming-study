## x01-F

미션이 끝나면 면접관이 방금 쓴 코드의 이유를 묻습니다.

### Q1. 횟수를 일반 변수가 아니라 `useState`에 둔 이유는 무엇인가요?
- [필수] 값이 바뀌면 화면을 다시 그려야 하는데, 일반 변수는 바뀌어도 React 가 알지 못합니다.
- [보충] 화면에 보이지 않고 렌더링과 상관없는 값은 `useRef`에 둡니다.
> 막히면: `let count = 0`으로 바꾸고 버튼을 눌렀을 때 화면이 어떻게 되는지부터 말해 보세요.

### Q2. `setCount(count + 1)`과 `setCount((n) => n + 1)`은 무엇이 다른가요?
- [필수] 앞은 이번 렌더의 `count` 값을 쓰고, 뒤는 React 가 넘겨 주는 가장 최근 값을 씁니다.
- [필수] 한 이벤트 안에서 두 번 부르면 앞은 한 번만 오르고 뒤는 두 번 오릅니다.
> 막히면: 한 번 누를 때 `setCount(count + 1)`을 두 줄 적어 두면 숫자가 몇이 되는지 말해 보세요.

### 약한 답
> "React 에서는 원래 state 를 쓰니까요."

관례라고만 답하면 state 가 바뀔 때 화면을 다시 그린다는 동작이 빠집니다.

### 이어 말하기
> "일반 변수는 바뀌어도 React 가 모릅니다. useState 로 두면 setCount 가 불릴 때 React 가 App 을 다시 실행해서 바뀐 글자를 화면에 반영합니다."
