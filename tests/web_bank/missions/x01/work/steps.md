## 0. 코드 설명

### 요구
> 면접관: 받은 코드를 어떻게 읽으셨는지 1분 정도 설명해 주세요. 버튼을 눌렀을 때 무슨 일이 일어나는지 위주로요.

### 점검
- 횟수가 `App`의 state 에 있다고 말했습니다.
- 버튼을 누르면 `setCount`가 불려 화면이 다시 그려진다고 말했습니다.

## 1. 더하기 버튼

### 요구
> 면접관: 버튼 이름을 "더하기"로 바꾸고, 누를 때마다 횟수가 1씩 오르게 해 주세요.

버튼 안의 글자는 화면 읽기 프로그램이 읽는 이름이 되는데, 이 이름을 접근성 이름이라고 합니다.

### 검사
- 이름이 "더하기"인 버튼이 있는지 봅니다.
- 더하기 버튼을 두 번 누르면 "지금까지 2번"이 보이는지 봅니다.

### 힌트
- "버튼 안의 글자가 그대로 접근성 이름이 됩니다."

## 2. 초기화 버튼

### 요구
> 면접관: 횟수를 0으로 되돌리는 "초기화" 버튼을 더해 주세요.

### 검사
- 더하기를 누른 뒤 초기화를 누르면 "지금까지 0번"이 보이는지 봅니다.

### 힌트
- "state 를 바꾸는 함수에 0 을 넘기면 됩니다."
- "버튼 두 개가 같은 state 를 바꿉니다."

### 통과 뒤 질문
> 면접관: 초기화 버튼을 눌렀을 때 React 는 화면의 어느 부분을 다시 그리나요?
- [필수] `App` 함수가 다시 실행되고, 글자가 바뀐 요소만 DOM 에 반영됩니다.
- [보충] 다시 그리는 범위는 state 를 가진 컴포넌트와 그 아래 컴포넌트입니다.
