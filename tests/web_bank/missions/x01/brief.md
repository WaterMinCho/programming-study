# x01. 횟수 세기 버튼

이 미션은 버튼을 누르면 숫자가 오르는 작은 화면을 다룹니다. 받은 코드를 2분 동안 읽고, 이어지는 6분 동안 면접관이 하나씩 건네는 요구에 맞게 고칩니다.

## 어떤 앱인가요

제목 아래에 "지금까지 0번"이라는 글자와 버튼이 있습니다. 버튼을 누르면 숫자가 오릅니다.

## 어떻게 실행하나요

미션 폴더의 터미널에서 아래 명령을 실행하세요. 패키지는 스터디 저장소 맨 위 `node_modules` 폴더에 설치되어 있으니 미션 폴더에서 `npm install`을 하지 마세요.

```
npm run dev      # http://localhost:5173 에서 앱이 열립니다
npm test         # 저장소에 들어 있는 테스트를 실행합니다
```

## 파일은 어떻게 나뉘어 있나요

```
src/
  main.tsx       앱 시작 파일
  App.tsx        횟수 state 와 버튼을 가진 컴포넌트
  App.test.tsx   지금 통과하는 기존 테스트
```
