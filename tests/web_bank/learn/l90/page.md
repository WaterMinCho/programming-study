# state 가 바뀌면 무엇이 다시 그려지나요

## 일반 변수는 화면을 바꾸지 못합니다

컴포넌트 함수를 다시 실행해 화면에 보일 내용을 계산하는 일을 렌더링이라고 합니다. React 는 state 가 바뀔 때 렌더링을 다시 합니다. 일반 변수가 바뀌는 것은 React 가 알지 못해서 화면이 그대로 남습니다.

```tsx
const [count, setCount] = useState(0);
```

`setCount`를 부르면 React 가 이 컴포넌트를 다시 실행합니다.

## 같은 렌더의 값을 두 번 쓰면

`setCount(count + 1)`을 한 이벤트 안에서 두 번 부르면 두 호출 모두 이번 렌더의 `count`를 씁니다. 가장 최근 값으로 계산하려면 `setCount((n) => n + 1)`처럼 함수를 넘깁니다.

```figure
파일: assets/l90-1.png
캡션: 그림 1. 두 호출이 같은 값을 넣어 숫자가 1 만 오릅니다.
내용: 왼쪽에 count=0 상자, 오른쪽에 setCount(1) 두 번.
```

새로 계산한 결과를 앞 결과와 비교해 달라진 곳만 DOM 에 반영하는 단계를 커밋이라고 합니다.
