# 경험과 관심으로 직무 둘러보기

직무 추천은 현재 로드맵의 업무와 선택한 경험을 연결합니다. 관심 결과, 직접 해본 활동, 경력 분야, 전공의 순서로 연결 근거를 비교합니다. 같은 근거 수를 가진 직무는 함께 표시합니다. 학위 높이나 경력 연수로 적성·실력·취업 가능성을 계산하지 않습니다.

관심이나 활동을 고르지 않았어도 개발·데이터·머신러닝·임베디드·로봇·인프라 운영·소프트웨어 품질 분야의 경력이 있으면 관련 직무를 검토할 수 있습니다. 이때는 경력 분야로 연결한 후보라고 안내합니다. 실제 업무와 연결할 근거가 없는 넓은 경력명이나 학위만으로 직무를 정하지 않습니다. 활동과 관심을 추가하면 다시 비교할 수 있습니다. 선택지는 기존 항목을 사용합니다.

공식 업무 사례에서는 [삼성전자 DX 광고 데이터·플랫폼 개발][samsung]이 데이터 파이프라인과 서비스 운영을, [NAVER LABS 연구개발][naver]이 모델 연구와 로봇 적용을 함께 다룹니다. 2026-11-16에 확인한 업무 연결의 근거입니다. 해당 공고의 경력·학위 조건을 모든 직무의 자격으로 적용하지 않습니다. 직무별 기존 과제·출처는 `data/roles.json`에서 확인할 수 있습니다.

## 입력과 추천 결과 저장하기

입력은 현재 사용자의 기기 설정에 자동 저장합니다. `추천받기`를 누르면 추천 직무 목록도 저장합니다. 창을 닫고 다시 열면 입력과 추천 기준이 같은 경우 저장한 결과를 표시합니다. 추천 결과가 비어 있으면 입력 화면부터 엽니다. 입력이나 규칙·직무 자료가 바뀌면 이전 결과를 지우고 다시 추천받을 수 있습니다.

`저장한 입력 삭제`는 해당 사용자의 입력과 추천 결과를 함께 지웁니다. 직접 선택해 저장한 관심 직무는 따로 유지합니다. 학교·회사명, 경력 연수, 이력서 파일을 추가로 요구하지 않습니다. 입력과 추천 결과를 서버·학습 기록·답안 제출·문의·로그로 보내지 않습니다.

## 저장 형식과 검증하기

`gui/career_profile.py`는 기존 `career/profile/<user.casefold()>`의 v1 형식과 엄격한 키 검사를 유지합니다. 추천 결과는 `career/recommendation/<user.casefold()>`에 분리합니다. 결과에는 `input_fingerprint`, `rules_version`, `catalog_fingerprint`, `role_ids`만 저장합니다. fingerprint는 변경을 확인하는 SHA-256 값이며 입력을 암호화하거나 익명화하지 않습니다.

결과를 읽을 때 현재 입력과 명시적인 `career/recommend.py`의 `VERSION`, 직무·학습 연결·출처를 포함한 카탈로그 내용, 추천 직무 순서를 확인합니다. 손상되거나 기준과 다른 결과는 결과 키에서만 제거합니다. 입력이 손상됐으면 기존 복구 안내를 유지합니다. 규칙의 동작을 바꾸면 `VERSION`도 갱신합니다.

추천 화면은 `recommend(..., include_experience_only=True)`로 경력 단독 검토를 요청합니다. 기존 호출은 기본값을 유지해 관심·활동이 있는 경우에만 추천합니다. 저장되는 결과는 화면이 명시적으로 요청한 경력 검토 기준으로 검증합니다.

관련 검사는 기존 `tests/test_career_recommend.py`, `tests/test_gui_career_recommend.py`와 신규 `tests/test_career_recommend_results.py`, `tests/test_gui_career_recommend_results.py`입니다. 신규 검사는 임시 설정 파일로 사용자 격리, 입력·규칙·카탈로그 변경, 삭제, v1 읽기, 손상 결과, 동률과 경력 단독 검토, 결과 재열기를 확인합니다.
