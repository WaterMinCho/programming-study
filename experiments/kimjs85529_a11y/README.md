## 예측할 값과 모델을 고른 이유

기본 LSTM이 사용하는 과거 문제 ID, 개념, 정오답 및 현재 문제 정보에 **풀이 간격(Time Gap)**을 추가하여 다음 문제의 정답 확률을 예측하도록 모델을 구현했다.

시간 정보 유무에 따른 모델 성능을 비교할 수 있도록 기본 LSTM 구조를 유지하고, 최종 예측 계층에 시간 특성 두 개를 추가했다.

다만 현재까지 완료한 것은 **모델 구현 및 기능 검증**이며, 실제 학습과 공식 성능 비교는 수행하지 않았다.

시간 특성은 `[gap_log, gap_known]`으로 구성한다.

- `gap_log`: 확인된 풀이 간격(초)을 일 단위로 변환한 뒤 `log1p()` 적용
- `gap_known`: 시간 확인 여부를 나타내는 `0.0` 또는 `1.0`

예를 들어 시간 미확인은 `[0.0, 0.0]`, 실제 0초 간격은 `[0.0, 1.0]`로 구분한다.

### 기본 LSTM과의 관계

팀원 `michae18`의 `SmallLSTM`을 상속해 구현했다.

- 참고 경로: `experiments/michae18/model.py`
- 기본 모델 원본 전체 커밋 SHA: **PR 제출 전 확인 필요**
- 기존 Embedding, LSTM 및 `encode_history()`의 빈 이력·패딩 처리 로직은 변경하지 않았다.
- 기존 최종 Linear 계층 입력에 `gap_log`, `gap_known` 두 특성만 추가했다.
- `copy_baseline_weights()`로 기본 모델의 공통 가중치를 복사하고 새 시간 가중치를 0으로 설정하면 초기 Logit이 일치함을 검증했다.

### 풀이 간격 선택 정책

현재 문제에 연결된 **등록 개념 중 시간값이 확인된 개념의 최단 간격 하나**를 선택한다.

PAD(개념 ID 0)와 UNK(개념 ID 1)는 제외한다. UNK에는 여러 미등록 개념의 기록이 합쳐질 수 있어 특정 개념의 정확한 간격으로 판단하지 않는다.

Python 개별 전처리 결과는 두 개의 float 값이고, PyTorch 배치 전처리 결과는 `(batch_size, 2)` 형태의 `float32` 텐서이다.

PyTorch를 설치하지 않아도 개별 전처리 함수를 사용할 수 있다. `inspect_gaps.py`의 실행 예제는 PyTorch가 있을 때 기존 개별 결과와 새 배치 결과가 일치하는지도 검사한다.

## 입력 처리부터 학습·예측까지 내 코드 설명

1. **입력 준비:** 공통 `load()`와 `batch()`로 데이터를 읽는다. 실제 데이터 순전파에서는 이력을 32개까지 사용하고, 현재 문제의 정답(`targets`)은 모델 입력에 넣지 않는다.
2. **시간 전처리:** `inspect_gaps.py`에서 `query_concepts`, `query_gap_seconds`, `query_gap_known`을 사용해 등록 개념의 확인된 최단 풀이 간격을 `[gap_log, gap_known]`으로 변환한다.
3. **모델 입력:** `make_model_inputs()`가 문제, 개념, 정오답, 이력 길이, 현재 문제 정보와 시간 특성을 PyTorch 텐서로 만든다.
4. **모델 순전파:** `TimeGapLSTM`은 팀원의 `SmallLSTM`을 상속하여 기존 이력 인코더를 사용하고, 마지막 예측 계층에 시간 특성 두 개를 결합해 Logit을 반환한다. 확률이 필요한 경우 `sigmoid()`를 적용한다.
5. **기본 모델 비교:** `copy_baseline_weights()`로 공통 가중치를 복사하고 추가 시간 가중치를 0으로 설정해 초기 Logit이 일치하는지 검증한다.
6. **학습 가능성 확인:** 인공 입력·인공 정답에 대해 `BCEWithLogitsLoss()`, `backward()`, SGD 1회 갱신을 수행해 기울기와 가중치 변화를 확인한다. 실제 데이터 학습은 아니다.
7. **실제 데이터 순전파:** 실제 AI Train 953건을 최대 32건씩 나눠 순전파하며, 출력 크기와 유한성 및 전체 처리 건수를 확인한다.
8. **저장·복원:** 초기 모델의 `state_dict`를 임시 저장하고 같은 프로세스에서 새 모델 객체에 복원한 뒤 동일 입력 Logit을 비교한다.
9. **미실행:** 실제 학습, 학습된 모델 저장, 새 프로세스 복원, 예측 파일 생성, 공식 채점 및 성능 비교.
