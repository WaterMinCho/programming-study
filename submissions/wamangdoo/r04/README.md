## s15_p17 (고급 함수 · 출력 · 제곱 제너레이터 함수 · 4점)

## 제한 사항
- 0 ≤ n ≤ 1000

## 테스트 코드와 출력 예

```python

print(next(gen))
print(next(gen))
print(next(gen))
```

```

4
9
```

```python
for v in square_gen(5):
    print(v)
```

```
1
4
9
16
25
```

```python
gen = square_gen(3)
print(type(gen).__name__)
print(next(gen), next(gen), next(gen))
try:
    next(gen)
except StopIteration:
    print("stop")
```

```
generator
1 4 9
stop
```
