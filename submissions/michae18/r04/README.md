## s09_Q20 (클래스(1) · 객관식 · 2점)

다음 코드를 실행했을 때의 결과로 옳은 것은?

```python
class Fan:
    def __init__(self, speed):
        self.speed = speed

    def up(self):
        self.speed = self.speed + 1

    def show():
        print("speed:", self.speed)

f = Fan(1)
f.up()
print(f.speed)
f.show()
```

1. `def show():` 줄에서 오류가 발생해 아무것도 출력되지 않는다.
2. `2` 를 출력한 뒤 `f.show()` 에서 오류가 발생한다.
3. `2` 와 `speed: 2` 를 차례로 출력한다.
4. `1` 을 출력한 뒤 `f.show()` 에서 오류가 발생한다.

## s12_p05 (파일 처리 · 반환값 · 파일 속 숫자 합계 · 6점)

파일: `s12_p05.py`

한 줄에 정수가 하나씩 적힌 텍스트 파일의 경로 `path` 가 주어질 때, 파일에 적힌 모든 정수의 합을 정수로 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 파일은 현재 폴더에 이미 만들어져 있습니다.
- 각 줄에는 정수 하나만 있고, 음수가 있을 수 있습니다. 마지막 줄 끝에 줄바꿈이 없을 수도 있습니다.
- 빈 파일이면 `0` 을 반환합니다.
- 읽은 줄은 문자열이므로 `int()` 로 바꿔서 더합니다. `int()` 는 문자열 앞뒤의 공백·줄바꿈을 무시하고 변환합니다. (`int("10\n")` → `10`)
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 입출력 예

| 호출 | 파일 내용 | 반환값 |
|---|---|---|
| `solution("n.txt")` | `10`⏎`20`⏎`30`⏎ | `60` |
| `solution("n.txt")` | `5` | `5` |
| `solution("n.txt")` | `-3`⏎`3`⏎ | `0` |

(⏎ 는 줄바꿈을 뜻합니다)

## s16_p07 (알고리즘(1) · 출력 · 회전 큐 · 6점)

파일: `s16_p07.py`

숫자들을 덱(deque)에 넣은 뒤 왼쪽으로 `k` 만큼 회전시키고, 그 덱을 출력하는 프로그램을 작성하세요.

- 왼쪽으로 1 회전은 맨 앞 요소를 꺼내 맨 뒤에 붙이는 것입니다. 이것을 `k` 번 반복합니다.
- `collections` 모듈의 `deque` 를 사용하고, 마지막에 덱 객체를 그대로 `print` 합니다(출력은 `deque([...])` 형태가 됩니다).

입력

- 첫 줄에 숫자의 개수 `n` (1 ≤ n ≤ 20)
- 다음 `n` 줄에 정수가 한 줄에 하나씩
- 마지막 줄에 회전 횟수 `k` (0 ≤ k ≤ 100)

## 입출력 예

입력

```
5
1
2
3
4
5
2
```

출력

```
deque([3, 4, 5, 1, 2])
```

입력

```
3
7
8
9
4
```

출력

```
deque([8, 9, 7])
```

- 두 번째 예: 왼쪽으로 4 번 회전하면 `[8, 9, 7]` → `[9, 7, 8]` → `[7, 8, 9]` → `[8, 9, 7]` 입니다.
- 출력은 글자 하나까지 같아야 합니다(`deque(`, 쉼표 뒤 공백 포함).
