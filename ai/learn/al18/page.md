<!-- skel: S101 표준형 -->
```python

if image is None:
    raise ValueError("tray.jpg를 읽지 못했습니다.")
rows, cols = image.shape[:2]                                  # 8, 12
if top + h > rows or left + w > cols:
    raise ValueError("자를 영역이 사진 밖으로 나갑니다.")
preview = image.copy()
corner = (left + w - 1, top + h - 1)                          # (9, 6)
cv2.rectangle(preview, (left, top), corner, (0, 0, 255), -1)
ok = cv2.imwrite("tray_preview.png", preview)
if not ok:
    raise OSError("tray_preview.png를 저장하지 못했습니다.")
x = image[top:top + h, left:left + w]                         # (4, 8, 3)
x = cv2.cvtColor(x, cv2.COLOR_BGR2RGB)
x = cv2.resize(x, (4, 2))                                     # (2, 4, 3)
x = x.astype("float32") / 255.0
x = x.transpose(2, 0, 1)                                      # (3, 2, 4)
x = x[None, ...]                                              # (1, 3, 2, 4)
```

### 색 순서, 크기, 자료형, 축 순서를 모델 입력에 맞추기
<!-- facts: FA18-101 FA18-103 FA18-107 FA18-108 FA18-109 FA18-110 FA18-111 -->

3단계에서 자른 `x`는 (4, 8, 3)인 uint8 배열이고 색 순서는 BGR입니다. 영역 안의 픽셀은 모두 [0, 51, 255]라고 두고 남은 다섯 줄을 따라갑니다. 그림 3은 이 픽셀 하나와 배열의 모양이 줄마다 어떻게 바뀌는지 보입니다.

```figure
파일: assets/a18a-3.gif
캡션: 그림 3. 한 픽셀이 모델 입력이 되기까지. 빨강·초록·파랑 칸은 R·G·B 값, 회색 숫자는 그 줄 뒤의 shape입니다.
프레임:
1. 자른 x는 (4, 8, 3)이고 한 픽셀의 값은 BGR 순서의 [0, 51, 255]입니다. (2200ms)
2. cvtColor가 0번과 2번 채널을 맞바꿔 RGB 순서의 [255, 51, 0]이 됩니다. 모양은 (4, 8, 3)입니다. (2400ms)
3. resize(x, (4, 2))가 너비 4·높이 2로 줄여 (2, 4, 3)이 됩니다. 영역의 색이 하나라 픽셀 값은 [255, 51, 0]입니다. (2400ms)
4. astype("float32")로 자료형을 바꾼 뒤 255.0으로 나눠 [1.0, 0.2, 0.0]이 됩니다. 자료형은 float32입니다. (2400ms)
5. transpose(2, 0, 1)이 채널 축을 맨 앞으로 옮겨 (3, 2, 4)가 됩니다. 0번 채널에는 R 값 1.0만 8개 있습니다. (2400ms)
6. x[None, ...]이 맨 앞에 크기 1인 축을 붙여 (1, 3, 2, 4)가 됩니다. (2200ms)
```

`cv2.cvtColor(x, cv2.COLOR_BGR2RGB)`는 0번과 2번 채널을 맞바꿔 [255, 51, 0]을 만듭니다. `cv2.resize(x, (4, 2))`는 크기를 너비·높이 순서로 받아 너비 4·높이 2로 줄입니다. 결과 shape는 높이부터 읽어 (2, 4, 3)입니다.

`astype("float32")`는 자료형만 바꾸고 값 255는 255.0으로 남습니다. 그 뒤에 255.0으로 나눠야 [1.0, 0.2, 0.0]인 float32가 됩니다. `astype` 없이 `x / 255.0`만 쓰면 uint8 배열을 파이썬 실수로 나눈 결과가 float64로 나옵니다.

`transpose(2, 0, 1)`은 새 0번 축에 원래 2번 축인 채널을, 새 1번 축에 원래 0번 축인 높이를, 새 2번 축에 원래 1번 축인 너비를 놓습니다. 개론 2차시 셋째 단원 5단계에서 본 규칙입니다. (2, 4, 3)이 (3, 2, 4)가 되고 `x[0]`에는 R 값만 모입니다. `x.reshape(3, 2, 4)`도 모양은 같습니다. 하지만 값을 앞에서부터 다시 채우므로 `x[0]`에 한 픽셀의 R, G, B 값이 섞여 들어갑니다.

마지막 줄 `x[None, ...]`은 맨 앞에 크기 1인 배치 축을 붙입니다. 사진 한 장을 담은 배치라 (1, 3, 2, 4)가 되어 모델 조건과 맞습니다.

자르기 줄과 입력을 만드는 다섯 줄은 순서를 바꾸면 오류가 나거나 다른 배열이 나옵니다. 배치 축을 먼저 붙이면 축이 넷이 되어 `transpose(2, 0, 1)`이 ValueError를 냅니다. `resize` 줄을 자르기 줄 앞으로 옮겨 사진 전체를 `cv2.resize(image, (4, 2))`로 줄이면 사진이 높이 2·너비 4가 됩니다. 이 사진에는 0번과 1번 행만 있어 `[3:7, 2:10]`으로 자르면 (0, 2, 3)인 빈 배열이 나옵니다.

모델이 받는 입력이 달라지면 표준형에서 빼야 하는 줄이 생깁니다. 예를 들어 BGR 순서의 (1, 2, 4, 3) 입력을 받는 모델이면 `cvtColor` 줄과 `transpose` 줄을 뺍니다. `cv2.imread`가 이미 BGR로 읽었고, 줄인 (2, 4, 3)에 배치 축만 붙이면 (1, 2, 4, 3)이 됩니다.

### 배치에서 설명할 점수 고르기
<!-- facts: FA18-1001 FA18-1002 FA18-1004 -->

이 예제는 PyTorch에서 CPU로 실행합니다. 값이 두 개인 합성 샘플 하나와 두 클래스의 점수를 만드는 함수만 씁니다. 강의와 과제의 이미지 입력과 모델 대신 `sample`과 `score_batch`를 사용합니다.

`sample`의 모양은 (2,)입니다. `unsqueeze`로 맨 앞에 축을 하나 더하면 모양은 (1, 2)이고, 한 행이 한 샘플입니다. 강의에서 이미지 한 장의 모양을 (채널, 높이, 너비)에서 (1, 채널, 높이, 너비)로 바꾸는 것과 같은 자리입니다. 아래 함수의 `unbind`는 특징 축을 따라 첫째 값과 둘째 값을 따로 꺼냅니다. `stack`으로 점수 둘을 열로 모으므로 `scores`의 첫 축은 샘플, 둘째 축은 클래스입니다.

<!-- skel: S110 표준형 -->
```python
import torch
def score_batch(batch):
    left, right = batch.unbind(dim=1)
    class0 = left + right
    class1 = left.square() - right
    return torch.stack((class0, class1), dim=1)
sample = torch.tensor([2., 3.])
batch = sample.unsqueeze(0).requires_grad_()
scores = score_batch(batch)
target = 1
score = scores[0, target]
(signed,) = torch.autograd.grad(score, batch)
baseline = torch.zeros_like(batch)
middle = ((batch + baseline) / 2).detach().requires_grad_()
mid_score = score_batch(middle)[0, target]
(path_grad,) = torch.autograd.grad(mid_score, middle)
ig = (batch.detach() - baseline) * path_grad
print(scores.detach().tolist())
print(signed.tolist())
print(signed.abs().tolist())
print(ig.tolist())
```

출력 첫 줄은 `[[5.0, 1.0]]`입니다. `argmax`는 가장 큰 점수의 위치인 0을 반환합니다. 여기서 설명할 클래스는 1이라 `scores[0, target]`으로 그 클래스의 점수 1을 고릅니다. 강의와 과제의 `sample_targets[0]`은 정답 라벨입니다. 오답 분석처럼 설명하려는 클래스가 달라지면 그 클래스의 점수를 선택합니다.

`requires_grad_`는 입력의 기울기 기록을 켭니다. `torch.autograd.grad`는 선택한 점수가 입력의 각 값에 따라 얼마나 달라지는지 계산합니다. <u>기울기를 구하려면 점수를 만드는 순전파부터 기록이 필요하므로 이 계산을 `torch.no_grad()` 안에 넣지 않습니다.</u>
