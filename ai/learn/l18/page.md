### 한 에폭을 학습하는 코드 열다섯 줄
<!-- facts: F18-03 F18-04 F18-10 -->

1단계의 배치 셋을 차례로 꺼내 학습하는 코드는 아래 열다섯 줄입니다. `model`, `criterion`, `optimizer`, `device`, `loader`는 루프 앞에서 만들어 두었고, `model`은 이미 `device`에 있습니다.

<!-- skel: S1 표준형 -->
```python
model.train()
loss_sum, correct, total = 0.0, 0, 0
for x, y in loader:                               # 배치를 하나씩 꺼냄
    x = x.to(device)                              # 옮긴 텐서를 받음
    y = y.to(device)
    optimizer.zero_grad()
    out = model(x)
    loss = criterion(out, y)                      # 배치 평균 손실
    loss.backward()
    optimizer.step()
    loss_sum += loss.item() * x.size(0)           # 이번 배치 손실의 합
    total += y.size(0)                            # 이번 배치의 데이터 수
    correct += (out.argmax(1) == y).sum().item()  # 이번 배치에서 맞힌 수
epoch_loss = loss_sum / total                     # 데이터 하나당 평균 손실
epoch_acc = correct / total                       # 정확도
```

### 학습 다섯 줄과 zero_grad를 둘 수 있는 자리
<!-- facts: F18-01 F18-02 F18-15 F18-16 -->

2단계 코드에서 `optimizer.zero_grad()`부터 `optimizer.step()`까지 다섯 줄은 1차시 둘째 단원 3단계의 학습 다섯 줄과 같습니다. 배치를 하나 꺼낼 때마다 이 다섯 줄로 파라미터를 한 번 갱신하므로, 1단계의 배치 셋이면 한 에폭에 3번 갱신합니다.

순전파, 손실, `backward()`, `step()` 네 줄은 앞 줄이 만든 값을 다음 줄이 쓰므로 순서를 바꿀 수 없습니다. 손실은 `out`으로 계산하고, `backward()`는 `loss`에서 기울기를 구하고, `step()`은 `backward()`가 `.grad`에 담은 기울기로 파라미터를 갱신합니다.

4차시 셋째 단원 6단계에서 본 것처럼 `backward()`는 새 기울기를 `.grad`에 있던 값에 더합니다. 그래서 `zero_grad()`는 이번 배치의 `backward()`가 기울기를 더하기 전에 지난 배치의 기울기를 지워야 합니다. `backward()` 앞이나 `step()` 뒤에 두면 이 조건을 지킵니다. `backward()`와 `step()` 사이에 두면 `step()`이 쓸 기울기까지 지우므로 둘 수 없습니다.

### 데이터 하나당 평균 손실과 정확도 세기
<!-- facts: F18-05 F18-06 F18-07 F18-08 F18-09 F18-10 F18-11 F18-14 -->

3단계의 `loss = criterion(out, y)`에서 `criterion`이 돌려주는 손실은 배치 평균입니다. 6차시 첫째 단원 3단계에서 본 것처럼 손실 함수의 `reduction` 기본값이 `'mean'`이라서, `criterion`은 데이터마다 구한 손실을 더해 그 배치의 데이터 수로 나눈 숫자 하나를 돌려줍니다. 6차시 다섯째 단원처럼 `CrossEntropyLoss`에 `weight=`를 주면 데이터 수 대신 데이터마다 정답 클래스의 가중치를 더한 값으로 나눕니다. 이 단원에서는 `weight=`를 주지 않은 손실만 다룹니다.

1단계의 첫 배치는 데이터 4개의 평균 손실이 0.5이므로 네 손실을 더하면 0.5 × 4 = 2.0입니다. 배치 평균에 그 배치의 데이터 수를 곱하면 그 배치 손실의 합이 됩니다. `loss_sum += loss.item() * x.size(0)`이 배치마다 이 합을 `loss_sum`에 더합니다. 5차시 일곱째 단원 3단계에서 본 것처럼 `x.size(0)`은 이번 배치의 데이터 수입니다. `loss.item()`은 3차시 여덟째 단원 3단계에서 본 것처럼 손실 값을 계산 기록이 없는 파이썬 수로 꺼냅니다. 루프가 끝나면 `epoch_loss = loss_sum / total`이 손실의 합을 데이터 수로 나눠 데이터 하나당 평균 손실을 냅니다.

맞힌 수를 세는 줄은 5차시 일곱째 단원 4단계의 줄과 같습니다. `out.argmax(1)`이 행마다 가장 큰 점수의 열 번호를 고르고, `== y`가 예측이 정답과 같은 데이터를 True로 만듭니다. `.sum()`이 True의 개수를 세고, `.item()`이 그 수를 파이썬 정수로 꺼냅니다. `epoch_acc = correct / total`은 맞힌 수를 데이터 수로 나눈 정확도입니다.
