<!-- facts: FA04-a -->

<mark>TM_CCOEFF_NORMED</mark>는 큰 점수, TM_SQDIFF는 작은 점수의 위치를 택합니다. 정규화 상관 점수는 음수도 가질 수 있습니다. 점수 0.8을 정답 확률 80%로 해석하지 않습니다. 물체의 크기나 회전이 달라지면 템플릿을 그대로 비교하기 어려울 수 있습니다.

### 입력부터 반환값까지 코드로 연결하기
<!-- facts: FA04-c -->

```python
roi = first_frame[y:y+h, x:x+w]
if roi.size == 0:
    raise ValueError("대상 영역이 비었습니다.")
h, w = roi.shape[:2]
roi_hsv = cv2.cvtColor(roi, cv2.COLOR_BGR2HSV)
hist = cv2.calcHist([roi_hsv], [0], None, [180], [0, 180])
cv2.normalize(hist, hist, 0, 255, cv2.NORM_MINMAX)
# 이어지는 프레임마다 실행함
hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
score = cv2.calcBackProject([hsv], [0], hist, [0, 180], 1)
criteria = (cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 10, 1)
iterations, window = cv2.meanShift(score, (x, y, w, h), criteria)
```

first_frame은 첫 프레임, frame은 뒤이어 읽은 현재 프레임입니다. x·y는 영상 안의 왼쪽 위 좌표이고 w·h는 요청한 영역 크기입니다. 실제로 잘린 높이·너비로 초기 창 크기를 맞춥니다. calcHist의 첫 입력에는 색상 영상 roi_hsv를 넣습니다. 아직 계산하지 않은 hist를 입력 영상으로 쓰지 않습니다.
