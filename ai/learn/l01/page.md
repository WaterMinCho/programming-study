### 예측을 내고 손실을 잽니다
<!-- facts: F01-01 F01-02 F01-03 -->

입력 x에 숫자 w를 곱해 답을 내는 모델로 정답 5 를 맞혀 봅니다. 지금은 x = 2, w = 2 이므로 모델의 답은 2 × 2 = 4 입니다. 이렇게 모델이 입력을 받아 답을 계산하는 과정을 <mark>순전파</mark>(forward)라고 부릅니다. 순전파로 나온 답 4 는 모델의 예측입니다.

예측 4 는 정답 5 보다 1 작습니다. 예측이 정답과 얼마나 다른지를 숫자 하나로 나타낸 값을 <mark>손실</mark>(loss)이라고 부릅니다. 이 단원은 차이를 제곱한 (예측 − 정답)² 을 손실로 씁니다.

```figure
파일: assets/1a-1.png
캡션: 그림 1. 입력 2 에 w = 2 를 곱한 예측 4 와 정답 5, 그리고 둘의 차이로 잰 손실 1. 파랑은 순전파와 예측, 빨강은 손실 계산입니다.
내용: 왼쪽에 입력 2, w 곱하기, 예측 4 상자 줄. 오른쪽에 0~6 수직선 위 예측 4(파랑)와 정답 5(검정), 차이 1 과 손실 (4 − 5)² = 1 표시
```

예측과 정답의 차이가 1 이면 제곱한 손실도 1 입니다. 차이와 손실이 우연히 같아진 경우입니다. 차이가 0.2 라면 제곱한 손실은 0.04 입니다. 손실이 작을수록 예측이 정답에 가깝습니다.

학습 손실은 학습에 쓴 자료에서 계산합니다. 손실이 작으면 그 자료에서 예측이 정답에 가까워졌는지 알 수 있습니다. 처음 보는 자료에서도 잘 맞히는지는 별도로 확인합니다. 자료를 나누고 평가하는 방법은 4차시에서 배웁니다.

### 역전파로 기울기를 구하고 파라미터를 갱신합니다
<!-- facts: F01-01 F01-04 F01-05 -->

앞 단계의 손실 1 을 줄이려면 w를 어느 쪽으로 바꿔야 할지 알아야 합니다. 학습하면서 바꿔 가는 w 같은 값을 <mark>파라미터</mark>(parameter)라고 부릅니다. 손실에서 입력 쪽으로 계산을 거슬러 가며 파라미터를 조금 바꿀 때 손실이 얼마나 바뀌는지 구하는 과정을 역전파(backward)라고 부릅니다. 이렇게 구한 값을 기울기(gradient)라고 부릅니다. 이 예에서 w의 기울기는 −4 입니다. 기울기가 음수이면 w를 키울 때 손실이 줄어듭니다. 양수이면 w를 줄일 때 손실이 줄어듭니다.

### PyTorch가 맡는 일
<!-- facts: F01-08 -->

앞 단원에서는 기울기를 구하고 w를 갱신하는 계산을 손으로 따라갔습니다. 파라미터가 수백만 개인 모델에서는 같은 계산을 손으로 하기 어렵습니다. PyTorch처럼 딥러닝에 필요한 계산 코드를 미리 만들어 둔 도구를 딥러닝 프레임워크라고 부릅니다.

- 순전파 계산을 코드로 쓰면 PyTorch가 그 과정을 기록합니다. `loss.backward()`는 이 기록을 따라 기울기를 계산합니다. 이 기능을 <mark>자동 미분</mark>(Autograd)이라고 부릅니다.
- 예측과 정답을 비교하는 손실 함수와, 기울기를 읽어 파라미터를 갱신하는 도구를 가져다 쓸 수 있습니다. 갱신을 맡는 도구를 <mark>옵티마이저</mark>(optimizer)라고 부릅니다.
- PyTorch가 다루는 숫자 배열을 <mark>텐서</mark>(tensor)라고 부릅니다. 여러 입력과 예측을 텐서에 담아 numpy와 비슷한 문법으로 계산합니다. 텐서는 3차시에서 자세히 배웁니다.

### 학습 기본 패턴
<!-- facts: F01-09 F01-01 F01-11 -->

앞 단원에서 따라간 순전파, 손실 계산, 역전파, 갱신을 PyTorch 코드로 옮깁니다. 이 계산을 반복하기 전에 지난 기울기를 지우는 줄을 먼저 둡니다.

```python
optimizer.zero_grad()        # 1 기울기 초기화
output = model(input)        # 2 순전파
loss = fn(output, target)    # 3 손실 계산
loss.backward()              # 4 역전파
optimizer.step()             # 5 파라미터 갱신
```

- `optimizer.zero_grad()`는 지난 기울기를 담은 버퍼를 비웁니다. 버퍼는 기울기를 보관하는 자리이며 설정에 따라 `None`이나 0으로 비웁니다. <u>버퍼를 비워도 w와 b의 값은 유지합니다.</u>
- `model(input)`은 현재 w와 b로 예측을 계산해 `output`에 담습니다. 그림 6의 시작점에서는 `[0×0+0, 0×1+0]=[0,0]`입니다.
- `fn(output, target)`은 예측과 정답을 비교한 손실을 `loss`에 담습니다. 이 예의 fn은 제곱 오차의 평균이므로 `((0−1)²+(0−3)²)÷2=5`입니다.
- `loss.backward()`는 `dL/dw=−3`, `dL/db=−4`를 계산해 기울기 버퍼에 담습니다. w와 b, 이미 계산한 `output`과 `loss`는 바뀌지 않습니다.
- `optimizer.step()`은 이번 예의 학습률 0.2와 기울기로 파라미터를 갱신합니다. `w=0−0.2×(−3)=0.6`, `b=0−0.2×(−4)=0.8`입니다. <u>이 줄 뒤에도 저장된 예측과 손실은 이전 계산값을 유지합니다.</u>

### backward는 기울기를 구하고 step은 파라미터를 바꿉니다
<!-- facts: F01-11 F01-10 F01-09 -->

그림 2 에서 w의 값이 바뀐 줄은 5번 줄이었습니다. `loss.backward()`는 기울기를 계산해 담습니다. 파라미터 값을 바꾸는 줄은 `optimizer.step()`입니다.

| 줄 | 하는 일 | w | w의 기울기 |
|---|---|---|---|
| `optimizer.zero_grad()` | 지난 기울기를 지웁니다 | 2 | 빈 칸 |
| `loss.backward()` | 기울기를 계산해 담습니다 | 2 | −4 |
| `optimizer.step()` | 기울기로 w를 갱신합니다 | 2 → 2.4 | −4 |
| `with torch.no_grad():` | 안쪽 계산의 기울기 기록을 끕니다 | 바꾸지 않습니다 | 기록하지 않습니다 |

### y = x는 같은 배열에 이름을 하나 더 붙입니다
<!-- facts: F01-12 F01-13 F01-15 F01-14 F01-60 -->

### copy()는 새 배열을 만듭니다
<!-- facts: F01-14 F01-12 F01-53 -->

앞 단계의 `y = x`에서는 `x[0] = 100` 뒤 y도 [100, 7, 9]가 되었습니다. `y = x.copy()`는 x의 값을 새 메모리에 복사한 뒤 y가 그 배열을 가리키게 합니다. 이때는 `x[0] = 100`을 해도 y가 [5, 7, 9]로 남습니다.

### 텐서와 numpy 배열도 메모리를 함께 씁니다
<!-- facts: F01-16 F01-17 F01-19 -->

앞 단계에서는 `copy()`로 새 배열을 만들어 메모리를 따로 썼습니다. 텐서에서 numpy 배열을 꺼낼 때도 메모리를 함께 쓸지 따로 쓸지 구분합니다. 1 다섯 개로 만든 텐서 `x1 = torch.ones(5)`에서 `x1.data.numpy()`로 배열을 꺼내 봅니다.


### 함수를 이어 붙인 합성 함수
<!-- facts: F01-20 F01-21 -->

입력 3 을 제곱하는 f1, 2를 곱하는 f2, 2를 더하는 f3에 차례로 넣어 봅니다. 한 함수의 출력을 다음 함수의 입력으로 넣어 이은 함수를 합성 함수라고 부릅니다.

```python

    return x ** 2        # 제곱합니다

def f2(x):
    return x * 2         # 2를 곱합니다

def f3(x):
    return x + 2         # 2를 더합니다

y = f3(f2(f1(3)))        # 3 → 9 → 18 → 20
```

앞 단계의 f(x) = 2x² + 2 에서 x를 3 에서 3.001 로 0.001 키우면 f는 20 에서 20.012002 로 약 0.012 커집니다. 0.012 는 x를 바꾼 양 0.001 의 12배입니다. 이렇게 x를 조금 바꿀 때 f(x)가 바뀐 양이 x를 바꾼 양의 몇 배인지를 그 점의 미분값이라고 부릅니다. 그래프의 한 점에 닿는 직선을 접선이라고 부릅니다. 직선의 기울기는 가로로 1 갈 때 세로로 바뀌는 양입니다. 미분값은 그 점에서 그은 접선의 기울기와 같습니다. f(x) = 2x² + 2 를 미분하면 4x 이므로 x = 3 에서 미분값은 12 입니다. x² 을 미분하면 2x 이고 앞에 곱한 2 는 그대로 남으므로 2x² 을 미분한 결과는 4x 입니다. 더한 2 는 x와 상관없는 수라서 미분하면 0 입니다.

### fdiff는 함수를 받아 함수를 돌려줍니다
<!-- facts: F01-25 F01-58 -->

앞 단원에서는 두 점의 함수 값으로 중앙 차분을 계산했습니다. 같은 계산을 fdiff라는 함수로 옮깁니다. fdiff는 함수 f를 받아 중앙 차분으로 f의 기울기를 어림하는 함수 diff를 만들어 돌려줍니다. 파이썬에서는 함수도 다른 함수에 넘기고 돌려받을 수 있습니다. 함수를 인자로 받거나 함수를 돌려주는 함수를 <mark>고차 함수</mark>라고 부릅니다.

```python
def fdiff(f):
    def diff(x):
        h = 1e-6                                   # 0.000001
        return (f(x + h) - f(x - h)) / (2 * h)    # 중앙 차분
    return diff                                    # 계산 결과가 아니라 함수 diff를 돌려줌

f = lambda x: 2 * x**2 + 2
f_prime = fdiff(f)       # f_prime은 함수
f_prime(3.0)             # 12.000000001677336
```

- `def diff(x):`는 fdiff 안에서 기울기를 어림할 함수를 정의합니다.
- `1e-6`은 0.000001 을 파이썬에서 줄여 쓴 꼴입니다.
- `return diff`는 diff의 계산 결과 대신 함수 자체를 돌려줍니다.
- `lambda x: 식`은 짧은 함수를 만드는 문법입니다. 위의 f는 x를 받아 2x² + 2 를 돌려줍니다.
- `f_prime = fdiff(f)`는 돌려받은 함수를 f_prime이라는 이름으로 가리키게 합니다.
- `f_prime(3.0)`은 그 함수에 3.0 을 넣어 기울기를 계산합니다.

```figure
파일: assets/1e-1.png

내용: 왼쪽 함수 f 상자가 보라 fdiff 상자로 들어가 초록 함수 diff 상자가 나옴. diff 상자에 3.0 이 들어가 12.000000001677336 이 나옴
```

### __init__과 self로 인스턴스의 좌표를 다룹니다
<!-- facts: F01-30 F01-31 -->

앞 단계에서 만든 Point 인스턴스에 좌표를 담고 좌표를 바꾸는 메서드와 읽는 메서드를 정의합니다.

```python
class Point:
    def __init__(self, x, y):    # 인스턴스를 만들 때 불려 속성을 채움
        self.x = x
        self.y = y

    def move(self, dx, dy):      # 좌표를 dx, dy만큼 옮김
        self.x += dx
        self.y += dy

    def coord(self):             # 지금 좌표를 (x, y)로 돌려줌
        return (self.x, self.y)

p = Point(2, 3)
p.move(1, -1)
print(p.coord())                 # (3, 2)
```

`Point(2, 3)`을 실행하면 파이썬이 `__init__`을 불러 속성을 처음 값으로 채웁니다. 이 메서드를 생성자라고 부릅니다.
메서드의 첫 인자 `self`는 그 메서드를 부른 인스턴스를 가리킵니다. `p.move(1, -1)`에서는 self가 p입니다.
- `self.x += dx`는 p의 x에 dx를 더해 2 에서 3 으로 바꿉니다. 같은 방식으로 y에는 dy를 더합니다.
- `p.coord()`는 바뀐 좌표 (3, 2)를 돌려줍니다. 이렇게 괄호로 묶은 값 묶음을 튜플이라고 부릅니다. 튜플은 이 차시 마지막 단원에서 다시 봅니다.

### 상속과 super()
<!-- facts: F01-32 F01-33 -->

앞 단계의 Point에 반지름 r을 더해 원을 나타내는 Circle1 클래스를 만듭니다. 기존 클래스의 속성과 메서드를 물려받아 새 클래스를 만드는 것을 상속이라고 부릅니다. Point처럼 물려주는 클래스는 부모, Circle1처럼 물려받는 클래스는 자식이라고 부릅니다.

```python
class Circle1(Point):                # Point를 물려받음
    def __init__(self, x, y, r):
        super().__init__(x, y)       # 부모의 __init__으로 x, y를 채움
        self.r = r                   # 원만 가진 속성
```

이 예제의 `super().__init__(x, y)`는 부모 Point의 `__init__`을 불러 x, y 속성을 만듭니다. `super()`는 상속 관계의 메서드 탐색 순서를 따라 다음 메서드를 찾을 때 씁니다.

그림 3 은 앞의 Point와 달리 move, coord 대신 점을 찍는 메서드 draw를 둔 예입니다. 자식 클래스가 draw를 정의하는 방법에 따라 그려지는 모양이 달라집니다. 자식이 부모와 같은 이름의 메서드를 다시 정의하는 것을 재정의(overriding)라고 부릅니다.

### __call__과 model(x)
<!-- facts: F01-34 F01-35 F01-36 F01-37 F01-54 -->


PyTorch 모델은 모두 `nn.Module`을 상속한 클래스이고 `nn.Module`이 미리 정의해 둔 `__call__`이 우리가 쓴 `forward`를 부릅니다. 그래서 모델은 `model.forward(x)` 대신 `model(x)`로 부릅니다. PyTorch 문서도 forward를 직접 부르지 말라고 합니다. `model(x)`로 불러야 forward 앞뒤에 등록해 둔 동작까지 실행되기 때문입니다. 이 동작을 훅(hook)이라고 부릅니다.

이 상속 구조를 모델 클래스로 옮기면 다음 코드가 됩니다.

```python
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()     # nn.Module의 준비를 먼저 함
        # 쓸 층을 여기서 만듦
    def forward(self, x):
        # 순전파 계산을 여기에 적음
        return x
```

`super().__init__()`은 `nn.Module`의 준비를 먼저 합니다. 순전파 계산은 `forward` 메서드에 씁니다. 학습은 「PyTorch의 학습 기본 패턴」에서 예측·손실 계산·기울기 계산·파라미터 갱신을 반복합니다.

### 슬라이스와 뒤집기

리스트 [1, 2, 3, 4, 5]에서 일부 원소만 꺼내려면 먼저 자리 번호를 알아야 합니다. 원소의 자리 번호를 <mark>인덱스</mark>라고 부릅니다. 첫 원소 1 의 인덱스는 0 이고 마지막 원소 5 의 인덱스는 4 입니다. 음수 인덱스는 뒤에서부터 세어 -1 이 맨 뒤 원소, -2 가 뒤에서 둘째 원소입니다.

일부 구간을 잘라 새 리스트로 꺼내는 문법 `l[시작:끝]`을 <mark>슬라이스</mark>라고 부릅니다. 시작 인덱스의 원소는 들어가고 끝 인덱스의 원소는 빠집니다. 시작을 비우면 처음부터, 끝을 비우면 맨 뒤 원소까지 자릅니다.

```figure
파일: assets/1g-3.png
캡션: 그림 3. [1, 2, 3, 4, 5]의 인덱스와 슬라이스 [1:-1]. 초록은 [1:-1]이 고른 칸과 그 결과입니다.
내용: 다섯 칸 위에 인덱스 0~4, 아래에 −5~−1. [1:-1]이 칸 2, 3, 4 를 고르고 끝 인덱스 −1 칸은 빠짐. 오른쪽에 [:-1], [::-1] 결과
```

```python
list1 = [1, 2, 3, 4, 5]
list1[:-1]      # [1, 2, 3, 4]     맨 뒤 하나를 뺌
list1[1:-1]     # [2, 3, 4]
list1[::2]      # [1, 3, 5]        두 칸씩 건너뜀
list1[::-1]     # [5, 4, 3, 2, 1]  순서를 뒤집은 새 리스트
```

`l[시작:끝:간격]`처럼 셋째 수를 쓰면 그 간격만큼 건너뛰며 꺼냅니다. `list1[::2]`는 인덱스 0, 2, 4 의 원소인 [1, 3, 5]를 꺼냅니다. 간격이 -1 인 `list1[::-1]`은 맨 뒤 원소부터 하나씩 거꾸로 꺼냅니다.

`[::-1]`은 정렬하지 않고 순서만 뒤집습니다. `[3, 1, 2][::-1]`은 `[2, 1, 3]`입니다. 큰 수부터 정렬하려면 `sorted(l, reverse=True)`를 씁니다. 리스트를 뒤집는 코드에는 `reverse()`와 `reversed()`도 있습니다. 각 코드가 원본을 바꾸는지, 무엇을 돌려주는지를 아래 표에 적었습니다.

### 튜플, 딕셔너리, 반복문
<!-- facts: F01-42 F01-43 F01-44 F01-45 F01-62 F01-63 -->

앞 단원의 `p.coord()`가 돌려준 (3, 2)가 튜플입니다. 튜플은 괄호로 묶거나 `t3 = 1, 2, 3, 4`처럼 쉼표로만 이어서도 만듭니다. 한 번 만든 뒤에는 원소를 바꿀 수 없습니다. 튜플의 원소에 대입하면 TypeError가 나고 바꾸려면 `list(t)`로 리스트로 바꿔 고친 뒤 `tuple()`로 되돌립니다. 키와 값을 짝지어 담는 `{키: 값}` 묶음을 딕셔너리(dict)라고 부릅니다. `d[키]`로 값을 읽습니다. 없는 키에 대입하면 짝이 더해지고 있는 키에 대입하면 값이 바뀝니다.

```figure
파일: assets/1g-4.png
캡션: 그림 4. 바꿀 수 없는 튜플, 키와 값을 짝지은 딕셔너리, items()가 내주는 짝. 빨강은 오류, 초록은 items()가 내주는 짝입니다.
내용: 왼쪽 튜플 (1, 2, 3, 4)와 t[1] = 10 의 TypeError(빨강). 가운데 딕셔너리 {'수학': 90, '영어': 85}의 키→값 화살표. 오른쪽 items()가 내주는 초록 ('수학', 90), ('영어', 85)
```

```python
scores = {'수학': 90, '영어': 85}
for k, v in scores.items():     # (키, 값) 짝을 하나씩 꺼냄
    print(k, ':', v)            # 수학 : 90, 다음 줄에 영어 : 85

for i in range(1, 4):           # 1, 2, 3 (끝 값 4 는 빠짐)
    print(i)

def square(x):
    return x * x, x * x * x     # 튜플 하나를 돌려줌

a, b = square(3)                # a = 9, b = 27
```

- `scores.items()`는 (키, 값) 짝을 하나씩 내줍니다. `for k, v in scores.items():`는 그 짝을 k와 v로 나눠 받습니다.
- `print(k, ':', v)`는 값 사이에 공백을 넣어 `수학 : 90`처럼 찍습니다.
- `range(1, 4)`는 끝 값 4 를 빼고 1, 2, 3 을 차례로 내줍니다. 반복문은 이 수들을 하나씩 출력합니다.
- `square(3)`은 계산한 값을 튜플 하나로 돌려줍니다. 받는 쪽은 `a, b = square(3)`처럼 나눠 받습니다. 함수에서 `return a, b`로 쓰는 경우도 튜플 하나를 돌려줍니다.

### 코드 읽기 f-string으로 출력 모양을 정합니다
<!-- facts: F01-46 F01-67 F01-65 -->

학습 코드에서 손실을 `{avg_train_loss:.5f}`로 출력할 때 소수점 아래 자릿수는 `.5f`가 정합니다. 문자열 앞에 f를 붙이고 중괄호 안에 변수를 넣어 값을 끼워 넣는 문자열을 f-string이라고 부릅니다. 중괄호 안 콜론 뒤의 서식으로 자릿수와 표기를 정합니다.

```python
a1 = 1 / 7          # 0.14285714285714285
a2 = 123
f'{a1:.4f}'         # '0.1429'      소수 넷째 자리까지 반올림한 고정소수점
f'{a2:04}'          # '0123'        0 으로 빈자리를 채운 네 자리
f'{a1:.04e}'        # '1.4286e-01'  지수 표기, 1.4286 × 10의 −1제곱
f'{a2:#x}'          # '0x7b'        0x를 붙인 16진수
f'{0.9:.1%}'        # '90.0%'       100 을 곱하고 %를 붙임
```

`.4f`의 f는 고정소수점 표기, `.4`는 소수점 아래 자릿수입니다. `04`처럼 너비 앞에 0 을 붙이면 빈자리를 0 으로 채웁니다. `.04e`는 소수점 아래 네 자리의 지수 표기이고 `#x`는 0x를 붙인 16진수입니다. 서식은 화면에 보이는 글자만 바꾸고 변수 a1의 값은 바꾸지 않습니다.

```figure
파일: assets/1g-5.png
캡션: 그림 5. f'{a1:.4f}'의 각 부분과 서식별 결과. 보라는 서식, 초록은 서식을 적용한 결과입니다.
내용: f'{a1:.4f}'의 a1(검정), 콜론(회색), 서식 .4 와 f(보라)에 이름표. 아래 표 .4f → 0.1429, 04 → 0123, .04e → 1.4286e-01, #x → 0x7b, .1% → 90.0%, 결과는 초록
```

> **[보충 설명]** `f'{2.675:.2f}'`는 2.68 이 아니라 2.67 을 찍습니다. 2.675 가 이진수로 정확히 저장되지 않고 2.67499… 에 가까운 값으로 들어 있기 때문입니다. 반올림할 자리 바로 다음 숫자가 5 인 값은 예상과 다르게 찍힐 수 있습니다.
