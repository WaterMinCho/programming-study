### 예측을 내고 손실을 잽니다
<!-- facts: F01-01 F01-02 F01-03 -->

가장 작은 모델로 시작합니다. 입력 x에 숫자 w를 곱해 답을 내는 모델이고, 지금 x = 2, w = 2 라서 모델이 내는 답은 2 × 2 = 4 입니다. 모델이 입력을 받아 답을 계산해 내는 과정을 순전파(forward)라고 부릅니다. 순전파로 나온 답은 예측이라고 부릅니다. 이 데이터의 정답은 5 입니다.

예측 4 는 정답 5 보다 1 작습니다. 예측이 정답과 얼마나 다른지를 숫자 하나로 나타낸 값을 손실(loss)이라고 부릅니다(1차시 슬라이드 4쪽). 이 단원은 차이를 제곱한 (예측 − 정답)² 을 손실로 씁니다.

```figure
파일: assets/1a-1.png
캡션: 그림 1. 입력 2 에 w = 2 를 곱한 예측 4 와 정답 5, 그리고 둘의 차이로 잰 손실 1
내용: 왼쪽에 입력 2, w 곱하기, 예측 4 상자 줄. 오른쪽에 0~6 수직선 위 예측 4(파랑)와 정답 5(검정), 차이 1 과 손실 (4 − 5)² = 1 표시
```

차이가 1 이면 제곱해도 1 이라서, 손실이 슬라이드 4쪽의 예와 우연히 같은 1 로 나왔습니다. 차이가 0.2 라면 제곱한 손실은 0.04 입니다. 손실이 작을수록 예측이 정답에 가깝습니다.

### 역전파로 기울기를 구하고 파라미터를 갱신합니다
<!-- facts: F01-01 F01-04 F01-05 -->

손실 1 을 줄이려면 w를 바꿔야 합니다. 학습하면서 바꿔 가는 w 같은 값을 파라미터(parameter)라고 부릅니다. 손실에서 출발해 입력 쪽으로 거슬러 가며 파라미터마다 손실에 얼마나 영향을 주었는지 계산하는 과정을 역전파(backward)라고 부릅니다. 역전파로 구한 값은 기울기(gradient)라고 부릅니다(1차시 슬라이드 6쪽). 이 예에서 w의 기울기는 −4 입니다. 기울기가 음수이면 w를 키울 때 손실이 줄어들고, 양수이면 w를 줄일 때 손실이 줄어듭니다.

파라미터는 Param = Param − (lr × grad) 식으로 갱신합니다(1차시 슬라이드 7쪽). grad는 기울기이고, lr은 파라미터를 한 번에 얼마나 바꿀지 정하는 작은 수입니다. 이 수를 학습률(learning rate)이라고 부릅니다. 이 단원은 학습률로 0.1 을 씁니다.

### PyTorch가 맡는 일
<!-- facts: F01-08 -->

앞 단원에서는 기울기를 구하고 w를 갱신하는 계산을 손으로 따라갔습니다. 파라미터가 수백만 개인 모델에서는 이 계산을 PyTorch에 맡깁니다. PyTorch처럼 딥러닝에 필요한 계산 코드를 미리 만들어 둔 도구를 딥러닝 프레임워크라고 부릅니다. 1차시 슬라이드 9쪽은 PyTorch가 맡는 일을 이렇게 꼽습니다.

- 순전파 계산만 코드로 쓰면 기울기를 알아서 계산합니다. 이 기능을 자동 미분(Autograd)이라고 부릅니다.
- 기울기로 파라미터를 갱신하는 일을 맡은 도구를 옵티마이저(optimizer)라고 부릅니다. PyTorch는 손실 함수와 옵티마이저를 모듈로 만들어 두어서, 직접 짜지 않고 가져다 씁니다.
- PyTorch가 다루는 숫자 배열을 텐서(tensor)라고 부릅니다. PyTorch는 numpy와 비슷한 문법으로 텐서를 계산합니다. 텐서는 3차시에서 자세히 배웁니다.

### 학습 다섯 줄과 그 순서
<!-- facts: F01-09 F01-01 F01-11 -->

1차시 슬라이드 10쪽은 PyTorch로 모델을 학습시킬 때 되풀이하는 다섯 줄을 보여 줍니다.

```python
optimizer.zero_grad()        # 1 기울기 초기화
output = model(input)        # 2 순전파
loss = fn(output, target)    # 3 손실 계산
loss.backward()              # 4 역전파
optimizer.step()             # 5 파라미터 갱신
```

둘째 줄부터 다섯째 줄까지는 앞 단원의 네 단계와 차례로 맞습니다. 첫 줄 `optimizer.zero_grad()`는 지난 바퀴에서 구한 기울기를 지웁니다. PyTorch는 `backward()`를 부를 때마다 새 기울기를 앞의 값에 더해 두기 때문에, 지우지 않으면 기울기가 쌓입니다. 쌓이는 모습은 3차시에서 숫자로 확인합니다.

```figure
파일: assets/1b-2.gif
캡션: 그림 2. 다섯 줄을 한 줄씩 실행할 때 바뀌는 값(x = 2, 정답 5, 학습률 0.1)
프레임:
1. 다섯 줄 옆에 w, w의 기울기, 예측, 손실 칸을 둡니다. 시작할 때 w는 2 이고 기울기 칸은 비어 있습니다. (2200ms)
2. 1번 줄 optimizer.zero_grad(): 기울기 칸을 비우고 w는 바꾸지 않습니다. (1800ms)
3. 2번 줄 output = model(input): 예측 4 를 냅니다. (1800ms)
4. 3번 줄 loss = fn(output, target): 손실 1 을 계산합니다. (1800ms)
5. 4번 줄 loss.backward(): 기울기 칸에 −4 가 들어가고 w는 아직 2 로 남아 있습니다. (2200ms)
6. 5번 줄 optimizer.step(): w가 2 − 0.1 × (−4) = 2.4 로 바뀝니다. (2200ms)
7. 다음 바퀴도 같은 다섯 줄을 돌아 예측 4.8, 손실 0.04 가 됩니다. (2500ms)
```

기울기는 다음 `backward()`를 부르기 전에만 지우면 되므로, `zero_grad()`를 `step()` 뒤에 두어도 결과가 같습니다. 4차시 노트북과 PyTorch 튜토리얼은 맨 뒤에 두고, 이 차시는 슬라이드처럼 맨 앞에 둡니다.

### 줄마다 바꾸는 것: backward는 기울기, step은 파라미터
<!-- facts: F01-11 F01-10 F01-09 -->

그림 2 에서 w의 값이 바뀐 줄은 5번 줄 하나뿐이었습니다. `loss.backward()`는 기울기를 계산해 담기만 하고, 파라미터 값을 실제로 바꾸는 줄은 `optimizer.step()`입니다.

```ai-reveal
{"guess": "g3"}
```

| 줄 | 하는 일 | w | w의 기울기 |
|---|---|---|---|
| `optimizer.zero_grad()` | 지난 기울기를 지웁니다 | 2 | 빈 칸 |
| `loss.backward()` | 기울기를 계산해 담습니다 | 2 | −4 |
| `optimizer.step()` | 기울기로 w를 갱신합니다 | 2 → 2.4 | −4 |
| `with torch.no_grad():` | 안쪽 계산의 기울기 기록을 끕니다 | 바꾸지 않습니다 | 기록하지 않습니다 |

> **[정정]** 강사 요약본 1주차 16쪽은 역전파 단계에서 파라미터를 갱신한다고 적었습니다. 그림 2 에서 본 것처럼 `loss.backward()`를 부른 뒤에도 w는 2 로 남고, w를 2.4 로 갱신하는 줄은 `optimizer.step()`입니다. 같은 요약본 20쪽의 학습 순서 표도 `loss.backward()`와 `optimizer.step()`을 다른 단계로 나눠 적었습니다.

모델이 얼마나 잘 맞히는지 재는 일을 평가라고 부릅니다. 평가에서는 예측이 정답과 맞은 비율을 자주 잽니다. 이 비율을 정확도라고 부릅니다. 평가할 때는 파라미터를 갱신하지 않으므로 기울기가 필요 없습니다. 이때는 계산을 `with torch.no_grad():` 블록 안에 넣습니다. 그러면 PyTorch가 기울기 계산을 위한 기록을 남기지 않아 그만큼 메모리와 연산을 아낍니다(1차시 슬라이드 10쪽). 평가에서는 `backward()`와 `step()`을 부르지 않습니다.

### copy()는 새 배열을 만듭니다
<!-- facts: F01-14 F01-12 F01-53 -->

앞 단계의 `y = x`에서는 `x[0] = 100` 뒤 y도 [100, 7, 9]가 되었습니다. `y = x.copy()`는 x의 값을 새 메모리에 따로 담은 배열을 만들고 y가 그 배열을 가리키게 합니다. 그래서 `x[0] = 100`을 해도 y는 [5, 7, 9]로 남습니다(1차시 슬라이드 13쪽, 노트북 02 [12]).

```figure

```

| 코드 | 강의 표현 | 파이썬 문서의 표현 | x[0] = 100 뒤 y |
|---|---|---|---|
| `y = x` | 얕은 복사(참조 복사) | 대입, 같은 객체에 이름을 하나 더 | [100, 7, 9] |
| `y = x.copy()` | 깊은 복사 | 값을 새 배열로 복사 | [5, 7, 9] |

> **[정정]** 1차시 슬라이드 12~13쪽은 `y = x`를 "얕은 복사", `x.copy()`를 "깊은 복사"라고 부릅니다. 파이썬 문서의 말로는 `y = x`는 복사가 아니라 이름을 하나 더 붙이는 대입입니다. 파이썬 문서의 얕은 복사(`copy.copy`)와 깊은 복사(`copy.deepcopy`)는 안쪽에 든 객체까지 복사하느냐로 나뉩니다. numpy 문서는 `x.copy()`를 얕은 복사로 설명합니다. 숫자만 든 배열에서는 `x.copy()`로 값이 모두 새로 복사되므로 결과는 슬라이드와 같습니다.

> **[보충 설명]** 리스트를 `l[:]`처럼 잘라 낸 것은 새 리스트입니다. numpy 배열을 `a[1:]`처럼 잘라 낸 것은 원본과 메모리를 함께 쓰는 배열이라서, 고치면 원본도 바뀝니다. 자르는 문법은 이 차시 마지막 단원에서, numpy는 2차시에서 자세히 배웁니다.

### fdiff는 함수를 받아 함수를 돌려줍니다
<!-- facts: F01-25 F01-58 -->

앞 단원에서 손으로 계산한 중앙 차분을 노트북 02 [35]는 fdiff라는 함수로 짭니다. fdiff는 함수 f를 받아, 중앙 차분으로 f의 기울기를 어림하는 함수 diff를 만들어 돌려줍니다. 파이썬에서 함수 이름은 함수를 가리키는 이름이라서 함수도 값처럼 다른 함수에 넘기고 돌려받을 수 있습니다(노트북 02 [33]). 함수를 인자로 받거나 함수를 돌려주는 함수를 고차 함수라고 부릅니다.

```python
def fdiff(f):
    def diff(x):
        h = 1e-6                                   # 0.000001
        return (f(x + h) - f(x - h)) / (2 * h)    # 중앙 차분
    return diff                                    # 계산 결과가 아니라 함수 diff를 돌려줌

f = lambda x: 2 * x**2 + 2
f_prime = fdiff(f)       # f_prime은 함수
f_prime(3.0)             # 12.000000001677336
```

`lambda x: 식`은 이름을 붙이지 않고 짧은 함수를 만드는 문법입니다. 위의 f는 x를 받아 2x² + 2 를 돌려줍니다. `1e-6`은 0.000001 을 파이썬에서 줄여 쓴 꼴입니다.

```figure
파일: assets/1e-1.png
캡션: 그림 1. fdiff에 함수 f를 넣으면 함수 diff가 나오고, diff에 3.0 을 넣어야 숫자가 나옵니다
내용: 왼쪽 함수 f 상자가 fdiff 상자로 들어가 함수 diff 상자가 나옴. diff 상자에 3.0 이 들어가 12.000000001677336 이 나옴
```

`fdiff(f)`는 숫자가 아니라 함수 diff를 돌려주므로, 기울기 숫자를 얻으려면 `f_prime(3.0)`처럼 돌려받은 함수를 한 번 더 불러야 합니다.

### 자동 미분: requires_grad, backward, grad
<!-- facts: F01-28 F01-72 F01-73 F01-56 -->

fdiff는 f를 두 번 계산해 x = 3 의 기울기를 12.000000001677336 으로 어림했습니다. 1차시 슬라이드 19쪽의 코드는 미분한 식을 쓰지 않고 같은 기울기를 PyTorch의 자동 미분으로 구합니다.

```python
import torch
x = torch.tensor(3.0, requires_grad=True)    # 이 텐서로 하는 계산을 기록
y = 2 * x**2 + 2                              # 순전파: y = 20
y.backward()                                  # 역전파: 기울기 계산
print(x.grad)                                 # tensor(12.)
```

### __init__과 self: Point(2, 3)을 만들고 옮기기
<!-- facts: F01-30 F01-31 -->

1차시 슬라이드 21쪽의 Point는 좌표를 담고, 옮기고, 지금 좌표를 알려 줍니다.

```python
class Point:
    def __init__(self, x, y):    # 인스턴스를 만들 때 불려 속성을 채움
        self.x = x
        self.y = y

    def move(self, dx, dy):      # 좌표를 dx, dy만큼 옮김
        self.x += dx
        self.y += dy

    def coord(self):             # 지금 좌표를 (x, y)로 돌려줌
        return (self.x, self.y)

p = Point(2, 3)
p.move(1, -1)
print(p.coord())                 # (3, 2)
```

`Point(2, 3)`처럼 인스턴스를 만들 때 불려 속성을 처음 값으로 채우는 메서드 `__init__`을 생성자라고 부릅니다. 메서드의 첫 인자 `self`는 그 메서드를 부른 인스턴스 자신을 가리킵니다. `p.move(1, -1)`을 부르면 self는 p입니다. `self.x += dx`는 self.x에 dx를 더해 다시 담는 줄이라 p의 x를 2 에서 3 으로 바꿉니다. coord가 돌려주는 (3, 2)처럼 괄호로 묶은 값 묶음을 튜플이라고 부릅니다. 튜플은 이 차시 마지막 단원에서 다시 봅니다.

```figure
파일: assets/1f-2.gif
캡션: 그림 2. p = Point(2, 3)을 만들고 move(1, -1)로 옮기기
프레임:
1. p = Point(2, 3): __init__이 불려 p.x = 2, p.y = 3 이 됩니다. 점이 (2, 3)에 찍힙니다. (2200ms)
2. p.move(1, -1)을 부르면 메서드 안의 self는 p를 가리킵니다. (2000ms)
3. self.x += 1 로 x가 2 에서 3 이 됩니다. (2000ms)
4. self.y += -1 로 y가 3 에서 2 가 되어 점이 (3, 2)로 옮겨졌습니다. (2200ms)
5. p.coord()는 (3, 2)를 돌려줍니다. (2000ms)
6. p.move(1, -1)을 한 번 더 하면 바뀐 (3, 2)에서 다시 옮겨 (4, 1)이 됩니다. (2400ms)
```

### 상속과 super()
<!-- facts: F01-32 F01-33 -->

노트북 02 [53]은 Point를 물려받아 반지름 r을 더한 원 클래스 Circle1을 만듭니다. 이렇게 이미 있는 클래스의 속성과 메서드를 물려받아 새 클래스를 만드는 것을 상속이라고 부릅니다. Point처럼 물려주는 클래스를 부모라고 부릅니다. Circle1처럼 물려받는 클래스는 자식이라고 부릅니다.

```python
class Circle1(Point):                # Point를 물려받음
    def __init__(self, x, y, r):
        super().__init__(x, y)       # 부모의 __init__으로 x, y를 채움
        self.r = r                   # 원만 가진 속성
```

`super()`는 부모 클래스를 가리키고, `super().__init__(x, y)`는 부모 Point의 `__init__`을 불러 x, y 속성을 만듭니다. 노트북 02 [49]의 Point에는 슬라이드의 Point와 달리 move, coord가 없고 점을 찍는 메서드 draw가 있습니다. 노트북 02 [53]~[64]는 자식 클래스가 draw를 정의하는 방법을 바꿔 가며 무엇이 그려지는지 봅니다. 자식이 부모와 같은 이름의 메서드를 다시 정의하는 것을 재정의(overriding)라고 부릅니다.


### __call__과 model(x)
<!-- facts: F01-34 F01-35 F01-36 F01-37 F01-54 -->

1차시 슬라이드 22쪽의 클래스 H는 `__call__` 메서드가 2 * x + 2 를 돌려주게 만듭니다. 클래스에 `__call__`을 정의하면 인스턴스를 함수처럼 괄호로 부를 수 있습니다.

```python

    def __call__(self, x):
        return 2 * x + 2

h = H()
h(3)      # h.__call__(3)이 불려 8
```


`h(3)`은 `h.__call__(3)`을 부르므로 2 × 3 + 2 = 8 입니다. 노트북 02 [66]의 H는 `2*x**2 + 2`를 돌려주게 만들어서 같은 `h(3)`이 20 이 됩니다.

```figure
파일: assets/1f-4.png
캡션: 그림 4. h(3)과 model(x)는 모두 __call__을 거칩니다
내용: 위 줄 h(3) → __call__(self, 3) → 2 × 3 + 2 = 8. 아래 줄 model(x) → nn.Module의 __call__ → forward(x) → 출력
```

PyTorch 모델은 모두 `nn.Module`을 상속한 클래스이고, `nn.Module`이 미리 정의해 둔 `__call__`이 우리가 쓴 `forward`를 부릅니다. 그래서 모델은 `model.forward(x)` 대신 `model(x)`로 부릅니다(1차시 슬라이드 22쪽). PyTorch 문서도 forward를 직접 부르지 말라고 합니다. `model(x)`로 불러야 forward 앞뒤에 등록해 둔 동작까지 실행되기 때문입니다. 이 동작을 훅(hook)이라고 부릅니다.

슬라이드 23쪽은 앞으로 쓸 모델 클래스의 틀을 미리 보여 줍니다.

```python
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()     # nn.Module의 준비를 먼저 함
        # 쓸 층을 여기서 만듦
    def forward(self, x):
        # 순전파 계산을 여기에 적음
        return x
```

`__init__` 첫 줄에서 `super().__init__()`을 불러 `nn.Module`의 준비를 먼저 하고, 순전파 계산은 `forward` 메서드에 씁니다. 학습은 「PyTorch의 학습 다섯 줄」 단원의 다섯 줄로 합니다.

### 슬라이스와 뒤집기
<!-- facts: F01-39 F01-40 F01-41 F01-81 -->

리스트 [1, 2, 3, 4, 5]에서 1 은 0 번 자리, 5 는 4 번 자리에 있습니다. 이렇게 리스트에서 원소의 자리 번호를 인덱스라고 부릅니다. 첫 원소의 인덱스는 0 입니다. 음수 인덱스는 뒤에서부터 세어 -1 이 맨 뒤 원소, -2 가 뒤에서 둘째 원소입니다. 리스트에서 일부 구간을 잘라 새 리스트로 꺼내는 문법 `l[시작:끝]`을 슬라이스라고 부릅니다. 시작 인덱스의 원소는 들어가고 끝 인덱스의 원소는 빠집니다. 시작을 비우면 처음부터, 끝을 비우면 맨 뒤 원소까지 자릅니다.

```figure
파일: assets/1g-3.png
캡션: 그림 3. [1, 2, 3, 4, 5]의 인덱스와 슬라이스 [1:-1]
내용: 다섯 칸 위에 인덱스 0~4, 아래에 −5~−1. [1:-1]이 칸 2, 3, 4 를 고르고 끝 인덱스 −1 칸은 빠짐. 오른쪽에 [:-1], [::-1] 결과
```

```python
list1 = [1, 2, 3, 4, 5]
list1[:-1]      # [1, 2, 3, 4]     맨 뒤 하나를 뺌
list1[1:-1]     # [2, 3, 4]
list1[::2]      # [1, 3, 5]        두 칸씩 건너뜀
list1[::-1]     # [5, 4, 3, 2, 1]  순서를 뒤집은 새 리스트
```

`l[시작:끝:간격]`처럼 셋째 수를 쓰면 그 간격만큼 건너뛰며 꺼냅니다. `list1[::2]`는 인덱스 0, 2, 4 의 원소라서 [1, 3, 5] 이고, 간격이 -1 인 `list1[::-1]`은 맨 뒤 원소부터 하나씩 거꾸로 꺼냅니다.

`[::-1]`은 정렬하지 않고 순서만 뒤집습니다. `[3, 1, 2][::-1]`은 `[2, 1, 3]`입니다. 큰 수부터 정렬하려면 `sorted(l, reverse=True)`를 씁니다. 리스트를 뒤집는 코드에는 `reverse()`와 `reversed()`도 있습니다. 각 코드가 원본을 바꾸는지, 무엇을 돌려주는지를 아래 표에 적었습니다.

```ai-reveal
{"guess": "g9"}
```

| 코드 | 원본 list1 | 돌려주는 것 |
|---|---|---|
| `list1[::-1]` | 건드리지 않습니다 | 뒤집은 새 리스트 |
| `list1.reverse()` | 원본을 뒤집습니다 | `None` |
| `reversed(list1)` | 건드리지 않습니다 | 차례로 꺼내 쓰는 반복자. `list()`로 감싸야 값이 보입니다 |

> **[정정]** 노트북 03 [17]의 주석은 `list1[::-1]`을 내림차순 정렬이라고 적었습니다. `[1, 2, 3, 4, 5]`처럼 이미 오름차순인 리스트라서 정렬한 것처럼 보였을 뿐이고, `[::-1]`은 순서만 뒤집습니다.

### 튜플, 딕셔너리, 반복문
<!-- facts: F01-42 F01-43 F01-44 F01-45 F01-62 F01-63 -->

앞 단원의 `p.coord()`가 돌려준 (3, 2)가 튜플입니다. 튜플은 괄호로 묶거나 `t3 = 1, 2, 3, 4`처럼 쉼표로만 이어서도 만듭니다. 한 번 만든 뒤에는 원소를 바꿀 수 없습니다. 튜플의 원소에 대입하면 TypeError가 나고, 바꾸려면 `list(t)`로 리스트로 바꿔 고친 뒤 `tuple()`로 되돌립니다(노트북 03 [23]~[30]). 키와 값을 짝지어 담는 `{키: 값}` 묶음을 딕셔너리(dict)라고 부릅니다. `d[키]`로 값을 읽습니다. 없는 키에 대입하면 짝이 더해지고, 있는 키에 대입하면 값이 바뀝니다.

```figure
파일: assets/1g-4.png
캡션: 그림 4. 바꿀 수 없는 튜플, 키와 값을 짝지은 딕셔너리, items()가 내주는 짝
내용: 왼쪽 자물쇠를 단 튜플 (1, 2, 3, 4). 가운데 딕셔너리 {'수학': 90, '영어': 85}의 키→값 화살표. 오른쪽 items()가 내주는 ('수학', 90), ('영어', 85)
```

```python
scores = {'수학': 90, '영어': 85}
for k, v in scores.items():     # (키, 값) 짝을 하나씩 꺼냄
    print(k, ':', v)            # 수학 : 90, 다음 줄에 영어 : 85

for i in range(1, 4):           # 1, 2, 3 (끝 값 4 는 빠짐)
    print(i)

def square(x):
    return x * x, x * x * x     # 튜플 하나를 돌려줌

a, b = square(3)                # a = 9, b = 27
```

`d.items()`는 (키, 값) 짝을 차례로 내주므로 `for k, v in d.items():`로 키와 값을 한꺼번에 받습니다. `print(k, ':', v)`는 값 사이에 공백을 넣어 `수학 : 90`처럼 찍습니다. `range(1, 4)`는 1, 2, 3 이고 끝 값은 빠집니다. 함수가 `return a, b`처럼 쉼표로 여러 값을 돌려주면 실제로는 튜플 하나를 돌려줍니다. 받는 쪽은 `a, b = square(3)`처럼 나눠 받습니다.

### 코드 읽기: f-string 출력 서식
<!-- facts: F01-46 F01-67 F01-65 -->

노트북 01 [29]의 학습 코드는 손실을 `{avg_train_loss:.5f}` 꼴로 찍습니다. 문자열 앞에 f를 붙이고 중괄호 안에 변수를 넣어 값을 끼워 넣는 문자열을 f-string이라고 부릅니다. 중괄호 안 콜론 뒤에 서식을 붙이면 자릿수와 표기를 정합니다. 노트북 03 [52]~[54]의 예로 읽어 봅니다.

```python
a1 = 1 / 7          # 0.14285714285714285
a2 = 123
f'{a1:.4f}'         # '0.1429'      소수 넷째 자리까지 반올림한 고정소수점
f'{a2:04}'          # '0123'        0 으로 빈자리를 채운 네 자리
f'{a1:.04e}'        # '1.4286e-01'  지수 표기, 1.4286 × 10의 −1제곱
f'{a2:#x}'          # '0x7b'        0x를 붙인 16진수
f'{0.9:.1%}'        # '90.0%'       100 을 곱하고 %를 붙임
```

```figure
파일: assets/1g-5.png
캡션: 그림 5. f'{a1:.4f}'의 각 부분과 서식별 결과
내용: f'{a1:.4f}'의 a1(파랑), 콜론(회색), .4(초록), f(주황)를 색으로 나누고 이름표. 아래 표 .4f → 0.1429, 04 → 0123, .04e → 1.4286e-01, #x → 0x7b, .1% → 90.0%
```

`.4f`의 f는 고정소수점 표기, `.4`는 소수점 아래 자릿수입니다. `04`처럼 너비 앞에 0 을 붙이면 빈자리를 0 으로 채웁니다. `.04e`는 소수점 아래 네 자리의 지수 표기이고 `#x`는 0x를 붙인 16진수입니다. 서식은 화면에 보이는 글자만 바꾸고 변수 a1의 값은 바꾸지 않습니다.

> **[보충 설명]** `f'{2.675:.2f}'`는 2.68 이 아니라 2.67 을 찍습니다. 2.675 가 이진수로 정확히 저장되지 않고 2.67499… 에 가까운 값으로 들어 있기 때문입니다. 반올림할 자리 바로 다음 숫자가 5 인 값은 예상과 다르게 찍힐 수 있습니다.

```ai-recall
{"id": "r29", "q": "f'{2.71828:.3f}' 가 찍는 글자는 ____ 입니다.", "answer": ["2.718", "'2.718'"], "mode": "exact", "why": "소수점 아래 셋째 자리까지 반올림하면 2.718 입니다."}
```
