### 높이와 너비에 같은 식을 따로 적용합니다
<!-- facts: F16-201 F16-202 F16-203 -->

입력 한 변을 H, 커널을 K, 한쪽 padding 폭을 P, stride를 S로 둡니다. 양쪽에 P씩 붙이므로 늘어난 길이는 2P입니다. dilation=1일 때 출력 공간 크기 = floor((H+2P-K)/S)+1입니다. <mark>floor</mark>는 소수 부분을 버리는 내림입니다.

### 중간 모양을 관찰한 뒤 hook을 해제합니다
<!-- facts: F16-703 -->

특정 모듈이 계산을 끝낼 때 확인 함수를 호출하도록 등록하는 기능을 <mark>forward hook</mark>이라고 부릅니다. 출력의 `shape`를 읽으면 어느 층에서 예상과 다른 모양이 생겼는지 좁힐 수 있습니다. 관찰 함수가 출력을 바꾸지 않고 모양만 기록하는 예를 사용합니다.

```python
handle = layer.register_forward_hook(read_shape)
output = model(sample)
handle.remove()
```

`layer`, `read_shape`, `sample`은 이 흐름을 설명하기 위한 이름입니다. 모듈에 등록한 hook은 함수 호출을 모두 가로채는 기능이 아닙니다. 예를 들어 `forward` 안의 `F.relu(x)`는 독립된 `nn.ReLU` 자식 모듈이 아니므로 자식 모듈 목록에 별도로 나타나지 않습니다. 모양 확인이 끝나면 반환받은 handle의 `remove()`로 등록을 해제합니다.
