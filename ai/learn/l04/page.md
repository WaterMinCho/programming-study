### 선형 모델: Yp = W × X + B
<!-- facts: F04-08 F04-17 F04-27 F04-64 -->

앞 단계에서 만든 X를 넣어 Y를 맞히는 식을 세웁니다. 입력을 받아 예측을 내놓는 식을 모델이라고 부릅니다. 이 단원은 가장 단순한 모델인 직선을 씁니다.

**Yp = W × X + B**

- X는 모델에 넣는 입력으로, 평균을 뺀 신장입니다. Yp는 예측한 체중입니다. p는 예측을 뜻하는 predict의 머리글자입니다.
- W는 직선의 기울기입니다. X가 1 커질 때 Yp가 W만큼 커집니다.
- B는 X = 0일 때 직선의 높이입니다.

이렇게 입력에 W를 곱하고 B를 더하는 직선 꼴의 모델을 선형 모델이라고 부릅니다. W와 B처럼 학습하면서 바꿔 갈 값은 파라미터라고 부릅니다. 강의는 이 식을 앞으로 배울 모델의 기본 블록으로 소개합니다(4차시 슬라이드 11쪽, 13쪽). 노트북은 W = 1, B = 1에서 시작합니다.

```figure
파일: assets/4a-3.gif
캡션: 그림 3. 직선 하나로 예측하기. 파랑은 직선과 예측, 보라는 B입니다.
프레임:
1. 앞 단계에서 옮긴 다섯 점입니다. (1600ms)
2. W = 1, B = 1인 직선 Yp = 1 × X + 1을 그었습니다. (1800ms)
3. 파란 계단을 보면 X가 1 커질 때 Yp가 W = 1만큼 커집니다. 보라 원은 X = 0일 때의 높이 B = 1입니다. (2400ms)
4. 사람 1의 X = −5를 넣으면 1 × (−5) + 1 = −4입니다. 직선 위의 빈 원이 예측이고, 노란 상자에 그 계산을 적었습니다. (2200ms)
5. 사람 2는 1 × 5 + 1 = 6입니다. 앞 장에서 구한 사람 1의 예측은 옅은 파랑으로 남겨 둡니다. (2200ms)
6. 나머지 세 사람까지 넣으면 Yp = [−4, 6, 1, 3, −1]입니다. (2500ms)
```

PyTorch 코드로는 이렇게 씁니다.

```python
X = torch.tensor(X).float()   # numpy 배열을 텐서로 바꿈
Y = torch.tensor(Y).float()

W = torch.tensor(1.0, requires_grad=True).float()
B = torch.tensor(1.0, requires_grad=True).float()

def pred(X):
    return W * X + B

Yp = pred(X)
# tensor([-4.,  6.,  1.,  3., -1.], grad_fn=<AddBackward0>)
```

`torch.tensor(...)`는 값을 텐서로 만듭니다. 텐서는 PyTorch가 다루는 숫자 배열입니다. `.float()`는 텐서의 자료형을 32비트 실수로 바꿉니다. X, Y는 numpy의 64비트 실수에서 32비트로 바뀝니다. 1.0으로 만든 W, B는 처음부터 32비트 실수라 `.float()`를 불러도 자료형이 바뀌지 않습니다.

`requires_grad=True`는 이 텐서가 들어간 계산을 PyTorch가 기록해 두라는 표시입니다(3차시 슬라이드 11쪽, 4차시 슬라이드 23쪽). 출력 끝의 `grad_fn=<AddBackward0>`는 Yp를 만든 마지막 계산이 덧셈이었다는 기록입니다. 이 기록을 어떻게 쓰는지는 이 차시 셋째 단원에서 봅니다.

### 손실: 얼마나 틀렸는지 숫자 하나로
<!-- facts: F04-28 F04-30 -->

앞 단계에서 구한 예측 Yp = [−4, 6, 1, 3, −1]이 정답 Y에서 얼마나 벗어났는지 잽니다. 예측에서 정답을 뺀 값을 오차(e)라고 부릅니다.

**e = Yp − Y**

사람 1은 −4 − (−6.7) = 2.7이라 예측이 2.7 높습니다. 사람 2는 6 − 10.3 = −4.3이라 예측이 4.3 낮습니다.

이렇게 오차를 제곱해 평균 낸 값을 평균 제곱 오차(MSE, Mean Squared Error)라고 부릅니다. 모델이 얼마나 틀렸는지 나타내는 숫자 하나를 손실(loss)이라고 부릅니다. 손실이 작을수록 예측이 정답에 가깝습니다. 세 단원의 손실은 MSE이고, 지금 직선의 손실은 13.352입니다.

```python
def mse(Yp, Y):
    loss = ((Yp - Y)**2).mean()
    return loss

loss = mse(Yp, Y)
# tensor(13.3520, grad_fn=<MeanBackward0>)
```

`(Yp - Y)**2`는 다섯 오차를 하나씩 제곱하고, `.mean()`은 그 다섯 값의 평균을 냅니다.

> **[정정]** 4차시 슬라이드 32쪽은 이 줄의 출력을 16.5980으로 적었습니다. 노트북 실행 결과와 앞의 손계산은 13.3520입니다. 33쪽에 적힌 다음 계산 값 3.16, 2.68도 노트북 값 −19.04, 2.0과 다릅니다. 노트북 값은 다음 단원에서 구합니다. 세 단원과 연습 문항은 노트북 값을 씁니다.

### 경사하강법: 기울기의 반대쪽으로 파라미터를 바꿉니다
<!-- facts: F04-11 F04-12 F04-34 F04-74 -->

앞 단계에서 구한 기울기 (−19.04, 2.0)은 손실이 가장 빨리 커지는 쪽을 가리킵니다. 손실을 줄이려면 W와 B를 그 반대쪽으로 바꾸면 됩니다. 이렇게 파라미터를 기울기의 반대쪽으로 조금씩 바꾸는 방법을 경사하강법(gradient descent)이라고 부릅니다. 4차시 강의 자료는 기울기를 "경사"나 "그라디언트"라고도 부릅니다.

**새 W = W − 학습률 × W.grad**

**새 B = B − 학습률 × B.grad**

기울기에 곱해 파라미터를 한 번에 얼마나 바꿀지 정하는 작은 수를 학습률(learning rate)이라고 부릅니다. 코드에서는 `lr`로 씁니다. 노트북은 0.001을 씁니다.

- W는 1 − 0.001 × (−19.04) = 1 + 0.01904 = 1.01904가 됩니다.
- B는 1 − 0.001 × 2.0 = 0.998이 됩니다.

`W.grad`가 음수이므로 그 값을 빼면 W는 커집니다. `B.grad`는 양수이므로 그 값을 빼면 B는 작아집니다. 이렇게 W를 키우면 앞 단계에서 본 것처럼 손실이 줄어듭니다.

### 연쇄법칙: 사람 2 하나만 따라가기
<!-- facts: F04-14 F04-15 F04-65 -->

앞 단원에서는 W를 바꿔 가며 손실을 두 번 계산해 기울기를 구했습니다. 파라미터가 수만 개면 파라미터마다 손실을 두 번씩 다시 계산해야 합니다. PyTorch는 다른 방법을 씁니다. 손실을 만든 계산을 작은 단계로 나누고, 단계마다 미분값을 구해 곱합니다. 이 원리를 연쇄법칙(chain rule)이라고 부릅니다(4차시 슬라이드 21쪽).

사람 2(X = 5, Y = 10.3) 하나만 따라가 봅니다. 입력에서 손실 쪽으로 값을 차례로 계산하는 것을 순전파라고 부릅니다. 거꾸로 손실에서 입력 쪽으로 미분값을 곱해 가는 것을 역전파라고 부릅니다.

사람 2의 계산을 네 단계로 나눠 표에 적었습니다. 마지막 단계의 L은 다섯 사람의 s를 더해 5로 나누므로, 표에는 사람 2가 L에 보태는 값만 적었습니다.

| 단계 | 계산 | 값 | 이 단계의 미분값 |
|---|---|---|---|
| 예측 | Yp = W × X + B | 1 × 5 + 1 = 6 | Yp를 W로 미분하면 X = 5 |
| 오차 | e = Yp − Y | 6 − 10.3 = −4.3 | e를 Yp로 미분하면 1 |

- Yp는 5배인 0.05만큼 커집니다.
- e도 0.05만큼 커집니다.
- s는 −8.6배인 약 −0.43만큼 바뀝니다.
- 사람 2가 L에 보태는 값은 0.2배인 약 −0.086만큼 바뀝니다.

### PyTorch 코드로 한 번 갱신하기: backward, no_grad, zero_
<!-- facts: F04-17 F04-18 F04-31 F04-32 F04-33 F04-34 F04-35 F04-72 -->

앞의 두 단계에서 손으로 한 계산은 `loss.backward()`를 부르면 PyTorch가 대신 합니다. 노트북 코드를 한 줄씩 따라가며 W, B, `W.grad`, `B.grad`가 어떻게 바뀌는지 봅니다.

```python
lr = 0.001
Yp = pred(X)
loss = mse(Yp, Y)
loss.backward()            # 기울기 계산, W.grad와 B.grad를 채움
with torch.no_grad():      # 이 안의 계산은 기록하지 않음
    W -= lr * W.grad
    B -= lr * B.grad
W.grad.zero_()             # 기울기를 0으로 지움
B.grad.zero_()
```

- `loss.backward()`는 기울기를 계산해 `.grad`에 둘 뿐 W와 B를 바꾸지 않습니다. 값은 그다음 갱신 줄이 바꿉니다.
- `requires_grad=True`인 W를 `W -= ...`로 바로 갱신하면 오류가 납니다. 그림 3의 6번 장에 적은 오류 문구에서 leaf Variable은 W처럼 사용자가 직접 만든 텐서를 가리킵니다. 이런 텐서를 잎 텐서라고 부릅니다. in-place operation은 `-=`처럼 텐서 자신의 값을 바꾸는 연산을 가리킵니다. `with torch.no_grad():` 안에서는 기록을 멈추므로 갱신할 수 있습니다(4차시 슬라이드 34쪽).
- PyTorch는 `backward()`를 부를 때마다 새 기울기를 `.grad`에 더합니다(3차시 슬라이드 11쪽, 4차시 슬라이드 23쪽). 지난 기울기를 지우지 않으면 그림 3의 7번 장처럼 이번에 계산한 기울기의 두 배 가까운 값으로 파라미터를 갱신합니다.

### optimizer로 줄여 쓰는 표준 학습 루프
<!-- facts: F04-18 F04-40 F04-41 F04-69 -->

앞 단계에서 직접 한 파라미터 갱신과 기울기 지우기는 `torch.optim`의 객체에 맡길 수 있습니다. 이렇게 파라미터 갱신을 맡는 PyTorch 객체를 최적화 함수(optimizer)라고 부릅니다.

```python
import torch.optim as optim

W = torch.tensor(1.0, requires_grad=True).float()
B = torch.tensor(1.0, requires_grad=True).float()
optimizer = optim.SGD([W, B], lr=0.001)

for epoch in range(500):
    optimizer.zero_grad()     # W.grad.zero_(), B.grad.zero_()를 대신함
    Yp = pred(X)              # ① 예측
    loss = mse(Yp, Y)         # ② 손실
    loss.backward()           # ③ 기울기 계산(역전파)
    optimizer.step()          # ④ 갱신, no_grad 안의 W -= lr * W.grad를 대신함
```

`optim.SGD([W, B], lr=0.001)`은 W와 B를 학습률 0.001로 갱신하는 optimizer를 만듭니다. `optimizer.step()`은 앞 단계의 `no_grad` 블록과 같은 계산을 하고, `optimizer.zero_grad()`는 연결된 파라미터의 기울기를 지웁니다. 노트북의 결과도 W 1.820683, B 0.3675114, 손실 4.6796으로 수동 갱신과 같습니다(4차시 노트북 01의 50번 셀). 4차시 노트북은 `optimizer.zero_grad()`를 루프 맨 끝에 두는데, 맨 앞에 두어도 결과가 같은 까닭은 다음 단계에서 봅니다.

```figure

프레임:
1. 한 번 반복할 때 optimizer.zero_grad()부터 실행합니다. 첫 반복이라 지울 기울기가 아직 없습니다. (1800ms)
```

이 다섯 줄은 5차시부터의 학습 코드에 이름만 바뀌어 거듭 나옵니다. 5차시부터는 `pred` 대신 모델 `net`, `mse` 대신 `criterion`을 씁니다(5차시 슬라이드 8~9쪽).

| 이 단원 | 5차시 노트북 |
|---|---|
| `Yp = pred(X)` | `outputs = net(inputs)` |
| `loss = mse(Yp, Y)` | `loss = criterion(outputs, labels)` |
| `optim.SGD([W, B], lr=lr)` | `optim.SGD(net.parameters(), lr=lr)` |

학습 루프에서 헷갈리는 코드를 한 표에 모았습니다.

| 코드 | 하는 일 | W, B의 값 | `.grad` |
|---|---|---|---|
| `loss.backward()` | 손실에서 거꾸로 기울기를 계산합니다 | 바꾸지 않습니다 | 새 기울기를 더합니다 |
| `optimizer.step()` | W ← W − lr × `W.grad`로 갱신합니다 | 바꿉니다 | 건드리지 않습니다 |
| `optimizer.zero_grad()` | 연결된 파라미터의 기울기를 지웁니다 | 바꾸지 않습니다 | None으로 비웁니다(PyTorch 2.x) |
| `W.grad.zero_()` | W의 기울기만 지웁니다 | 바꾸지 않습니다 | 0이 됩니다 |
| `with torch.no_grad():` | 안쪽 계산을 기록하지 않습니다 | 안에서 직접 바꿀 수 있게 합니다 | 바꾸지 않습니다 |

> **[정정]** 4차시 슬라이드 42쪽과 노트북의 주석은 이 optimizer를 확률적 경사하강법이라고 부릅니다. SGD는 확률적 경사하강법(Stochastic Gradient Descent)의 줄임말이 맞지만, 이 예는 다섯 사람을 모두 써서 기울기를 구하므로 실제 계산은 전체 데이터로 하는 경사하강법입니다. "확률적"은 데이터 일부를 무작위로 뽑아 기울기를 구할 때 붙는 이름입니다. 데이터를 작은 묶음으로 나눠 쓰는 방법은 5차시에서 배웁니다.

### 코드 읽기: zero_grad의 자리와 None
<!-- facts: F04-35 F04-44 F04-67 F04-68 F04-72 -->

앞 단계의 루프는 `optimizer.zero_grad()`를 맨 앞에 두었습니다. 4차시 노트북 01은 이 줄을 루프 맨 끝(step 뒤)에 두고, 5차시부터의 노트북은 맨 앞에 둡니다(5차시 노트북 01의 18번 셀). 슬라이드는 이 차이를 따로 설명하지 않습니다. backward는 기울기를 `.grad`에 더하므로, 이번 `backward()`를 부르기 전에 지난 기울기가 지워져 있기만 하면 두 자리의 결과는 같습니다. 세 단원은 5차시부터의 노트북처럼 루프 맨 앞에 둡니다.

```figure
파일: assets/4c-5.png
캡션: 그림 5. zero_grad를 루프 맨 앞에 둘 때와 맨 끝에 둘 때. 회색으로 칠한 줄은 backward 바로 앞 줄이고, 초록 숫자는 W.grad에 담긴 기울기입니다.

```

PyTorch 2.0부터 `optimizer.zero_grad()`는 기울기를 0으로 채우지 않고 `None`으로 비웁니다(기본값 `set_to_none=True`). 그래서 PyTorch 2.x에서 `optimizer.zero_grad()` 직후 `print(W.grad)`를 하면 `None`이 찍힙니다. 4차시 노트북 주석처럼 0으로 채우는 것은 1.x의 기본 동작입니다. 앞에서 본 `W.grad.zero_()`는 0을 채워 `tensor(0.)`가 찍힙니다. 4차시 과제 4번을 완성해 실행하면 마지막 줄의 기울기가 `None`으로 찍힙니다.

`with torch.no_grad():`는 갱신 말고도 쓰입니다. 블록 안의 계산을 기록하지 않으므로, 학습이 끝난 모델로 예측만 할 때도 이 블록을 씁니다. 그 쓰임은 10차시 평가 코드에서 다시 봅니다.
