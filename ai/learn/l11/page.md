### 커널의 가중치를 모든 위치에서 함께 학습합니다

<!-- facts: F11-01 F11-02 F11-03 -->

같은 커널의 가중치를 여러 위치에서 쓰는 방법을 <mark>가중치 공유</mark>라고 부릅니다. 이미지 여러 위치에 같은 무늬가 있는지 찾을 때 같은 가중치를 적용합니다. CNN은 이런 합성곱 층으로 지역 특징을 학습하는 신경망입니다. 앞 계산에서는 값을 이해하려고 커널을 고정했지만 실제 학습에서는 커널 값이 파라미터입니다.

```python
conv = nn.Conv2d(1, 1, kernel_size=2, bias=False)
features = conv(images)
```

Conv2d의 앞 두 수는 입력·출력 채널 수입니다. bias=False는 편향을 두지 않는 설정입니다. PyTorch가 합성곱 층이라고 부르는 이 연산은 커널을 뒤집지 않는 교차상관입니다. 그림도 커널을 뒤집지 않고 계산했습니다.

### 바깥을 채운 길이에서 출력 크기를 계산합니다

<!-- facts: F11-04 F11-05 F11-06 -->

이미지 바깥을 값으로 채우는 방법을 <mark>패딩</mark>이라고 부릅니다. 여기서는 각 축의 양 끝을 0으로 한 칸씩 채웁니다. 원래 길이 5에 두 칸을 더해 7칸에서 커널을 움직입니다.

커널 내부 간격을 늘리지 않는 dilation=1에서 출력 길이는 floor((입력 + 2 × 패딩 − 커널) ÷ 스트라이드) + 1입니다. floor는 소수 부분을 버려 내리는 계산입니다. 커널을 놓은 뒤 이동할 수 있는 횟수를 구하고 처음 놓은 위치까지 세어 1을 더합니다.

입력 5, 패딩 1, 커널 3, 스트라이드 2라면 채운 길이에서 커널 길이를 빼고 이동 간격으로 나눕니다. 이 예는 나누어떨어져 (5 + 2 − 3) ÷ 2 + 1 = 3입니다.

```python
layer = nn.Conv2d(1, 2, kernel_size=3, stride=2, padding=1)
output = layer(images)
```

stride가 이동 간격이고 padding이 양 끝에 채울 칸 수입니다. stride=1로 바꾸면 같은 3×3 커널과 padding=1에서 공간 크기를 유지합니다.
