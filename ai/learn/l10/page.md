### 은닉층이 특징을 바꾸고 출력층이 숫자별 점수를 냅니다

<!-- facts: F10-01 F10-02 F10-03 -->

입력 784개를 은닉층의 값 32개로 바꾼 뒤 숫자별 점수 10개를 냅니다. `nn.Linear(784, 32)`는 마지막 축의 특징 784개를 32개로 바꾸는 층입니다. 그 뒤 `nn.ReLU()`로 음수를 0으로 바꾸고 `nn.Linear(32, 10)`을 잇습니다.

각 Linear의 가중치 수는 입력 수와 출력 수를 곱하고 편향은 출력 수만큼 더합니다. 첫 층은 784 × 32 + 32개이고 마지막 층은 32 × 10 + 10개입니다. 합하면 784 × 32 + 32 + 32 × 10 + 10 = 25,450개입니다.

이 모델은 소프트맥스로 바꾸기 전 점수인 logit을 냅니다. 소프트맥스와 손실의 짝은 9차시 9c/4 「CrossEntropyLoss는 로그 소프트맥스와 NLLLoss를 이은 손실입니다」에서 배웠습니다. Fashion-MNIST도 한 장이 28×28 흑백이고 종류가 10개이므로 이 입력·출력 크기를 쓸 수 있습니다.

### 변환을 이은 뒤 이미 바꾼 입력을 다시 바꾸지 않습니다

<!-- facts: F10-04 F10-05 F10-06 -->

변환 결과를 다음 변환의 입력으로 넘기는 목록을 Compose로 만듭니다.

```python
prepare = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5,), (0.5,)),
    transforms.Lambda(lambda pixels: pixels.reshape(-1)),
])
```

Compose는 적은 순서대로 실행합니다. Lambda는 전달한 작은 함수를 각 샘플에 적용합니다. 여기서는 reshape(-1)이 [1, 28, 28]의 값 784개를 [784]로 펼칩니다.

이미지를 바꿀 때뿐 아니라 표 자료를 바꿀 때도 같은 입력을 두 번 변환하는지 확인합니다. 표 자료에 적용하는 StandardScaler는 5차시 5g/2 「나누고 표준화하기」에서 배웠습니다. <u>원본 예측 입력에는 학습에 쓴 변환을 한 번만 적용합니다.</u> 평균 5, 표준편차 4인 변환이라면 원본에서 5를 뺀 뒤 4로 나눕니다.

원본 9를 바꾸면 1입니다. 이미 바꾼 1에 같은 변환을 다시 적용하면 −1이 됩니다. 그림에서는 같은 원본을 한 번 바꾼 값과 두 번 바꾼 값을 견줍니다.

Dataset은 번호로 샘플 하나를 읽는 객체입니다. <mark>DataLoader</mark>는 Dataset에서 읽은 샘플을 미니배치로 묶습니다. 앞 단원의 prepare를 Dataset의 transform에 넘기면 이미지를 읽을 때 같은 변환을 적용합니다.

아래 코드의 root는 데이터 폴더입니다. train=True는 훈련 분할을, train=False는 테스트 분할을 고릅니다. download=False는 이미 준비한 파일만 사용하므로 파일이 없으면 오류가 납니다. download=True는 필요한 파일을 받는 설정입니다.

```python
from torchvision import datasets
from torch.utils.data import DataLoader

train_data = datasets.MNIST(
    root="data", train=True, download=False, transform=prepare)
test_data = datasets.MNIST(
    root="data", train=False, download=False, transform=prepare)
train_loader = DataLoader(train_data, batch_size=32, shuffle=True)
test_loader = DataLoader(test_data, batch_size=32, shuffle=False)
```

Fashion-MNIST도 같은 인자를 씁니다. 위 두 생성자에서 datasets.MNIST를 datasets.FashionMNIST로 바꾸면 옷 이미지의 훈련·테스트 분할을 읽습니다. 두 자료 모두 prepare 뒤에는 한 장이 [784], 한 배치가 [배치, 784]입니다. 첫 Linear의 입력 784개와 마지막 출력 10개인 기존 전결합 구성을 재사용할 수 있습니다.

모델을 고르거나 예측 확률을 조정할 때 쓸 검증 자료는 훈련 자료에서 따로 떼어 둡니다. 테스트 분할은 마지막 평가에 사용합니다.

배치 수는 작은 예로 세어 보겠습니다. 샘플 5개를 2개씩 묶으면 2개, 2개, 1개인 배치가 나옵니다. 마지막 배치의 크기는 1입니다. 기본 설정인 `drop_last=False`는 이 1개도 사용합니다.

### 온도 하나로 확률 분포를 조절합니다

<!-- facts: F10-19 F10-20 F10-21 -->

logit을 양수 T로 나눈 뒤 소프트맥스를 적용하는 방법을 <mark>온도 스케일링</mark>이라고 부릅니다. [2, 0]의 logit에 T=1을 쓰면 점수는 [2, 0]이고 확률은 약 [0.881, 0.119]입니다. T=2를 쓰면 점수가 [1, 0]으로 바뀌어 확률은 약 [0.731, 0.269]입니다. 이 예에서는 온도를 높여 확률을 더 완만하게 바꿉니다.

T가 양수이면 두 logit의 대소관계가 바뀌지 않습니다. 가장 큰 점수의 클래스를 고르는 argmax 예측도 유지합니다. `prob = torch.softmax(scores / temperature, dim=1)`의 temperature에는 양수 온도를 넣습니다.

### 저장한 값에 맞는 모델 구조를 준비합니다

<!-- facts: F10-25 F10-26 F10-27 -->

앞에서 좋은 시점의 상태를 별도 복사했습니다. 프로그램을 닫은 뒤에도 쓰려면 상태를 파일에 저장합니다.

```python
torch.save(model.state_dict(), path)
state = torch.load(path, weights_only=True)

model.eval()
```

첫 줄의 save는 파라미터와 저장 대상 버퍼를 파일로 씁니다. load는 그 파일의 값을 읽고 weights_only=True는 텐서와 기본 자료 중심으로 읽도록 제한합니다. <u>load_state_dict는 준비한 같은 모델 구조에 값을 넣습니다.</u> eval은 예측에 쓸 층 동작으로 바꿉니다.

### 샘플마다 뽑힐 무게를 따로 줍니다

<!-- facts: F10-25 F10-26 F10-27 -->

지금까지 평가 자료 전체를 읽는 방법을 봤습니다. 훈련에서는 클래스 불균형에 대응하려고 샘플마다 뽑힐 무게를 다르게 줄 수 있습니다. 대응 원리는 6차시 6e/5 「불균형 대응 방법을 적용하는 때」에 있습니다. 샘플 세 개의 추출 가중치를 [1, 3, 1]로 두면 가운데 샘플을 양쪽 샘플보다 세 배의 무게로 뽑습니다.

tiny_train은 위 샘플 세 개만 담은 별도 훈련 Dataset입니다.

```python
weights = [1.0, 3.0, 1.0]
train_sampler = WeightedRandomSampler(weights, num_samples=3, replacement=True)
train_loader = DataLoader(tiny_train, batch_size=2, sampler=train_sampler)
```

WeightedRandomSampler는 샘플마다 뽑힐 가중치를 받습니다. num_samples는 한 번 순회할 때 뽑을 개수이고 replacement=True는 같은 샘플을 다시 뽑는 것을 허용합니다. 이번에 어느 샘플이 몇 번 나올지는 무작위입니다. train_sampler가 순서를 정하므로 shuffle=True는 함께 지정하지 않습니다.

전체 평가는 별도 test_loader에서 중복 없이 모든 샘플을 읽습니다. 복원 추출한 훈련 배치를 모두 읽어도 원자료의 샘플을 모두 읽었다고 보장할 수 없습니다. 스케줄러 호출 위치는 5차시 5e/5 「scheduler.step()의 자리」를 적용합니다.
