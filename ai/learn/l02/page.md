숫자 여섯 개를 리스트에 담을 때와 numpy 배열에 담을 때 메모리를 쓰는 방식이 다릅니다.

```figure
파일: assets/l02-1.png
```


`import numpy as np`는 numpy를 `np`라는 짧은 이름으로 불러옵니다. `np.array(...)`는 파이썬 리스트를 numpy 배열(ndarray)로 바꿉니다.

파이썬 리스트의 각 칸에는 값이 있는 곳의 주소가 들어 있습니다. 그 주소가 가리키는 값은 메모리 여기저기에 흩어져 있습니다. 정수, 실수, 문자열처럼 값의 종류를 <mark>자료형</mark>이라고 부릅니다. 리스트는 자료형이 다른 값을 섞어 담을 수 있습니다. numpy 배열은 값을 연속된 메모리에 붙여 저장하고 모든 원소에 같은 자료형을 씁니다. `data.dtype`을 읽으면 이 배열의 자료형을 알 수 있습니다.

numpy는 값을 붙여 저장하고 내부의 C 코드로 원소를 계산합니다. 파이썬 반복문 없이 계산하는 방법은 다음 단계에서 봅니다. 모양이 다른 배열끼리 계산하는 방법은 넷째 단원에서 배웁니다.

PyTorch가 쓰는 배열을 텐서(tensor)라고 부릅니다. 데이터를 담는 도구는 파이썬 리스트, numpy 배열, PyTorch 텐서 순으로 발전했습니다. 텐서는 numpy 배열에 GPU 계산과 자동 미분을 더한 것입니다. 텐서는 3차시에서 배웁니다.

### shape은 축마다 원소가 몇 개인지 적은 튜플입니다
<!-- facts: F02-07 F02-08 F02-09 F02-10 -->

앞 단계에서는 여섯 원소를 한 줄로 계산했습니다. 같은 원소를 두 행에 나눠 담으면 모양이 어떻게 달라지는지 봅니다.

```figure
파일: assets/l02-3.png
캡션: 그림 3. 1차원 배열과 2차원 배열의 shape, ndim, len. 파랑은 0번 축, 주황은 1번 축입니다.
내용: 왼쪽 data의 0번 축 여섯 칸, 오른쪽 M의 0번 축 두 칸(파랑)과 1번 축 세 칸(주황), 아래 [[1, 2, 3]]의 shape (1, 3)
```

```python

M.ndim       # 2

```

배열에서 원소가 늘어서는 방향을 <mark>축</mark>(axis)이라고 부릅니다. 축 번호는 0 부터 셉니다.

- `data.shape`은 여섯 원소가 한 축을 따라 놓여 있어 (6,) 입니다. `M.shape`은 위에서 아래로 두 행, 왼쪽에서 오른쪽으로 세 열이 있어 (2, 3) 입니다. 이처럼 축마다 원소가 몇 개인지 차례로 적은 튜플이 `shape`입니다.
- `M.ndim`은 축의 개수 2 를 알려 줍니다.
- `len(M)`은 0번 축의 길이인 행 수 2 를 돌려줍니다. 전체 원소 수는 6 입니다.

2차원 배열을 행렬(matrix)이라고 부릅니다. 1차원 배열은 벡터(vector)라고 부릅니다. 숫자 하나는 스칼라(scalar)라고 부릅니다. 3차시에서 텐서의 차수로 다시 봅니다.

원소가 하나뿐인 축도 축으로 셉니다. `np.array([[1, 2, 3]])`은 대괄호가 두 겹이라 축도 두 개 생겨 shape (1, 3), ndim 2 입니다.

정수 리스트로 만든 배열의 `dtype`은 int64 입니다. `np.array([1, 2, 3], dtype=np.float32)`처럼 자료형을 정해 만들 수도 있습니다.

> **[보충 설명]** int64 는 NumPy 2 버전과 리눅스에서 도는 Colab 기준입니다. NumPy 1 버전을 Windows에서 쓰면 같은 코드가 int32 를 만들었습니다.

### 모양을 정해 0, 1, 난수로 채웁니다
<!-- facts: F02-11 F02-12 F02-17 F02-18 -->

앞 단계의 M은 숫자를 직접 적어 만든 (2, 3) 배열입니다. 모양만 정하고 같은 값이나 난수로 채워 만들 수도 있습니다.

```figure
파일: assets/l02-4.png
캡션: 그림 4. 모양을 정해 값을 채우는 함수와 np.ones(2, 3)의 오류. 노랑은 np.eye가 1 을 넣은 대각선 자리, 빨강은 오류입니다.
내용: np.zeros(3), np.ones((2, 3)), np.eye(2, 3), np.random.randn(2, 3)의 격자와 TypeError 상자
```

```python
np.zeros(3)              # array([0., 0., 0.])
np.ones((2, 3))          # 2행 3열을 1 로 채움
np.eye(2, 3)             # 대각선 자리만 1
np.random.randn(2, 3)    # 표준정규분포 난수 2행 3열, 값은 실행마다 달라짐
# np.ones(2, 3)          # TypeError: Cannot interpret '3' as a data type
```

- `np.zeros(3)`은 0 으로 채운 실수 배열을 만듭니다.
- `np.ones((2, 3))`은 2행 3열을 1 로 채웁니다.
- `np.eye(2, 3)`은 2행 3열에서 대각선 자리만 1 로 채웁니다.

`np.ones`에 2차원 이상 모양을 줄 때는 `(2, 3)`처럼 튜플 하나로 묶습니다. `np.ones(2, 3)`으로 쓰면 numpy가 둘째 자리 3 을 자료형으로 읽으려다 TypeError를 냅니다. 3차시에서 배울 `torch.ones(2, 3)`은 정수를 따로 넘겨도 됩니다.

평균 근처 값이 가장 자주 나오고 평균에서 멀수록 드물게 나오는 종 모양의 분포를 정규분포라고 부릅니다. 값이 평균에서 퍼진 정도는 표준편차라는 숫자로 나타냅니다. 평균 0, 표준편차 1 인 정규분포는 표준정규분포라고 부릅니다. `np.random.randn`은 표준정규분포에서 뽑은 난수로 배열을 채웁니다. 모양은 튜플 대신 정수 여러 개로 받습니다. `np.random.randn(2, 3, 4)`의 shape은 (2, 3, 4) 입니다.

`randn`의 n은 정규분포를 뜻하는 normal의 n입니다. σ는 표준편차를 나타냅니다.

단위 행렬은 대각선이 1이고 나머지가 0인 정사각 행렬입니다. `np.eye(2, 3)`은 직사각 배열의 대각선 자리만 1로 채우며, 정사각 단위 행렬은 `np.identity(3)`처럼 만듭니다.

### arange는 끝값을 빼고 linspace는 끝값을 넣습니다
<!-- facts: F02-13 F02-14 F02-15 F02-16 F02-73 -->

앞 단계에서는 배열을 같은 값이나 난수로 채웠습니다. 이번에는 일정한 간격의 수를 채웁니다. 간격을 정할 때와 원소 개수를 정할 때 쓰는 함수가 다릅니다.

```figure
파일: assets/l02-5.png
캡션: 그림 5. linspace(-1, 1, 11)과 arange(-1, 1, 0.2)가 만드는 점
내용: 위 수직선에 1 까지 들어간 점 11개, 아래 수직선에 1 이 빠진 점 10개, 맨 아래 arange(6)과 linspace(0, 5, 6) 결과
```

```python
np.arange(6)             # array([0, 1, 2, 3, 4, 5])
np.arange(20, 200, 10)   # 20 부터 10 씩, 200 은 빼고 18개
np.linspace(-1, 1, 11)   # -1 부터 1 까지 11개, 간격 0.2
np.arange(-1, 1, 0.2)    # -1 부터 0.2 씩, 1 은 빼고 10개
```

- `np.arange(6)`은 0 부터 6 바로 앞까지 정수를 만듭니다.
- `np.arange(시작, 끝, 간격)`은 시작에서 간격만큼 늘리며 끝값을 빼고 만듭니다. 정수 간격이면 개수는 (끝 − 시작) ÷ 간격을 올림한 값입니다. `np.arange(20, 200, 10)`은 180 ÷ 10 = 18개입니다.

`np.linspace(시작, 끝, 개수)`는 양 끝을 넣고 그 사이를 같은 간격으로 나눠 개수를 맞춥니다. `np.linspace(-1, 1, 11)`은 -1, -0.8, …, 0.8, 1 로 0.2 간격입니다.

간격이 0.1 같은 실수면 `arange`는 끝값 근처에서 반올림 오차 때문에 개수가 예상과 달라질 수 있습니다. 그래서 numpy 문서도 이때는 `linspace`를 권합니다. 0 부터 10 까지 0.1 간격으로 10 도 넣으려면 `np.linspace(0, 10, 101)`을 씁니다. `np.arange(0, 10, 0.1)`은 9.9 에서 끝나는 100개입니다.

### -1 자리는 numpy가 나눗셈으로 정합니다
<!-- facts: F02-29 F02-30 F02-31 F02-39 -->

앞 단계에서는 행 수와 열 수를 모두 정했습니다. 원소 수가 6개일 때 행 수를 3 으로 정하면 열 수는 나눗셈으로 구할 수 있습니다.


### 행렬곱은 행과 열을 곱해 더하고 안쪽 길이가 같아야 합니다
<!-- facts: F02-41 F02-42 F02-40 -->

앞에서 본 `M * M`은 같은 자리의 값끼리 곱했습니다. 이번에는 M의 행 하나와 W의 열 하나를 곱해 더한 값으로 결과의 한 칸을 채웁니다.

```figure
파일: assets/l02-18.gif
캡션: 그림 21. M @ W를 한 칸씩 계산하기
프레임:
1. M (2, 3) @ W (3, 2)의 결과는 (2, 2) 입니다. 왼쪽의 열 수 3 과 오른쪽의 행 수 3 이 같아야 곱할 수 있습니다. 곱해 더하는 행과 열은 노랑, 계산 결과는 초록, 오류는 빨강으로 칠합니다. (2200ms)
2. [0, 0] 칸은 M의 0번 행과 W의 0번 열을 자리끼리 곱해 더한 3×1 + 8×0 + 1×1 = 4 입니다. (2000ms)
3. [0, 1] 칸은 0번 행과 1번 열로 3×0 + 8×1 + 1×1 = 9 입니다. 이미 구한 칸은 회색으로 칠합니다. (2000ms)
4. [1, 0] 칸은 6×1 + 2×0 + 9×1 = 15 입니다. (2000ms)
5. [1, 1] 칸은 6×0 + 2×1 + 9×1 = 11 입니다. (2000ms)
6. `M * M`은 원소별 곱입니다. `M @ M`은 안쪽 길이 3 과 2 가 달라 오류이고, `M @ M.T`는 (2, 3) @ (3, 2) 라 (2, 2) 입니다. (2500ms)
7. M @ W는 [[4, 9], [15, 11]] 이고, (m, n) @ (n, p)의 결과는 (m, p) 입니다. (2500ms)
```

```python
W = np.array([[1, 0], [0, 1], [1, 1]])
M @ W            # array([[ 4,  9], [15, 11]])
np.dot(M, W)     # 같은 행렬곱
# M @ M          # ValueError, (2, 3) 과 (2, 3) 은 안쪽 길이가 다름
M @ M.T          # (2, 3) @ (3, 2) 라 shape (2, 2)
```

`M @ W`의 [0, 0] 칸은 M의 0번 행과 W의 0번 열로 구합니다. 같은 자리끼리 곱해 더하면 3×1 + 8×0 + 1×1 = 4 입니다. 이 규칙으로 결과의 [i, j] 칸마다 왼쪽 i번 행과 오른쪽 j번 열을 곱해 더하는 계산을 <mark>행렬곱</mark>(matrix multiplication)이라고 부릅니다. `np.dot(M, W)`와 `np.matmul(M, W)`도 2차원 배열에서는 같은 행렬곱입니다.

2×3 행렬 A, B를 그대로 곱한 `A * B`는 원소별 곱입니다. `np.dot(A, B)`는 안쪽 길이 3 과 2 가 달라 오류가 납니다. `np.dot(A, B.T)`처럼 오른쪽 행렬을 전치하면 (2, 3) @ (3, 2)를 계산할 수 있습니다. 이 계산으로 [[50, 68], [122, 167]]을 얻는 예도 있습니다. 3차시에서 같은 계산을 PyTorch 텐서로 다시 합니다.

| | `X * Y` (원소별 곱) | `X @ Y` (행렬곱) |
|---|---|---|
| 하는 계산 | 같은 자리 원소끼리 곱합니다 | 왼쪽 행과 오른쪽 열을 곱해 더합니다 |
| 모양 조건 | 같은 모양이거나 브로드캐스팅으로 맞는 모양 | 왼쪽 열 수 = 오른쪽 행 수 |
| (2, 3)과 (2, 3) | (2, 3) | 오류 |
| (2, 3)과 (3, 2) | 오류 | (2, 2) |

### 집계는 여러 값을 숫자 하나로 줄입니다
<!-- facts: F02-52 F02-57 F02-58 -->

data의 원소 [3, 8, 1, 6, 2, 9]를 모두 더하면 29 입니다. 여러 값을 모아 합이나 평균처럼 더 적은 수의 값으로 나타내는 계산을 봅니다.

```figure

```

```python
data.sum()    # np.int64(29)
data.max()    # np.int64(9)
data.min()    # np.int64(1)
data.mean()   # np.float64(4.833333333333333)
```

- `data.sum()`은 모든 원소를 더한 합을 냅니다.
- `data.max()`와 `data.min()`은 가장 큰 값과 가장 작은 값을 냅니다.
- `data.mean()`은 합을 원소 수로 나눈 평균을 냅니다.

이처럼 여러 값을 숫자 하나나 더 작은 배열로 줄이는 계산을 <mark>집계</mark>(aggregation)라고 부릅니다.

1차시에서 본 손실은 모델이 얼마나 틀렸는지를 숫자 하나로 나타낸 값입니다. 손실을 계산할 때도 원소마다 구한 예측과 정답의 차이를 평균이나 합으로 줄여 숫자 하나로 만드는 집계 단계가 들어 있습니다. 손실은 4차시에서 자세히 배웁니다.

값이 평균에서 얼마나 퍼져 있는지는 표준편차와 분산으로 잽니다. `std`는 표준편차, `var`는 분산을 구합니다. 두 값은 데이터의 범위를 맞추는 변환과 가중치 초기화에 씁니다. 가중치 초기화는 학습을 시작할 때 모델 파라미터의 처음 값을 정하는 일입니다.

> **[보충 설명]** `np.std`와 `np.var`는 기본으로 원소 수 n으로 나눕니다(`ddof=0`). PyTorch의 `torch.var`는 기본으로 n − 1 로 나누어 같은 데이터에서 값이 서로 어긋납니다. [1, 2, 3, 4, 5]의 `np.var`는 2.0 이고, n − 1 로 나누면 2.5 입니다.

### axis를 정하면 그 축을 따라 줄이고 그 축이 사라집니다
<!-- facts: F02-48 F02-49 F02-50 F02-51 F02-72 -->

앞 단계에서는 data 전체를 더해 합 하나를 구했습니다. M에서 열마다 합을 구할 때와 행마다 합을 구할 때는 더할 축을 정합니다.

```figure

2. `M.sum(axis=0)`은 위아래로 더해 열마다 값 하나를 남깁니다. 결과는 [9, 10, 10] 이고 shape에서 0번 축의 2 가 빠져 (3,) 입니다. (2400ms)
3. `M.sum(axis=1)`은 옆으로 더해 행마다 값 하나를 남깁니다. 결과는 [12, 17] 이고 1번 축의 3 이 빠져 (2,) 입니다. (2400ms)

6. 행이 샘플이고 열이 특징이면 axis=0 은 특징마다 여러 샘플을 모으고, axis=1 은 샘플마다 여러 특징을 모읍니다. (2400ms)
```

```python
M.sum()          # np.int64(29)
M.sum(axis=0)    # array([ 9, 10, 10])
M.sum(axis=1)    # array([12, 17])
```

- `M.sum()`은 모든 원소를 더해 29 를 냅니다.
- `M.sum(axis=0)`은 열마다 위아래로 더해 [9, 10, 10]을 냅니다. 0번 축이 사라져 열 수만큼 값이 남습니다.
- `M.sum(axis=1)`은 행마다 옆으로 더해 [12, 17]을 냅니다. 1번 축이 사라져 행 수만큼 값이 남습니다.

`[[1, 2, 3], [4, 5, 6]]`으로 같은 계산을 하면 전체 합은 21, axis=0 합은 [5, 7, 9], axis=1 합은 [6, 15] 입니다.

행 하나에 샘플 하나를 담으면 샘플이 0번 축을 따라 늘어섭니다. 그래서 `axis=0`은 여러 샘플 사이의 집계, `axis=1`은 한 샘플 안 특징끼리의 집계입니다.

`np.sum`, `np.mean`, `np.max`는 axis를 생략하면 모든 원소를 집계합니다. 이때 axis는 `None`입니다. 배열을 붙이는 `np.concatenate`는 기본 axis가 0이므로 함수마다 기본값을 구별합니다.

### 정확도와 min-max 정규화도 배열 한 줄로 계산합니다
<!-- facts: F02-59 F02-60 F02-61 -->

앞에서 배운 비교, 합, 최솟값, 최댓값을 함께 써 봅니다. 예측이 맞은 비율을 구하고 data의 값을 0~1 사이로 바꿉니다.

```figure
파일: assets/l02-23.gif
캡션: 그림 27. 맞은 비율 계산과 0~1 로 맞추는 변환
프레임:
1. 정답 yt와 예측 yp가 여섯 개씩 있습니다. yp는 「인덱스와 조건으로 원소 고르기」 단원에서 만든 `np.where(data > 5, 1, 0)` 입니다. (1800ms)
2. `yt == yp`는 자리마다 같은지 비교해 True와 False를 냅니다. False 칸만 회색으로 칠했습니다. (2200ms)
3. `.sum()`은 True를 1 로 세어 맞은 개수 3 을 냅니다. 계산 결과는 초록으로 적습니다. (2000ms)
4. 맞은 개수 3 을 전체 개수 6 으로 나누면 0.5 입니다. (2200ms)

6. 나머지 값은 (값 − 1) ÷ 8 로 옮겨 [0.25, 0.875, 0, 0.625, 0.125, 1]이 됩니다. (2400ms)
7. 두 계산을 배열 한 줄씩으로 모았습니다. (2500ms)
```

```python
yt = np.array([1, 1, 0, 1, 1, 0])   # 정답
yp = np.where(data > 5, 1, 0)       # 예측 [0, 1, 0, 1, 0, 1]
(yt == yp).sum() / len(yt)          # np.float64(0.5)

(data - data.min()) / (data.max() - data.min())
# array([0.25 , 0.875, 0.   , 0.625, 0.125, 1.   ])
```

`np.where(data > 5, 1, 0)`으로 만든 예측 yp를 정답 yt와 자리마다 비교합니다. `yt == yp`의 True는 예측이 맞은 자리입니다. `.sum()`으로 맞은 개수를 세고 `len(yt)`로 나누면 전체 샘플 가운데 예측이 맞은 비율이 나옵니다. 이 비율을 정확도(accuracy)라고 부릅니다. 열 개 가운데 일곱 개가 맞으면 0.7 입니다. 정확도는 8차시 평가 지표에서 다시 배웁니다.

가장 작은 값을 0, 가장 큰 값을 1 로 옮기고 나머지를 그 사이에 같은 비율로 놓는 변환을 <mark>min-max 정규화</mark>라고 부릅니다. 식은 (x − 최솟값) ÷ (최댓값 − 최솟값) 입니다. 이 식은 최댓값이 최솟값보다 클 때 적용합니다. 모든 값이 같으면 분모가 0이어서 이 식으로 계산하지 않습니다. 같은 데이터의 평균을 빼고 0보다 큰 표준편차로 나누는 변환을 표준화라고 부릅니다. 계산에 쓴 평균·표준편차 기준에서 결과의 평균은 0, 표준편차는 1입니다.

| | min-max 정규화 | 표준화 |
|---|---|---|
| 식 | (x − 최솟값) ÷ (최댓값 − 최솟값) | (x − 평균) ÷ 표준편차 |
| 적용 조건 | 최댓값 > 최솟값 | 표준편차 > 0 |
| 결과 범위 | 0 이상 1 이하 | 평균 0, 표준편차 1 |
| data의 최솟값 1 을 바꾼 값 | 0 | 음수 |

### plot은 점을 선으로 잇고 scatter는 점만 찍습니다
<!-- facts: F02-62 F02-69 -->

앞 단원까지 계산에 쓴 data의 숫자 여섯 개를 그래프로 그립니다. 원소의 자리 번호를 가로축, 원소 값을 세로축에 놓습니다.

```figure
파일: assets/l02-24.png

내용: 왼쪽 plt.plot(x, data) 선 그래프, 가운데 plt.scatter(x, data) 점 그래프, 오른쪽 a = 1 과 a = 2 인 sigmoid 곡선
```


- `import matplotlib.pyplot as plt`는 그래프 함수 모음을 `plt`라는 이름으로 불러옵니다.
- `np.arange(6)`은 가로축에 쓸 자리 번호 0~5 를 만듭니다.
- `plt.plot(x, data)`는 (x, data) 점을 차례로 이은 선 그래프를 그립니다.
- `plt.scatter(x, data)`는 같은 자리에 점만 찍습니다.

### 코드 읽기: rand와 randint는 끝값을 넣지 않습니다
<!-- facts: F02-70 F02-12 -->

```figure
파일: assets/l02-27.png
캡션: 그림 32. numpy 난수 함수 셋이 내는 값의 범위. 초록은 나올 수 있는 값이고, 빈 원은 나오지 않는 끝값입니다.
내용: rand의 0 이상 1 미만 구간(1 은 빈 원), randint(1, 10)의 정수 1~9(10 은 빈 원), randn의 평균 0 종 모양 곡선
```

앞에서 배열을 채울 때 쓴 난수 함수는 데이터 하나를 무작위로 고를 때도 씁니다. 테스트 데이터 `X_test`의 자리 번호를 뽑으려면 데이터 길이를 벗어나지 않는 수가 필요합니다.

```python
sample_idx = np.random.randint(0, len(X_test))   # 0 이상 len(X_test) 미만
```

`np.random.randint(low, high)`는 low 이상 high 미만의 정수를 뽑습니다. high는 나오지 않아서 `len(X_test)`를 넣어도 마지막 번호 `len(X_test) - 1` 까지만 나옵니다. 그래서 인덱스로 써도 IndexError가 나지 않습니다. `np.random.rand()`는 0 이상 1 미만의 실수, `np.random.randn()`은 평균 0, 표준편차 1 인 정규분포의 실수를 뽑습니다.

numpy 문서는 이 난수 함수를 예전 방식(legacy)으로 분류합니다. 새 코드에는 `np.random.default_rng()`로 만든 생성기를 권합니다. 위 예제는 예전 방식의 코드입니다.
