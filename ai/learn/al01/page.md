### 크기와 값 범위를 모델 조건에 맞춥니다
<!-- facts: FA01-b1 FA01-b2 FA01-b3 FA01-b4 -->

`cv2.resize(bgr, (8, 6))`은 너비 8·높이 6으로 바꿉니다. 결과 shape는 `(6, 8, 3)`입니다. <u>resize의 크기는 너비부터, 배열의 shape는 높이부터 읽습니다.</u>

아래 코드의 `bgr`에는 읽기에 성공한 8비트 BGR 컬러 이미지가 들어 있다고 가정합니다. 파일 읽기에 실패하면 `None`이 나오므로 먼저 확인합니다. 모델이 RGB·CHW·0~1 실수 입력을 받는다고 정한 예라면 다음 순서로 준비할 수 있습니다. `float32`는 실수 자료형이고 `transpose(2, 0, 1)`은 채널 축을 맨 앞으로 옮깁니다.

```python
import cv2

rgb = cv2.cvtColor(bgr, cv2.COLOR_BGR2RGB)
small = cv2.resize(rgb, (8, 6))
x = small.astype("float32") / 255.0
x = x.transpose(2, 0, 1)
```

모양은 `(6, 8, 3)`에서 `(3, 6, 8)`로 바뀝니다. 한 번에 처리할 이미지 묶음을 <mark>배치</mark>라고 부릅니다. 그 개수 축을 N으로 적습니다. 한 장을 담은 배치 축을 `x = x[None, ...]`로 붙이면 `(1, 3, 6, 8)` 모양인 NCHW가 됩니다. 전처리 조건은 모델마다 확인합니다. 입력 크기를 항상 2의 거듭제곱으로 고르지 않습니다. 각 모델이 요구하는 크기를 확인합니다. 이 연산은 모델의 가중치를 갱신하지 않습니다.

### 범위를 넓힌 뒤 자릅니다
<!-- facts: FA01-c1 FA01-c2 FA01-c3 FA01-c4 -->

이미 범위를 넘어 12가 된 뒤 `clip()`을 호출해도 268을 되찾을 수 없습니다. **먼저 넓은 자료형으로 바꿔 계산**합니다. 다음 예의 `gray`는 이미 읽은 `uint8` 흑백 이미지 배열입니다. 여기에 양수 30을 더합니다.

```python
import numpy as np

wide = gray.astype("uint16") + 30
```

### 슬라이더 값은 원본에 매번 적용합니다
<!-- facts: FA01-h1 FA01-h2 FA01-h3 -->

슬라이더 위치 level을 100으로 나누어 밝기 배율로 쓰겠습니다. 100이면 1배, 150이면 1.5배, 50이면 0.5배입니다. 다음 `original`은 계속 보관하는 uint8 흑백 이미지입니다.

```python
import cv2
from google.colab.patches import cv2_imshow

def change_brightness(level):
    factor = level / 100
    adjusted = cv2.convertScaleAbs(original, alpha=factor, beta=0)
    cv2_imshow(adjusted)
```
