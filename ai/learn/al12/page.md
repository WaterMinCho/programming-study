## 후보 영역을 만드는 검출과 한 번에 예측하는 검출

### 후보 영역을 먼저 고르는 모델
<!-- facts: FA12-a1 -->

Faster R-CNN은 이미지 특징을 공유한 뒤 RPN으로 후보 영역을 제안합니다. RoI 헤드는 후보마다 클래스를 고르고 박스 위치를 보정합니다. 창고 사진에서 물체가 있을 만한 곳을 고르는 일과 각 후보가 무엇인지 판별하는 일이 두 단계입니다.

### 특징 맵에서 위치와 종류 예측하기
<!-- facts: FA12-a2 -->

YOLOv8은 별도의 영역 제안 단계 없이 특징 맵에서 박스 위치와 클래스 점수를 예측합니다. 이런 흐름을 한 단계 검출이라고 합니다. 속도나 정확도를 비교할 때는 같은 이미지 크기와 장치, 모델 크기, 평가 기준을 사용합니다.

### 후보를 정리하는 시점 확인하기
<!-- facts: FA12-a3 -->

한 번의 모델 예측 뒤에도 후보를 정리할 수 있습니다. 예를 들어 기본 YOLOv8 검출 흐름에서는 점수가 낮은 후보를 제외한 뒤 같은 물체의 겹친 후보를 NMS로 줄일 수 있습니다. NMS가 있다는 사실만으로 검출기가 Faster R-CNN처럼 후보를 제안하는 두 단계 구조라고 판단할 수는 없습니다.

### 클래스 번호 뒤에 네 값 쓰기
<!-- facts: FA12-c3 -->

이 물체의 클래스 번호가 1이면 라벨에 한 줄로 1 0.275 0.3 0.35 0.4를 씁니다. 첫 값부터 클래스 번호, 중심 x, 중심 y, 너비, 높이입니다. 물체가 여럿이면 각 물체의 상자를 한 줄씩 기록합니다. 사진의 크기를 알면 정규화된 중심과 크기를 픽셀 좌표로 되돌려 그림으로 확인할 수 있습니다.

```python
width, height = 1280, 720
x1, y1, x2, y2 = 128, 72, 576, 360
center_x = (x1 + x2) / (2 * width)
center_y = (y1 + y2) / (2 * height)
box_width = (x2 - x1) / width
box_height = (y2 - y1) / height
print(1, center_x, center_y, box_width, box_height)
```

### 위치 손실과 클래스 손실 읽기
<!-- facts: FA12-f1 -->

YOLOv8 검출에서 box_loss는 예측 박스와 목표 박스의 위치를 맞추는 항이고 cls_loss는 클래스 예측을 맞추는 항입니다. 훈련에서 어떤 값을 줄이고 있는지 로그 이름으로 확인할 수 있습니다. 좌표와 클래스의 검출 성능을 보려면 별도 자료에서 평가 결과도 봅니다.

<!-- facts: FA12-f2 -->
