# p06. 튜플을 리스트로 (빈칸 채우기 · 6점)

시험 점수가 튜플 `record` 에 저장되어 있습니다. 튜플은 값을 바꿀 수 없으므로 리스트로 바꾼 사본을 만들어 고치려고 합니다. 빈칸(`____`)을 채워 프로그램을 완성하세요.

프로그램은 먼저 `record` 의 자료형을 출력한 뒤(이미 작성되어 있습니다) 아래 순서로 동작합니다.

1. `record` 를 리스트로 변환해 `scores` 에 저장합니다.
2. `scores` 의 마지막 점수(`64`)를 `100` 으로 바꿉니다.
3. `scores` 전체를 출력합니다.
4. `scores` 에서 1번 인덱스와 2번 인덱스 요소만 잘라서 출력합니다.
5. 원래 튜플 `record` 를 출력합니다.

빈칸만 채우세요. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 시작 코드

```python
record = (72, 85, 90, 64)
print(type(record))
scores = ____(record)
scores[____] = 100
print(scores)
print(scores[1:____])
print(record)
```

## 출력 예

```

[72, 85, 90, 100]
[85, 90]
(72, 85, 90, 64)
```
