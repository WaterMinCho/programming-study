# p07. 구간 잘라내기 (반환값 · 6점)

리스트 `items` 와 정수 `start`, `end` 가 주어집니다.
`items` 의 `start` 번 인덱스부터 `end` 번 인덱스까지의 요소를 순서대로 담은 새 리스트를 반환하는 `solution` 함수를 완성하세요.
`end` 번 인덱스의 요소도 **포함**해야 합니다.

- 함수 이름과 매개변수는 바꾸지 않습니다.
- 반환값은 리스트여야 합니다. 요소가 하나여도 리스트로 반환합니다.

## 제한 사항
- `items` 의 길이는 1 이상 100 이하
- 0 ≤ `start` ≤ `end` ≤ (`items` 의 마지막 인덱스)

## 입출력 예

| items | start | end | 반환값 |
|---|---|---|---|
| `['가', '나', '다', '라', '마']` | 1 | 3 | `['나', '다', '라']` |
| `[10, 20, 30, 40]` | 0 | 0 | `[10]` |
| `[10, 20, 30, 40]` | 2 | 3 | `[30, 40]` |
