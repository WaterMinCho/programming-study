# 4차시 · 리스트와 딕셔너리

값 여러 개를 변수 하나에 모아 담는 자료형(컨테이너) 세 가지, **리스트·튜플·딕셔너리**를 다룹니다.
반복문은 5차시 내용이라 이 세트에는 나오지 않습니다.

## 세 자료형 비교

| | 리스트 `list` | 튜플 `tuple` | 딕셔너리 `dict` |
|---|---|---|---|
| 만들기 | `[1, 2, 3]` | `(1, 2, 3)` 또는 `1, 2, 3` | `{'키': 값, '키2': 값2}` |
| 빈 것 | `[]` | `()` | `{}` |
| 값 꺼내기 | `a[인덱스]` | `t[인덱스]` | `d[키]` 또는 `d.get(키)` |
| 만든 뒤 변경 | 가능 | 불가능 | 가능 |
| 섞어 담기 | 자료형 달라도 됨 | 자료형 달라도 됨 | 값은 아무 자료형, 키는 변경 불가능한 자료형만 |

## 1. 리스트

대괄호 안에 값을 쉼표로 나열합니다. 리스트를 이루는 값 하나하나를 **요소**, 요소의 위치 번호를 **인덱스**라고 하며 인덱스는 0부터 시작합니다.

```python
data = [5, "five", 5.0]      # 자료형이 달라도 함께 담김
print(data)                  # [5, 'five', 5.0]
print(data[1])               # five
data[0] = 50                 # 인덱스로 값 변경
print(data)                  # [50, 'five', 5.0]
print(len(data))             # 3
```

리스트를 통째로 출력하면 문자열 요소에 작은따옴표가 붙고, 요소 하나만 출력하면 따옴표가 없습니다.

### 추가 (append · insert · extend)

```python
a = []
a.append(1)           # [1]
a.append(3)           # [1, 3]
a.insert(1, 2)        # [1, 2, 3]
a.extend([4, 5])      # [1, 2, 3, 4, 5]
a.append([6, 7])      # [1, 2, 3, 4, 5, [6, 7]]
```

`append` 는 맨 뒤에 값 하나를 붙이고, `insert(인덱스, 값)` 은 그 자리에 끼워 넣습니다. `extend` 는 리스트 안의 값들을 풀어서 붙이지만, `append` 에 리스트를 주면 리스트가 통째로 한 칸에 들어갑니다.

### 삭제 (remove · del · pop)

```python
b = ["x", "y", "x", "z"]
b.remove("x")         # ['y', 'x', 'z']
del b[0]              # ['x', 'z']
last = b.pop()        # last 는 'z', b 는 ['x']
```

`remove` 는 값으로 찾아 처음 발견한 하나만 지우고, `del` 은 인덱스로 지웁니다. `pop()` 은 마지막 요소를 꺼내서 돌려줍니다. 삭제하면 뒤에 있던 요소들이 앞으로 한 칸씩 당겨져 인덱스가 바뀝니다.

### 슬라이싱 `리스트[start:stop]`

```python
c = [10, 20, 30, 40, 50]
print(c[1:4])              # [20, 30, 40]
print(c)                   # [10, 20, 30, 40, 50]
print(c[1:len(c) - 1])     # [20, 30, 40]   양 끝을 하나씩 뺀 가운데
print(c[2:2])              # []             범위 안에 요소가 없으면 빈 리스트
```

`c[1:4]` 는 1번부터 3번까지 잘라 오며 stop 인 4번은 포함되지 않습니다. 잘라 온 결과는 새 리스트라서 원본 `c` 는 바뀌지 않습니다.

숫자 리스트의 합은 `sum(c)`, 개수는 `len(c)` 로 구합니다(차시 과제에 나온 내장 함수).

## 2. 튜플

리스트와 비슷하지만 한 번 만들면 추가·수정·삭제가 안 됩니다. 바뀌면 안 되는 데이터에 씁니다.

```python
t1 = (1, "a", 2.5)    # 소괄호와 쉼표
t2 = 1, "a", 2.5      # 괄호를 생략해도 튜플
t3 = (1,)             # 값이 하나면 쉼표가 있어야 튜플
n  = (1)              # 정수 1
print(t1[1])          # a
print(type(t3), type(n))   # <class 'tuple'> <class 'int'>
```

```python
t = (4, 5, 6)
# t[0] = 9            # TypeError
lst = list(t)         # 리스트 사본
lst[0] = 9
print(lst)            # [9, 5, 6]
print(t)              # (4, 5, 6)
t = (9, 5, 6)         # 변수에 새 튜플을 다시 대입하는 것은 가능
```

값을 꺼낼 때는 리스트처럼 대괄호를 씁니다. 요소를 바꿔야 하면 `list()` 로 사본을 만들어 고치며, 이때 원래 튜플은 바뀌지 않습니다.

튜플로 된 결과가 필요하면 요소를 꺼내 계산한 값을 소괄호로 묶어 새 튜플을 만듭니다.

```python
pos = (3, 4)
moved = (pos[0] + 1, pos[1] - 2)
print(moved)          # (4, 2)
print(pos)            # (3, 4)
```

## 3. 딕셔너리

`키: 값` 쌍을 중괄호 안에 쉼표로 나열합니다. 위치(인덱스)가 아니라 키로 값을 찾습니다.

```python
car = {"model": "K5", "year": 2024}
print(car["model"])          # K5
print(car.get("year"))       # 2024

car["color"] = "white"       # 없는 키 → 맨 뒤에 추가
car["year"] = 2025           # 있는 키 → 값만 수정
print(car)                   # {'model': 'K5', 'year': 2025, 'color': 'white'}

del car["model"]             # 키-값 쌍 삭제
print(car)                   # {'year': 2025, 'color': 'white'}
```

```python
print(car.keys())            # dict_keys(['year', 'color'])
print(car.values())          # dict_values([2025, 'white'])
print(car.items())           # dict_items([('year', 2025), ('color', 'white')])
```

값이 리스트이면 `딕셔너리[키]` 뒤에 인덱스나 리스트 메서드를 이어서 씁니다.

```python
part = {"이름": "볼트", "재고": [40, 10]}
print(part["재고"][0])       # 40
part["재고"][0] = 35         # {'이름': '볼트', '재고': [35, 10]}
part["재고"].append("발주")   # {'이름': '볼트', '재고': [35, 10, '발주']}
```

- 키는 중복될 수 없습니다. `{'a': 1, 'a': 2}` 는 오류는 아니지만 나중 값만 남아 `{'a': 2}` 가 됩니다.
- 키에는 문자열·숫자·튜플처럼 변경 불가능한 자료형만 쓸 수 있습니다(리스트는 키로 못 씀). 값에는 리스트도 됩니다: `{'점수': [90, 80]}`

## 시험에서 헷갈리기 쉬운 포인트

- 인덱스는 0부터입니다. 요소가 3개면 인덱스는 0·1·2 이고 `a[3]` 은 IndexError 입니다. "n번째"는 `a[n - 1]`, 마지막은 `a[len(a) - 1]` 로 씁니다. 없는 인덱스에는 대입(`a[3] = 값`)도 안 되므로, 리스트를 늘릴 때는 `append()` 를 씁니다.
- 출력 모양을 정확히 기억해 두세요. `print([1, "a"])` 는 `[1, 'a']` 로 나옵니다(쉼표 뒤 공백 한 칸, 문자열은 작은따옴표). 튜플은 `(1, 'a')`, 딕셔너리는 `{'k': 1}` (콜론 뒤 공백 한 칸)입니다. 요소 하나만 출력하면 따옴표가 없습니다.
- 슬라이싱의 stop 은 미포함입니다. `a[2:5]` 는 2·3·4번이고 개수는 `stop - start` 입니다. 결과는 새 리스트이고 원본은 안 바뀝니다. 값 하나만 잘라도 `[값]` 처럼 리스트이고, 자를 요소가 없으면 `[]` 입니다.
- 평균은 `sum(a) / len(a)` 로 구하며 결과는 나누어떨어져도 실수입니다. 빈 리스트는 `len` 이 0 이라 나눗셈에서 오류가 나므로 길이를 `if` 로 먼저 확인합니다.
- `append([3, 4])` 는 리스트를 통째로 한 칸에 넣어 `[1, 2, [3, 4]]`, `extend([3, 4])` 는 풀어서 `[1, 2, 3, 4]` 가 됩니다. `append` 는 값을 하나만 받습니다. 통째로 들어간 리스트는 요소 한 개로 세므로 `len([1, 2, [3, 4]])` 는 3 이고 2번 인덱스가 `[3, 4]` 입니다.
- 문자열을 `extend("발주")` 로 넣으면 글자 단위로 풀려 `'발'`, `'주'` 두 요소가 들어갑니다. 문자열 하나를 한 칸에 넣을 때는 `append` 를 씁니다.
- `insert` 는 (인덱스, 값) 순서입니다. 끼워 넣은 자리부터 뒤 요소들이 한 칸씩 밀립니다.
- `remove` 는 값, `del` 은 인덱스를 받습니다. `remove` 는 같은 값이 여러 개여도 처음 하나만 지웁니다. `del a[1]` 뒤에는 인덱스가 한 칸씩 당겨집니다.
- `pop()` 은 지우면서 돌려줍니다. `x = a.pop()` 하면 마지막 요소가 `x` 에 들어가고 리스트에서는 사라집니다.
- `(1)` 은 int, `(1,)` 이 tuple 입니다. 괄호가 없어도 쉼표가 있으면 튜플이라 `v = 1,` / `v = 1, 2` 모두 튜플이고, 빈 튜플은 `()` 입니다.
- 튜플은 수정할 수 없습니다. `t[0] = 9` 는 TypeError 이고 `append`·`remove` 같은 메서드도 없습니다. 바꾸려면 `list(t)` 로 사본을 만들거나 변수에 새 튜플을 다시 대입합니다. `list(t)` 는 새 리스트를 만들 뿐 `t` 를 바꾸지 않습니다.
- 튜플을 반환하거나 출력해야 할 때 값을 대괄호로 묶으면 리스트가 됩니다. `(t[0] + 1, t[1])` 처럼 소괄호와 쉼표로 묶습니다.
- `d[키] = 값` 은 추가이자 수정입니다. 없는 키면 맨 뒤에 추가되고, 있는 키면 그 자리에서 값만 바뀝니다(순서 유지).
- 없는 키로 꺼낼 때 `d['없는키']` 는 KeyError, `d.get('없는키')` 는 오류 없이 `None` 입니다.
- 대입문은 오른쪽을 먼저 계산합니다. `'y'` 키가 없을 때 `d['y'] = 1` 은 새 키를 추가하지만, `d['y'] = d['y'] + 1` 은 오른쪽의 `d['y']` 를 꺼내다가 KeyError 가 납니다.
- `d["name"]` 은 `name` 이라는 글자가 키이고, `d[name]` 은 변수 `name` 에 담긴 값이 키입니다.
- 숫자 키는 인덱스가 아닙니다. `d = {1: 'a', 2: 'b'}` 에서 `d[1]` 은 1번 인덱스가 아니라 키 `1` 의 값 `'a'` 이고, `d[0]` 은 키가 없어 KeyError 입니다. 같은 `[1]` 이라도 리스트 `['a', 'b'][1]` 은 1번 인덱스의 `'b'` 를 꺼냅니다.
- `print(d.keys())` 는 `dict_keys([...])`, `print(d.values())` 는 `dict_values([...])`, `print(d.items())` 는 `dict_items([(키, 값), ...])` 로 나옵니다. 대괄호만 나오는 것이 아닙니다.
- `print(type([1]))` 은 `<class 'list'>`, 튜플은 `<class 'tuple'>`, 딕셔너리는 `<class 'dict'>` 로 출력됩니다.
- `len` 은 중복도 셉니다. `len(["a", "b", "a"])` 는 3 입니다. 딕셔너리의 `len(d)` 는 키-값 쌍의 개수이며, 있는 키의 값을 수정할 때는 늘지 않고 없는 키를 추가할 때만 1 늘어납니다.
