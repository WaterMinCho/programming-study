# p04. 사탕 나누기와 예외 이름 (빈칸 채우기 · 6점)

`groups` 는 팀 이름을 키로, 그 팀의 조별 인원수 리스트를 값으로 갖는 딕셔너리입니다. 함수 `candies` 는 `team` 팀의 `index` 번째 조가 사탕 120개를 똑같이 나눌 때 한 사람이 받는 개수(몫)를 **반환(return)** 합니다. 값을 구할 수 없으면 상황에 맞는 문자열을 반환합니다. 빈칸(`____`) 3곳에 예외 클래스의 이름을 채워 함수를 완성하세요.

```python
def candies(groups, team, index):
    try:
        sizes = groups[team]
        size = sizes[index]
        return 120 // size
    except ____:
        return "팀 없음"
    except ____:
        return "조 없음"
    except ____:
        return "인원 0명"
```

| 상황 | 반환값 |
|---|---|
| `groups` 에 `team` 이라는 키가 없다 | `"팀 없음"` |
| 그 팀의 리스트에 `index` 번째 요소가 없다 | `"조 없음"` |
| 그 조의 인원수가 0 이다 | `"인원 0명"` |

- 빈칸마다 예외 클래스 이름을 하나씩 적습니다. 대소문자와 철자가 정확해야 합니다.
- `index` 는 정수입니다. `-1` 처럼 음수이면 리스트의 뒤에서부터 셉니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

아래 예에서 `groups` 는 모두 `{"A": [4, 5], "B": [0, 8]}` 입니다.

| team | index | 반환값 |
|---|---|---|
| `"A"` | `1` | `24` |
| `"C"` | `0` | `"팀 없음"` |
| `"A"` | `2` | `"조 없음"` |
| `"B"` | `0` | `"인원 0명"` |
