# p06. 할 일 추가하고 번호 붙여 출력 (출력 · 6점)

할 일 목록을 `todo.txt` 파일에 한 줄에 하나씩 적어 둡니다. 새 할 일을 입력받아 파일 끝에 추가한 다음, 파일 전체를 다시 읽어 번호를 붙여 출력하는 프로그램을 작성하세요.

입력

- 첫 줄에 추가할 할 일의 수 `n` (0 이상 5 이하)
- 다음 `n` 줄에 추가할 할 일이 한 줄에 하나씩

처리와 출력

1. 입력받은 할 일을 `todo.txt` 끝에 입력 순서대로 한 줄에 하나씩 추가합니다. `todo.txt` 가 없으면 새로 만들고, 이미 있으면 원래 있던 내용을 지우지 않고 그 뒤에 붙입니다.
2. 추가가 끝난 `todo.txt` 를 처음부터 읽어 `1. 장보기` 처럼 `번호. 할 일` 형식으로 한 줄씩 출력합니다. 번호는 1 부터 시작합니다.
3. 마지막 줄에 `총 4개` 처럼 파일에 들어 있는 할 일의 수를 출력합니다. 할 일이 하나도 없으면 `총 0개` 만 출력합니다. `n` 이 0 이고 `todo.txt` 가 없을 때도 오류 없이 `총 0개` 를 출력해야 합니다.

- 원래 있던 `todo.txt` 는 모든 줄이 줄바꿈 문자로 끝나고 빈 줄이 없습니다. 추가하는 줄의 끝에도 줄바꿈 문자(`\n`)를 넣습니다.
- 할 일의 양 끝에는 공백이 없고, 가운데에는 공백이 있을 수 있습니다.
- 번호 뒤에는 마침표와 공백 한 칸이 옵니다. `총` 뒤에는 공백이 한 칸 있고 숫자와 `개` 는 붙여 씁니다.
- 파일은 UTF-8 로 저장되어 있습니다. 열 때마다 `encoding="utf-8"` 을 지정하고, 추가한 뒤에는 파일을 닫고 나서 다시 엽니다.

## 입출력 예

`todo.txt` 의 내용이 아래와 같을 때

```
장보기
운동
```

입력

```
2
숙제
청소
```

출력

```
1. 장보기
2. 운동
3. 숙제
4. 청소
총 4개
```

실행 후 `todo.txt` 의 내용

```
장보기
운동
숙제
청소
```

`todo.txt` 가 없을 때

입력

```
1
책 읽기
```

출력

```
1. 책 읽기
총 1개
```

실행 후 `todo.txt` 의 내용

```
책 읽기
```
