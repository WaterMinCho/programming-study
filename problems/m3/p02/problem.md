# p02. 폴더가 없으면 만들기 (빈칸 채우기 · 4점)

폴더 이름을 한 줄로 입력받아, 현재 폴더에 그 이름의 폴더가 없으면 새로 만든 다음 그 폴더 바로 안에 들어 있는 파일과 폴더의 수를 출력하는 프로그램입니다. `os` 모듈을 사용합니다. 빈칸(`____`) 3곳을 채워 프로그램을 완성하세요.

```python
import os

name = input()
if not os.path.____(name):
    os.____(name)
    print(name, "폴더를 만들었습니다")
print("항목 수:", len(os.____(name)))
```

- 첫 번째 빈칸은 그 경로가 있는지 확인해 `True` 나 `False` 를 돌려주는 `os.path` 의 함수입니다.
- 두 번째 빈칸은 폴더(디렉터리)를 새로 만드는 `os` 모듈의 함수입니다.
- 세 번째 빈칸은 폴더 바로 안에 있는 파일과 폴더의 이름을 리스트로 돌려주는 `os` 모듈의 함수입니다.
- 폴더가 이미 있으면 새로 만들지 않고 `항목 수` 줄만 출력합니다. 안에 들어 있던 파일은 지워지지 않아야 합니다.
- 하위 폴더는 1개로 세고, 하위 폴더 안에 든 파일은 세지 않습니다.
- 입력되는 이름은 영어 소문자로만 이루어져 있고, 현재 폴더에 같은 이름의 파일은 없습니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

현재 폴더에 `backup` 폴더가 없을 때

입력

```
backup
```

출력

```
backup 폴더를 만들었습니다
항목 수: 0
```

현재 폴더에 `photos` 폴더가 있고, 그 안에 파일 `a.png`, `b.png` 와 폴더 `raw` 가 있으며 `raw` 안에 `c.png` 가 있을 때

입력

```
photos
```

출력

```
항목 수: 3
```
