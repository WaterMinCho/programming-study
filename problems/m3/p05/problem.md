# p05. DFS 로 k번째에 방문하는 노드 (반환값 · 6점)

그래프가 딕셔너리 `graph` 로 주어집니다. 키는 노드이고 값은 그 노드에서 바로 갈 수 있는 노드의 리스트입니다.
노드 `start` 에서 출발해 깊이 우선 탐색(DFS)으로 그래프를 탐색할 때 `k` 번째로 방문하는 노드를 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 한 노드에서 갈 수 있는 노드가 여럿이면 리스트의 **앞에 적힌 노드를 먼저** 방문합니다. 강의의 `my_dfs` 와 같은 순서입니다.
- 이미 방문한 노드는 다시 방문하지 않습니다. 그래프에는 사이클이 있을 수 있습니다.
- 시작 노드가 1번째입니다.
- 시작 노드를 포함해 방문하는 노드가 `k` 개보다 적으면 `None` 을 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줍니다.

## 제한 사항

- 노드는 1개 이상 20개 이하이고 모두 문자열입니다. 리스트에 나오는 노드는 모두 `graph` 의 키로 들어 있습니다.
- 갈 수 있는 노드가 없는 노드의 값은 빈 리스트 `[]` 입니다.
- `start` 는 `graph` 의 키 가운데 하나이고, `k` 는 1 이상 30 이하의 정수입니다.

## 입출력 예

아래 예에서 `graph` 는 모두 다음 딕셔너리입니다.

```python
{
    "A": ["B", "C"],
    "B": ["A", "D", "E"],
    "C": ["A", "F"],
    "D": ["B"],
    "E": ["B", "F"],
    "F": ["C", "E", "G"],
    "G": ["F"],
}
```

| start | k | 반환값 |
|---|---|---|
| `"A"` | `6` | `"C"` |
| `"A"` | `1` | `"A"` |
| `"A"` | `8` | `None` |
| `"D"` | `4` | `"C"` |

`"A"` 에서 출발하면 `A`, `B`, `D`, `E`, `F`, `C`, `G` 순서로 방문하고, `"D"` 에서 출발하면 `D`, `B`, `A`, `C`, `F`, `E`, `G` 순서로 방문합니다.
