# p01. 길이별로 단어 묶기 (빈칸 채우기 · 4점)

문자열 리스트 `words` 를 받아, 글자 수를 키로 하고 그 글자 수인 단어들의 리스트를 값으로 하는 딕셔너리를 **반환(return)** 하는 함수 `group_by_length` 입니다. 빈칸(`____`) 3곳을 채워 함수를 완성하세요.

```python
def group_by_length(words):
    result = {}
    for w in words:
        n = ____(w)
        if n ____ result:
            result[n] = []
        result[n].____(w)
    return result
```

- 첫 번째 빈칸은 글자 수를 구하는 내장 함수, 두 번째 빈칸은 딕셔너리에 그 키가 아직 없는지 확인하는 연산자, 세 번째 빈칸은 리스트 맨 뒤에 요소 하나를 추가하는 메서드입니다.
- 값 리스트 안의 단어는 `words` 에 나온 순서를 따르고, 같은 단어가 여러 번 나오면 나온 횟수만큼 넣습니다.
- `words` 의 길이는 0 이상 100 이하이고, 빈 리스트를 받으면 빈 딕셔너리 `{}` 를 반환합니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

| words | 반환값 |
|---|---|
| `["hi", "sun", "to", "cat"]` | `{2: ['hi', 'to'], 3: ['sun', 'cat']}` |
| `["a"]` | `{1: ['a']}` |
| `[]` | `{}` |
