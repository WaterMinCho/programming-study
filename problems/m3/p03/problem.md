# p03. 버전 번호 찾기 (반환값 · 4점)

문자열 `text` 에서 `v2.10` 처럼 생긴 버전 번호를 모두 찾아, 찾은 순서대로 담은 리스트를 **반환(return)** 하는 `solution` 함수를 완성하세요.

버전 번호는 소문자 `v` 바로 뒤에 숫자가 1개 이상, 점(`.`) 한 개, 숫자가 1개 이상 차례로 붙어 있는 부분입니다.

## 제한 사항

- `text` 는 길이가 0 이상 100 이하인 문자열입니다.
- 대문자로 시작하는 `V3.1` 은 버전 번호가 아닙니다.
- 점 자리에 다른 글자가 들어간 `v2x10`, `v2,10` 과 중간에 공백이 낀 `v 4.0`, `v4 .0` 은 버전 번호가 아닙니다.
- 점의 앞이나 뒤에 숫자가 없는 `v.5`, `v3.`, `v7` 도 버전 번호가 아닙니다.
- `v` 가 아닌 글자 뒤에 숫자와 점이 붙은 `x1.5`, `ver2.0` 은 버전 번호가 아닙니다.
- 점의 앞뒤에 붙는 숫자의 자릿수에는 제한이 없습니다. `v2024.10` 에서는 `v2024.10` 전체를 찾습니다.
- 버전 번호의 앞뒤에는 다른 글자가 공백 없이 붙어 있을 수 있습니다. `(v0.9)` 에서는 `v0.9` 를, `앱v12.34로` 에서는 `v12.34` 를 찾습니다. 문장 끝의 마침표는 버전 번호에 넣지 않으므로 `v2.1.` 에서는 `v2.1` 을 찾습니다.
- `v1.2.3` 처럼 숫자 사이에 점이 두 번 들어간 표기는 주어지지 않습니다.
- 같은 버전 번호가 여러 번 나오면 나온 횟수만큼 리스트에 넣습니다. 하나도 없으면 빈 리스트 `[]` 를 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 입출력 예

| text | 반환값 |
|---|---|
| `"v1.0 에서 v2.10 으로 올렸습니다"` | `['v1.0', 'v2.10']` |
| `"V3.1 과 v2x10 은 버전 번호가 아닙니다"` | `[]` |
| `"(v0.9) 앱v12.34로"` | `['v0.9', 'v12.34']` |
| `""` | `[]` |
