# p10. JSON 성적 파일 요약 (반환값 · 8점)

한 반의 성적이 JSON 파일에 아래와 같은 모양으로 저장되어 있습니다. `students` 는 학생 정보의 배열이고, 학생마다 이름 `name` 과 점수 배열 `scores` 가 있습니다.

```json
{
    "class": "A",
    "students": [
        {"name": "kim", "scores": [80, 90, 70]},
        {"name": "lee", "scores": []},
        {"name": "park", "scores": [100, 95]}
    ]
}
```

파일 경로 `path` 가 주어질 때, 그 파일을 읽어 아래 네 가지를 담은 **딕셔너리**를 **반환(return)** 하는 `solution` 함수를 완성하세요.

| 키 | 값 |
|---|---|
| `"class"` | 파일에 적힌 반 이름 |
| `"count"` | 학생 수. 점수가 하나도 없는 학생도 셉니다 |
| `"averages"` | 학생 이름을 키, 그 학생의 평균 점수를 값으로 하는 딕셔너리. 점수가 하나도 없는 학생은 넣지 않습니다 |
| `"best"` | 평균 점수가 가장 높은 학생의 이름. 평균이 같은 학생이 여럿이면 파일에 먼저 나온 학생. `averages` 가 비어 있으면 `None` |

`path` 의 파일이 없으면 빈 딕셔너리 `{}` 를 반환합니다.

## 제한 사항

- 파일이 있으면 그 내용은 위와 같은 모양의 올바른 JSON 입니다. 줄바꿈과 들여쓰기 없이 한 줄로 적혀 있을 수도 있고, 키의 순서가 위와 다를 수도 있습니다.
- 학생은 0명 이상 20명 이하이고 이름은 서로 다른 영어 문자열입니다. 점수는 0 이상 100 이하의 정수입니다.
- 평균은 점수의 합을 개수로 나눈 **실수**이며 반올림하지 않습니다. 점수가 `[80, 90, 70]` 이면 `80.0` 입니다.
- `averages` 의 키 순서는 파일에 학생이 나온 순서를 따릅니다.
- 없는 파일을 읽기 모드로 열면 `FileNotFoundError` 가 발생합니다. 파일을 열 때는 `encoding="utf-8"` 을 지정합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. JSON 문자열이 아니라 딕셔너리를 반환합니다.

## 입출력 예

| 파일 | 호출 | 반환값 |
|---|---|---|
| `scores.json` 의 내용이 위의 예와 같음 | `solution("scores.json")` | `{'class': 'A', 'count': 3, 'averages': {'kim': 80.0, 'park': 97.5}, 'best': 'park'}` |
| `none.json` 이라는 파일이 없음 | `solution("none.json")` | `{}` |
| `empty.json` 의 내용이 `{"class": "B", "students": [{"name": "a", "scores": []}]}` | `solution("empty.json")` | `{'class': 'B', 'count': 1, 'averages': {}, 'best': None}` |
