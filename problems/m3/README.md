# 모의고사 3회 (1~21차시)

1~21차시 전 범위에서 고른 세 번째 종합 모의고사입니다. 퀴즈 18문항(44점)과 코드 문제 10문제(56점), 총 100점이며 제한 시간은 실제 평가와 같은 120분입니다.
1회와 2회는 1~16차시만 다뤘습니다. 3회는 절반쯤을 14~21차시(정규표현식, 이터레이터, 스택과 큐, DFS·BFS, 데이터 분석 패키지, 파일 관리, JSON)에서 내고, 나머지를 1~13차시의 클래스와 상속, 예외 처리, 파일 처리, 함수, 자료구조에서 냈습니다. 개념 정리는 각 차시 세트의 README.md 에 있으므로 여기서는 응시 요령만 적습니다.

## 시작하기

```bash
python study.py start m3     # 문제를 받는 순간부터 120분을 잽니다
python study.py grade m3     # 채점 (경과 시간이 함께 표시됩니다)
```

## 구성과 배점

| 구분 | 유형 | 문항 수 | 배점 |
|---|---|---|---|
| 퀴즈 | 객관식 | 10 | 문항당 2점 |
| 퀴즈 | 출력 예측 | 6 | 문항당 3점 |
| 퀴즈 | 단답 | 2 | 문항당 3점 |
| 코드 | 빈칸 채우기 | 4 | 4점 2문제, 6점 2문제 |
| 코드 | 반환값 | 4 | 4점, 6점 2문제, 8점 |
| 코드 | 출력 | 2 | 6점 2문제 |

- 부분 점수는 없습니다. 코드 문제는 화면에 보이는 예시뿐 아니라 제출할 때 돌리는 나머지 테스트까지 모두 통과해야 점수를 받습니다.
- 18~20차시의 패키지(pandas, NumPy, scikit-learn, OpenCV 등)와 21차시의 openpyxl 은 코드를 읽고 답을 고르는 객관식으로만 나옵니다. 코드 문제는 `re`, `os`, `json` 같은 파이썬 표준 라이브러리만으로 풉니다.
- 17차시의 DFS·BFS 는 방문 순서에서 몇 번째 노드인지 적는 단답과, 탐색 함수를 직접 작성하는 반환값 문제로 나옵니다.
- 클래스를 상속해 완성하는 코드 문제는 제출할 때 부모 클래스의 메서드를 다른 함수로 바꿔 놓은 테스트도 함께 돌립니다. 부모의 메서드를 호출하지 않고 부모의 코드를 자식에 옮겨 적으면 예시는 통과해도 오답 처리됩니다.

## 실전처럼 푸는 법

- 시간을 잽니다. `start` 를 실행한 뒤에는 중간에 쉬지 않고 한 번에 끝까지 풉니다. 퀴즈에 40분, 코드 문제에 70분을 쓰고 남은 10분은 형식 검토에 씁니다.
- 퀴즈는 코드를 실행하지 않고 머릿속으로만 풉니다. 실제 평가에서는 IDE·자동완성·레퍼런스를 쓸 수 없으므로 함수, 메서드, 예외 클래스의 이름도 대소문자와 철자까지 외워서 적습니다.
- DFS·BFS 문항은 스택이나 큐에 든 값을 한 줄씩 적어 가며 따라갑니다. 어느 쪽 끝에서 꺼내는지와 인접 노드를 넣는 순서부터 확인합니다. 방문 순서는 번호나 가나다 순이 아니라 딕셔너리의 리스트에 적힌 순서를 따릅니다.
- 상속 문항은 메서드를 호출할 때마다 그 객체의 클래스에서 부모 쪽으로 올라가며 어느 클래스의 메서드가 실행되는지 표시합니다. 부모 메서드 안의 `self.메서드()` 와 `self.변수` 도 호출한 객체의 클래스부터 찾습니다.
- 예외 처리 문항은 오류가 난 줄에 표시하고 그 줄이 `try` 블록 안에 있는지부터 확인합니다. 실행되지 않은 줄을 지운 뒤 이름이 맞는 `except` 를 찾고, 그 함수에서 잡지 못한 예외는 호출한 쪽의 `try` 로 넘어간다고 보고 따라갑니다.
- JSON 문항은 문자열을 다루는 함수와 파일을 다루는 함수의 이름이 끝의 한 글자만 다르다는 점부터 확인합니다. 딕셔너리를 `print` 하면 작은따옴표로, JSON 문자열을 `print` 하면 큰따옴표로 출력됩니다.
- 패키지 객관식은 함수 이름의 철자와 대소문자, 인자의 순서, 리스트와 NumPy 배열의 출력 모양 차이를 보고 고릅니다.

## 제출 전 형식 검토

부분 점수가 없으므로 답이 맞아도 형식이 맞지 않으면 0점입니다. 제출 전에 유형별로 아래 항목을 확인합니다.

| 유형 | 확인할 것 |
|---|---|
| 출력 예측 | 띄어쓰기 한 칸, 줄 수, `True`·`False`·`None` 의 대소문자, 작은따옴표와 큰따옴표, `indent=4` 의 들여쓰기 4칸 |
| 단답 | 묻는 값 하나만 적었는지(값 앞뒤에 단위나 설명을 붙이지 않음) |
| 반환값 | `return` 으로 돌려주는지, 튜플과 리스트, 정수와 실수(`//` 와 `/`), `None` 과 빈 리스트 |
| 출력 | 예시와 글자 하나까지 같은지, `print` 의 쉼표가 넣는 공백, 마침표나 콜론 뒤의 공백 |
| 빈칸 채우기 | 빈칸이 아닌 줄을 고치거나 줄을 추가하지 않았는지 |

## 끝난 뒤 오답 정리

1. 틀린 문항은 해설을 보기 전에 한 번 더 풉니다. `python study.py explain m3 Q8` 처럼 해설은 그다음에 봅니다.
2. 틀린 이유를 '개념을 몰랐다', '코드 읽기에서 한 줄을 놓쳤다', '형식(띄어쓰기·자료형)에서 틀렸다' 중에서 골라 적습니다.
3. 개념이 원인이면 해당 차시 README.md 의 "시험에서 헷갈리기 쉬운" 항목을 다시 읽고, 코드 읽기가 원인이면 그 코드를 종이에 한 줄씩 실행해 봅니다.
4. 틀린 문항을 고친 뒤 `python study.py grade m3` 를 다시 실행해 전부 통과하는지 확인합니다. 모의고사 결과는 적응형 학습의 문항 선택에 반영되지 않으므로, 약한 개념은 해당 차시 문항으로 다시 연습합니다.
