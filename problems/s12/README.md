# 12차시 · 파일 처리

프로그램이 끝나도 데이터가 남도록 파일에 쓰고, 파일에서 읽는 방법을 배우는 차시입니다.
용어(경로·인코딩·모드)를 묻는 객관식과, `write`·`readline`·`readlines`·`read` 의 결과를 눈으로 따라가는 출력 문제가 함께 나오기 좋은 단원입니다.

## 1. 파일 개요

파일(File)은 컴퓨터에서 데이터를 저장하는 기본 단위입니다. 관련 자료의 모음에 이름을 붙인 것이며, 보통 보조기억장치(HDD·SSD·USB)에 저장되고 이름과 확장자로 식별합니다. 주간 요약본은 컴퓨터 메모리를 시스템 영역과 데이터 영역으로 나누고, 파일은 데이터 영역에 속한다고 적었습니다.

파일의 구성

| 구성 | 뜻 | 예 |
|---|---|---|
| 이름(Name) | 파일을 식별하는 문자열 | `report.txt` |
| 데이터(Data) | 파일의 내용 | 글, 이미지, 영상 |
| 메타데이터(Metadata) | 파일에 대한 정보 | 크기, 생성·수정 날짜, 접근 권한 |

파일의 분류

| | 텍스트 파일 | 바이너리 파일 |
|---|---|---|
| 저장 형태 | 사람이 읽을 수 있는 문자 | 기계가 이해하는 이진 형식 |
| 확장자 예 | `.txt` `.csv` `.html` | `.exe` `.jpg` `.mp3` |
| 내용 확인 | 텍스트 에디터로 바로 가능 | 전용 프로그램 필요 |

- 파일 시스템은 운영체제가 파일을 저장·관리·검색하는 체계입니다. 파일을 다루려면 파일 이름과 경로가 필요합니다.
- 디렉터리(폴더)는 여러 파일을 분류해 담는 공간이고, 안에 파일이나 하위 디렉터리를 둘 수 있습니다. 윈도우에는 그 위에 드라이브(`C:`)가 있습니다.

## 2. 파일 경로

| | 절대 경로 | 상대 경로 |
|---|---|---|
| 기준 | 최상위(드라이브)부터 전부 | **현재 작업 디렉터리** |
| 예 | `C:/rokey/work/data/score.txt` | `./data/score.txt`, `../a.txt` |

- `.` 은 현재 디렉터리, `..` 은 한 단계 위 디렉터리입니다.
- 현재 작업 디렉터리가 `C:/rokey/work/ch12` 일 때
  - `C:/rokey/work/ch12/data/a.txt` → `./data/a.txt` (그냥 `data/a.txt` 도 같은 파일을 가리킴)
  - `C:/rokey/work/b.txt` → `../b.txt` (한 단계 올라간 뒤 `b.txt`)
- `.` 으로 시작하는 상대 경로는 `.` 자리에 현재 작업 디렉터리를 넣으면 절대 경로가 됩니다. `./memo/todo.txt` → `C:/rokey/work/ch12/memo/todo.txt`
- 현재 작업 디렉터리 확인

```python
import os
print(os.getcwd())     # 예) C:\rokey
```

## 3. 인코딩과 디코딩

- 인코딩(Encoding)은 문자를 컴퓨터가 이해하는 바이너리로 바꾸는 것입니다. 예) `A` → 65, `a` → 97 을 이진수로.
- 디코딩(Decoding)은 반대 방향으로, 바이너리를 사람이 읽는 문자로 되돌립니다.

| 이름 | 설명 |
|---|---|
| ASCII | 미국에서 표준화한 정보 교환용 7비트 부호 체계 |
| 유니코드(Unicode) | 모든 문자를 다루도록 설계된 국제 표준(16·32비트 문자 체계) |
| CP949 | 윈도우의 한글 인코딩(확장 완성형). `MS949`, `WINDOWS949` 라고도 부름. EUC-KR 의 문제를 보완 |
| UTF-8 | 유니코드를 인코딩하는 방식 중 하나 |

- 파이썬은 운영체제의 기본 방식으로 인코딩합니다. 윈도우의 기본은 CP949 이고 VSCode 의 기본은 UTF-8 이라서, CP949 로 저장된 파일을 VSCode 로 열면 한글이 깨져 보일 수 있습니다.
- 기본값이 아닌 방식으로 읽고 쓰려면 `open()` 에 지정합니다. 쓸 때 지정한 인코딩과 읽을 때 지정한 인코딩이 같아야 한글이 깨지지 않습니다.

```python
f = open("memo.txt", "w", encoding="utf-8")
```

## 4. 파일 열기: `open()` 과 모드

```python
f = open("경로/파일이름", "모드")      # 파일 객체를 돌려줍니다
```

| 모드 | 이름 | 파일이 있을 때 | 파일이 없을 때 |
|---|---|---|---|
| `"r"` | 읽기 | 처음부터 읽음 | 오류(FileNotFoundError) |
| `"w"` | 쓰기 | 기존 내용을 지우고 새로 씀 | 새 파일 생성 |
| `"a"` | 추가 | 기존 내용 뒤에 이어 씀 | 새 파일 생성 |

- 모드를 생략하면 `"r"` 입니다. `open("a.txt")` 는 `open("a.txt", "r")` 과 같습니다.
- `"w"` 는 `open()` 을 실행하는 순간 파일을 비웁니다. `write()` 를 한 번도 부르지 않고 닫아도 빈 파일이 남습니다.
- 파일 객체의 메서드(`write`, `read`, `close` …)로 파일을 다룹니다.

## 5. 파일 닫기: `close()`

```python
f = open("memo.txt", "w")
f.write("hello")
f.close()          # 자원 반환. 닫은 뒤에는 읽기·쓰기 모두 오류(ValueError)
```

쓰기 모드로 열었다면 닫아야 내용이 안전하게 파일에 반영됩니다. `close()` 는 파일을 닫을 뿐이고 파일을 지우지 않습니다.

## 6. 파일에 쓰기: `write()`

```python
f = open("memo.txt", "w")
n = f.write("rokey")        # 반환값 5 = 저장한 글자 수
f.write("11")               # 줄바꿈이 자동으로 붙지 않음 → 파일 내용은 rokey11
f.close()
```

- `write()` 는 문자열만 받습니다. `f.write(100)` 은 TypeError 이고, 숫자는 `str(100)` 이나 `"%d" % 100` 으로 바꿔서 씁니다.
- `print()` 와 달리 줄바꿈을 붙여 주지 않습니다. 줄을 나누려면 `"\n"` 을 직접 넣습니다.
- 반환값: 강의 자료는 "저장된 문자의 바이트 수"라고 적었고, 실제로 실행하면 쓴 글자 수가 나옵니다. 영문·숫자만 쓰면 두 값이 같습니다(`"rokey"` → 5).
- 반복문으로 여러 줄 쓰기(강의 예제 패턴)

```python
f = open("lines.txt", "w")
for i in range(1, 4):
    f.write("%d번째 줄\n" % i)      # 1번째 줄 / 2번째 줄 / 3번째 줄
f.close()
```

`%d` 자리에는 정수, `%s` 자리에는 문자열이 들어갑니다. 값이 둘 이상이면 `"%s %d개\n" % (name, count)` 처럼 괄호로 묶어 넘깁니다. `f"{name} {count}개\n"` 으로 써도 같은 문자열이 만들어집니다.

## 7. 파일 읽기: `readline()` · `readlines()` · `read()`

`lines.txt` 의 내용이 `"a\nb\nc\n"` 일 때

| 메서드 | 돌려주는 것 | 결과 |
|---|---|---|
| `f.readline()` | 한 줄을 문자열로. 끝의 `\n` 포함 | `'a\n'` (한 번 더 부르면 `'b\n'`) |
| `f.readlines()` | 모든 줄을 요소로 갖는 리스트 | `['a\n', 'b\n', 'c\n']` |
| `f.read()` | 내용 전체를 문자열 하나로 | `'a\nb\nc\n'` |

- 읽은 줄 끝에는 `\n` 이 들어 있어서 `print(line)` 은 빈 줄을 하나 더 만듭니다. 강의 예제처럼 `print(line, end='')` 로 출력하면 파일에 적힌 모양대로 나옵니다.
- 마지막 줄이 `\n` 없이 끝나면 그 요소에만 `\n` 이 없습니다: `"1\n2\n3"` → `['1\n', '2\n', '3']`
- 리스트를 통째로 `print` 하면 `\n` 은 글자 `\n` 으로 보입니다.
- 줄 수는 `len(f.readlines())`, 글자 수는 `len(f.read())` 입니다. `len('a\n')` 은 `\n` 까지 세어 2 입니다.
- 빈 파일에서 `readlines()` 는 `[]`, `read()` 와 `readline()` 은 `''` 를 돌려줍니다.

```python
f = open("lines.txt", "r")
lines = f.readlines()
for line in lines:
    print(line, end='')
f.close()
```

읽기 메서드는 앞에서 읽은 곳 다음부터 읽습니다. 한 파일 객체에서 메서드를 섞어 부르면 뒤의 메서드는 남은 부분만 받습니다.

```python
f = open("lines.txt", "r")      # 내용: a / b / c
first = f.readline()            # 'a\n'
rest = f.readlines()            # ['b\n', 'c\n']  남은 두 줄
more = f.read()                 # ''              끝까지 읽은 뒤라 빈 문자열
f.close()
```

파일을 닫고 다시 열면 처음부터 읽습니다.

## 8. 파일 내용 추가: `"a"` 모드

```python
f = open("lines.txt", "a")      # 기존 내용 유지
f.write("d\n")                  # 맨 끝에 추가
f.close()
```

같은 파일을 `"w"` 로 다시 열면 이전 내용은 모두 사라집니다. 반복문 안에서 매번 `"w"` 로 열어 쓰면 마지막에 쓴 내용만 남고, `"a"` 로 열어 쓰면 쓴 내용이 차례로 쌓입니다.

## 9. 자동으로 닫기: `with … as`

```python
with open("memo.txt", "w") as f:     # 블록이 끝나면 자동으로 f.close()
    f.write("first line")
    print(f.closed)                  # False (아직 블록 안)
print(f.closed)                      # True  (블록을 나오며 닫힘)
```

- `with` 를 쓰는 이유는 파일을 자동으로 닫기 위해서입니다. `close()` 를 적지 않아도 되고, 블록 중간에 오류가 나도 닫힙니다.
- 블록 밖에서도 변수 `f` 는 남아 있지만 닫힌 파일이라 `f.read()` 등은 오류입니다.
- `with` 로 열 때도 모드를 생략하면 읽기 모드로 열립니다. 쓰기와 읽기 모두 `with` 로 쓸 수 있습니다.

```python
with open("memo.txt", "r") as f:
    data = f.read()
print(data)
```

`with` 블록이 끝나면 파일 객체만 닫히므로, 블록 안에서 읽어 둔 문자열이나 리스트는 블록 밖에서도 쓸 수 있습니다.

## 10. 읽은 줄을 리스트·딕셔너리로 옮기기

강의 연습 문제(계좌 파일을 읽어 리스트·딕셔너리로 저장)와 차시 과제(피자 목록을 리스트로)에 나온 형태입니다. 파일에서 읽은 값은 모두 문자열이므로, 줄을 나누고 숫자는 `int()` 로 바꿉니다.

```python
# fruit.txt 의 내용:  사과 1200 / 배 3000 / 귤 500   (한 줄에 "이름 가격")
names = []
prices = {}
with open("fruit.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()
for line in lines:
    parts = line.split()             # '사과 1200\n' → ['사과', '1200']
    names.append(parts[0])
    prices[parts[0]] = int(parts[1])

print(names)      # ['사과', '배', '귤']
print(prices)     # {'사과': 1200, '배': 3000, '귤': 500}
```

- 인수 없는 `split()` 은 공백과 줄바꿈을 기준으로 나누므로 줄 끝의 `\n` 이 결과에 남지 않습니다. `split()` 은 13차시에서 다시 다룹니다.
- `int("1200\n")` 처럼 줄바꿈이 붙은 문자열도 `int()` 는 정수로 바꿉니다. 한 줄에 숫자 하나만 있는 파일은 `int(line)` 으로 바로 더할 수 있습니다.
- 숫자를 비교하거나 더하기 전에 `int()` 로 바꾸지 않으면 문자열끼리 비교·연결됩니다. `"10000" <= "5000"` 은 글자 순서로 비교해 `True` 입니다.
- 같은 키에 다시 대입하면 나중 값이 남습니다(4차시 딕셔너리).

## 11. 클래스 안에서 파일 다루기

메서드 안에서도 `open()` 을 똑같이 씁니다. 경로를 인스턴스 변수에 저장해 두고, 메서드마다 열고 닫습니다.

```python
class Counter:
    mode = "w"                           # 클래스 변수

    def __init__(self, path):
        self.path = path

    def record(self, n):
        f = open(self.path, self.mode)   # self.mode 는 객체의 클래스에서 먼저 찾음
        f.write("%d\n" % n)
        f.close()


class History(Counter):                  # 상속
    mode = "a"                           # 클래스 변수만 다시 선언


c = Counter("c.txt")
h = History("h.txt")
for n in [1, 2, 3]:
    c.record(n)
    h.record(n)
# c.txt 에는 3 한 줄만 남고, h.txt 에는 1, 2, 3 세 줄이 쌓입니다.
```

- `record()` 는 부모에만 있지만 `h.record(n)` 안의 `self.mode` 는 `History` 의 `"a"` 를 읽습니다(10차시: 자식이 다시 선언한 클래스 변수).
- 자식이 메서드를 재정의하면서 파일에 쓰는 일은 부모에게 맡기려면 `super().record(...)` 처럼 부모 메서드를 부릅니다.
- 부모의 `__init__` 이나 다른 메서드 안에서 `self.record(...)` 를 부르면, 객체가 자식 클래스로 만들어졌을 때 자식이 재정의한 `record` 가 실행됩니다(10차시: 메서드를 찾는 순서). 부모는 `"w"`, 자식은 `"a"` 로 여는 코드라면 같은 호출이라도 객체에 따라 파일에 남는 줄 수가 달라집니다.
- 생성자에서 `open(self.path, "w")` 후 바로 닫으면 빈 파일이 만들어집니다. 그 뒤의 메서드는 `"a"` 로 열어야 앞서 쓴 줄이 남습니다.

## 시험에서 헷갈리기 쉬운 포인트

- 모드 기본값은 `"r"` 입니다. 없는 파일을 `"r"` 로(또는 모드 없이) 열면 FileNotFoundError 가 나고, `"w"`, `"a"` 는 없으면 만들어 줍니다.
- `"w"` 는 덮어쓰기입니다. 파일이 이미 있으면 내용이 전부 삭제된 뒤 새로 쓰이며, 뒤에 붙이는 것은 `"a"` 입니다.
- `write()` 는 줄바꿈을 붙이지 않습니다. `f.write("a"); f.write("b")` 의 결과는 `ab` 이고, 줄을 바꾸려면 `"\n"` 을 직접 넣습니다.
- `write()` 는 문자열만 받습니다. 숫자를 쓰려면 `str()` 또는 `%d` 포맷을 거치고, 반환값은 쓴 글자 수입니다(화면에 출력되는 값이 아님).
- 읽은 줄 끝에는 `\n` 이 들어 있습니다. `print(line)` 은 빈 줄이 하나 더 생기고, `print(line, end='')` 는 파일에 적힌 모양대로 출력합니다.
- `readline()` 은 문자열 한 줄, `readlines()` 는 리스트, `read()` 는 문자열 전체입니다. `s` 하나 차이로 자료형이 달라집니다.
- `readline()` 을 두 번 부르면 다음 줄이 나옵니다(읽은 위치가 앞으로 이동). `readline()` 뒤의 `readlines()` 는 남은 줄만 담고, 파일 끝에서는 `readline()` 과 `read()` 가 빈 문자열 `''` 을 돌려줍니다.
- 닫은 파일에 `write`·`read` 를 하면 ValueError 가 납니다. `with` 블록을 나온 뒤에도 같은 오류가 납니다.
- `with` 블록이 끝나면 자동으로 닫힙니다. 블록 안에서 `f.closed` 는 `False`, 밖에서는 `True` 입니다.
- `with` 를 쓰는 주된 이유는 파일을 자동으로 닫기 위해서입니다(속도·오류 방지가 아님).
- `..` 은 상위 폴더, `.` 은 현재 폴더이며, 상대 경로의 기준은 현재 작업 디렉터리(`os.getcwd()`)입니다.
- 인코딩과 디코딩의 방향을 바꿔 묻는 보기, "파이썬은 항상 UTF-8 로 저장한다" 같은 보기는 틀린 설명입니다(운영체제 기본 방식을 따르며, 윈도우는 CP949).
- `.jpg`·`.mp3`·`.exe` 는 바이너리 파일이라 텍스트 에디터로 내용을 읽을 수 없습니다.
- 파일에서 읽은 숫자는 문자열입니다. 더하거나 크기를 비교하기 전에 `int()` 로 바꿉니다.
