# p02. 작업 로그 추가하기 (빈칸 채우기 · 4점)

`log.txt` 에 `start` 한 줄을 쓴 뒤, 파일을 다시 열어 작업 완료 메시지 세 줄을 기존 내용 뒤에 추가하고, 마지막으로 파일 전체를 읽어 출력하는 프로그램입니다.
빈칸(`____`) 3곳을 채워 프로그램을 완성하세요.

- 두 번째 `open` 은 `start` 줄이 남아 있도록 추가 모드로 엽니다.
- 반복문은 `1번 작업 완료`, `2번 작업 완료`, `3번 작업 완료` 를 한 줄씩 씁니다.
- 쓰기가 끝나면 파일을 닫습니다.
- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

```python
f = open("log.txt", "w")
f.write("start\n")
f.close()

f = open("log.txt", ____)
for i in range(1, 4):
    f.write("%d번 작업 완료\n" % ____)
f.____()

f = open("log.txt", "r")
print(f.read(), end="")
f.close()
```

## 출력 예

```
start
1번 작업 완료
2번 작업 완료
3번 작업 완료
```

실행이 끝난 뒤 `log.txt` 의 내용도 위와 같아야 합니다.
