# p14. 11번째 줄 추가하기 (출력 · 4점)

현재 폴더에 `data.txt` 가 이미 있습니다. 이 파일에 `11번째 줄입니다.` 한 줄을 `a` 모드로 추가한 뒤, 파일 내용 전체를 읽어 출력하는 프로그램을 작성하세요.

- `data.txt` 는 UTF-8 로 저장되어 있습니다. 열 때마다 `encoding="utf-8"` 을 지정합니다.
- 기존 내용은 그대로 두고 맨 끝에 `11번째 줄입니다.` 를 추가합니다(줄 끝에 줄바꿈 문자 `\n` 포함).
- 추가가 끝나면 `data.txt` 를 읽기 모드로 열어 내용 전체를 그대로 출력합니다.
- `data.txt` 에 적힌 줄 수는 테스트마다 다릅니다. 파일에 무엇이 있든 그 뒤에 한 줄을 붙입니다.

## 입출력 예

`data.txt` 에 `1번째 줄입니다.` 부터 `10번째 줄입니다.` 까지 열 줄이 적혀 있을 때의 출력(그리고 실행 후 `data.txt` 의 내용)

```
1번째 줄입니다.
2번째 줄입니다.
3번째 줄입니다.
4번째 줄입니다.
5번째 줄입니다.
6번째 줄입니다.
7번째 줄입니다.
8번째 줄입니다.
9번째 줄입니다.
10번째 줄입니다.
11번째 줄입니다.
```

`data.txt` 에 `1번째 줄입니다.`, `2번째 줄입니다.` 두 줄만 적혀 있을 때의 출력

```
1번째 줄입니다.
2번째 줄입니다.
11번째 줄입니다.
```
