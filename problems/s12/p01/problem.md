# p01. 메뉴 파일 쓰고 읽기 (빈칸 채우기 · 4점)

메뉴 두 개를 `menu.txt` 파일에 쓴 다음, 그 파일을 다시 읽어 화면에 출력하는 프로그램입니다.
빈칸(`____`) 3곳을 채워 프로그램을 완성하세요.

- 첫 번째 `open` 은 쓰기 모드로 엽니다. `menu.txt` 가 이미 있어도 기존 내용은 지우고 새로 씁니다.
- 두 번째 `open` 은 읽기 모드로 열고, 파일 내용 전체를 문자열 하나로 읽어 `data` 에 담습니다.
- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

```python
with open("menu.txt", ____, encoding="utf-8") as f:
    f.write("김밥\n")
    f.write("라면\n")

with open("menu.txt", ____, encoding="utf-8") as f:
    data = f.____()

print(data, end="")
```

## 출력 예

```
김밥
라면
```

실행이 끝난 뒤 `menu.txt` 의 내용도 위와 같아야 합니다.

`menu.txt` 에 `비빔밥`, `돈가스` 두 줄이 이미 적혀 있는 상태에서 실행해도 출력과 파일 내용은 위와 같아야 합니다.
