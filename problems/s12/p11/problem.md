# p11. 걸음 수 기록하기 (출력 · 6점)

며칠 동안의 걸음 수를 입력받아 `steps.txt` 파일에 기록하고, 마지막 줄에 합계를 적은 뒤, 파일을 다시 읽어 화면에 출력하는 프로그램을 작성하세요.

- 입력의 첫째 줄은 기록할 날 수 `n`(1 이상의 정수)이고, 이어지는 `n` 줄에 하루 걸음 수(0 이상의 정수)가 하나씩 들어옵니다.
- `steps.txt` 는 현재 폴더에 쓰기 모드로 만들고 `encoding="utf-8"` 로 엽니다. `steps.txt` 가 이미 있으면 기존 내용은 지우고 새로 씁니다.
- 입력받은 순서대로 한 줄에 하루씩 `1일차 4200` 형식으로 씁니다(`일차` 뒤에 공백 한 칸). 날짜 번호는 1부터 시작합니다.
- 그다음 줄에 `합계 13500` 형식으로 걸음 수의 합을 씁니다(`합계` 뒤에 공백 한 칸).
- 모든 줄 끝에 줄바꿈 문자(`\n`)를 넣습니다.
- 쓰기를 마친 뒤 `steps.txt` 를 읽기 모드로 열어 내용 전체를 출력합니다.

## 입출력 예

| 입력 | 출력 |
|---|---|
| `3`⏎`4200`⏎`6100`⏎`3200` | `1일차 4200`⏎`2일차 6100`⏎`3일차 3200`⏎`합계 13500` |
| `1`⏎`0` | `1일차 0`⏎`합계 0` |

(⏎ 는 줄바꿈을 뜻합니다)

첫 번째 예의 출력(그리고 실행 후 `steps.txt` 의 내용)

```
1일차 4200
2일차 6100
3일차 3200
합계 13500
```
