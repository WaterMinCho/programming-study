# p13. n번째 줄 파일 쓰고 읽기 (빈칸 채우기 · 4점)

다음 작업을 하는 프로그램입니다. 빈칸(`____`) 3곳을 채워 프로그램을 완성하세요.

1. `data.txt` 파일을 쓰기 모드(`w` 모드)로 엽니다. `data.txt` 가 이미 있어도 기존 내용은 지우고 새로 씁니다.
2. 1부터 10까지의 숫자를 `n번째 줄입니다.` 형식으로 한 줄씩 파일에 저장합니다.
3. 파일을 읽기 모드(`r` 모드)로 열고 모든 내용을 출력합니다.

- 첫 번째와 세 번째 빈칸은 따옴표 안에 있습니다. 따옴표 안에 들어갈 글자만 적습니다.
- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

```python
with open("data.txt", '____', encoding='utf-8') as file:
    for i in range(1, 11):
        file.____(f"{i}번째 줄입니다.\n")

print('파일이 성공적으로 작성되었습니다.')

with open("data.txt", "____", encoding='utf-8') as file:
    contents = file.read()

print('파일내용:')
print(contents)
```
