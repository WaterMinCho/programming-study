# p08. 주문 내역 추가하기 (출력 · 6점)

현재 폴더에 지금까지의 주문이 적힌 `order.txt` 가 이미 있습니다. 새 주문 하나를 입력받아 파일 끝에 추가한 뒤, 파일 전체를 읽어 화면에 출력하는 프로그램을 작성하세요.

- 입력은 세 줄입니다: 첫째 줄 메뉴 이름, 둘째 줄 가격(정수), 셋째 줄 수량(정수).
- 추가하는 줄의 형식은 다음과 같습니다(괄호·공백·`x` 위치를 그대로 지킵니다). 합계는 가격 × 수량입니다.

  ```
  - 메뉴이름 (가격원) x 수량 합계원
  ```

- 기존 내용은 그대로 두고 그 뒤에 한 줄을 추가해야 합니다(줄 끝에 줄바꿈 포함).
- 추가가 끝나면 `order.txt` 를 다시 읽어 내용 전체를 그대로 출력합니다.

## 입출력 예

`order.txt` 의 내용이 다음과 같을 때

```
주문 내역:
- 김밥 (3000원) x 2 6000원
```

| 입력 | 출력 |
|---|---|
| `라면`⏎`4000`⏎`1` | `주문 내역:`⏎`- 김밥 (3000원) x 2 6000원`⏎`- 라면 (4000원) x 1 4000원` |

출력(그리고 실행 후 `order.txt` 의 내용)

```
주문 내역:
- 김밥 (3000원) x 2 6000원
- 라면 (4000원) x 1 4000원
```
