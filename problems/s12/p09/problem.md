# p09. 할 일 목록 합치기 (출력 · 8점)

현재 폴더에 오전 할 일이 적힌 `morning.txt` 와 오후 할 일이 적힌 `evening.txt` 가 이미 있습니다. 두 파일의 줄을 오전, 오후 순서로 이어 붙이고, 각 줄 앞에 `1. `, `2. `, … 처럼 이어지는 번호를 붙여 `all.txt` 파일에 쓴 다음, `all.txt` 를 다시 읽어 화면에 출력하는 프로그램을 작성하세요.

- 두 파일 모두 한 줄에 할 일 하나이며, 모든 줄은 줄바꿈 문자로 끝납니다. 파일 중 하나가 비어 있을 수 있습니다.
- 번호는 1부터 시작해 두 파일에 걸쳐 끊기지 않고 이어집니다.
- 각 줄의 형식은 `번호. 내용` 입니다(마침표 뒤 공백 한 칸).
- `all.txt` 는 쓰기 모드로 새로 만들며, 각 줄 끝에 줄바꿈이 있어야 합니다.
- 다 쓴 뒤 `all.txt` 를 읽어 내용 전체를 그대로 출력합니다.

## 입출력 예

`morning.txt`

```
스트레칭
독서
```

`evening.txt`

```
산책
```

출력(그리고 실행 후 `all.txt` 의 내용)

```
1. 스트레칭
2. 독서
3. 산책
```
