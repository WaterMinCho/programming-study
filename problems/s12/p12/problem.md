# p12. 일지와 번호 일지 (출력 · 8점)

텍스트 파일에 한 줄씩 기록을 남기는 `Journal` 클래스와, 이를 **상속받아** 줄마다 번호를 붙여 기록하는 `NumberedJournal` 클래스를 정의하세요.

## Journal 클래스

1. **생성자** `Journal(path)`: 파일 경로를 인스턴스 변수 `path` 에 저장하고, 그 파일을 내용이 없는 빈 파일로 만듭니다. 같은 이름의 파일이 이미 있으면 기존 내용은 지워집니다.
2. **`add(text)`**: 파일의 맨 끝에 `text` 한 줄을 추가합니다(줄 끝에 줄바꿈 문자 `\n` 포함). 앞서 추가한 줄은 파일에 남아 있어야 합니다.
3. **`count()`**: 파일에 적힌 줄 수를 정수로 **반환**합니다. 기록이 없으면 `0` 입니다.
4. **`show()`**: 파일 내용 전체를 읽어 화면에 출력합니다. 읽은 내용에 줄바꿈이 이미 들어 있으므로 빈 줄이 더 생기지 않게 `end=""` 로 출력합니다. 기록이 없으면 아무것도 출력하지 않습니다.

## NumberedJournal 클래스 (Journal 상속)

1. **`add(text)`** 를 재정의합니다. 지금까지 적힌 줄 수에 1 을 더한 번호를 붙여 `번호. text` 형식(마침표 뒤 공백 한 칸)의 한 줄을 추가합니다. 파일에 쓰는 일은 부모의 `add()` 를 `super()` 로 불러서 처리합니다.
2. 생성자, `count()`, `show()` 는 재정의하지 않습니다(부모의 것을 그대로 씁니다).

- 파일은 열 때마다 `encoding="utf-8"` 을 지정합니다.
- 클래스만 정의하면 됩니다. 채점할 때는 아래와 같은 테스트 코드가 객체를 만들어 메서드를 호출합니다.

## 테스트 코드와 출력 예

```python
j = Journal("day.txt")
j.add("운동")
j.add("독서")
j.show()
print(j.count())
```

```
운동
독서
2
```

실행 후 `day.txt` 의 내용은 `운동`, `독서` 두 줄입니다.

```python
n = NumberedJournal("todo.txt")
n.add("장보기")
n.add("청소")
n.add("빨래")
n.show()
```

```
1. 장보기
2. 청소
3. 빨래
```

실행 후 `todo.txt` 의 내용도 위 세 줄과 같습니다.

`old.txt` 에 `지난 기록` 한 줄이 이미 적혀 있을 때

```python
j = Journal("old.txt")
print(j.count())
j.add("새 기록")
j.show()
```

```
0
새 기록
```

- 출력은 글자 하나까지 같아야 합니다.
