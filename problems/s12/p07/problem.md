# p07. 준비물 파일 만들기 (출력 · 4점)

리스트 `items` 에 들어 있는 준비물을 `items.txt` 파일에 한 줄에 하나씩 쓴 다음, 그 파일을 다시 읽어 내용을 화면에 출력하는 프로그램을 작성하세요.

- 파일 이름은 `items.txt`, 현재 폴더에 만듭니다. `encoding="utf-8"` 로 엽니다.
- 리스트의 순서대로 쓰고, 각 줄 끝에는 줄바꿈 문자(`\n`)를 넣습니다.
- 쓰기를 마친 뒤 파일을 읽기 모드로 열어 내용 전체를 읽고, 아래 출력 예와 똑같이 출력합니다.
- 시작 코드의 `items` 줄은 그대로 두고 그 아래에 작성합니다.

## 출력 예

```
연필
지우개
공책
```

실행이 끝난 뒤 `items.txt` 의 내용도 위와 같아야 합니다(세 줄, 각 줄 끝에 줄바꿈).
