# p10. 예산 안의 메뉴 고르기 (반환값 · 6점)

한 줄에 `메뉴 가격` 형식(공백 하나로 구분)으로 적힌 텍스트 파일의 경로 `path` 와 예산 `budget` 이 주어질 때, 가격이 `budget` **이하**인 메뉴의 이름을 파일에 적힌 순서대로 담은 리스트를 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 파일은 현재 폴더에 이미 만들어져 있고 UTF-8 로 저장되어 있습니다. `encoding="utf-8"` 로 엽니다.
- 가격과 `budget` 은 0 이상의 정수입니다. 가격이 `budget` 과 같은 메뉴도 리스트에 넣습니다.
- 리스트에는 메뉴 이름만 문자열로 넣습니다. 가격이나 줄바꿈 문자가 섞이면 오답입니다.
- 조건에 맞는 메뉴가 없거나 빈 파일이면 빈 리스트 `[]` 를 반환합니다.
- 마지막 줄 끝에 줄바꿈이 없을 수도 있습니다.
- 힌트: 문자열의 `split()` 메서드는 공백(줄바꿈 포함)을 기준으로 문자열을 나눠 리스트로 돌려줍니다.
  `"라면 4500\n".split()` → `['라면', '4500']`
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 입출력 예

`menu.txt` 의 내용이 다음과 같을 때

```
김밥 3500
라면 4500
돈가스 9000
우동 5000
```

| 호출 | 반환값 |
|---|---|
| `solution("menu.txt", 5000)` | `['김밥', '라면', '우동']` |
| `solution("menu.txt", 3000)` | `[]` |
| `solution("menu.txt", 10000)` | `['김밥', '라면', '돈가스', '우동']` |
