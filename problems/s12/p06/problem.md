# p06. 점수표를 딕셔너리로 (반환값 · 8점)

한 줄에 `이름 점수` 형식(공백 하나로 구분)으로 적힌 텍스트 파일의 경로 `path` 가 주어질 때, 이름을 키, 점수(정수)를 값으로 하는 딕셔너리를 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 파일은 현재 폴더에 이미 만들어져 있습니다.
- 점수는 문자열이 아니라 정수(`int`)로 저장합니다.
- 같은 이름이 여러 줄에 나오면 나중에 나온 점수가 남습니다.
- 빈 파일이면 빈 딕셔너리 `{}` 를 반환합니다.
- 힌트: 문자열의 `split()` 메서드는 공백(줄바꿈 포함)을 기준으로 문자열을 나눠 리스트로 돌려줍니다.
  `"민수 90\n".split()` → `['민수', '90']`
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 입출력 예

| 파일 내용 | 반환값 |
|---|---|
| `민수 90`⏎`지영 85`⏎ | `{'민수': 90, '지영': 85}` |
| `현우 100` | `{'현우': 100}` |
| `민수 90`⏎`민수 70`⏎ | `{'민수': 70}` |

(⏎ 는 줄바꿈을 뜻합니다)
