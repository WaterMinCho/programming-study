# p07. 지도 입력받기 (빈칸 채우기 · 6점)

지도의 세로 크기(행의 수) `n` 과 가로 크기(열의 수) `m`, 그리고 길(0)과 벽(1)을 나타내는 숫자를 입력받아 2차원 리스트 `graph` 를 만들고 출력하는 프로그램입니다.
빈칸(`____`) 3곳을 채워 프로그램을 완성하세요. 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

입력

- 첫 줄에 세로 크기 `n`, 둘째 줄에 가로 크기 `m`
- 다음 `n` 줄에 지도의 가로 한 줄씩. 한 줄에는 0 또는 1 이 공백으로 구분되어 `m` 개 들어옵니다.

출력

- 지도의 가로 한 줄을 정수 리스트 모양으로 한 줄에 하나씩 출력합니다.
- 마지막 줄에 `세로 n 가로 m` 형식으로 크기를 출력합니다. `n` 과 `m` 자리에는 입력받은 숫자가 들어갑니다.

```python
n = int(input())
m = int(input())
```
