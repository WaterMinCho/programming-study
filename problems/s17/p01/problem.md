# p01. 인접 노드와 차수 (빈칸 채우기 · 4점)

- 인접 여부는 `True` 또는 `False` 로 출력합니다.
- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
