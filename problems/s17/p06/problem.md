# p06. 엣지 목록으로 그래프 만들기 (반환값 · 6점)

노드가 `1` 번부터 `n` 번까지 있는 무방향 그래프의 엣지 목록 `edges` 가 주어집니다. `edges` 의 요소는 엣지 하나가 잇는 두 노드를 담은 튜플 `(a, b)` 입니다.
이 그래프를 키는 노드, 값은 그 노드와 연결된 노드의 리스트인 딕셔너리로 만들어 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 무방향 그래프이므로 엣지 `(a, b)` 는 `a` 의 리스트에 `b` 를, `b` 의 리스트에 `a` 를 넣습니다.
- 리스트 안의 순서는 `edges` 에 엣지가 나온 순서를 따릅니다.
- 엣지가 하나도 없는 노드도 키로 넣고 값은 빈 리스트 `[]` 로 둡니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줍니다.

## 제한 사항
- 1 ≤ n ≤ 20
- `edges` 의 길이는 0 이상 50 이하이고, 같은 엣지가 두 번 나오지 않습니다.

## 입출력 예

| n | edges | 반환값 |
|---|---|---|
| 5 | `[(1, 2), (1, 3), (1, 5), (2, 3), (3, 4), (4, 5)]` | `{1: [2, 3, 5], 2: [1, 3], 3: [1, 2, 4], 4: [3, 5], 5: [1, 4]}` |
| 3 | `[]` | `{1: [], 2: [], 3: []}` |
| 4 | `[(3, 4)]` | `{1: [], 2: [], 3: [4], 4: [3]}` |
