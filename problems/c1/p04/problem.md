# p04. 짝수 자릿수 세기 (반환값 · 4점)

## 문제 설명

0 이상의 정수 `n` 을 십진수로 썼을 때 **짝수인 자릿수**(0, 2, 4, 6, 8)가 몇 개인지 세어 **반환(return)** 하는 `solution` 함수를 완성하세요.

예를 들어 `2024` 의 자릿수는 2, 0, 2, 4 이고 넷 다 짝수이므로 4 를 반환합니다.

- 0 은 짝수입니다. `n` 이 `0` 이면 자릿수가 `0` 하나이므로 1 을 반환합니다.
- 반환값은 **정수(int)** 입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항

- `n` 은 0 이상 1,000,000,000 이하의 정수입니다.

## 입출력 예

| n | result |
|---|---|
| `2024` | `4` |
| `1357` | `0` |
| `10` | `1` |
| `0` | `1` |

## 입출력 예 설명

입출력 예 #1
네 자릿수 2, 0, 2, 4 가 모두 짝수라 4 를 반환합니다.

입출력 예 #2
1, 3, 5, 7 중 짝수는 하나도 없습니다.

입출력 예 #3
자릿수 1 은 홀수, 0 은 짝수이므로 1 입니다.

입출력 예 #4
`0` 은 자릿수가 한 개이고 그 값 0 이 짝수이므로 1 을 돌려줘야 합니다. 반복문이 `n` 이 0 보다 클 때만 돌도록 짜면 이 경우 0 이 나와 틀립니다.
