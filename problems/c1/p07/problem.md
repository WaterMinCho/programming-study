# p07. 최고 기록의 위치 (반환값 · 6점)

## 문제 설명

로봇 달리기 대회에서 각 로봇이 기록한 점수가 출전 순서대로 정수 리스트 `records` 에 담겨 있습니다. **가장 높은 점수**를 받은 로봇이 **몇 번째 인덱스**인지 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 인덱스는 0 부터 셉니다. 첫 번째 로봇의 인덱스는 0 입니다.
- 가장 높은 점수가 여러 번 나오면 **가장 먼저 나온 위치**를 반환합니다.
- 반환값은 점수가 아니라 **인덱스(int)** 입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항

- `records` 에는 점수가 1개 이상 100개 이하로 들어 있습니다.
- 각 점수는 -100 이상 100 이하의 정수입니다. 음수 점수가 있을 수 있습니다.

## 입출력 예

| records | result |
|---|---|
| `[4, 9, 2, 9]` | `1` |
| `[7]` | `0` |
| `[3, 3, 3]` | `0` |
| `[-5, -2, -9]` | `1` |

## 입출력 예 설명

입출력 예 #1
가장 높은 점수 9 는 인덱스 1 과 3 에 있습니다. 먼저 나온 인덱스 1 을 반환합니다.

입출력 예 #2
로봇이 하나뿐이면 그 로봇의 인덱스 0 을 돌려줍니다.

입출력 예 #3
모든 점수가 같으면 가장 먼저 나온 인덱스 0 입니다.

입출력 예 #4
모두 음수일 때 가장 높은 점수는 -2 이고, 그 위치는 인덱스 1 입니다. 최댓값을 0 에서 시작하면 어떤 점수도 0 보다 크지 않아 갱신이 일어나지 않고 0 을 돌려주게 되어 틀립니다.
