# p03. 전시회 입장료 (반환값 · 4점)

## 문제 설명

로봇 전시회의 입장료는 나이에 따라 다음과 같이 정해집니다.

| 나이 | 입장료 |
|---|---|
| 7세 이하 | 0원 |
| 8세 이상 13세 이하 | 5000원 |
| 14세 이상 64세 이하 | 12000원 |
| 65세 이상 | 6000원 |

관람객의 나이 `age` 가 주어질 때, 입장료를 정수로 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 반환값은 **정수(int)** 입니다. `"5000원"` 같은 문자열을 돌려주면 오답입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항

- `age` 는 0 이상 120 이하의 정수입니다.

## 입출력 예

| age | result |
|---|---|
| `30` | `12000` |
| `7` | `0` |
| `13` | `5000` |
| `65` | `6000` |

## 입출력 예 설명

입출력 예 #1
30세는 14세 이상 64세 이하 구간이므로 12000 을 반환합니다.

입출력 예 #2
7세는 7세 이하 구간이라 입장료가 없습니다.

입출력 예 #3
13세는 8세 이상 13세 이하 구간의 마지막 나이라 5000 을 반환합니다. 한 살 많은 14세부터는 12000 으로 바뀝니다.

입출력 예 #4
65세부터 6000 이 적용됩니다. 바로 아래인 64세는 아직 12000 을 냅니다.
