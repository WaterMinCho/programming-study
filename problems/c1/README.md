# 코딩테스트 연습 Lv.1

프로그래머스 Lv.1 수준의 창작 문제 8개입니다. 모두 `solution` 함수를 완성해 값을 **반환**하는 형식이고,
앞 4문제는 레벨 1(4점), 뒤 4문제는 레벨 2(6점)입니다. 1~16차시에서 배운 문법만으로 풀 수 있습니다.

## 문제를 읽는 순서

1. `solution` 의 매개변수와 반환값의 **자료형**을 확인합니다. 정수를 돌려줘야 하는데 문자열이나 실수를 돌려주면 값이 같아 보여도 오답입니다.
2. 제한 사항에서 입력의 범위를 봅니다. 빈 문자열이 올 수 있는지, 음수가 섞이는지, 길이가 1일 수 있는지에 따라 초깃값과 반복 범위가 정해집니다.
3. 입출력 예를 손으로 한 번 따라갑니다. 예의 결과가 왜 그 값인지 설명할 수 있게 된 뒤에 코드를 쓰기 시작합니다.

## 입출력 예로 검산하기

코드를 다 쓴 뒤에는 입출력 예의 입력을 넣어 머릿속으로 실행하면서 아래 항목을 확인합니다.

- 반복문이 **처음 요소**와 **마지막 요소**를 빠뜨리지 않는지 (`range(1, n)` 과 `range(1, n + 1)` 의 차이)
- 경계값에서 `<` 와 `<=` 중 어느 쪽이 맞는지 (`60 > 60` 은 `False`)
- 초깃값이 적절한지 (최댓값을 `0` 에서 시작하면 음수만 있는 리스트에서 틀립니다)

제출 전에 `python study.py grade c1` 로 채점하면 어느 테스트에서 어떤 값이 나왔는지 보여 줍니다.

## 자주 쓰는 패턴

```python
# 개수 세기 / 합계: 밖에서 0 으로 시작해 안에서 더한다
count = 0
for x in data:
    if x % 2 == 0:
        count += 1

# 최댓값과 그 위치: 첫 요소로 시작하고, 더 큰 값을 만나면 둘 다 갱신한다
best = data[0]
pos = 0
for i in range(1, len(data)):
    if data[i] > best:
        best = data[i]
        pos = i

# 딕셔너리로 개수 세기: 처음 보는 키는 1, 이미 있으면 1 더하기
counts = {}
for ch in text:
    if counts.get(ch) == None:
        counts[ch] = 1
    else:
        counts[ch] += 1

# 자릿수 분해: 문자열로 바꿔 한 글자씩 꺼내거나, 10 으로 나눈 나머지를 반복해서 뗀다
for ch in str(n):
    digit = int(ch)
```

정렬이 필요하면 8차시의 선택 정렬을 씁니다. 나눗셈 `/` 의 결과는 나누어떨어질 때도 실수입니다(`6 / 3` 은 `2.0`). 채점은 화면에 출력한 내용이 아니라 `return` 으로 돌려준 값을 봅니다.
