# p02. 평균 이상 점수 세기 (반환값 · 4점)

## 문제 설명

학생들의 점수가 담긴 정수 리스트 `scores` 가 주어집니다. 전체 평균 **이상**인 점수가 몇 개인지 세어 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 평균은 `(점수의 합) / (점수의 개수)` 이며, 반올림하지 않은 값으로 비교합니다.
- 평균과 정확히 같은 점수도 "평균 이상"에 포함합니다.
- 반환값은 **정수(int)** 입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항

- `scores` 의 길이는 1 이상 100 이하입니다.
- 각 점수는 0 이상 100 이하의 정수입니다.

## 입출력 예

| scores | result |
|---|---|
| `[80, 90, 70]` | `2` |
| `[50]` | `1` |
| `[1, 2, 3, 4]` | `2` |

## 입출력 예 설명

입출력 예 #1
평균은 `240 / 3 = 80.0` 입니다. 80 과 90 이 평균 이상이므로 2 를 반환합니다.

입출력 예 #2
점수가 하나뿐이면 그 점수가 곧 평균이므로 1 을 반환합니다.

입출력 예 #3
평균은 `10 / 4 = 2.5` 입니다. 3 과 4 가 평균 이상이므로 2 를 반환합니다. 평균을 정수 나눗셈으로 구해 2 로 잡으면 2, 3, 4 세 개를 세게 되어 틀립니다.
