# p05. 두 번 이상 나온 글자 (반환값 · 6점)

## 문제 설명

영어 소문자로만 이루어진 문자열 `s` 가 주어집니다. `s` 에 **두 번 이상 등장한 서로 다른 글자**가 몇 종류인지 세어 **반환(return)** 하는 `solution` 함수를 완성하세요.

예를 들어 `"programming"` 에서 `r`, `g`, `m` 은 각각 두 번씩 나오고 나머지 글자는 한 번씩 나오므로 3 을 반환합니다.

- 같은 글자가 세 번 이상 나와도 한 종류로 셉니다. `"aaa"` 의 답은 1 입니다.
- 반환값은 **정수(int)** 입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항

- `s` 의 길이는 0 이상 100 이하이고, 빈 문자열 `""` 이 올 수 있습니다.
- `s` 는 영어 소문자로만 이루어져 있습니다.

## 입출력 예

| s | result |
|---|---|
| `"programming"` | `3` |
| `"abc"` | `0` |
| `"aaa"` | `1` |
| `""` | `0` |

## 입출력 예 설명

입출력 예 #1
글자별 등장 횟수는 p 1, r 2, o 1, g 2, a 1, m 2, i 1, n 1 입니다. 두 번 이상인 글자는 r, g, m 세 종류입니다.

입출력 예 #2
모든 글자가 한 번씩만 나오므로 0 입니다.

입출력 예 #3
`a` 가 세 번 나오지만 글자의 종류는 하나이므로 1 입니다. 등장 횟수 3 이나 "첫 번째 이후 반복된 횟수" 2 를 돌려주면 틀립니다.

입출력 예 #4
빈 문자열에는 글자가 없으므로 0 입니다.
