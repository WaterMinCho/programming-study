# p06. 가운데 값 찾기 (반환값 · 6점)

## 문제 설명

정수 리스트 `nums` 가 주어집니다. `nums` 를 **오름차순으로 정렬했을 때 정가운데에 오는 값**을 **반환(return)** 하는 `solution` 함수를 완성하세요.

예를 들어 `[5, 1, 9, 3, 7]` 을 정렬하면 `[1, 3, 5, 7, 9]` 이고 가운데 값은 `5` 입니다.

- `nums` 의 길이는 항상 **홀수**이므로 가운데 값은 하나로 정해집니다.
- 반환값은 **정수(int)** 입니다. 정렬된 리스트 전체를 돌려주면 오답입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항

- `nums` 의 길이는 1 이상 99 이하의 홀수입니다.
- 각 요소는 -1000 이상 1000 이하의 정수이며, 같은 값이 여러 번 나올 수 있습니다.

## 입출력 예

| nums | result |
|---|---|
| `[5, 1, 9, 3, 7]` | `5` |
| `[1]` | `1` |
| `[2, 2, 1]` | `2` |
| `[-5, 0, 5]` | `0` |

## 입출력 예 설명

입출력 예 #1
정렬하면 `[1, 3, 5, 7, 9]` 이고, 5개 중 가운데인 세 번째(인덱스 2) 값은 5 입니다. 정렬하지 않고 인덱스 2 를 꺼내면 9 가 나와 틀립니다.

입출력 예 #2
요소가 하나이면 그 값이 가운데 값입니다.

입출력 예 #3
정렬하면 `[1, 2, 2]` 이고 가운데 값은 2 입니다. 같은 값이 있어도 위치만 보면 됩니다.

입출력 예 #4
이미 정렬된 리스트입니다. 음수가 섞여 있어도 가운데 값은 인덱스 `길이 // 2` 의 값입니다.
