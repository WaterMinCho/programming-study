# p10. 선택 정렬 k단계 (반환값 · 8점)

숫자 리스트 `data` 와 정수 `k` 가 주어집니다. `data` 를 선택 정렬(오름차순)로 정렬하되,
앞에서부터 k단계까지만 수행한 뒤의 리스트를 **반환(return)** 하는 `solution` 함수를 완성하세요.

선택 정렬의 i단계는 인덱스 i-1 부터 끝까지에서 가장 작은 값을 찾아 인덱스 i-1 의 값과 맞바꿉니다.

- 1단계: 인덱스 0 부터 끝까지에서 가장 작은 값을 찾아 인덱스 0 의 값과 맞바꿉니다.
- 2단계: 인덱스 1 부터 끝까지에서 가장 작은 값을 찾아 인덱스 1 의 값과 맞바꿉니다.

가장 작은 값이 여러 개이면 그중 가장 앞에 있는 것과 맞바꿉니다.

- 함수 이름과 매개변수는 바꾸지 않습니다.
- 정렬 기능이 있는 메서드나 내장 함수는 사용하지 않고 반복문으로 직접 구현합니다.

## 제한 사항
- `data` 의 길이는 2 이상 100 이하
- 0 ≤ k ≤ (`data` 의 길이 - 1). k 가 0 이면 리스트를 그대로 반환합니다.

## 입출력 예

| data | k | 반환값 |
|---|---|---|
| `[26, 54, 17, 93, 31]` | `1` | `[17, 54, 26, 93, 31]` |
| `[26, 54, 17, 93, 31]` | `3` | `[17, 26, 31, 93, 54]` |
| `[5, 1, 1]` | `1` | `[1, 5, 1]` |

첫 번째 예: 가장 작은 값 17(인덱스 2)과 맨 앞의 26 을 맞바꿉니다.
세 번째 예: 가장 작은 값 1 이 두 개이므로 앞쪽(인덱스 1)의 1 과 맞바꿉니다.
