# p01. 리스트 두 칸 맞바꾸기 (빈칸 채우기 · 4점)

- 함수는 아무것도 반환하지 않습니다. 넘겨받은 리스트를 직접 바꿉니다.

## 시작 코드

```python
def fswap(cb, i, j):
    temp = cb[i]
    cb[i] = ____
    cb[j] = ____
```

## 실행 예
