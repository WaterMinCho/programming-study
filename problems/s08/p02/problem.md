# p02. 최솟값을 돌려주는 함수 (빈칸 채우기 · 4점)

리스트의 길이가 몇이든 동작하도록 빈칸(`____`)을 채워 함수를 완성하세요.

- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
- `fu` 에는 숫자가 1개 이상 들어 있습니다.

def fmin(fu):
