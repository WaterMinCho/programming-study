# p08. 가산점을 주는 함수 (출력 · 6점)

이름을 키로, 점수를 값으로 가진 딕셔너리 `scores` 와 가산점 `bonus` 를 받아
모든 사람의 점수에 가산점을 더하는 함수 `add_bonus(scores, bonus)` 를 작성하세요.

- 넘겨받은 딕셔너리의 값을 직접 바꿉니다. (새 딕셔너리를 만들어 돌려주는 것이 아닙니다)
- 가산점을 더한 점수가 100 을 넘으면 100 으로 저장합니다.
- 한 사람의 점수를 바꿀 때마다 `이름 점수` 형식(이름, 공백 한 칸, 바뀐 점수)으로 한 줄씩 출력합니다.
  출력 순서는 딕셔너리에 들어 있는 순서입니다.
- 함수는 아무것도 반환하지 않습니다.

## 제한 사항
- 점수는 0 이상 100 이하의 정수, `bonus` 는 0 이상 100 이하의 정수
- 딕셔너리가 비어 있으면 아무것도 출력하지 않습니다.

## 실행 예

```python
score = {"kim": 80, "lee": 95, "park": 62}
add_bonus(score, 10)
print(score)
```

```
kim 90
lee 100
park 72
{'kim': 90, 'lee': 100, 'park': 72}
```

마지막 줄은 실행 예의 `print(score)` 가 출력한 것입니다. 함수 밖의 `score` 가 바뀌어 있어야 합니다.
