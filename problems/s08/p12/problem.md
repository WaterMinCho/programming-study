# p12. 점수 순위 출력 (출력 · 8점)

이름을 키로, 점수를 값으로 가진 딕셔너리 `scores` 를 받아
점수가 높은 사람부터 순위를 출력하는 함수 `print_rank(scores)` 를 작성하세요.

- 한 사람에 한 줄씩 `순위 이름 점수` 형식(순위, 공백 한 칸, 이름, 공백 한 칸, 점수)으로 출력합니다. 순위는 1 부터 시작합니다.
- 넘겨받은 딕셔너리는 바꾸지 않습니다. 함수가 끝난 뒤에도 키의 순서와 값이 호출 전과 같아야 합니다.
- 함수는 아무것도 반환하지 않습니다.

강의에서 배운 선택 정렬처럼 반복문과 `if` 비교로 직접 순서를 정해 보세요.

## 제한 사항
- 사람 수는 0명 이상 50명 이하이고, 딕셔너리가 비어 있으면 아무것도 출력하지 않습니다.
- 점수는 0 이상 100 이하의 정수이고, 점수가 같은 사람은 없습니다.

## 실행 예

```python
score = {"kim": 80, "lee": 95, "park": 62}
print_rank(score)
print(score)
```

```
1 lee 95
2 kim 80
3 park 62
{'kim': 80, 'lee': 95, 'park': 62}
```

마지막 줄은 실행 예의 `print(score)` 가 출력한 것입니다. 함수 밖의 `score` 는 호출 전과 같은 내용으로 출력되어야 합니다.
