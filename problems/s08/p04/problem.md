# p04. 입력받은 두 위치 맞바꾸기 (출력 · 4점)

시작 코드에는 리스트 `arr = [3, 6, 9, 12, 15]` 와 두 인덱스 `i`, `j` 를 입력받는 코드가 들어 있습니다.
`arr[i]` 와 `arr[j]` 를 서로 맞바꾸고, 바꾸기 전과 바꾼 후의 리스트를 아래 형식으로 출력하는 프로그램을 완성하세요.

## 입력

- 첫째 줄에 `i`, 둘째 줄에 `j` 가 주어집니다. (0 ≤ i, j ≤ 4, 같은 값일 수도 있음)

## 출력

- 첫째 줄: `바꾸기 전:` 뒤에 한 칸 띄고 바꾸기 전의 리스트
- 둘째 줄: `바꾼 후:` 뒤에 한 칸 띄고 바꾼 후의 리스트

## 입출력 예

입력

```
0
2
```

출력

```
바꾸기 전: [3, 6, 9, 12, 15]
바꾼 후: [9, 6, 3, 12, 15]
```

- 출력은 글자 하나까지 같아야 합니다(콜론, 띄어쓰기, 대괄호와 쉼표 포함).
