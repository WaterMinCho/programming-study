# 8차시 · 자료구조와 알고리즘

리스트·딕셔너리를 변수에 할당하거나 함수에 넘길 때 실제로 무슨 일이 일어나는지와,
그 위에서 돌아가는 맞바꾸기, 최댓값 찾기, 선택 정렬을 다루는 차시입니다.
코드가 길어 보여도 `temp` 3줄, `if` 비교, `for` 반복의 조합입니다.

| 강의 절 | 내용 |
|---|---|
| 8.1 리스트 데이터 SWAP | `temp` 3줄 맞바꾸기, 요소를 넘긴 함수 vs 리스트를 넘긴 함수 |
| 8.2 id 함수와 리스트 | `b = a` 는 별명, `id()` 는 메모리 주소, 리스트를 return 하는 함수 |
| 8.3 최대값 찾기(1) | `if` 나열 → `range` 로 도는 `for` → 요소를 직접 꺼내는 `for` |
| 8.4 선택 정렬 | 최솟값을 찾아 맨 앞과 교환하는 일을 반복, 중첩 `for`, 함수로 만들기 |
| 8.5 최대값 찾기(2) | 최댓값 함수 `fmax`: 매개변수 여러 개 → 리스트 하나, 최솟값 함수 `fmin` |
| 8.6 딕셔너리 매개변수 | 딕셔너리도 별명·매개변수로 넘기면 원본이 바뀐다 |

## 1. 맞바꾸기(SWAP)

두 값을 바꾸려면 한쪽 값을 임시 변수에 먼저 보관해야 합니다.

```python
ca = [3, 8]
temp = ca[0]      # 앞의 값을 보관
ca[0] = ca[1]     # 뒤의 값을 앞으로
ca[1] = temp      # 보관해 둔 값을 뒤로
print(ca)         # [8, 3]
```

- `temp` 없이 `ca[0] = ca[1]` → `ca[1] = ca[0]` 두 줄만 쓰면 첫 줄에서 앞의 값이 사라져 `[8, 8]` 이 됩니다.
- 파이썬은 `ca[0], ca[1] = ca[1], ca[0]` 한 줄로도 맞바꿀 수 있습니다(과제에 이 형태가 나옵니다).
  오른쪽 값을 먼저 모두 계산한 뒤 왼쪽에 차례로 넣기 때문입니다. 왼쪽과 오른쪽의 순서가 서로 반대여야 바뀝니다.

## 2. 함수로 맞바꾸기: 무엇을 넘겼는가

```python
def swap_a(na, nb):       # 값 두 개를 받는다
    temp = na
    na = nb
    nb = temp

def swap_b(cb):           # 리스트를 받는다
    temp = cb[0]
    cb[0] = cb[1]
    cb[1] = temp

ca = [3, 8]
swap_a(ca[0], ca[1])
print(ca)                 # [3, 8]  ← 안 바뀜
swap_b(ca)
print(ca)                 # [8, 3]  ← 바뀜
```

- `swap_a(ca[0], ca[1])`: 함수 안의 이름 `na`, `nb` 가 가리키는 대상만 서로 바뀝니다. 함수가 끝나면 그 이름들은 사라지고 바깥 리스트의 요소는 바뀌지 않습니다.
- `swap_b(ca)`: 매개변수 `cb` 가 바깥의 `ca` 와 같은 리스트를 가리킵니다. `cb[0] = ...` 은 그 리스트의 칸을 바꾸는 것이므로 바깥에서도 보입니다.
- "인수 → 매개변수" 전달은 `cb = ca` 라는 할당과 같은 일입니다.

리스트를 넘겨받았더라도 함수 안에서 매개변수 이름에 새 리스트를 할당하면 바깥 리스트는 바뀌지 않습니다.

```python
def swap_c(cb):
    cb = [cb[1], cb[0]]   # cb 라는 이름이 새 리스트를 가리키게 될 뿐
    return cb

ca = [3, 8]
cd = swap_c(ca)
print(ca, cd)             # [3, 8] [8, 3]  ← ca 는 안 바뀌고, 새 리스트는 cd 로 받는다
```

## 3. 별명과 `id()`

```python
a = [10, 11, 12]
b = a               # 복사가 아니라 같은 리스트에 이름을 하나 더 붙임
b[1] = 21
print(a)            # [10, 21, 12]  ← a 로 봐도 바뀌어 있다
print(id(a) == id(b))   # True

b = [30, 31, 32]    # b 가 새 리스트를 가리키게 됨 (이때부터 a 와 다른 리스트)
b[0] = 99
print(a)            # [10, 21, 12]  ← 영향 없음
print(id(a) == id(b))   # False
```

- `id(x)` 는 x 가 가리키는 객체의 메모리 주소 값을 돌려주는 내장 함수입니다. 숫자 자체는 실행할 때마다 달라지므로, 시험에서는 "같은가/다른가"를 묻습니다.
- 요소를 바꾸는 것(`a[1] = 21`)은 리스트 안의 칸이 다른 값을 가리키게 하는 것입니다. `id(a)` 는 바뀌지 않고 `id(a[1])` 만 달라집니다.
- 내용이 같아도 `[10, 11, 12]` 를 두 번 쓰면 리스트가 두 개 만들어집니다. 두 리스트를 `==` 로 비교하면 `True` 이지만 `id()` 끼리 비교하면 `False` 입니다.
- 같은 작은 정수는 하나의 객체를 같이 씁니다. `x = 42`, `y = 42` 이면 `id(x) == id(y)` 는 `True` 입니다(과제에 나온 형태).

리스트를 `return` 해도 새 리스트가 생기지 않습니다.

```python
def fk(cb):
    cb[2] = cb[0] + cb[1]
    return cb

ca = [1, 2, 0]
cd = fk(ca)
print(ca, cd)       # [1, 2, 3] [1, 2, 3]  ← ca, cb, cd 모두 같은 리스트
```

## 4. 최댓값 찾기

첫 요소를 일단 최댓값으로 잡고, 더 큰 값을 만나면 바꿉니다. 강의는 같은 일을 `if` 나열, `range` 로 도는 `for`, 요소를 직접 꺼내는 `for` 순서로 고쳐 씁니다.

```python
ca = [6, 13, 9, 4]

# if 를 요소 수만큼 나열
max = ca[0]
if max < ca[1]:
    max = ca[1]
if max < ca[2]:
    max = ca[2]
if max < ca[3]:
    max = ca[3]

# 인덱스의 규칙(1, 2, 3)을 range 로
max = ca[0]
for sb in range(1, 4, 1):
    if max < ca[sb]:
        max = ca[sb]

# 요소를 직접 꺼내기
max = ca[0]
for sb in ca:
    if max < sb:
        max = sb
print(max)          # 13
```

- 두 번째 코드의 `sb` 는 인덱스라서 `ca[sb]` 로 쓰고, 세 번째 코드의 `sb` 는 요소 값이라서 그냥 `sb` 로 씁니다. 세 번째 코드에서 `ca[sb]` 로 쓰면 값을 인덱스로 쓰게 되어 틀립니다.
- 세 번째 코드는 첫 요소도 한 번 더 비교하지만(`6 < 6` 은 거짓) 결과에는 영향이 없습니다.
- 최솟값은 부등호만 뒤집습니다: `if mina > sb: mina = sb`.
- 강의 코드는 `max` 를 변수 이름으로 씁니다. 내장 함수가 아니라 그냥 변수로 읽으면 됩니다.

## 5. 선택 정렬

남은 구간에서 가장 작은 값을 찾아 그 구간의 맨 앞 요소와 맞바꾸는 일을, 앞자리부터 차례로 반복하는 정렬입니다.

```python
ca = [6, 2, 9, 4, 7]
for sa in range(0, 4, 1):            # 채울 자리: 0, 1, 2, 3  (요소 5개 → 4번)
    mina = ca[sa]                    # 일단 구간의 맨 앞을 최솟값으로
    minix = sa                       # 그 위치
    for sb in range(sa + 1, 5, 1):   # 다음 칸부터 끝까지 비교
        if mina > ca[sb]:
            mina = ca[sb]            # 값과
            minix = sb               # 위치를 함께 갱신
    temp = ca[sa]                    # ca[sa] 와 ca[minix] 맞바꾸기
    ca[sa] = ca[minix]
    ca[minix] = temp
    print(ca)
```

| 단계 | 찾은 최솟값(위치) | 맞바꾼 뒤 |
|---|---|---|
| 시작 | | `[6, 2, 9, 4, 7]` |
| sa=0 | 2 (인덱스 1) | `[2, 6, 9, 4, 7]` |
| sa=1 | 4 (인덱스 3) | `[2, 4, 9, 6, 7]` |
| sa=2 | 6 (인덱스 3) | `[2, 4, 6, 9, 7]` |
| sa=3 | 7 (인덱스 4) | `[2, 4, 6, 7, 9]` |

- 강의는 1단계 코드를 먼저 만들고(최솟값의 값 `mina` 와 위치 `minix` 찾기 + 맞바꾸기), 그것을 시작 위치만 바꿔 가며 2·3·4단계로 반복한 뒤,
  반복되는 부분을 중첩 `for` 로 묶고, 마지막에 함수(`fselsort(ca)`)로 만듭니다.
- 함수로 만들면 리스트를 매개변수로 받으므로 `return` 없이도 바깥 리스트가 정렬됩니다(2절과 같은 이유).

과제에는 최솟값의 위치만 기억하고 한 줄로 맞바꾸는 형태도 나옵니다. 위 코드와 같은 순서로 같은 칸을 맞바꿉니다.

```python
def sel_sort(nums):
    for i in range(len(nums)):
        pos = i                           # 최솟값의 위치
        for j in range(i + 1, len(nums)):
            if nums[j] < nums[pos]:       # 지금까지의 최솟값보다 작으면 위치 갱신
                pos = j
        nums[i], nums[pos] = nums[pos], nums[i]
    return nums

print(sel_sort([6, 2, 9, 4, 7]))          # [2, 4, 6, 7, 9]
```

큰 값부터 놓는 내림차순 정렬은 남은 구간에서 최댓값을 찾아 맨 앞과 맞바꿉니다. 비교의 부등호만 반대로 써서 `if nums[j] > nums[pos]:`(위쪽 코드라면 `if mina < ca[sb]:`)로 고칩니다.

## 6. 최댓값을 돌려주는 함수

값을 하나씩 받던 함수가 리스트 하나를 받는 함수로 바뀌는 과정입니다.

```python
su = [5, 12, 7]

def fmax_a(a, b, c):        # 값 3개를 받아 if 를 나열
    max = a
    if max < b:
        max = b
    if max < c:
        max = c
    return max

def fmax_b(a, b, c):        # 받은 값을 리스트로 묶으면 for 를 쓸 수 있다
    fu = [a, b, c]          # fu = [] 뒤에 fu.append(a) … 로 넣어도 같다
    max = fu[0]
    for sfu in fu:
        if max < sfu:
            max = sfu
    return max

def fmax_c(fu):             # 처음부터 리스트를 받는다
    max = fu[0]
    for sfu in fu:
        if max < sfu:
            max = sfu
    return max

print(fmax_a(su[0], su[1], su[2]), fmax_b(su[0], su[1], su[2]), fmax_c(su))   # 12 12 12
```

- `fmax_a`, `fmax_b` 는 요소 수가 바뀌면 매개변수도 고쳐야 하지만, `fmax_c` 는 리스트 길이와 상관없이 씁니다.
- 강의 코드처럼 바깥에서 `max = fmax(su)` 로 결과를 받으면, 함수 안의 `max`(지역 변수)와 바깥의 `max`(전역 변수)는 이름만 같은 서로 다른 변수입니다.
- 최솟값 함수 `fmin` 은 부등호를 `>` 로 바꾸면 됩니다.

## 7. 딕셔너리 매개변수

```python
def fch(x):
    x["b"] = 0          # 넘겨받은 딕셔너리의 값을 바꾼다

a = {"a": 1, "b": 2}
x = a                   # 별명
x["a"] = 100
print(a)                # {'a': 100, 'b': 2}

fch(a)
print(a)                # {'a': 100, 'b': 0}
```

- 딕셔너리도 리스트처럼 `x = a` 는 별명이고, 함수에 넘기면 함수 안에서 바꾼 내용이 원본에 남습니다.
- 딕셔너리의 값을 모두 더하는 함수(과제)는 `for value in d.values():` 로 하나씩 꺼내 더합니다.
- 값이 큰 순서로 키를 나열하려면 키를 리스트에 옮겨 담고 그 리스트를 선택 정렬합니다. 비교는 `d[names[j]]` 처럼 키로 꺼낸 값으로 하고, 맞바꾸기는 키 리스트의 칸끼리 합니다. 이렇게 하면 넘겨받은 딕셔너리의 키 순서와 값이 바뀌지 않습니다.

## 시험에서 헷갈리기 쉬운 포인트

- `temp` 3줄의 순서는 `temp = A` → `A = B` → `B = temp` 입니다. `temp` 없이 두 줄로 쓰면 두 칸이 같은 값이 됩니다.
- 한 줄 맞바꾸기 `lst[0], lst[3] = ____` 의 빈칸은 순서를 뒤집은 `lst[3], lst[0]`. 같은 순서로 쓰면 아무 변화가 없습니다.
- 요소를 넘긴 함수는 원본을 못 바꾸고, 리스트·딕셔너리를 넘긴 함수는 바꿉니다. 호출문이 `f(ca[0], ca[1])` 인지 `f(ca)` 인지부터 확인하세요.
- `b = a` 는 복사가 아닙니다. 단, 그 뒤에 `b = [ ... ]` 처럼 통째로 새로 할당하면 그때부터 `a` 와 무관합니다. "칸을 바꾸는가(`b[0] = `) / 이름을 다시 붙이는가(`b = `)"를 구분하세요.
- 함수 안에서도 같은 구분이 적용됩니다. `cb[0] = ...` 은 바깥 리스트를 바꾸고, `cb = [ ... ]` 은 매개변수 이름만 새 리스트로 옮겨 바깥 리스트를 바꾸지 못합니다.
- 요소를 바꿔도 `id(a)` 는 바뀌지 않습니다. 별명끼리는 `id` 가 같고, 내용이 같아도 따로 만든 리스트끼리는 `id` 를 비교하면 `False` 입니다. 같은 작은 정수(`x = 42`, `y = 42`)는 `id` 가 같습니다.
- 리스트를 return 받아도 같은 리스트입니다. `cd = fk(ca)` 뒤에는 `ca` 와 `cd` 가 같은 것을 가리킵니다.
- 함수가 리스트를 바꾸면서 횟수 같은 값을 함께 셌다면, 리스트의 변화는 바깥에 남지만 센 값은 함수 안의 지역 변수에 있습니다. `n = f(ca)` 처럼 반환값을 받아야 바깥에서 쓸 수 있고, 바깥에 같은 이름의 변수가 있어도 그 변수는 바뀌지 않습니다.
- 초깃값은 `0` 이 아니라 첫 요소입니다. `max = 0` 으로 시작하면 음수만 있는 리스트에서 `0` 이 나옵니다.
- `if` 를 `elif` 로 잇지 않습니다. `elif` 는 앞 조건이 참이면 건너뛰므로 뒤쪽의 더 큰 값을 놓칩니다.
- 부등호 방향은 최댓값 `max < x`, 최솟값 `mina > x`. 선택 정렬(오름차순)은 최솟값을 찾으므로 `mina > ca[sb]`, 내림차순은 최댓값을 찾으므로 부등호가 반대입니다.
- 선택 정렬의 한 단계는 교환입니다. `[35, 12, 27, 8, 19]` 의 1단계 결과는 `[8, 12, 27, 35, 19]` 입니다(8 과 35 가 자리를 바꿈). 8 을 앞에 끼워 넣고 뒤로 미는 것이 아닙니다.
- 선택 정렬의 범위는 바깥 반복이 요소 수 - 1 번, 안쪽 반복이 `sa + 1` 부터입니다. `mina`, `minix` 는 단계마다 다시 초기화하고, 맞바꾸기는 안쪽 `for` 가 끝난 뒤 한 번 합니다.
- `minix` 는 값이 아니라 위치입니다. 맞바꿀 때는 `ca[minix]` 로 씁니다. 최솟값이 이미 맨 앞이면 `minix == sa` 라 제자리 교환(변화 없음)이 됩니다.
- 출력 형식은 리스트가 `[8, 12, 27]`(쉼표 뒤 한 칸), 딕셔너리가 `{'kim': 95, 'lee': 90}`(문자열은 작은따옴표, 콜론 뒤 한 칸)이고, `print("최댓값은", m)` 은 쉼표 자리에 공백 한 칸.
- 함수 호출이 든 `print("결과", f(x))` 는 `f(x)` 를 끝까지 실행한 뒤에 출력하므로, `f` 안의 `print` 가 출력한 줄이 `결과` 줄보다 위에 나옵니다.
