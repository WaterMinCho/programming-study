# p03. 딕셔너리 값의 합 (반환값 · 4점)

상품 이름을 키로, 가격을 값으로 가진 딕셔너리 `prices` 가 주어집니다.
딕셔너리에 들어 있는 모든 값의 합을 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 함수 이름과 매개변수는 바꾸지 않습니다.
- 값은 모두 정수입니다. 키는 문자열일 수도, 정수일 수도 있습니다.
- 빈 딕셔너리가 주어지면 `0` 을 반환합니다.

## 입출력 예

| prices | 반환값 |
|---|---|
| `{'pen': 1200, 'note': 2500, 'eraser': 800}` | `4500` |
| `{'apple': 3}` | `3` |
| `{}` | `0` |
