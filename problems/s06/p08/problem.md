# p08. 구구단 함수 (출력 · 6점)

정수 `dan` 을 매개변수로 받아 구구단 `dan` 단을 출력하는 함수 `gugu` 를 정의하세요.

- `gugu(dan)` 을 호출하면 `dan x 1` 부터 `dan x 9` 까지 아홉 줄을 출력합니다.
- 한 줄의 형식은 `2 x 1 = 2` 와 같습니다. 숫자와 `x`, `=` 사이를 공백 한 칸으로 띄웁니다.
- 채점기는 제출한 파일을 불러온 뒤 `gugu(2)` 처럼 함수를 직접 호출해 출력을 확인합니다.
  파일에 `input()` 은 쓰지 않습니다. (확인용으로 직접 호출해 본 코드가 남아 있어도 채점에는 영향이 없습니다)

## 제한 사항
- 1 ≤ dan ≤ 9

## 출력 예

`gugu(2)` 를 호출했을 때

```
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
2 x 4 = 8
2 x 5 = 10
2 x 6 = 12
2 x 7 = 14
2 x 8 = 16
2 x 9 = 18
```
