# p13. 기본값이 있는 인사말 (출력 · 4점)

매개변수 `name` 을 받아 `Hello, 이름!` 형식으로 한 줄 출력하는 함수 `greet` 를 정의하세요.

- `greet("Alice")` 로 호출하면 `Hello, Alice!` 를 출력합니다.
- 인수 없이 `greet()` 로 호출하면 `name` 의 기본값 `"Guest"` 를 써서 `Hello, Guest!` 를 출력합니다.
- 쉼표 뒤에 공백이 한 칸 있고, 이름 바로 뒤에 느낌표가 붙습니다.
- 채점기는 제출한 파일을 불러온 뒤 `greet("Alice")` 처럼 함수를 직접 호출해 출력을 확인합니다.
  파일에 `input()` 은 쓰지 않습니다. (확인용으로 직접 호출해 본 코드가 남아 있어도 채점에는 영향이 없습니다)

## 출력 예

`greet("Alice")` 를 호출했을 때

```
Hello, Alice!
```

`greet()` 를 호출했을 때

```
Hello, Guest!
```
