# p09. 사칙연산 계산기 (출력 · 8점)

두 정수 `a`, `b` 를 한 줄에 하나씩 입력받아 덧셈·뺄셈·곱셈·나눗셈 결과를 출력하는 프로그램을 작성하세요.

- 덧셈, 뺄셈, 곱셈, 나눗셈을 하는 함수를 각각 정의하고(예: `add`, `sub`, `mul`, `div`),
  각 함수는 두 수를 매개변수로 받아 계산 결과를 반환하도록 만듭니다.
- 나눗셈은 `/` 연산자를 사용합니다.
- `b` 가 0 이면 나눗셈 줄 대신 `0으로는 나눌 수 없습니다.` 를 출력합니다.

## 제한 사항
- -1000 ≤ a, b ≤ 1000
- `b` 가 0 이 아닐 때, `a / b` 는 소수 첫째 자리 안에서 나누어떨어지는 값만 주어집니다.

## 입출력 예

입력

```
20
5
```

출력

```
20 + 5 = 25
20 - 5 = 15
20 * 5 = 100
20 / 5 = 4.0
```

입력

```
9
0
```

출력

```
9 + 0 = 9
9 - 0 = 9
9 * 0 = 0
0으로는 나눌 수 없습니다.
```

- 숫자와 연산 기호, `=` 사이는 공백 한 칸으로 띄웁니다.
- 출력은 글자 하나까지 같아야 합니다(띄어쓰기, 마침표 포함).
