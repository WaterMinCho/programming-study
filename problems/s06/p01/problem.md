# p01. 막대 그리기 함수 (빈칸 채우기 · 4점)

정수 `n` 을 입력받아 첫째 줄에 `#` 을 `n` 개, 둘째 줄에 `#` 을 `n + 2` 개 출력하는 프로그램입니다.
`#` 을 원하는 개수만큼 한 줄에 출력하는 일은 `draw_bar` 함수가 맡습니다. 빈칸(`____`)을 채워 프로그램을 완성하세요.

- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 주어진 코드

```python
____ draw_bar(____):
    print("#" * count)

n = int(input())
draw_bar(n)
draw_bar(n + 2)
```

## 제한 사항
- 1 ≤ n ≤ 50

입력

```
3

###
#####
```
