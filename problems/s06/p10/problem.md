# p10. 처음 나오는 위치 (반환값 · 6점)

정수 리스트 `nums` 와 정수 `target` 이 주어질 때, `nums` 에서 `target` 이 처음 나오는 위치(인덱스)를 반환하는 `solution` 함수를 완성하세요.
`nums` 에 `target` 이 없으면 -1 을 반환합니다.

- 위치는 0 부터 셉니다. 맨 앞 요소의 위치가 0 입니다.
- `target` 이 여러 번 나오면 가장 앞에 있는 위치를 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항
- `nums` 의 길이는 0 이상 100 이하입니다. (빈 리스트일 수 있습니다)
- -1000 ≤ `nums` 의 요소, `target` ≤ 1000

## 입출력 예

| nums | target | 반환값 | 설명 |
|---|---|---|---|
| `[5, 3, 7, 3]` | 3 | 1 | 3 은 1번과 3번 위치에 있고, 앞쪽인 1 을 반환 |
| `[5, 3, 7, 3]` | 5 | 0 | 맨 앞 요소의 위치는 0 |
| `[5, 3, 7, 3]` | 9 | -1 | 9 는 리스트에 없음 |
