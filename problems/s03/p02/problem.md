# p02. 짝수 홀수 판별 (출력 · 4점)

정수 하나를 입력받아 짝수인지 홀수인지 판별하는 프로그램을 작성하세요.

- 첫째 줄: 입력받은 수와 판별 결과(`짝수` 또는 `홀수`)를 **공백 한 칸**으로 구분해 출력합니다.
- 둘째 줄: 결과와 상관없이 항상 `판별 끝` 을 출력합니다.

## 제한 사항
- 입력은 0 이상 1000 이하의 정수 하나입니다. (0 은 짝수입니다)

## 입력 예 1

```
37
```

## 출력 예 1

```
37 홀수
판별 끝
```

## 입력 예 2

```
8
```

## 출력 예 2

```
8 짝수
판별 끝
```

- 출력은 글자 하나까지 같아야 합니다(띄어쓰기 포함).
