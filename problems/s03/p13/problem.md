# p13. 삼각형 분류 (출력 · 8점)

세 변의 길이 `a`, `b`, `c` 를 차례로 입력받아 어떤 삼각형인지 출력하는 프로그램을 작성하세요.

| 조건 | 출력 |
|---|---|
| 세 변으로 삼각형을 만들 수 없다 | `삼각형 아님` |
| 삼각형이고, 세 변의 길이가 모두 같다 | `정삼각형` |
| 삼각형이고, 길이가 같은 변이 두 개뿐이다 | `이등변삼각형` |
| 삼각형이고, 세 변의 길이가 모두 다르다 | `부등변삼각형` |

- 가장 긴 변의 길이가 나머지 두 변의 길이의 합보다 **작아야** 삼각형을 만들 수 있습니다. 같거나 크면 만들 수 없습니다.
- 가장 긴 변이 몇 번째로 입력되는지는 정해져 있지 않습니다.
- 네 문구 중 하나만 출력합니다.

## 입력
- 정수 `a`, `b`, `c` 가 한 줄에 하나씩, 세 줄로 주어집니다.

## 제한 사항
- 1 ≤ a, b, c ≤ 1000

## 입력 예 1

```
3
4
5
```

## 출력 예 1

```
부등변삼각형
```

## 입력 예 2

```
5
5
5
```

## 출력 예 2

```
정삼각형
```

## 입력 예 3

```
5
5
8
```

## 출력 예 3

```
이등변삼각형
```

## 입력 예 4

```
1
2
3
```

## 출력 예 4

```
삼각형 아님
```

- 예 4 는 `1 + 2` 가 `3` 과 같아서 삼각형을 만들 수 없습니다.
