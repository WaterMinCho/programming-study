# p08. 윤년 판별 (빈칸 채우기 · 8점)

연도(정수)를 입력받아 윤년인지 평년인지 출력하는 프로그램입니다. 빈칸(`____`) 세 곳을 채워 완성하세요.

## 윤년 규칙

- 연도가 4의 배수이면서 100의 배수가 아니면 윤년입니다.
- 연도가 400의 배수이면 (100의 배수이더라도) 윤년입니다.
- 그 밖의 연도는 모두 평년입니다.

## 시작 코드

빈칸에는 비교 연산자 또는 논리 연산자가 하나씩 들어갑니다.

```python
year = int(input())
if (year % 4 == 0 ____ year % 100 ____ 0) ____ year % 400 == 0:
    print(year, "윤년")
else:
    print(year, "평년")
```

- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 제한 사항
- 1 ≤ 연도 ≤ 9999

## 입출력 예

| 입력 | 출력 | 설명 |
|---|---|---|
| `2024` | `2024 윤년` | 4의 배수이고 100의 배수가 아님 |
| `2023` | `2023 평년` | 4의 배수가 아님 |
| `1900` | `1900 평년` | 100의 배수이지만 400의 배수가 아님 |
| `2000` | `2000 윤년` | 400의 배수 |
