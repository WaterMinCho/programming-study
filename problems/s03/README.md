# 3차시 · 조건식과 제어문

참·거짓을 따지는 식(조건식)을 만들고, 그 결과에 따라 실행할 코드를 고르는 if 문을 다룹니다.
시험 직전에는 맨 아래 "시험에서 헷갈리기 쉬운 포인트"만 다시 읽어도 됩니다.

## 조건식과 bool

- 조건식은 계산하면 `True`(참) 또는 `False`(거짓)가 나오는 식입니다.
- `True` 와 `False` 만 값으로 갖는 자료형이 bool(논리형, 불리언)입니다.
- 비교 연산자와 논리 연산자의 계산 결과가 bool 입니다.

```python
print(7 > 3)          # True
print(type(7 > 3))    # <class 'bool'>
print(type("True"))   # <class 'str'>   따옴표가 붙으면 문자열
```

비교 결과도 값이므로 변수에 담을 수 있습니다. 대입하는 순간의 결과가 저장되고, 그 뒤에 원래 변수를 바꿔도 담아 둔 `True`/`False` 는 다시 계산되지 않습니다.

```python
score = 55
passed = score >= 60   # False 가 저장된다
score = score + 10     # score 는 65 가 되지만
print(passed)          # False
if passed:             # bool 변수는 조건 자리에 바로 쓸 수 있다
    print("합격")       # 실행되지 않는다
```

## 비교 연산자 (6개)

연산자 양쪽의 값(피연산자)을 견주어 `True`/`False` 를 돌려줍니다.

| 연산자 | 뜻 | 예 (`a = 3`, `b = 5`) | 결과 |
|---|---|---|---|
| `==` | 같다 | `a == b` | `False` |
| `!=` | 같지 않다 | `a != b` | `True` |
| `<` | 왼쪽이 작다 | `a < b` | `True` |
| `<=` | 왼쪽이 작거나 같다 | `a <= 3` | `True` |
| `>` | 왼쪽이 크다 | `a > 3` | `False` |
| `>=` | 왼쪽이 크거나 같다 | `a >= 3` | `True` |

문자열도 `==`, `!=` 로 비교할 수 있습니다. 글자가 완전히 같아야 `True` 입니다(대소문자 구분).

```python
color = "red"
print(color == "red")   # True
print(color == "Red")   # False
```

문자열과 숫자를 `==` 로 비교하면 오류 없이 `False` 가 나옵니다. 크기 비교(`<`, `>=` 등)를 문자열과 숫자 사이에 쓰면 TypeError 가 납니다.

```python
print("7" == 7)    # False
print("7" >= 7)    # TypeError
```

## 논리 연산자 (and · or · not)

조건식 여러 개를 하나로 묶거나, 결과를 뒤집을 때 씁니다.

| 연산자 | True 가 되는 경우 | 예 | 결과 |
|---|---|---|---|
| `and` | 양쪽이 모두 True | `5 > 1 and 5 > 9` | `False` |
| `or` | 양쪽 중 하나라도 True | `5 > 1 or 5 > 9` | `True` |
| `not` | 뒤의 값이 False (참·거짓 뒤집기) | `not 5 > 9` | `True` |

| A | B | A and B | A or B |
|---|---|---|---|
| False | False | False | False |
| False | True | False | True |
| True | False | False | True |
| True | True | True | True |

- `and` 는 둘 다 True 인 줄에서만 True 이고, `or` 는 둘 다 False 인 줄에서만 False 입니다.
- 강의 자료의 진리표는 False 를 0, True 를 1 로 적습니다.
- `and` 와 `or` 의 양쪽에는 각각 완성된 조건식을 적습니다. "토요일이거나 일요일"은 `day == "토" or day == "일"` 입니다. `day == "토" or "일"` 로 줄여 쓰면 `day` 가 무엇이든 if 블록이 실행됩니다.

## 연산자 우선순위

괄호 → 산술(`+ - * / // % **`) → 비교 → 논리 순서로 계산합니다.

```python
print(4 + 3 > 2 * 3 and 10 % 3 == 1)
# ① 산술:  7 > 6 and 1 == 1
# ② 비교:  True and True
# ③ 논리:  True

print(2 * 5 - 1)      # 9   (곱셈 먼저)
print(2 * (5 - 1))    # 8   (괄호 먼저)
```

그래서 `n % 2 == 0` 은 괄호 없이도 "`n % 2` 를 먼저 구하고 0 과 비교"로 읽습니다.

## 제어문

- 프로그램은 기본적으로 위에서 아래로 한 줄씩 차례대로 실행됩니다.
- 이 흐름을 바꾸는 문장이 제어문이고, 조건문과 반복문이 있습니다.
  - 조건문은 조건에 따라 골라서 실행합니다(이번 차시의 `if`).
  - 반복문은 여러 번 되풀이해서 실행합니다(5차시).

## 조건문: if / if-else / if-elif-else

```python
if 조건식:          # 끝에 콜론(:)
    실행할 문장      # 들여쓰기(공백 4칸)한 줄들이 블록
```

### if: 참일 때만 실행

```python
price = 12000
if price > 10000:
    print("배송비 무료")    # 조건이 True 일 때만 실행
print("주문 완료")          # 들여쓰기가 없으므로 if 와 상관없이 항상 실행
```

### if-else: 둘 중 하나만 실행

```python
n = 7
if n % 2 == 0:
    print(n, "짝수")
else:                      # else 뒤에는 조건식을 쓰지 않습니다
    print(n, "홀수")
```

### if-elif-else: 여러 갈래 중 하나만 실행

```python
speed = 60
if speed > 100:
    print("빠름")
elif speed > 60:           # 위 조건이 False 일 때만 검사합니다
    print("보통")
else:                      # 위 조건이 전부 False 인 "그 밖의 모든 경우"
    print("느림")
# 출력: 느림   (60 > 60 은 False)
```

- 위에서부터 차례로 검사하다가 처음으로 True 가 된 블록 하나만 실행하고 조건문 전체를 빠져나갑니다.
- `elif` 는 `else if` 를 줄인 말이고, 필요한 만큼 이어 쓸 수 있습니다. `elif` 뒤에는 조건식을 반드시 적습니다.
- `elif` 와 `else` 는 혼자 쓸 수 없고 앞에 `if` 가 있어야 합니다. `else` 는 없어도 되며, 이때 어느 조건도 True 가 아니면 아무 블록도 실행하지 않고 지나갑니다.

### 중첩 if: 블록 안에 또 if

```python
age = 15
if age >= 8:
    if age < 14:
        print("어린이 요금")
    else:
        print("일반 요금")
    print("입장 가능")       # 바깥 if 블록에 속한 줄
else:
    print("입장 불가")
# 출력: 일반 요금 / 입장 가능
```

들여쓰기 깊이가 같은 `if` 와 `else` 가 짝입니다. 4칸 들여 쓴 `else` 는 안쪽 `if` 의 짝이고, 들여 쓰지 않은 `else` 는 바깥 `if` 의 짝입니다.

## 자주 나오는 패턴

```python
# (1) 입력받은 수로 비교: input() 은 문자열을 돌려주므로 int() 로 바꾼 뒤 비교
n = int(input())

# (2) 짝수·홀수 / 배수 판별: 나머지(%)와 == 를 함께
if n % 2 == 0:
    print("짝수")

# (3) 구간 나누기: 큰 기준부터 elif 로 내려가기
if n >= 90:
    print("A")
elif n >= 80:      # 여기까지 왔다면 이미 n < 90 입니다
    print("B")
else:
    print("C")

# (4) 범위 안인지 검사: and 로 양쪽 경계를 묶기
if n >= 1 and n <= 12:
    print("올바른 월")

# (5) 값이 범위를 벗어나지 않게 자르기
if n > 100:
    n = 100
elif n < 0:
    n = 0

# (6) 문자열로 갈래 나누기
menu = input()
if menu == "start":
    print("시작")
elif menu == "stop":
    print("정지")
else:
    print("알 수 없는 명령")

# (7) 한 조건이 다른 조건에 포함될 때: 좁은 조건을 위에
a = 4
b = 4
c = 4
if a == b and b == c:
    print("셋 다 같음")
elif a == b or b == c or a == c:    # 셋 다 같을 때도 이 조건은 True
    print("둘만 같음")
else:
    print("모두 다름")
# 출력: 셋 다 같음
```

## 반환값 문제에서 조건문 쓰기

함수는 6차시에 자세히 배우지만, 반환값 문제는 지금도 풀 수 있습니다. 주어진 뼈대에서
`def` 줄과 `return answer` 줄은 고치지 않고, 그 사이에 한 단계 들여 써서 조건문을 넣은 뒤 결과를 `answer` 에 담습니다.

```python
def solution(n):
    answer = ''
    if n % 3 == 0:              # 함수 안쪽이라 4칸 들여 씁니다
        answer = "3의 배수"      # if 블록은 한 단계 더(8칸)
    else:
        answer = "3의 배수 아님"
    return answer               # print 가 아니라 return 으로 돌려줍니다
```

## 시험에서 헷갈리기 쉬운 포인트

- `=` 는 대입이고 `==` 는 "같은가?"를 묻는 비교입니다. `if x = 3:` 은 문법 오류입니다.
- `if`·`elif`·`else` 줄 끝의 `:` 을 빼먹거나, 다음 줄을 들여 쓰지 않으면 오류가 납니다.
- `x = 60` 일 때 `x > 60` 은 `False`, `x >= 60` 은 `True` 입니다. "초과·미만"은 `>`·`<` 로, "이상·이하"는 `>=`·`<=` 로 옮깁니다.
- `True` 와 `False` 는 첫 글자만 대문자로 씁니다. `true`, `TRUE` 는 정의되지 않은 이름이고 `"True"` 는 문자열입니다. 출력 문제의 답도 `True`, `False` 로 적습니다.
- `elif` 사슬은 처음 True 가 된 블록 하나만 실행합니다. `if` 를 따로따로 쓰면 각 `if` 를 전부 검사하므로 여러 블록이 실행될 수 있습니다.
- 위쪽 `if` 블록에서 변수 값을 바꾸면, 아래에 따로 쓴 `if` 는 바뀐 값으로 검사합니다.
- 구간을 나눌 때는 큰 기준부터 적습니다. `if s >= 70:` 을 먼저 쓰면 95점도 그 블록에서 처리되고 아래의 `elif s >= 90:` 은 검사하지 않습니다.
- 들여쓰기가 `if` 와 같은 깊이인 줄은 조건과 상관없이 실행됩니다.
- `else` 뒤에는 조건식을 쓰지 않습니다. `else x < 5:` 는 오류이고, 조건이 필요하면 `elif` 를 씁니다.
- `input()` 은 문자열을 돌려줍니다. `age = input()` 뒤의 `age >= 20` 은 TypeError 이고, `age == 20` 은 오류 없이 항상 `False` 입니다. 숫자로 비교하려면 `int(input())` 으로 받습니다.
- 계산 순서는 괄호 → 산술 → 비교 → 논리입니다. `not x == 8` 은 `not (x == 8)` 로 읽습니다.
- `and` 는 하나라도 False 면 False, `or` 는 하나라도 True 면 True 입니다. "10 이상 20 이하"처럼 범위 안을 묻는 조건은 `and` 로, "10 미만이거나 20 초과"처럼 범위 밖을 묻는 조건은 `or` 로 묶습니다.
- 비교 결과를 담아 둔 변수(`low = hp < 50`)는 `hp` 가 나중에 바뀌어도 다시 계산되지 않습니다.
- `print(a, b)` 는 값 사이에 공백 한 칸을 넣습니다. `print(37, "홀수")` 는 `37 홀수` 를 출력합니다. `8분` 처럼 붙여 쓰려면 `str(8) + "분"` 으로 이어 붙입니다.
- 문자열 비교는 대소문자를 구분합니다. `"auto" == "AUTO"` 는 `False` 입니다.
- 반환값 문제에서 `True` 를 반환하라고 했는데 `"True"`(문자열)를 반환하면 오답입니다.
