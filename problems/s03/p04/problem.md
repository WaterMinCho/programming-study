# p04. 회원 등급 (빈칸 채우기 · 6점)

한 달 구매 금액(정수)을 입력받아 회원 등급을 출력하는 프로그램입니다. 빈칸(`____`) 세 곳을 채워 완성하세요.

| 구매 금액 | 등급 |
|---|---|
| 100000원 이상 | `VIP` |
| 50000원 이상 100000원 미만 | `GOLD` |
| 10000원 이상 50000원 미만 | `SILVER` |
| 10000원 미만 | `BRONZE` |

```python
amount = int(input())
if amount >= 100000:
    print("VIP")
____ amount >= 50000:
    print("GOLD")
elif ____:
    print("SILVER")
____
    print("BRONZE")
```

- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
- 등급은 한 번에 하나만 출력되어야 합니다.

## 제한 사항
- 0 ≤ 구매 금액 ≤ 1000000

## 입출력 예

| 입력 | 출력 |
|---|---|
| `120000` | `VIP` |
| `50000` | `GOLD` |
| `49999` | `SILVER` |
| `3000` | `BRONZE` |
