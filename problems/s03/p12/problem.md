# p12. 다음 버스 (출력 · 6점)

어느 정류장에는 버스가 매시 0분, 15분, 30분, 45분에 도착합니다(15분 간격).
지금 시각의 분(0~59)을 정수로 입력받아 안내 문구를 출력하는 프로그램을 작성하세요.

- 지금이 버스가 도착하는 분이면 `버스 도착` 을 출력합니다.
- 그 밖에는 다음 버스가 올 때까지 남은 시간을 `8분 뒤 도착` 형식으로 출력합니다. 숫자와 `분` 은 **붙여** 씁니다.
- 45분을 넘긴 시각의 다음 버스는 다음 시 0분에 옵니다. 46분이면 14분 뒤입니다.

## 제한 사항
- 0 ≤ 입력 ≤ 59

## 입력 예 1

```
7
```

## 출력 예 1

```
8분 뒤 도착
```

## 입력 예 2

```
30
```

## 출력 예 2

```
버스 도착
```

## 입력 예 3

```
46
```

## 출력 예 3

```
14분 뒤 도착
```
