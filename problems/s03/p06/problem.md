# p06. 볼륨 조절 (출력 · 6점)

스피커의 볼륨은 0 이상 100 이하의 값만 가질 수 있습니다.
현재 볼륨과 변화량을 차례로 입력받아, 변화량을 더한 뒤의 볼륨을 출력하는 프로그램을 작성하세요.

- 더한 결과가 100 보다 크면 100 을 출력합니다.
- 더한 결과가 0 보다 작으면 0 을 출력합니다.
- 그 밖에는 더한 결과를 그대로 출력합니다.

## 입력
- 첫째 줄: 현재 볼륨 (0 이상 100 이하의 정수)
- 둘째 줄: 변화량 (-100 이상 100 이하의 정수, 음수면 볼륨을 줄인다는 뜻)

## 출력
- `볼륨:` 뒤에 **공백 한 칸**을 두고 결과 값을 출력합니다.

## 입력 예 1

```
50
20
```

## 출력 예 1

```
볼륨: 70
```

## 입력 예 2

```
90
20
```

## 출력 예 2

```
볼륨: 100
```

## 입력 예 3

```
10
-30
```

## 출력 예 3

```
볼륨: 0
```
