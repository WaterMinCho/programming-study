# p09. 입장료 계산 (반환값 · 8점)

과학관의 입장료는 나이에 따라 다릅니다. 나이 `age`(정수)와 회원 여부 `is_member`(`True` 또는 `False`)가 주어질 때,
내야 할 입장료(정수)를 **반환(return)** 하는 `solution` 함수를 완성하세요.

| 나이 | 기본 입장료 |
|---|---|
| 8세 미만 | 0원 (무료) |
| 8세 이상 13세 이하 | 2000원 |
| 14세 이상 19세 이하 | 3000원 |
| 20세 이상 64세 이하 | 5000원 |
| 65세 이상 | 0원 (무료) |

- 회원(`is_member` 가 `True`)이면 기본 입장료에서 1000원을 할인합니다.
- 단, 기본 입장료가 무료인 사람은 회원이어도 그대로 0원입니다(음수가 되면 안 됩니다).
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 정수를 돌려줍니다.

## 제한 사항
- 0 ≤ age ≤ 120

## 입출력 예

| age | is_member | 반환값 | 설명 |
|---|---|---|---|
| 10 | False | 2000 | 8~13세 |
| 19 | True | 2000 | 3000원에서 1000원 할인 |
| 30 | False | 5000 | 20~64세 |
| 70 | True | 0 | 무료는 할인해도 0원 |
