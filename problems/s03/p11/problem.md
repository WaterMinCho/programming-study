# p11. 놀이기구 탑승 (빈칸 채우기 · 6점)

키(cm)와 나이를 차례로 입력받아 놀이기구 탑승 안내를 출력하는 프로그램입니다. 빈칸(`____`) 세 곳을 채워 완성하세요.

| 조건 | 출력 |
|---|---|
| 키가 110 이상 190 이하이고, 나이가 8세 미만 | `보호자 동반 탑승` |
| 키가 110 이상 190 이하이고, 나이가 8세 이상 | `단독 탑승` |
| 키가 110 미만이거나 190 초과 (나이와 상관없음) | `탑승 불가` |

## 시작 코드

```python
height = int(input())
age = int(input())

```

- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
- 안내 문구는 한 번에 하나만 출력되어야 합니다.

## 입력
- 첫째 줄: 키 (50 이상 250 이하의 정수)
- 둘째 줄: 나이 (1 이상 100 이하의 정수)
