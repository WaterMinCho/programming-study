# p03. 과속 판정 (반환값 · 4점)

차량 속도 `speed` 와 도로의 제한 속도 `limit` 가 정수로 주어집니다.
속도가 제한 속도를 초과하면 문자열 `"과속"` 을, 그렇지 않으면 `"정상"` 을 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 속도가 제한 속도와 같으면 과속이 아닙니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `def` 줄과 `return answer` 줄 사이에 코드를 작성합니다.
- `print` 로 출력하는 것이 아니라 `return` 으로 돌려줘야 합니다.

## 제한 사항
- 0 ≤ speed ≤ 300
- 10 ≤ limit ≤ 150

## 입출력 예

| speed | limit | 반환값 |
|---|---|---|
| 80 | 60 | `"과속"` |
| 60 | 60 | `"정상"` |
| 45 | 50 | `"정상"` |
