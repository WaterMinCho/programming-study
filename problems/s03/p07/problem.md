# p07. 간단 계산기 (출력 · 6점)

정수 두 개와 연산 기호를 입력받아 계산 결과를 출력하는 프로그램을 작성하세요.

## 입력
- 첫째 줄: 정수 `a`
- 둘째 줄: 연산 기호(문자열)
- 셋째 줄: 정수 `b`

## 출력
- 연산 기호가 `+`, `-`, `*`, `/` 중 하나이면 `a 기호 b = 결과` 형식으로 출력합니다. 각 항목 사이는 **공백 한 칸**입니다.
  - `+` 는 덧셈, `-` 는 뺄셈, `*` 는 곱셈, `/` 는 나눗셈(파이썬의 `/` 연산 결과 그대로)입니다.
- 그 밖의 기호가 입력되면 `지원하지 않는 연산자입니다.` 를 출력합니다.

## 제한 사항
- -1000 ≤ a, b ≤ 1000
- 연산 기호가 `/` 일 때 b 는 0 이 아닙니다.

## 입력 예 1

```
7
+
3
```

## 출력 예 1

```
7 + 3 = 10
```

## 입력 예 2

```
8
/
2
```

## 출력 예 2

```
8 / 2 = 4.0
```

## 입력 예 3

```
5
%
2
```

## 출력 예 3

```
지원하지 않는 연산자입니다.
```
