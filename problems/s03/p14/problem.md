# p14. 점수 구간 학점 (출력 · 6점)

점수를 정수로 입력받아 아래 표의 학점을 출력하는 프로그램을 작성하세요.

| 점수 | 학점 |
|---|---|
| 81~100 | A |
| 61~80 | B |
| 41~60 | C |
| 21~40 | D |
| 0~20 | E |

- `81~100` 은 81 이상 100 이하를 뜻합니다. 양 끝의 점수도 그 구간에 들어갑니다.
- `grade is` 뒤에 **공백 한 칸**을 두고 학점을 출력합니다.
- `input("score: ")` 처럼 입력 안내 문구를 넣어도 됩니다. 안내 문구는 채점하지 않습니다.

## 제한 사항
- 0 ≤ 점수 ≤ 100

## 입력 예 1

```
83
```

## 출력 예 1

```
grade is A
```

## 입력 예 2

```
80
```

## 출력 예 2

```
grade is B
```

## 입력 예 3

```
20
```

## 출력 예 3

```
grade is E
```
