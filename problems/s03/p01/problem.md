# p01. 로봇 조종 모드 (빈칸 채우기 · 4점)

로봇의 조종 모드를 문자열로 입력받아 안내 문구를 출력하는 프로그램입니다.
입력이 정확히 `auto` 이면 자동 주행 문구를, 그 밖의 모든 경우에는 수동 조종 문구를 출력하도록 빈칸(`____`)을 채우세요.

```python
mode = input()
if ____:
    print("로봇이 스스로 움직입니다.")
else:
    print("로봇을 직접 조종합니다.")
```

- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
- 문자열 비교는 대소문자를 구분합니다. `AUTO` 는 `auto` 와 다른 값입니다.

## 입출력 예

| 입력 | 출력 |
|---|---|
| `auto` | `로봇이 스스로 움직입니다.` |
| `manual` | `로봇을 직접 조종합니다.` |
| `AUTO` | `로봇을 직접 조종합니다.` |
