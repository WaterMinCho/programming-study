# p07. 직사각형 넓이 문장 (빈칸 채우기 · 6점)

직사각형의 가로와 세로 길이를 정수로 차례로 입력받아, 넓이를 구해 한 문장으로 출력하는 프로그램입니다. 빈칸(`____`)을 채워 프로그램을 완성하세요.

- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
- 첫째 줄에 가로, 둘째 줄에 세로가 입력됩니다(둘 다 1 이상의 정수).
- 출력 문장은 문자열을 `+` 로 이어 붙여 만듭니다. 숫자와 뒤따르는 글자(`인`, `입니다.`) 사이에 공백이 없어야 합니다.

## 시작 코드

```python
width = int(input())
height = int(input())
area = width ____ height
print("가로 " + str(width) + ", 세로 " + ____ + "인 직사각형의 넓이는 " + ____ + "입니다.")
```

## 입출력 예

입력

```
4
5
```

출력

```
가로 4, 세로 5인 직사각형의 넓이는 20입니다.
```

입력

```
12
3
```

출력

```
가로 12, 세로 3인 직사각형의 넓이는 36입니다.
```
