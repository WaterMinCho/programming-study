# p14. 두 단어를 한 줄에 출력하기 (빈칸 채우기 · 4점)

단어 두 개를 한 줄에 하나씩 입력받아, `print` 를 두 번 써서 두 단어를 공백 없이 한 줄에 이어 출력하는 프로그램입니다. 빈칸(`____`)을 채워 프로그램을 완성하세요.

- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
- 첫째 줄과 둘째 줄에 단어가 하나씩 입력됩니다.
- 세미콜론(`;`)은 한 줄에 명령을 여러 개 쓸 때 씁니다.

## 시작 코드

```python
first = input()
second = input()
print(first, ____); print(second)
```

## 입출력 예

입력

```
first
second
```

출력

```
firstsecond
```

입력

```
Ro
bot
```

출력

```
Robot
```
