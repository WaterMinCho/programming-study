# p10. 거스름돈 동전 세기 (출력 · 8점)

거스름돈 금액(원)을 정수로 입력받아, 500원·100원·10원짜리 동전으로 거슬러 줄 때 각 동전이 몇 개 필요한지 출력하는 프로그램을 작성하세요.

- 큰 동전부터 최대한 많이 사용합니다. (500원으로 줄 수 있는 만큼 주고, 남은 금액을 100원으로, 그다음 남은 금액을 10원으로 줍니다)
- 입력되는 금액은 0 이상 100000 이하인 10 의 배수입니다.
- 필요 없는 동전도 `0개` 로 출력합니다.

## 입출력 예

입력

```
1740
```

출력

```
500원: 3개
100원: 2개
10원: 4개
```

1740원 = 500원 × 3 + 100원 × 2 + 10원 × 4 입니다.

입력

```
90
```

출력

```
500원: 0개
100원: 0개
10원: 9개
```

- 콜론(`:`) 뒤에 공백이 한 칸 있고, 숫자와 `개` 사이에는 공백이 없습니다.
- 항상 500원, 100원, 10원 순서로 세 줄을 출력합니다.
