# p13. 로봇 주행 기록 (출력 · 8점)

로봇이 트랙을 돈 기록을 한 줄에 하나씩 네 줄로 입력받아, 주행 거리와 주행 시간을 아래 형식으로 출력하는 프로그램을 작성하세요.

입력되는 값

- 첫째 줄: 로봇 이름(문자열)
- 둘째 줄: 트랙 한 바퀴의 길이(m). `2.5` 처럼 소수점이 있는 수로 입력됩니다.
- 셋째 줄: 돈 바퀴 수(0 이상의 정수)
- 넷째 줄: 걸린 시간(초, 0 이상의 정수)

출력할 내용

- 첫째 줄에는 로봇 이름을 출력합니다.
- 둘째 줄의 주행 거리는 한 바퀴의 길이에 바퀴 수를 곱한 값입니다. 곱셈 결과를 `15.0` 처럼 소수점이 붙은 실수로 출력합니다.
- 셋째 줄의 주행 시간은 걸린 시간을 분과 초로 나눠 출력합니다. 분과 초는 소수점 없는 정수이고, 60분 이상이어도 시간 단위로 바꾸지 않습니다.

## 입출력 예

입력

```
터틀봇
2.5
6
135
```

출력

```
로봇: 터틀봇
주행 거리: 15.0m
주행 시간: 2분 15초
```

2.5m 트랙을 6바퀴 돌면 15.0m 이고, 135초는 2분 15초입니다.

입력

```
R2
0.5
3
59
```

출력

```
로봇: R2
주행 거리: 1.5m
주행 시간: 0분 59초
```

- 콜론(`:`) 뒤와 `분` 뒤에 공백이 한 칸씩 있습니다. 숫자와 `m`, `분`, `초` 사이에는 공백이 없습니다.
- 한 바퀴의 길이는 0.25 의 배수(예: `0.5`, `2.25`, `4.0`)만 입력됩니다.
