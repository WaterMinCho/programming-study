# p11. 연산자 채워 넣기 (빈칸 채우기 · 6점)

프로그램을 실행하면 아래 출력 예와 같은 두 줄이 나오도록, 빈칸(`____`)마다 산술 연산자를 한 개씩 채우세요.

- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
- 빈칸 하나에는 `+`, `-`, `*`, `/`, `//`, `%`, `**` 가운데 한 개가 들어갑니다. 같은 연산자를 여러 번 써도 됩니다.
- 숫자와 괄호는 바꾸지 않습니다.

## 시작 코드

```python
print(7 ____ 3 ____ 2)
print((7 ____ 3) * 2)
```

## 출력 예

```
13
2
```

- 소수점이 없는 정수로 출력되어야 합니다(`13.0`, `2.0` 은 오답).
