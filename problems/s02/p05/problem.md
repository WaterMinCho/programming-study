# p05. 총 무게 구하기 (반환값 · 4점)

부품 한 개의 무게(kg)가 **문자열** `weight` 로(예: `"2.5"`), 부품의 개수가 정수 `count` 로 주어집니다.
전체 무게(한 개의 무게 × 개수)를 **실수(float)로 반환** 하는 `solution` 함수를 완성하세요.

- 함수 이름과 매개변수는 바꾸지 않습니다.
- `print` 로 출력하는 것이 아니라 `return` 으로 돌려줘야 합니다.
- 반환값의 자료형은 실수(float)여야 합니다. 정수 `9` 나 문자열 `"9.0"` 을 반환하면 오답입니다.

## 제한 사항
- `weight` 는 0 이상 100 이하의 수를 문자열로 적은 것입니다. `"3"` 처럼 소수점 없이 적혀 있을 수도 있습니다.
- 0 ≤ `count` ≤ 100

## 입출력 예

| weight | count | 반환값 |
|---|---|---|
| `"2.5"` | `4` | `10.0` |
| `"0.5"` | `3` | `1.5` |
| `"3"` | `3` | `9.0` |
