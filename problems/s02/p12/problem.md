# p12. 총점과 평균 문장 (반환값 · 8점)

두 과목의 점수가 정수를 적은 **문자열** `first`, `second` 로 주어집니다(예: `"84"`, `"91"`).
두 점수의 총점과 평균을 구해 `"총점 175점, 평균 87.5점"` 형식의 **문자열로 반환** 하는 `solution` 함수를 완성하세요.

- 함수 이름과 매개변수는 바꾸지 않습니다. `def` 줄과 `return answer` 줄 사이에, `answer` 줄과 같은 칸(공백 4칸)에 맞춰 코드를 작성합니다.
- 구한 답을 `answer` 에 저장하면 `return answer` 줄이 그 값을 돌려줍니다. `print` 로 출력만 하면 오답입니다.
- 총점은 두 점수를 숫자로 더한 값이며 소수점 없이 적습니다(`175.0` 은 오답).
- 평균은 총점을 `/` 연산자로 2 로 나눈 결과를 적습니다. 나누어떨어질 때도 `90.0` 처럼 소수점 아래가 붙습니다.
- `총점`, 쉼표(`,`), `평균` 뒤에 공백이 한 칸씩 있고, 숫자와 `점` 사이에는 공백이 없습니다.

## 제한 사항
- `first`, `second` 는 0 이상 100 이하의 정수를 문자열로 적은 것입니다.

## 입출력 예

| first | second | 반환값 |
|---|---|---|
| `"84"` | `"91"` | `"총점 175점, 평균 87.5점"` |
| `"90"` | `"90"` | `"총점 180점, 평균 90.0점"` |
| `"5"` | `"50"` | `"총점 55점, 평균 27.5점"` |
