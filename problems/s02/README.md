# 2차시 · 프로그래밍 기초

변수, 자료형, 입력과 출력, 산술 연산자, 주석, 자료형 변환을 다룹니다.
뒤 차시의 모든 "눈으로 실행하기" 문제가 이 내용을 바탕으로 하므로, 표와 함정 목록은 시험 직전에 한 번 더 읽어 두세요.

## 1. 프로그램과 데이터

- 프로그램은 데이터와 명령어로 이루어집니다. 필요한 데이터를 변수에 담아 두고, 어떤 명령을 어떤 순서로 실행할지 미리 적어 둔 계획입니다.
- 컴퓨터 구조(폰 노이만 구조): `입력 장치 → CPU(제어 장치 + 산술/논리 장치) ⇄ 메모리 → 출력 장치`
- 프로그램이 실행되는 순서: 입력 장치(키보드 등)로 값을 받는다 → 메인 메모리에 저장한다 → CPU 가 명령어 순서대로 처리한다 → 결과를 출력 장치(모니터)에 보여 준다
- **자료형(데이터 타입)** 은 데이터를 종류별로 나눈 것입니다.

| 자료형 | 이름 | 예 |
|---|---|---|
| 정수 | `int` | `10`, `-2`, `0` |
| 실수 | `float` | `1.5`, `-0.25`, `4.0` |
| 문자열 | `str` | `"robot"`, `'2.5'`, `"True"` |
| 불리언 | `bool` | `True`, `False` |

리스트·튜플·딕셔너리·클래스도 자료형이며 뒤 차시에서 배웁니다.

문자열은 작은따옴표나 큰따옴표로 감쌉니다. 따옴표로 감싸면 안에 무엇이 적혀 있든 문자열입니다(`'2.5'`, `"False"`).

## 2. 변수

- 변수는 값을 저장하는 공간(메모리, RAM)에 붙인 이름입니다. 숫자·문자열 등 어떤 자료형이든 담을 수 있습니다.
- 이름 규칙
  - 문자, 숫자, 밑줄(`_`)만 사용
  - 대문자와 소문자를 구분 (`count` 와 `Count` 는 다른 변수)
  - 공백 불가, 숫자로 시작 불가
  - 예약어(키워드) 불가 — `if`, `for`, `while`, `def`, `class`, `return`, `import`, `in`, `is`, `and`, `or`, `not`, `True`, `False`, `None` 등. 전체 목록은 `import keyword` 후 `print(keyword.kwlist)` 로 볼 수 있습니다.

| 쓸 수 있음 | 쓸 수 없음 (이유) |
|---|---|
| `total`, `my_score`, `_tmp`, `robot2` | `2robot` (숫자로 시작), `my score` (공백), `for` (예약어) |

- **대입 연산자 `=`** 는 오른쪽 값을 왼쪽 변수에 저장합니다. 수학의 "같다"가 아닙니다.
  - 왼쪽(l_value)은 변수 이름, 오른쪽(r_value)은 저장할 값
  - 오른쪽을 먼저 계산하고, 그 결과를 왼쪽에 저장합니다.
  - `=` 없이 변수만 쓰면(`print(count)`, `count + 1`) 그 변수에 저장된 값을 뜻합니다.
- 변수의 자료형은 저장한 값이 정합니다(이름과는 무관).

```python
steps = 3        # 정수형 변수
ratio = 0.5      # 실수형 변수
name = "rokey"   # 문자열 변수

count = 0
count = count + 1    # 오른쪽 0 + 1 을 먼저 계산 → count 는 1
other = count        # 지금 값 1 을 복사
count = count + 1    # count 는 2, other 는 그대로 1
```

## 3. 출력 — print()

- `print(값)` 은 값을 화면에 출력하고 줄을 바꿉니다. 돌려주는 값(반환값)은 없습니다.
- 괄호 안에 넣는 값을 **인수(argument)** 라고 합니다. 쉼표로 여러 개를 넣으면 값 사이에 공백 한 칸이 들어갑니다.

```python
total = 30
print("합계", total)               # 합계 30
print("합계=", total)              # 합계= 30   ← = 뒤에 공백이 생긴다
print(12, "+", 18, "=", total)     # 12 + 18 = 30
```

- 따옴표가 들어간 문장은 다른 종류의 따옴표로 감쌉니다.

```python
print("Tom's robot")          # Tom's robot
print('그가 말했다. "출발"')    # 그가 말했다. "출발"
```

- 문자열 안의 `\n` 은 줄바꿈, `\t` 는 탭 간격입니다. (한글 키보드의 `₩` 와 `\` 는 같은 글자)
- `end=""` 를 넣으면 출력 뒤에 줄을 바꾸지 않습니다. 세미콜론(`;`)은 한 줄에 명령 여러 개를 쓸 때 씁니다.

```python
print("A\nB\tC")                      # 첫 줄 A, 둘째 줄 B(탭)C
print("Ro", end=""); print("bot")    # Robot (한 줄에 붙어서 출력)
```

- (주간 요약본에 나오는 표현) 문자열 앞에 `f` 를 붙이면 `{변수}` 자리에 값이 그대로 들어갑니다.

```python
team = "ROKEY"
print(f"{team} 11기")   # ROKEY 11기
```

## 4. 입력 — input()

- `input()` 은 키보드로 한 줄을 입력받아 항상 문자열(`str`)로 돌려줍니다. 숫자를 입력해도 문자열입니다.
- `input("안내 문구")` 의 문자열은 입력을 기다릴 때 화면에 보여 주는 설명입니다.

```python
a = input()      # 12 입력
b = input()      # 7 입력
print(a + b)     # 127  ← 문자열끼리 이어 붙음
```

## 5. 산술 연산자

| 연산자 | 뜻 | 예 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `7 + 2` | `9` |
| `-` | 빼기 | `7 - 2` | `5` |
| `*` | 곱하기 | `7 * 2` | `14` |
| `/` | 나누기 | `7 / 2`, `6 / 3` | `3.5`, `2.0` |
| `//` | 몫 | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `7 ** 2` | `49` |

- `/` 의 결과는 항상 실수입니다. 나누어떨어져도 `6 / 3` 은 `2.0` 입니다.
- 정수끼리의 `//`, `%`, `+`, `-`, `*`, `**` 는 정수입니다. 실수가 하나라도 섞이면 결과는 실수입니다(`7.0 // 2` → `3.0`).
- `+` 는 두 가지 역할을 합니다. 숫자 + 숫자는 덧셈, 문자열 + 문자열은 이어 붙이기입니다. 문자열 + 숫자는 오류(TypeError)입니다. 문자열끼리 `-` 도 오류입니다.

## 6. 주석

- `#` 부터 그 줄 끝까지는 실행되지 않습니다. 설명을 달거나, 코드 한 줄을 잠시 빼 둘 때 씁니다.
- 여러 줄은 따옴표 3개(`'''` 또는 `"""`)로 시작과 끝을 감쌉니다.

```python
price = 3500   # 김밥 한 줄 값
# print("이 줄은 실행되지 않는다")
"""
여기부터 여기까지
전부 실행되지 않는다
"""
```

## 7. 자료형 변환

| 함수 | 하는 일 | 예 |
|---|---|---|
| `int()` | 정수로 변환 | `int("20")` → `20` |
| `float()` | 실수로 변환 | `float("2.5")` → `2.5`, `float("3")` → `3.0` |
| `str()` | 문자열로 변환 | `str(25)` → `"25"` |
| `type()` | 자료형 확인 | `print(type("20"))` → `<class 'str'>` |

입력값으로 계산하려면 반드시 숫자로 바꿉니다.

```python
a = int(input())     # 12 입력
b = int(input())     # 7 입력
print(a, "+", b, "=", a + b)                 # 12 + 7 = 19
print(str(a) + "개와 " + str(b) + "개를 합치면 " + str(a + b) + "개")   # 12개와 7개를 합치면 19개
```

## 시험에서 헷갈리기 쉬운 포인트

- `input()` 은 언제나 문자열입니다. `"20" + "5"` 는 `"205"` 이고, `"20" - "5"` 나 `"20" + 3` 은 TypeError 입니다.
- `/` 는 항상 실수입니다. `8 / 2` 는 `4` 가 아니라 `4.0`. 정수 결과가 필요하면 `//`.
- `//` 는 몫, `%` 는 나머지, `**` 는 거듭제곱(`5 ** 2` 는 10 이 아니라 25).
- `print` 의 쉼표는 공백 한 칸을 넣습니다. `print("합계=", 30)` → `합계= 30`. 숫자와 글자를 붙여 쓰려면(`30개`) `str(30) + "개"` 처럼 이어 붙입니다.
- `print()` 는 한 번 부를 때마다 줄이 바뀝니다. 줄을 바꾸지 않으려면 `end=""`.
- 따옴표로 감싸면 문자열입니다. `"True"`, `'2.5'`, `"10"` 은 모두 `str`.
- `True` / `False` 는 따옴표 없이, 첫 글자를 대문자로 써야 불리언(`bool`)입니다.
- `int(year)` 는 바꾼 값을 돌려줄 뿐 `year` 자체를 바꾸지 않습니다. 바꾼 값을 쓰려면 `year = int(year)` 처럼 다시 저장해야 합니다.
- `b = a` 는 그 순간의 값을 복사합니다. 뒤에 `a` 를 바꿔도 `b` 는 그대로입니다.
- 대입문은 오른쪽부터 계산합니다. `count = count + 1` 은 "지금 값에 1 을 더해 다시 저장".
- 변수 이름은 대소문자를 구분합니다. `Count` 와 `count` 는 서로 다른 변수.
- 따옴표 안의 `#` 은 주석이 아니라 그냥 글자입니다. `print("# 메모")` 는 `# 메모` 를 출력합니다.
- `int("2.5")` 처럼 소수점이 있는 문자열은 `int()` 로 바로 바꿀 수 없습니다(오류). 실수 모양 문자열은 `float()` 로 바꿉니다.
- `type()` 의 출력 모양은 `<class 'int'>`, `<class 'float'>`, `<class 'str'>`, `<class 'bool'>` 입니다. 꺾쇠와 작은따옴표까지 그대로 적습니다.
- `print`, `input`, `int`, `type` 은 예약어가 아니라 함수 이름입니다. 변수 이름으로 쓰면 오류는 나지 않지만 원래 함수를 쓸 수 없게 되므로 쓰지 않습니다.
