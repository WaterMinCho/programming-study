# 2차시 · 프로그래밍 기초

변수, 자료형, 입력과 출력, 산술 연산자, 주석, 자료형 변환을 다룹니다.
뒤 차시의 "눈으로 실행하기" 문제는 모두 이 내용 위에서 풀게 되므로, 표와 맨 아래 목록은 시험 직전에 한 번 더 읽어 두세요.

## 1. 프로그램과 데이터

- 프로그램은 컴퓨터가 할 일을 미리 적어 둔 계획이고, 데이터(data)와 그 데이터를 처리하는 명령어(instruction)를 합친 것입니다.
- 필요한 데이터를 변수에 저장하고, 어떤 명령어를 어떤 순서로 실행할지 정해서 프로그램을 만듭니다. 명령어의 순서를 정하는 일을 알고리즘이라고 합니다.
- 명령어에는 조건문, 반복문, 함수가 있습니다. **함수**는 특정 동작을 수행하는 코드를 모아 둔 것입니다. 이번 차시에는 미리 만들어져 있는 입출력 함수 `input()` 과 `print()` 를 씁니다.
- 컴퓨터 구조(폰 노이만 구조): `입력 장치 → CPU(제어 장치 + 산술/논리 장치) ⇄ 메모리 → 출력 장치`
- 프로그램이 실행되는 순서: 입력 장치(키보드 등)로 값을 받는다 → 메인 메모리에 저장한다 → CPU 가 명령어 순서대로 처리한다 → 결과를 출력 장치(모니터)에 보여 준다

| 구분 | 표준 장치 | 표준 함수 |
|---|---|---|
| 입력 | 키보드 | `input()` |
| 출력 | 모니터 | `print()` |

**자료형(데이터 타입)** 은 데이터를 종류별로 나눈 것입니다.

| 자료형 | 이름 | 예 |
|---|---|---|
| 정수 | `int` | `10`, `-2`, `0` |
| 실수 | `float` | `1.5`, `-0.25`, `4.0` |
| 문자열 | `str` | `"robot"`, `'2.5'`, `"True"` |
| 불리언 | `bool` | `True`, `False` |

리스트·튜플·딕셔너리·클래스도 자료형이며 뒤 차시에서 배웁니다.

문자열은 작은따옴표나 큰따옴표로 감쌉니다. 따옴표로 감싸면 안에 무엇이 적혀 있든 문자열입니다(`'2.5'`, `"False"`).

## 2. 변수

- 변수는 값을 저장하는 공간(메모리, RAM)에 붙인 이름입니다. 컴퓨터는 저장 위치를 숫자(주소)로 기억하고, 우리는 변수 이름으로 그 값을 꺼내 씁니다. 숫자·문자열 등 어떤 자료형이든 담을 수 있습니다.
- 이름 규칙
  - 문자, 숫자, 밑줄(`_`)만 사용합니다. 한글도 문자라서 `평균 = 80` 은 실행됩니다. `my-score` 는 `my` 에서 `score` 를 빼는 식으로 읽혀서 이름으로 쓸 수 없습니다.
  - 대문자와 소문자를 구분합니다(`total` 과 `Total` 은 서로 다른 변수).
  - 공백을 넣을 수 없고, 숫자로 시작할 수 없습니다.
  - 예약어(키워드)는 쓸 수 없습니다. `if`, `for`, `while`, `def`, `class`, `return`, `import`, `in`, `is`, `and`, `or`, `not`, `True`, `False`, `None` 등이 예약어이고, 전체 목록은 `import keyword` 후 `print(keyword.kwlist)` 로 볼 수 있습니다.

| 쓸 수 있음 | 쓸 수 없음 (이유) |
|---|---|
| `total`, `my_score`, `_tmp`, `robot2`, `평균` | `2robot` (숫자로 시작), `my score` (공백), `my-score` (빼기 식), `for`·`None` (예약어) |

- **대입 연산자 `=`** 는 오른쪽 값을 왼쪽 변수에 저장합니다. 수학의 "같다"가 아닙니다.
  - 왼쪽(l_value)에는 변수 이름을, 오른쪽(r_value)에는 저장할 값을 적습니다.
  - 오른쪽을 먼저 계산하고, 그 결과를 왼쪽에 저장합니다. 오른쪽에 쓰인 변수의 값은 바뀌지 않습니다.
  - `=` 없이 변수만 쓰면(`print(count)`, `count + 1`) 그 변수에 저장된 값을 뜻합니다.
- 변수의 자료형은 이름이 아니라 저장한 값이 정합니다.

```python
steps = 3        # 정수형 변수
ratio = 0.5      # 실수형 변수
name = "rokey"   # 문자열 변수

count = 0
count = count + 1    # 오른쪽 0 + 1 을 먼저 계산 → count 는 1
other = count        # 지금 값 1 을 복사
count = count + 1    # count 는 2, other 는 1

unit = 800
cost = unit * 5      # cost 는 4000, unit 은 800
```

## 3. 출력: print()

- `print(값)` 은 값을 화면에 출력하고 줄을 바꿉니다. 돌려주는 값(반환값)은 없어서 `result = print("안녕")` 을 실행하면 `result` 에는 `None` 이 저장됩니다.
- 괄호 안에 넣는 값을 **인수(argument)** 라고 합니다. 쉼표로 여러 개를 넣으면 값 사이에 공백 한 칸이 들어갑니다.

```python
total = 30
print("합계", total)               # 합계 30
print("합계=", total)              # 합계= 30   ← = 뒤에 공백이 생긴다
print(12, "+", 18, "=", total)     # 12 + 18 = 30
```

- 따옴표가 들어간 문장은 다른 종류의 따옴표로 감쌉니다.

```python
print("I'm ready")            # I'm ready
print('그가 말했다. "출발"')    # 그가 말했다. "출발"
```

- 문자열 안의 `\n` 은 줄바꿈, `\t` 는 탭 간격입니다. 한글 키보드에서 `₩` 로 보이는 글자도 `\` 와 똑같이 동작합니다.
- `end=""` 를 넣으면 출력 뒤에 줄을 바꾸지 않습니다. 세미콜론(`;`)은 한 줄에 명령 여러 개를 쓸 때 씁니다.

```python
print("A\nB\tC")                      # 첫 줄 A, 둘째 줄 B(탭)C
print("Ro", end=""); print("bot")    # Robot (한 줄에 붙어서 출력)
```

- (주간 요약본에 나오는 표현) 문자열 앞에 `f` 를 붙이면 `{변수}` 자리에 값이 그대로 들어갑니다.

```python
team = "ROKEY"
print(f"{team} 11기")   # ROKEY 11기
```

## 4. 입력: input()

- `input()` 은 키보드로 한 줄을 입력받아 항상 문자열(`str`)로 돌려줍니다. 숫자를 입력해도 문자열입니다.
- `input("안내 문구")` 의 문자열은 입력을 기다릴 때 화면에 보여 주는 설명입니다.

```python
a = input()      # 12 입력
b = input()      # 7 입력
print(a + b)     # 127  ← 문자열끼리 이어 붙음
```

## 5. 산술 연산자

| 연산자 | 뜻 | 예 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `9 + 4` | `13` |
| `-` | 빼기 | `9 - 4` | `5` |
| `*` | 곱하기 | `9 * 4` | `36` |
| `/` | 나누기 | `9 / 4`, `8 / 4` | `2.25`, `2.0` |
| `//` | 몫 | `9 // 4` | `2` |
| `%` | 나머지 | `9 % 4` | `1` |
| `**` | 거듭제곱 | `9 ** 2` | `81` |

- `/` 의 결과는 항상 실수입니다. 나누어떨어져도 `8 / 4` 는 `2.0` 입니다.
- 정수끼리 `+`, `-`, `*`, `//`, `%` 로 계산한 결과는 정수입니다. `9 ** 2` 도 정수 `81` 입니다.
- 실수가 하나라도 섞이면 결과는 실수입니다(`9.0 // 4` → `2.0`). 계산 결과를 변수에 저장해도 자료형이 유지되므로, 실수가 저장된 변수로 계산하면 `//` 를 써도 실수가 나옵니다.

```python
score = 20
score = score + 1.5 * 4    # 20 + 6.0 → 26.0
print(score // 5)          # 5.0 (정수 5 가 아님)
```

- 한 식에 연산자가 여럿 있으면 수학과 같은 순서로 계산합니다. 괄호 안을 가장 먼저 계산하고, 곱셈과 나눗셈을 덧셈과 뺄셈보다 먼저 계산합니다. 비교·논리 연산자까지 포함한 우선순위는 3차시에서 배웁니다.

```python
print(5 + 4 * 3)        # 17    (4 * 3 을 먼저 계산)
print((5 + 4) * 3)      # 27    (괄호 안을 먼저 계산)
print((70 + 85) / 2)    # 77.5
print(70 + 85 / 2)      # 112.5 (85 / 2 를 먼저 계산)
```

- `+` 는 양쪽이 숫자면 덧셈을 하고, 양쪽이 문자열이면 두 문자열을 이어 붙입니다. 문자열 + 숫자는 오류(TypeError)가 나고, 문자열끼리 `-` 를 해도 오류가 납니다.

## 6. 주석

- `#` 부터 그 줄 끝까지는 실행되지 않습니다. 설명을 달거나, 코드 한 줄을 잠시 빼 둘 때 씁니다.
- 여러 줄은 따옴표 3개(`'''` 또는 `"""`)로 시작과 끝을 감쌉니다.

```python
price = 3500   # 김밥 한 줄 값
# print("이 줄은 실행되지 않는다")
"""
여기부터 여기까지
전부 실행되지 않는다
"""
```

## 7. 자료형 변환

| 함수 | 하는 일 | 예 |
|---|---|---|
| `int()` | 정수로 변환 | `int("20")` → `20` |
| `float()` | 실수로 변환 | `float("2.5")` → `2.5`, `float("3")` → `3.0` |
| `str()` | 문자열로 변환 | `str(25)` → `"25"`, `str(90.0)` → `"90.0"` |
| `type()` | 자료형 확인 | `print(type("20"))` → `<class 'str'>` |

입력값으로 계산하려면 반드시 숫자로 바꿉니다. 어떤 함수로 바꿀지는 입력값의 쓰임에 따라 고릅니다. `2.5` 처럼 소수점이 있는 수는 `float(input())`, 정수는 `int(input())` 로 받고, 이름처럼 계산에 쓰지 않는 값은 `input()` 이 돌려준 문자열을 바꾸지 않고 씁니다.

```python
a = int(input())     # 12 입력
b = int(input())     # 7 입력
print("합:", a + b, "/ 차:", a - b)             # 합: 19 / 차: 5
print(str(a) + "개와 " + str(b) + "개를 합치면 " + str(a + b) + "개")   # 12개와 7개를 합치면 19개
```

계산은 숫자로 하고, 숫자를 글자와 붙여 문장을 만들 때 `str()` 로 다시 문자열로 바꿉니다.

```python
left = "30"
right = "45"
length = int(left) + int(right)      # 75 (정수)
half = length / 2                    # 37.5 (실수)
print("전체 " + str(length) + "cm, 절반 " + str(half) + "cm")   # 전체 75cm, 절반 37.5cm
```

## 8. 반환값 문제의 시작 코드

반환값 문제는 아래와 같은 시작 코드로 나옵니다. 함수(`def`, `return`)는 6차시에서 배우고, 2차시 문제에서는 이 틀을 주어진 대로 두고 가운데만 채웁니다.

```python
def solution(width, height):
    answer = 0
    return answer
```

- 괄호 안의 `width`, `height` 에는 문제에서 준 값이 이미 들어 있습니다. `input()` 으로 다시 입력받지 않습니다.
- `def` 줄과 `return answer` 줄 사이에서 답을 계산해 `answer` 에 저장합니다. 마지막 줄 `return answer` 가 그 값을 돌려줍니다.
- 새로 쓰는 줄은 `answer` 줄과 같은 칸(공백 4칸)에서 시작합니다. 칸이 어긋나면 오류가 납니다.
- `print()` 로 답을 출력만 하고 `answer` 에 저장하지 않으면 오답입니다.
- 값이 같아도 자료형이 다르면 오답입니다. 정수 `14` 를 돌려줘야 하는 문제에서 `"14"` 나 `14.0` 을 돌려주면 틀립니다.

아래 답안은 가로 3, 세로 4 가 주어지면 직사각형의 둘레 14 를 돌려줍니다.

```python
def solution(width, height):
    side_sum = width + height
    answer = side_sum * 2
    return answer
```

## 시험에서 헷갈리기 쉬운 포인트

- `input()` 은 언제나 문자열입니다. `"20" + "5"` 는 `"205"` 이고, `"20" - "5"` 나 `"20" + 3` 은 TypeError 입니다.
- `/` 의 결과는 항상 실수입니다. `8 / 2` 는 `4` 가 아니라 `4.0` 이고, 정수 몫이 필요하면 `//` 를 씁니다.
- `//` 는 몫, `%` 는 나머지, `**` 는 거듭제곱을 구합니다. `3 ** 2` 는 6 이 아니라 9 입니다.
- `//` 를 써도 실수가 섞여 있으면 결과는 실수입니다. `9.0 // 2` 는 `4` 가 아니라 `4.0` 이고 `type(9.0 // 2)` 는 `<class 'float'>` 입니다.
- 곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 계산됩니다. 평균을 구할 때 `a + b / 2` 로 쓰면 `b` 만 2 로 나뉘므로 `(a + b) / 2` 처럼 괄호로 묶습니다.
- `print` 의 쉼표는 공백 한 칸을 넣습니다. `print("합계=", 30)` → `합계= 30`. 숫자와 글자를 붙여 쓰려면(`30개`) `str(30) + "개"` 처럼 이어 붙입니다.
- `print()` 는 한 번 부를 때마다 줄이 바뀝니다. 줄을 바꾸지 않으려면 `end=""` 를 넣습니다.
- 따옴표로 감싸면 문자열입니다. `"True"`, `'2.5'`, `"10"` 의 자료형은 모두 `str` 입니다.
- `True` / `False` 는 따옴표 없이, 첫 글자를 대문자로 써야 불리언(`bool`)입니다.
- `int(age)` 는 바꾼 값을 돌려줄 뿐 `age` 에 저장된 문자열을 바꾸지 않습니다. 바꾼 값을 쓰려면 `age = int(age)` 처럼 다시 저장해야 합니다.
- `b = a` 는 그 순간의 값을 복사합니다. 뒤에 `a` 에 다른 값을 저장해도 `b` 에 저장된 값은 바뀌지 않습니다.
- 대입문은 오른쪽부터 계산합니다. `count = count + 1` 은 지금 값에 1 을 더한 결과를 `count` 에 다시 저장합니다.
- 변수 이름은 대소문자를 구분합니다. `Total` 과 `total` 은 서로 다른 변수입니다.
- 따옴표 안의 `#` 은 주석이 아니라 그냥 글자입니다. `print("# 메모")` 는 `# 메모` 를 출력합니다.
- `int("2.5")` 처럼 소수점이 있는 문자열은 `int()` 로 바로 바꿀 수 없습니다(오류). 실수 모양 문자열은 `float()` 로 바꿉니다.
- `type()` 의 출력 모양은 `<class 'int'>`, `<class 'float'>`, `<class 'str'>`, `<class 'bool'>` 입니다. 꺾쇠와 작은따옴표까지 그대로 적습니다.
- `print`, `input`, `int`, `type` 은 예약어가 아니라 함수 이름입니다. `input = 3` 처럼 변수 이름으로 써도 오류는 나지 않지만 원래 함수를 쓸 수 없게 되므로 쓰지 않습니다. `True`, `False`, `None` 은 예약어라서 `None = 3` 은 오류입니다.
