# p03. 스택 명령 처리 (반환값 · 4점)

정수 리스트 `commands` 가 주어집니다. 각 정수는 스택에 대한 명령입니다.

- 양수 `n` 은 스택에 `n` 을 push 합니다.
- `0` 은 스택에서 pop 합니다. 스택이 비어 있으면 아무 일도 하지 않습니다.

모든 명령을 차례로 처리한 뒤 스택의 상태를 리스트로 **반환(return)** 하는 `solution` 함수를 완성하세요.
스택의 맨 아래가 리스트의 앞, 맨 위가 리스트의 뒤입니다.

- 함수 이름과 매개변수는 바꾸지 않습니다.
- `print` 로 출력하는 것이 아니라 `return` 으로 돌려줘야 합니다.

## 제한 사항
- `commands` 의 길이는 0 이상 100 이하
- 각 원소는 0 이상 1000 이하의 정수

## 입출력 예

| commands | 반환값 |
|---|---|
| `[3, 5, 0, 7]` | `[3, 7]` |
| `[1, 2, 3]` | `[1, 2, 3]` |
| `[0, 0, 4]` | `[4]` |
| `[]` | `[]` |

첫 번째 예: 3 push → `[3]`, 5 push → `[3, 5]`, pop → `[3]`, 7 push → `[3, 7]`.
