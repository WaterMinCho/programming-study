# p01. 스택과 큐에서 꺼내기 (빈칸 채우기 · 4점)

숫자 세 개를 입력받아 같은 순서로 스택과 큐에 넣은 뒤, 각각에서 하나씩 꺼내는 프로그램입니다.
빈칸(`____`) 2곳을 채워 프로그램을 완성하세요.

- 스택은 마지막에 넣은 것을, 큐는 처음에 넣은 것을 꺼냅니다.
- 꺼낸 값은 `print` 로 바로 출력합니다(꺼내는 메서드가 돌려주는 값을 그대로 씁니다).
- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

```python
stack = []
queue = []
for i in range(3):
    data = int(input())
    stack.append(data)
    queue.append(data)

print("스택에서 꺼냄:", stack.____)
print("큐에서 꺼냄:", queue.____)
print("스택:", stack)
print("큐:", queue)
```

## 입출력 예

입력

```
1
2
3
```

출력

```
스택에서 꺼냄: 3
큐에서 꺼냄: 1
스택: [1, 2]
큐: [2, 3]
```
