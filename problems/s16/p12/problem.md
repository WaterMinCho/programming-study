# p12. 여러 종류의 괄호 짝 검사 (반환값 · 8점)

문자열 `s` 에 소괄호 `(` `)`, 중괄호 `{` `}`, 대괄호 `[` `]` 가 섞여 있습니다.
괄호의 짝이 올바르게 맞으면 `True`, 아니면 `False` 를 반환하는 `solution` 함수를 스택을 이용해 완성하세요.

- 닫는 괄호는 아직 닫히지 않은 여는 괄호 가운데 **가장 나중에 열린 것**과 같은 종류여야 합니다. `"([)]"` 는 `)` 를 만났을 때 가장 나중에 열린 괄호가 `[` 라서 `False` 입니다.
- 닫는 괄호를 만났는데 아직 닫히지 않은 여는 괄호가 하나도 없으면 `False` 입니다.
- 끝까지 봤을 때 닫히지 않은 여는 괄호가 남아 있으면 `False` 입니다.
- 괄호가 아닌 문자는 무시합니다. 괄호가 하나도 없는 문자열(빈 문자열 포함)은 `True` 입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줍니다.

## 제한 사항
- `s` 의 길이는 0 이상 100 이하

## 입출력 예

| s | 반환값 |
|---|---|
| `"([]{})"` | `True` |
| `"([)]"` | `False` |
| `"(]"` | `False` |
| `"{[("` | `False` |
| `"a[0]+(b*{c})"` | `True` |
| `"())"` | `False` |
