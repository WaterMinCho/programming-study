# p17. 후위 표기법 계산 (반환값 · 8점)

후위 표기법(Postfix Notation)은 연산자를 피연산자 뒤에 적는 표기법입니다. `3 4 +` 는 `3 + 4` 를 나타내고 결과는 7 입니다.
후위 표기법 수식이 담긴 문자열 `expr` 이 주어질 때, 계산 결과를 **반환(return)** 하는 `solution` 함수를 스택을 이용해 완성하세요.

계산은 수식을 공백으로 나눠 앞에서부터 하나씩 보면서 합니다.

- 숫자는 정수로 바꿔 스택에 넣습니다.
- 연산자를 만나면 스택에서 값 두 개를 꺼내 계산하고, 결과를 다시 스택에 넣습니다. 먼저 꺼낸 값이 연산자의 **오른쪽**, 나중에 꺼낸 값이 **왼쪽**에 옵니다. `5 3 -` 는 `5 - 3` 입니다.
- 끝까지 본 뒤 스택에 하나 남은 값이 답입니다.

연산자는 `+`, `-`, `*`, `/` 네 가지이고, 파이썬의 같은 연산자로 계산합니다. 수식에 연산자가 여러 개 있을 수 있습니다.

- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줍니다.
- 계산한 값을 자료형을 바꾸지 않고 반환합니다. `/` 가 없는 수식의 결과는 정수이고, `/` 가 있는 수식의 결과는 실수입니다. 정수 `4` 와 실수 `4.0` 은 다른 답으로 채점됩니다.

## 제한 사항
- 숫자와 연산자는 공백 한 칸으로 구분됩니다.
- 수식의 숫자는 0 이상 1000 이하의 정수입니다. 두 자리 이상의 수도 나옵니다.
- 수식은 항상 올바른 후위 표기법이고, 0 으로 나누는 경우는 주어지지 않습니다.

## 입출력 예

| expr | 반환값 |
|---|---|
| `"3 4 +"` | `7` |
| `"5 3 -"` | `2` |
| `"2 3 4 * +"` | `14` |
| `"8 2 /"` | `4.0` |
| `"5 1 2 + 4 * + 3 -"` | `14` |

세 번째 예: 2, 3, 4 를 차례로 넣어 `[2, 3, 4]`, `*` 에서 3 과 4 를 꺼내 12 를 넣어 `[2, 12]`, `+` 에서 2 와 12 를 꺼내 14 를 넣어 `[14]` 가 됩니다.
