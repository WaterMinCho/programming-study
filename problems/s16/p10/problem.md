# p10. 브라우저 방문 기록 (출력 · 8점)

웹 브라우저의 뒤로 가기를 스택으로 흉내 내는 `Browser` 클래스를 정의하세요.

| 구분 | 이름 | 내용 |
|---|---|---|
| 생성자 | `__init__()` | 방문 기록을 담을 빈 리스트 `pages` 를 인스턴스 변수로 만듭니다 |
| 메서드 | `visit(page)` | `page` 를 `pages` 의 맨 뒤에 넣고 `방문: page` 를 출력합니다 |
| 메서드 | `back()` | `pages` 에 페이지가 2개 이상이면 마지막 페이지를 제거하고, 제거한 뒤 마지막에 남은 페이지를 `뒤로: page` 형식으로 출력합니다. 1개 이하이면 아무것도 제거하지 않고 `뒤로 갈 수 없음` 을 출력합니다 |
| 메서드 | `current()` | 현재 페이지(마지막 페이지)를 반환합니다. 기록이 비어 있으면 `None` 을 반환합니다 |

- 클래스만 정의하면 됩니다. 채점할 때는 아래와 같은 테스트 코드가 객체를 만들어 메서드를 호출합니다.
- 출력은 글자 하나까지 같아야 합니다(콜론 뒤 공백 한 칸).

## 테스트 코드와 출력 예

```python
b = Browser()
b.visit("home")
b.visit("news")
b.back()
print(b.current())
```

```
방문: home
방문: news
뒤로: home
home
```

```python
b = Browser()
b.back()
print(b.current())
b.visit("a")
b.back()
print(b.pages)
```

```
뒤로 갈 수 없음
None
방문: a
뒤로 갈 수 없음
['a']
```
