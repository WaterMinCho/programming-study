# p04. 대기열 처리 (출력 · 4점)

창구 앞에 선 손님을 큐로 관리하는 프로그램을 작성하세요.

입력

- 첫 줄에 손님 수 `n`
- 다음 `n` 줄에 손님 이름이 줄 선 순서대로 한 줄에 하나씩
- 마지막 줄에 처리할 손님 수 `m` (0 ≤ m ≤ n)

출력

- 먼저 온 손님부터 `m` 명을 차례로 `처리: 이름` 형식으로 한 줄씩 출력합니다.
- 마지막 줄에 아직 기다리는 손님의 리스트를 `대기: ` 뒤에 그대로 출력합니다(리스트를 `print` 한 형태).

## 입출력 예

입력

```
3
Kim
Lee
Park
2
```

출력

```
처리: Kim
처리: Lee
대기: ['Park']
```

입력

```
2
A
B
2
```

출력

```
처리: A
처리: B
대기: []
```

- 출력은 글자 하나까지 같아야 합니다(콜론 뒤 공백 한 칸, 리스트 표기 포함).
