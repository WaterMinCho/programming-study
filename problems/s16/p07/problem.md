# p07. 회전 큐 (출력 · 6점)

숫자들을 덱(deque)에 넣은 뒤 왼쪽으로 `k` 만큼 회전시키고, 그 덱을 출력하는 프로그램을 작성하세요.

- 왼쪽으로 1 회전은 맨 앞 요소를 꺼내 맨 뒤에 붙이는 것입니다. 이것을 `k` 번 반복합니다.
- `collections` 모듈의 `deque` 를 사용하고, 마지막에 덱 객체를 그대로 `print` 합니다(출력은 `deque([...])` 형태가 됩니다).

입력

- 첫 줄에 숫자의 개수 `n` (1 ≤ n ≤ 20)
- 다음 `n` 줄에 정수가 한 줄에 하나씩
- 마지막 줄에 회전 횟수 `k` (0 ≤ k ≤ 100)

## 입출력 예

입력

```
5
1
2
3
4
5
2
```

출력

```
deque([3, 4, 5, 1, 2])
```

입력

```
3
7
8
9
4
```

출력

```
deque([8, 9, 7])
```

- 두 번째 예: 왼쪽으로 4 번 회전하면 `[8, 9, 7]` → `[9, 7, 8]` → `[7, 8, 9]` → `[8, 9, 7]` 입니다.
- 출력은 글자 하나까지 같아야 합니다(`deque(`, 쉼표 뒤 공백 포함).
