# p05. txt 파일 수 세기 (반환값 · 6점)

폴더 경로 `folder_path` 가 주어질 때, 그 폴더 **바로 안에** 있는 파일 가운데 확장자가 `.txt` 인 파일의 개수를 정수로 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 하위 폴더 안에 든 파일은 세지 않습니다.
- 파일만 셉니다. 이름이 `.txt` 로 끝나는 폴더가 있어도 세지 않습니다.
- 확장자는 파일 이름의 마지막 점부터 끝까지입니다. `memo.txt.bak` 의 확장자는 `.bak` 이고, `app.log.txt` 의 확장자는 `.txt` 입니다.
- 필요한 모듈은 직접 `import` 합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줘야 합니다.

## 제한 사항
- `folder_path` 는 실제로 있는 폴더의 경로입니다.
- 확장자는 모두 영어 소문자입니다.

## 입출력 예

| 폴더의 상태 | folder_path | 반환값 |
|---|---|---|
| `docs` 폴더에 파일 `a.txt`, `b.txt`, `c.png` 가 있음 | `"docs"` | `2` |
| `docs` 폴더에 파일 `memo.txt` 와 폴더 `sub` 가 있고, `sub` 안에 `inner.txt` 가 있음 | `"docs"` | `1` |
| `notes` 폴더에 파일 `readme.md` 만 있음 | `"notes"` | `0` |
