# p07. config.ini 에서 값 불러오기 (출력 · 6점)

현재 폴더의 `config.ini` 파일에는 한 줄에 하나씩 `키 = 값` 형식으로 설정이 적혀 있습니다. 키 하나를 입력받아 `config.ini` 에서 그 키의 값을 찾아 출력하는 프로그램을 작성하세요.

- `os` 모듈로 `config.ini` 가 있는지 먼저 확인합니다. 파일이 없으면 `설정 파일이 없습니다` 한 줄만 출력합니다.
- 파일이 있으면 모든 줄을 읽어 첫째 줄에 `설정 N개` (`N` 은 설정의 개수)를 출력합니다.
- 둘째 줄에는 `키: 값` 을 출력합니다. 입력받은 키가 파일에 없으면 `키: 없음` 을 출력합니다.
- 키와 값은 `=` 를 기준으로 나눕니다. `=` 양옆과 줄 앞뒤의 공백 수는 줄마다 다를 수 있고, 키와 값에서 양 끝의 공백은 뺍니다. 값 가운데에 있는 공백은 그대로 둡니다.
- `config.ini` 는 UTF-8 로 저장되어 있습니다. 열 때 `encoding="utf-8"` 을 지정합니다.

## 제한 사항
- 입력은 키 한 줄입니다.
- `config.ini` 에 빈 줄은 없고, 줄마다 `=` 가 한 번씩 들어 있습니다. 같은 키가 두 번 나오지 않습니다.
- 마지막 줄 끝에는 줄바꿈 문자가 있을 수도 있고 없을 수도 있습니다.

## 입출력 예

`config.ini` 의 내용이 다음과 같을 때

```
1반 = 홍길동
2반 = 김철수
3반 = 박영희
4반 = 최로키
```

| 입력 | 출력 |
|---|---|
| `3반` | `설정 4개`⏎`3반: 박영희` |
| `5반` | `설정 4개`⏎`5반: 없음` |

첫 번째 예의 출력

```
설정 4개
3반: 박영희
```

`config.ini` 가 없을 때는 무엇을 입력해도 다음과 같이 출력합니다.

```
설정 파일이 없습니다
```

- 출력은 글자 하나까지 같아야 합니다(띄어쓰기 포함).
