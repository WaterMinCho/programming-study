# p02. 배수 판별 (반환값 · 4점)

정수 `num` 이 정수 `base` 의 배수이면 문자열 `"배수"` 를, 아니면 `"아님"` 을 **반환(return)** 하는 `solution` 함수를 완성하세요.

- `base` 를 **생략하고 호출하면 2 의 배수인지**(짝수인지) 판별해야 합니다. 이를 위해 `def` 줄에서 `base` 에 디폴트 값을 지정하세요.
- 함수 이름과 매개변수의 이름·순서는 바꾸지 않습니다.
- `print` 로 출력하는 것이 아니라 `return` 으로 돌려줘야 합니다.

## 제한 사항
- -1000 ≤ num ≤ 1000
- 1 ≤ base ≤ 100
- 0 은 모든 수의 배수로 봅니다. (`num % base` 가 0 이면 배수)

## 입출력 예

| 호출 | 반환값 |
|---|---|
| `solution(10)` | `"배수"` |
| `solution(7)` | `"아님"` |
| `solution(9, 3)` | `"배수"` |
| `solution(10, 4)` | `"아님"` |
