# p01. 임시 변수로 맞바꾸기 (빈칸 채우기 · 4점)

두 정수를 입력받아 변수 `a`, `b` 에 저장한 뒤, 임시 변수 `temp` 를 이용해 두 변수의 값을 서로 맞바꾸는(SWAP) 프로그램입니다.
빈칸(`____`)을 채워 프로그램을 완성하세요.

- 첫째 줄에 입력한 수가 `a`, 둘째 줄에 입력한 수가 `b` 에 저장됩니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

입력 예 1

```
3
8
```

출력 예 1

```
a 값은 8 b 값은 3
```

입력 예 2

```
10
11
```

출력 예 2

```
a 값은 11 b 값은 10
```

## 시작 코드

```python
a = int(input())
b = int(input())

temp = a
a = ____
b = ____

print("a 값은", a, "b 값은", b)
```
