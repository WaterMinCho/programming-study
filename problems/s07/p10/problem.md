# p10. 입금과 출금 (출력 · 8점)

시작 코드에는 통장 잔액을 나타내는 전역 변수 `balance = 0` 이 있습니다.
두 함수 `deposit`, `withdraw` 가 **같은 전역 변수 `balance` 를 함께 사용**하도록 정의하세요.

- `deposit(money)`: `balance` 에 `money` 를 더한 뒤 `입금 <money> 잔액 <balance>` 형식으로 출력합니다.
- `withdraw(money)`
  - `money` 가 `balance` 보다 크면 잔액을 바꾸지 않고 `잔액 부족` 만 출력합니다.
  - 그렇지 않으면 `balance` 에서 `money` 를 뺀 뒤 `출금 <money> 잔액 <balance>` 형식으로 출력합니다.
- 함수를 **정의만** 하면 됩니다. 채점기가 두 함수를 여러 번 호출한 뒤 전역 변수 `balance` 도 출력해 확인합니다.
- 전역 변수 이름 `balance` 는 바꾸지 않습니다.

## 제한 사항
- 1 ≤ money ≤ 1,000,000 (정수)

## 출력 예

아래 코드를 차례로 실행하면

```python
deposit(3000)
withdraw(1000)
withdraw(5000)
print(balance)
```

다음과 같이 출력되어야 합니다.

```
입금 3000 잔액 3000
출금 1000 잔액 2000
잔액 부족
2000
```

- 낱말과 숫자 사이는 공백 한 칸입니다. 잔액과 같은 금액은 출금할 수 있습니다(잔액 0).
