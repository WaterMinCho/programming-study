# p04. 값을 돌려주는 SWAP 함수 (빈칸 채우기 · 6점)

두 정수를 입력받아 `na`, `nb` 에 저장하고, `swap` 함수를 이용해 두 변수의 값을 맞바꾸는 프로그램입니다.

함수 안에서 매개변수 `pa`, `pb` 를 맞바꾸는 것만으로는 함수 밖의 `na`, `nb` 가 바뀌지 않습니다.
함수가 **맞바꾼 두 값을 반환**하고, 호출한 쪽에서 그 값을 **`na`, `nb` 에 다시 대입**하도록 빈칸(`____`)을 채우세요.

- 첫째 줄에 입력한 수가 `na`, 둘째 줄에 입력한 수가 `nb` 에 저장됩니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

입력 예 1

```
3
8
```

출력 예 1

```
교환 전: 3 8
교환 후: 8 3
```

입력 예 2

```
10
11
```

출력 예 2

```
교환 전: 10 11
교환 후: 11 10
```

## 시작 코드

```python
def swap(pa, pb):
    temp = pa
    pa = pb
    pb = temp
    return ____


na = int(input())
nb = int(input())
print("교환 전:", na, nb)
____ = swap(na, nb)
print("교환 후:", na, nb)
```
