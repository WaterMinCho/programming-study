# p09. 세 수를 작은 순서로 (반환값 · 8점)

정수 `a`, `b`, `c` 가 주어질 때, 세 수를 **작은 수부터 차례로 담은 리스트**를 반환하는 `solution` 함수를 완성하세요.

- 두 변수의 값을 맞바꾸는 SWAP 을 이용해 보세요. 예를 들어 `a` 가 `b` 보다 크면 두 값을 맞바꿉니다. 이런 비교를 몇 번, 어떤 순서로 해야 항상 정렬되는지 생각해 보세요.
- 시작 코드의 `a: int`, `-> list` 는 타입 힌트입니다. 매개변수와 반환값의 자료형을 알려 주는 표시일 뿐 동작에는 영향을 주지 않습니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항
- -1000 ≤ a, b, c ≤ 1000
- 같은 수가 여러 번 주어질 수 있습니다.

## 입출력 예

| a | b | c | 반환값 |
|---|---|---|---|
| 3 | 1 | 2 | `[1, 2, 3]` |
| 3 | 2 | 1 | `[1, 2, 3]` |
| 5 | 5 | 1 | `[1, 5, 5]` |
| -1 | -7 | 0 | `[-7, -1, 0]` |

- 반환값은 리스트여야 합니다. (튜플 `(1, 2, 3)` 은 오답)
