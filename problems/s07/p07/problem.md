# p07. 재귀 함수로 합 구하기 (빈칸 채우기 · 6점)

0 이상의 정수 `num` 을 입력받아 1 부터 `num` 까지의 합을 출력하는 프로그램입니다.
`total(n)` 은 **자기 자신을 다시 호출하는 재귀 함수**로, "1 부터 n 까지의 합 = n + (1 부터 n-1 까지의 합)" 이라는 관계를 이용합니다.

- `n` 이 0 이면 더 이상 자신을 호출하지 않고 멈춥니다(기저 조건). 0 까지의 합은 0 입니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 제한 사항
- 0 ≤ num ≤ 100

## 입출력 예

| 입력 | 출력 |
|---|---|
| `4` | `10` |
| `0` | `0` |
| `10` | `55` |

- 입력이 4 이면 4 + 3 + 2 + 1 = 10 입니다.
