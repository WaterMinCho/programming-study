# p06. 별 상자 출력 (출력 · 6점)

`*` 로 채운 직사각형을 출력하는 `print_box` 함수를 정의하세요.

- 매개변수는 순서대로 `width`(가로 길이), `height`(세로 길이)입니다.
- 한 줄에 `*` 를 `width` 개씩, 모두 `height` 줄을 출력합니다.
- 인수를 생략하면 `width` 는 3, `height` 는 2 로 동작해야 합니다(디폴트 매개변수).
- 함수를 **정의만** 하면 됩니다. 채점기가 직접 호출해서 출력을 확인합니다.

## 제한 사항
- 1 ≤ width, height ≤ 20

## 출력 예

`print_box()` 를 호출하면

```
***
***
```

`print_box(5)` 를 호출하면

```
*****
*****
```

`print_box(2, 4)` 를 호출하면

```
**
**
**
**
```

- `*` 사이에 공백이 없습니다.
