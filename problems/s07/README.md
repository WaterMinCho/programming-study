# 7차시 · 함수(2)

6차시에서 함수를 만들고 부르는 법을 배웠습니다. 이번 차시에서는 함수 안의 변수와 함수 밖의 변수가 서로 다른 공간에 놓인다는 점을 코드로 확인합니다.
SWAP, 전역 변수·지역 변수, `global`, 디폴트 매개변수, 타입 힌트, 재귀 함수를 다룹니다.

## 1. SWAP: 두 값 맞바꾸기

두 변수의 값을 서로 바꾸려면 값 하나를 잠깐 맡아 둘 **임시 변수**가 필요합니다.

```python
a = 3
b = 8

temp = a    # a 의 값을 맡겨 둔다
a = b       # a 에 b 의 값을 넣는다
b = temp    # 맡겨 둔 값을 b 에 넣는다
print(a, b)   # 8 3
```

- 임시 변수 없이 `a = b` 다음에 `b = a` 를 하면 둘 다 8 이 됩니다. `a = b` 를 실행하는 순간 a 에 있던 3 이 지워지기 때문입니다.
- 파이썬은 대입문 왼쪽에 변수를 여러 개 쓸 수 있어서 `a, b = b, a` 한 줄로도 바꿀 수 있습니다.

## 2. 함수로 SWAP 하면 왜 안 바뀔까

```python
def swap(pa, pb):
    temp = pa
    pa = pb
    pb = temp

na = 3
nb = 8
swap(na, nb)
print(na, nb)   # 3 8
```

함수를 호출하면 인수의 값이 매개변수에 대입됩니다(`pa = na`, `pb = nb`). 매개변수 `pa`, `pb` 는 `swap` 함수 안에서만 쓸 수 있는 변수라서, 함수 안에서 두 값을 맞바꿔도 바깥의 `na`, `nb` 에는 3 과 8 이 남아 있습니다. 함수가 끝나면 `pa`, `pb`, `temp` 는 사라집니다.

고치려면 바꾼 값을 `return` 으로 돌려주고, 호출한 쪽에서 다시 대입합니다.

```python
def swap(pa, pb):
    temp = pa
    pa = pb
    pb = temp
    return pa, pb

na = 3
nb = 8
na, nb = swap(na, nb)      # 돌려받은 값을 전역 변수에 다시 넣는다
print(na, nb)   # 8 3
```

## 3. 네임스페이스 · 전역 변수 · 지역 변수

**네임스페이스(namespace, 이름공간)** 는 변수 이름을 정의하는 공간이고, 한 네임스페이스 안에서 같은 이름은 변수 하나만 가리킵니다.
프로그램 전체가 쓰는 전역 네임스페이스가 있고, 함수마다 자기만의 지역 네임스페이스가 따로 생깁니다.
그래서 함수 안과 밖에 이름이 같은 변수가 있어도 서로 다른 변수입니다.
변수 이름이 통하는 범위는 **유효범위(스코프, scope)** 라고 부릅니다.

| | 전역 변수 (Global) | 지역 변수 (Local) |
|---|---|---|
| 만드는 곳 | 함수 바깥 | 함수 안 (매개변수 포함) |
| 쓸 수 있는 범위 | 프로그램 전체 (모든 함수에서 읽기 가능) | 그 함수 안에서만 |
| 사라지는 때 | 프로그램이 끝날 때 | 함수 실행이 끝날 때 |

```python
x = 1            # 전역 변수

def test():
    x = 50       # 이름만 같은 지역 변수가 새로 생긴다
    print(x)     # 50

test()
print(x)         # 1
```

함수 안에서 만든 지역 변수를 함수 밖에서 쓰면 `NameError` 가 납니다.

```python
def make():
    result = 7

make()
print(result)    # NameError
```

지역 변수는 호출이 끝날 때마다 사라지므로, 같은 함수를 다시 호출하면 처음부터 새로 만들어집니다.

## 4. global 키워드

함수 안에서 `global 변수이름` 을 선언하면 그 함수에서 쓰는 그 이름은 전역 변수를 가리킵니다.
같은 이름의 지역 변수는 만들어지지 않습니다.

```python
x = 1

def test():
    global x
    x = 50       # 전역 x 를 바꾼다
    print(x)     # 50

test()
print(x)         # 50
```

전역에 그 이름의 변수가 아직 없어도 `global` 로 선언할 수 있습니다. 함수 안의 대입문이 전역 변수를 새로 만듭니다. 함수를 호출해야 대입문이 실행되므로, 호출 전에는 그 변수가 없습니다.

```python
def set_mode():
    global mode
    mode = 3         # 전역 변수 mode 가 만들어진다

set_mode()
print(mode)          # 3   (set_mode() 호출 없이 출력하면 NameError)
```

### 읽기는 되지만 대입하면 오류: UnboundLocalError

```python
x = 10

def show(num):
    b = x + num      # 전역 x 를 읽기만 한다 (20)
    print(b)

def change(num):
    x = x + num      # UnboundLocalError
    print(x)

show(10)
change(10)
```

함수 안에 `x = ...` 대입문이 있으면 파이썬은 `x` 를 그 함수의 지역 변수로 취급합니다.
그런데 오른쪽의 `x + num` 을 계산하려는 순간 지역 변수 `x` 에는 아직 값이 없습니다. 할당 전에 참조해서 오류가 나는 것입니다.
대입문이 아래쪽에 있어도 같은 오류가 납니다. `print(x)` 다음 줄에 `x = 1` 이 있는 함수는 `print(x)` 에서 멈춥니다.

고치는 방법에 따라 전역 변수 `x` 가 바뀌기도 하고 10 으로 남기도 합니다.

```python
def change(num):     # 방법 1: global 선언. 전역 x 가 바뀐다
    global x
    x = x + num
    print(x)
```

```python
def change(num):     # 방법 2: 지역 변수로 초기화. 전역 x 는 10 으로 남는다
    x = 0
    x = x + num
    print(x)
```

## 5. 디폴트 매개변수

매개변수와 인수는 원래 하나씩 짝이 맞아야 하고, 개수가 맞지 않으면 `TypeError` 가 납니다.
매개변수에 기본값을 적어 두면, 그 자리의 인수를 생략했을 때 기본값이 쓰입니다.

```python
def room(width=6, height=2):
    print(width, height)

room()        # 6 2
room(9)       # 9 2   인수는 왼쪽 매개변수부터 채워진다
room(9, 5)    # 9 5
```

- 기본값이 없는 매개변수는 생략할 수 없습니다. `def order(menu, count=1)` 에서 `order()` 는 오류, `order("라떼")` 는 정상입니다.
- 기본값이 있는 매개변수는 기본값이 없는 매개변수 뒤쪽에 둡니다.
- 같은 이름으로 함수를 두 번 정의해도 두 개가 생기지 않고 나중에 정의한 것만 남습니다. 매개변수 개수만 다른 함수를 따로 만드는 대신 디폴트 매개변수를 씁니다.

## 6. 타입 힌트

매개변수와 반환값이 어떤 자료형이길 기대하는지 적어 두는 표시입니다(파이썬 3.5 이상).

```python
def double(x: int) -> int:
    return x * 2

print(double(4))      # 8
print(double(1.5))    # 3.0   힌트와 맞지 않는 값을 넘겨도 오류 없이 실행된다
```

형식은 `def 함수이름(매개변수: 타입, ...) -> 반환타입:` 입니다.
읽는 사람과 검사 도구를 위한 안내문일 뿐 강제성이 없고, 값이 자동으로 변환되지도 않습니다.

## 7. 재귀 함수

함수가 자기 자신을 다시 호출하는 기법입니다.
재귀 호출을 멈추는 조건을 **기저 조건(Base case)**, 자기 자신을 호출하는 부분을 **재귀 단계(Recursive step)** 라고 부릅니다.

```python
def stairs(n):
    if n == 0:           # 기저 조건
        print("바닥")
        return
    print("*" * n)
    stairs(n - 1)        # 재귀 단계
```

`stairs(3)` 을 호출하면 다음과 같이 출력됩니다.

```
***
**
*
바닥
```

`return` 뒤에 값을 적지 않으면 값 없이 함수만 끝냅니다. 기저 조건에서 함수를 끝낼 때 자주 씁니다.
이때 끝나는 것은 `return` 을 실행한 그 호출뿐이고, 그 호출을 부른 바깥 호출은 재귀 호출 다음 줄부터 이어서 실행됩니다.

```python
def up(n):
    if n == 0:
        return
    up(n - 1)
    print(n)         # 재귀 호출 뒤의 줄은 안쪽 호출이 모두 끝난 다음에 실행된다

up(3)                # 1, 2, 3 순서로 출력된다
```

재귀 함수도 값을 반환할 수 있습니다. 안쪽 호출의 반환값을 받아 계산을 이어 갑니다.

```python
def fact(n):
    if n == 1:
        return 1
    return n * fact(n - 1)      # fact(4) = 4 * 3 * 2 * 1 = 24
```

재귀 호출도 보통의 함수 호출이라 디폴트 매개변수 규칙이 똑같이 적용됩니다. 재귀 호출에서 인수를 생략하면 안쪽 호출은 기본값으로 실행됩니다.

```python
def stars(n, mark="*"):
    if n == 0:
        return
    print(mark * n)
    stars(n - 1, mark)      # mark 를 넘기지 않으면 둘째 줄부터 "*" 로 출력된다

stars(3, "#")               # ###, ##, # 순서로 출력된다
```

## 시험에서 헷갈리기 쉬운 포인트

- 함수 안에서 매개변수를 바꿔도 바깥 변수의 값은 바뀌지 않습니다. 값을 돌려받아 다시 대입하지 않는 SWAP 함수는 호출해도 바깥 값이 처음 값으로 남습니다.
- 임시 변수 없이 `a = b`, `b = a` 를 차례로 실행하면 두 변수가 같은 값이 됩니다.
- 이름이 같아도 함수 안에서 대입하면 새 지역 변수가 생깁니다. `global` 이 없으면 전역 변수는 변하지 않습니다.
- `global x` 가 있으면 함수 안의 `x = ...` 가 전역 변수를 바꿉니다. 함수를 정의하기만 하고 호출하지 않으면 전역 변수는 바뀌지 않습니다.
- 오류 이름 구분: 함수 밖에서 지역 변수 사용은 `NameError`, 함수 안에서 `global` 없이 `x = x + 1` 은 `UnboundLocalError`, 인수 개수가 안 맞으면 `TypeError`.
- 전역 변수를 함수 안에서 읽기만 하는 것은 `global` 없이도 됩니다. 오류는 함수 안에 그 이름에 대한 대입문이 있는데 대입보다 먼저 값을 읽으려 할 때 납니다.
- 지역 변수로 초기화해서 `UnboundLocalError` 를 없앤 함수는 전역 변수를 바꾸지 못합니다. 호출할 때마다 지역 변수가 초기값에서 다시 시작합니다.
- 디폴트 매개변수의 인수는 왼쪽부터 채워집니다. `room(9)` 는 첫 번째 매개변수만 9 가 되고 나머지에는 기본값이 쓰입니다.
- `print("width=", 6)` 의 출력은 `width= 6` 입니다. 쉼표로 나열하면 사이에 공백 한 칸이 들어갑니다.
- 같은 이름의 함수를 다시 정의하면 앞의 정의는 사라집니다. 앞의 방식으로 호출하면 `TypeError` 가 납니다.
- 파이썬은 실행할 때 타입 힌트를 검사하지 않습니다. `int` 라고 적어 둔 자리에 `1.5` 를 넘겨도 오류가 나지 않고, 정수로 바뀌지도 않습니다.
- 재귀 함수는 `print` 가 재귀 호출의 앞에 있는지 뒤에 있는지에 따라 출력 순서가 달라집니다. 앞에 있으면 바깥 호출의 값부터, 뒤에 있으면 가장 안쪽 호출의 값부터 출력됩니다.
- 기저 조건을 `n == 0` 으로 적었는데 `n` 이 2 씩 줄어 0 을 건너뛰면 기저 조건에 도달하지 못합니다. 끝없이 호출되다가 오류(RecursionError)가 납니다.
- `return pa, pb` 처럼 값 두 개를 돌려주면 받는 쪽도 `na, nb = swap(na, nb)` 처럼 두 변수로 받습니다.
