# p12. 간격을 두고 더하는 재귀 함수 (빈칸 채우기 · 8점)

`total(n, step)` 은 `n` 에서 시작해 `step` 씩 줄여 가며 만나는 수 가운데 **0 보다 큰 수를 모두 더한 값**을 반환하는 재귀 함수입니다.

- `total(7, 3)` 은 7 + 4 + 1 = 12 를 반환합니다. 1 다음에 만나는 -2 는 0 보다 크지 않아서 더하지 않습니다.
- `step` 을 생략하고 호출하면 1 씩 줄입니다. `total(4)` 는 4 + 3 + 2 + 1 = 10 을 반환합니다.

프로그램은 정수 `num`, `gap` 을 한 줄에 하나씩 입력받아 첫째 줄에 `total(num)`, 둘째 줄에 `total(num, gap)` 을 출력합니다.
빈칸(`____`)을 채워 프로그램을 완성하세요.

- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 제한 사항
- 0 ≤ num ≤ 100
- 1 ≤ gap ≤ 100

## 입출력 예

입력 예 1

```
7
3
```

출력 예 1

```
28
12
```

- 첫째 줄은 7 + 6 + 5 + 4 + 3 + 2 + 1 = 28, 둘째 줄은 7 + 4 + 1 = 12 입니다.

입력 예 2

```
5
2
```

출력 예 2

```
15
9
```

- 첫째 줄은 5 + 4 + 3 + 2 + 1 = 15, 둘째 줄은 5 + 3 + 1 = 9 입니다.
