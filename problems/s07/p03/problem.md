# p03. 할인가 출력 함수 (출력 · 4점)

상품 가격 `price` 를 매개변수로 받아, 정가와 **10% 할인된 가격**을 아래 형식으로 출력하는 `print_sale_price` 함수를 정의하세요.

- 함수를 **정의만** 하면 됩니다. 채점기가 `print_sale_price(20000)` 처럼 직접 호출해서 출력을 확인합니다.
- `price` 는 항상 10 의 배수인 양의 정수입니다.
- 할인된 가격은 **정수**로 출력합니다. `18000.0` 처럼 소수점이 붙으면 오답입니다.

## 출력 예

`print_sale_price(20000)` 을 호출하면

```
정가: 20000
할인가: 18000
```

`print_sale_price(990)` 을 호출하면

```
정가: 990
할인가: 891
```

- 콜론(`:`) 뒤에 공백이 한 칸 있습니다. 출력은 글자 하나까지 같아야 합니다.
