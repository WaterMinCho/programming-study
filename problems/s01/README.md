# 1차시 · 파이썬 소개 및 환경설정

이 차시는 코드보다 용어와 개념이 중심입니다. 객관식으로 묻기 좋은 내용이 많으니, 비슷한 용어의 뜻을
정확히 구분해 두세요. 코드는 `print()` 한 가지만 나옵니다.

## 1. 파이썬은 어떤 언어인가

- **1991년**에 처음 공개된 범용 고급 프로그래밍 언어입니다.
- **인터프리터 방식**으로 실행됩니다.

| 용어 | 뜻 |
|---|---|
| 인터프리터 | 소스 코드를 실행하는 도중에 해석해 가며 실행하는 프로그램 |
| 컴파일 방식 | 소스 코드를 미리 다른 형태의 코드로 바꿔 놓은 뒤 실행하는 방식 |

파이썬의 특징 (서술형·객관식 단골)

- 배우고 쓰기 쉽다(문법이 간단하다)
- 여러 운영체제에서 쓸 수 있다
- 무료 소프트웨어(오픈소스)다
- 라이브러리와 패키지가 풍부하다
- 객체지향 프로그래밍을 지원한다
- 인공지능·데이터 분석·백엔드·임베디드 등 여러 분야에서 쓰인다

## 2. 설치와 기본 개발 환경 IDLE

- 공식 사이트(python.org)의 Downloads 에서 내 운영체제에 맞는 설치 파일을 받아 설치합니다.
- 설치 창 아래쪽의 체크 상자 두 개(관리자 권한 사용, **Add python.exe to PATH**)를 체크하고 [Install Now] 를 누릅니다.
  (나중에 VSCode 에서 파이썬 인터프리터가 선택되지 않으면 파이썬 설치 여부와 환경 변수 Path 설정을 확인합니다.)
- **IDLE**(Integrated Development and Learning Environment): 파이썬을 설치하면 함께 들어오는 기본 개발 환경입니다. 따로 설치하지 않습니다.
- **대화형 셸**: `>>>` 뒤에 명령을 한 줄 입력하고 엔터를 누르면 바로 실행 결과를 보여 줍니다.

```
>>> print('Hello Python!')
Hello Python!
```

## 3. 첫 명령 print() 와 오류 메시지 읽기

`print()` 는 괄호 안 따옴표 사이의 내용을 그대로 화면에 출력합니다.

```python
print('Hello Python!')
print("ROKEY 11기")
print("1 + 2")
```

```
Hello Python!
ROKEY 11기
1 + 2
```

- 작은따옴표(`'`)와 큰따옴표(`"`) 어느 쪽으로 감싸도 결과는 같습니다.
- 따옴표 자체는 출력되지 않습니다.
- 따옴표 안은 계산하지 않습니다. 셋째 줄은 `3` 이 아니라 `1 + 2` 가 글자 그대로 나옵니다.
- `print()` 를 한 번 부를 때마다 줄이 바뀝니다. 명령은 위에서 아래로 차례대로 실행됩니다.
- 따옴표 안의 띄어쓰기·대소문자·기호는 하나도 바뀌지 않고 그대로 나옵니다.

파이썬은 대소문자를 구분합니다. `print` 를 `Print` 로 쓰면 오류가 납니다.

```
>>> Print('Hello Python!')
Traceback (most recent call last):
  File "<pyshell#0>", line 1, in <module>
    Print('Hello Python!')
NameError: name 'Print' is not defined
```

오류 메시지에서 읽을 수 있는 것

| 위치 | 알 수 있는 것 |
|---|---|
| `File "…", line 1` | 오류가 난 파일(위치)과 줄 번호 |
| 그 아래 줄 | 오류가 난 명령 |
| 마지막 줄 | 오류의 종류(`NameError`)와 이유(`Print` 라는 이름이 정의되어 있지 않다) |

오류 메시지는 "어디서, 왜" 틀렸는지를 알려 줍니다. 고친 코드를 대신 써 주지는 않습니다.
(최신 버전은 마지막 줄 끝에 `Did you mean: 'print'?` 같은 힌트를 덧붙이기도 합니다.)

## 4. 파이썬 개발 도구

| 도구 | 분류 | 기억할 점 |
|---|---|---|
| IDLE | 코드 편집기 | 파이썬에 기본 탑재, 대화형 셸 제공 |
| PyCharm | 통합개발환경(IDE) | |
| VSCode (Visual Studio Code) | 통합개발환경(IDE) | macOS·Linux·Windows 에서 실행되는 무료 코드 편집기 |
| Colab (Colaboratory) | 웹 브라우저 개발 환경 | 구글 제공, 클라우드 기반 |

**IDE**(Integrated Development Environment, 통합개발환경)는 개발에 필요한 도구를 한데 모은 환경입니다.

- 코드 편집기: 코드를 작성하는 곳
- **터미널**: 명령어를 입력해 컴퓨터를 직접 제어하는 소프트웨어
- **디버거**: 프로그램을 검사하고, 에러가 났을 때 고치는 일을 돕는 도구

## 5. VSCode 기본 사용법

- 화면 구성: 상단 메뉴 / 좌측 메뉴 / 탐색기 / 텍스트 에디터 / 하단 상태 표시
- 기능: 코드 자동 완성, 디버깅, 터미널 실행 등
- 실습 흐름
  1. [File → Open Folder] 로 작업 폴더를 엽니다.
  2. 탐색기에서 새 폴더와 새 파일을 만듭니다. 파이썬 파일의 확장자는 **`.py`** 입니다. (예: `test.py`)
  3. 텍스트 에디터 영역에 코드를 쓰고 저장합니다. 저장 단축키는 **Ctrl + S** 입니다. 자주 저장하는 습관을 들입니다.
  4. 파일을 우클릭해 **[터미널에서 Python 파일 실행]** 을 고르면 결과가 터미널에 나옵니다.
     (터미널은 `Ctrl + ~` 로 열 수 있습니다.)
- **확장(Extensions)** 으로 설치하는 것 — 처음부터 들어 있지 않습니다.
  - Korean Language Pack: 메뉴를 한국어로 표시 (설치 후 언어 변경 + 재시작)
  - Python 확장: `python` 검색 → 설치 → VSCode 를 껐다가 다시 시작

## 6. Colab 기본 사용법

- 구글이 제공하는 클라우드 기반 개발 환경. 웹 브라우저에서 코드를 쓰고 실행합니다.
- 내 컴퓨터에 파이썬이나 프로그램을 설치할 필요가 없습니다. 대신 **구글 계정**이 필요합니다.
- 데이터 분석 라이브러리가 기본으로 설치되어 있고, GPU 를 무료로 쓸 수 있습니다.
- 파일은 노트북(`.ipynb`)이며, **코드 셀**([+ 코드])과 **텍스트(마크다운) 셀**([+ 텍스트])로 이루어집니다.
  코드 셀 왼쪽의 재생 버튼을 누르면 실행되고, 결과는 셀 바로 아래에 나옵니다.

단축키 (주간 요약본에 실린 내용)

| 단축키 | 동작 |
|---|---|
| `Ctrl + Enter` | 셀 실행 (커서는 그 셀에 그대로) |
| `Shift + Enter` | 셀 실행 후 다음 셀로 이동 |
| `Alt + Enter` | 셀 실행 후 새 코드 셀 추가 |
| `Ctrl + M A` | 코드 셀을 위에 삽입 (Above) |
| `Ctrl + M B` | 코드 셀을 아래에 삽입 (Below) |
| `Ctrl + M D` | 셀 지우기 (Delete) |
| `Ctrl + M Y` | 코드 셀로 변경 |
| `Ctrl + M M` | 마크다운(텍스트) 셀로 변경 (Markdown) |
| `Ctrl + M Z` | 실행 취소 |

## 7. 프로그래밍과 프로그래밍 언어

- 프로그램(program) = pro(미리) + gram(작성된 것). **프로그래밍**은 프로그램을 만드는 일입니다.
- 프로그램이 하는 일: 데이터를 입력받아 → 처리하고 → 결과를 출력한다.
- 컴퓨터의 기본 장치: 입력 장치 → CPU(제어 장치, 산술/논리 장치) ↔ 메모리 → 출력 장치
- 컴퓨터는 0과 1(이진 숫자)로 동작합니다. **프로그래밍 언어**는 사람과 컴퓨터 사이의 번역기 역할을 하며
  C, C++, JAVA, 파이썬 등이 있습니다.
- **소스 코드**: 프로그램을 사람이 읽을 수 있는 프로그래밍 언어로 적은 텍스트 파일

## 8. ChatGPT 와 함께 프로그램 만들기

- 만들고 싶은 프로그램을 설명해 코드를 받고 → `.py` 파일에 붙여 넣어 저장 → 실행해 봅니다.
- 받은 코드는 완성본이 아닐 수 있습니다. 오류 메시지가 나오면 그 메시지를 그대로 입력해 다시 질문하고,
  답을 바탕으로 고쳐 실행하는 과정을 반복합니다.
- 마지막 완성은 사람이 합니다. 코드를 읽고 분석해 직접 고칠 수 있어야 합니다.
- 실습 예: 창(GUI)을 띄우는 `tkinter` 로 주문 프로그램 만들기

## 시험에서 헷갈리기 쉬운 포인트

- `print` 는 전부 소문자입니다. `Print`, `PRINT` 는 `NameError` 입니다.
- 따옴표를 빼먹으면 오류입니다. `print(Hello)` 는 글자가 아니라 `Hello` 라는 이름을 찾다가 `NameError` 가 납니다.
- 같은 철자라도 따옴표 안에 있으면 글자입니다. `print("print")` 는 오류 없이 `print` 를 출력합니다.
- 여는 따옴표와 닫는 따옴표는 같은 종류여야 합니다. `print("Hello')` 는 문법 오류(`SyntaxError`)입니다.
- 따옴표 안은 계산하지 않습니다. `print("1 + 2")` 의 출력은 `3` 이 아니라 `1 + 2` 입니다.
- 따옴표는 출력되지 않습니다. `print('Hi')` 의 출력은 `'Hi'` 가 아니라 `Hi` 입니다.
- 출력 문제는 글자 하나, 공백 하나까지 같아야 정답입니다. 대소문자·쉼표·느낌표·띄어쓰기를 예시와 똑같이 맞춥니다.
- 오류 메시지는 위치·명령·오류의 종류와 이유를 알려 줄 뿐, 고친 코드를 보여 주지는 않습니다.
- IDLE 과 IDE 는 다릅니다. IDLE 은 파이썬에 딸려 오는 기본 개발 환경의 이름이고, IDE 는 통합개발환경이라는 분류입니다(PyCharm, VSCode).
- 파이썬은 실행하면서 해석하는 인터프리터 방식입니다. "미리 변환"이라는 말이 나오면 컴파일 방식입니다.
- 명령어로 컴퓨터를 제어하면 터미널, 프로그램을 검사하고 에러 수정을 도우면 디버거입니다. 둘 다 장치가 아니라 소프트웨어입니다.
- 컴퓨터의 기본 장치 네 가지는 입력 장치, CPU, 메모리, 출력 장치입니다.
- Colab 은 설치가 필요 없고 구글 계정이 필요합니다. VSCode 의 한국어 메뉴와 Python 지원은 기본 기능이 아니라 확장을 설치해야 합니다.
- 파이썬 소스 파일은 `.py`, Colab 노트북은 `.ipynb` 입니다. 저장은 `Ctrl + S`, 터미널 열기는 `Ctrl + ~` 입니다.
- Colab 단축키는 `Ctrl + Enter`(제자리 실행) / `Shift + Enter`(실행 후 다음 셀) / `Alt + Enter`(실행 후 새 셀 추가)이고,
  `Ctrl + M` 다음의 A(위)·B(아래)·D(삭제)·Y(코드 셀)·M(마크다운 셀)을 서로 바꿔 놓은 보기에 주의합니다.
- 소스 코드는 사람이 읽는 글입니다. 0과 1로 된 것은 컴퓨터가 이해하는 형태입니다.
