# p05. 피자 주문 내역 출력 (출력 · 6점)

체크박스로 피자를 고르고 주문 버튼을 누르면 체크된 피자의 내역과 총 가격을 보여 주는 프로그램을, GUI 대신 표준 입력으로 흉내 내어 작성하세요.

## 입력
- 첫째 줄: 메뉴 개수 `n` (1 이상 10 이하의 정수)
- 이어서 메뉴마다 세 줄씩: 메뉴 이름(문자열), 가격(정수), 체크 여부(`1` 이면 체크됨, `0` 이면 체크 안 됨)

## 출력
- 체크된 메뉴마다 `- 이름 가격원` 을 입력 순서대로 한 줄씩 출력하고, 마지막 줄에 `총 가격: 합계원` 을 출력합니다.
- 체크된 메뉴가 하나도 없으면 `선택된 메뉴가 없습니다.` 한 줄만 출력합니다.

## 입출력 예

입력

```
3
치즈
3000
1
불고기
3500
0
페퍼로니
4000
1
```

출력

```
- 치즈 3000원
- 페퍼로니 4000원
총 가격: 7000원
```

입력

```
2
하와이안
4500
0
고르곤졸라
5000
0
```

출력

```
선택된 메뉴가 없습니다.
```

- 출력은 글자 하나까지 같아야 합니다. `-` 뒤와 이름 뒤에 공백이 하나씩, `총 가격:` 뒤에도 공백이 하나 있고, 가격 바로 뒤에 `원` 이 붙습니다.
