# p06. 누적 합 제너레이터 (반환값 · 6점)

정수 리스트 `nums` 가 주어질 때, 원소를 앞에서부터 더해 가며 그때까지의 합을 하나씩 돌려주는 **제너레이터**를 만드는 `solution` 함수를 완성하세요.

예를 들어 `[1, 2, 3]` 이면 1, 1+2=3, 1+2+3=6 을 차례로 돌려줍니다.

- `solution` 은 리스트가 아니라 **제너레이터 객체**를 돌려줘야 합니다. 함수 안에서 `yield` 를 쓰면 함수를 호출한 결과가 제너레이터가 됩니다.
- 채점은 `list(solution(...))`, `next(solution(...))`, `type(solution(...)).__name__` 으로 확인합니다.
- `nums` 가 비어 있으면 아무 값도 돌려주지 않습니다(`list()` 로 바꾸면 `[]`).

## 제한 사항
- 0 ≤ len(nums) ≤ 100, -1000 ≤ 원소 ≤ 1000

## 입출력 예

| 호출 | 결과 |
|---|---|
| `list(solution([1, 2, 3]))` | `[1, 3, 6]` |
| `list(solution([5]))` | `[5]` |
| `list(solution([]))` | `[]` |
| `next(solution([10, 20]))` | `10` |
| `type(solution([1])).__name__` | `'generator'` |
