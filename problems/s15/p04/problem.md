# p04. 첫 손님과 대기 손님 (출력 · 4점)

손님 이름들이 한 줄에 공백으로 구분되어 입력됩니다. 이름 리스트를 이터레이터로 바꾼 뒤,
첫 손님은 `next()` 로 꺼내 `first: 이름` 으로, 나머지 손님은 for 문으로 한 줄에 한 명씩 `wait: 이름` 으로 출력하는 프로그램을 작성하세요.

- 입력은 `input().split()` 으로 리스트로 만듭니다. 이름은 1명 이상입니다.
- 이름이 1명뿐이면 `first:` 줄만 출력합니다.
- 콜론 뒤에 공백 한 칸이 있습니다.

## 입출력 예

입력

```
민수 지연 하늘
```

출력

```
first: 민수
wait: 지연
wait: 하늘
```

입력

```
Hana
```

출력

```
first: Hana
```
