# p03. 홀수의 제곱 리스트 (반환값 · 4점)

정수 리스트 `nums` 가 주어질 때, 홀수인 원소만 골라 제곱한 값을 원래 순서대로 담은 **리스트**를 반환(return)하는 `solution` 함수를 완성하세요.
리스트 컴프리헨션 `[식 for 변수 in 리스트 if 조건]` 을 써 보세요.

- 함수 이름과 매개변수는 바꾸지 않습니다.
- 홀수가 하나도 없으면 빈 리스트 `[]` 를 반환합니다.
- 음수 홀수(예: -3)도 홀수입니다. 제곱하면 양수가 됩니다.

## 제한 사항
- 0 ≤ len(nums) ≤ 100, -100 ≤ 원소 ≤ 100

## 입출력 예

| nums | 반환값 |
|---|---|
| `[1, 2, 3, 4, 5]` | `[1, 9, 25]` |
| `[2, 4, 6]` | `[]` |
| `[-3, 0, 7]` | `[9, 49]` |
