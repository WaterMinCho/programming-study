# p12. 정수만 골라내는 제너레이터 (반환값 · 8점)

문자열 리스트 `tokens` 가 주어집니다. 각 문자열을 앞에서부터 `int()` 로 바꿔 보고, 바뀌면 그 **정수**를 하나씩 돌려주고 `ValueError` 가 나면 그 문자열을 건너뛰는 **제너레이터**를 만드는 `solution` 함수를 완성하세요.

- `solution` 은 리스트가 아니라 **제너레이터 객체**를 돌려줘야 합니다. 함수 안에서 `yield` 를 쓰면 함수를 호출한 결과가 제너레이터가 됩니다.
- 바꿀 수 없는 문자열이 중간에 있어도 멈추지 않고 그 뒤의 문자열을 계속 확인합니다.
- `"-4"` 처럼 부호가 붙은 문자열은 `int()` 로 바뀌므로 `-4` 를 돌려줍니다. `"2.5"` 와 빈 문자열 `""` 은 `int()` 가 `ValueError` 를 일으키므로 건너뜁니다.
- 문자열의 모양을 직접 검사하는 대신 `int()` 변환을 시도하고 예외를 잡는 방식으로 작성합니다.
- 채점은 `list(solution(...))`, `next(solution(...))`, `type(solution(...)).__name__` 으로 확인합니다.

## 제한 사항
- 0 ≤ len(tokens) ≤ 100, 각 원소는 문자열

## 입출력 예

| 호출 | 결과 |
|---|---|
| `list(solution(["3", "x", "10"]))` | `[3, 10]` |
| `list(solution(["-4", "2.5", "7"]))` | `[-4, 7]` |
| `next(solution(["a", "b", "8"]))` | `8` |
| `type(solution(["1"])).__name__` | `'generator'` |
