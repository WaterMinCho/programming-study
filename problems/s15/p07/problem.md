# p07. 긴 단어 길이 사전 (반환값 · 6점)

단어 리스트 `words` 가 주어질 때, 길이가 3 이상인 단어만 골라 `{단어: 글자 수}` 형태의 **딕셔너리**를 반환(return)하는 `solution` 함수를 완성하세요.
딕셔너리 컴프리헨션 `{키: 값 for 변수 in 리스트 if 조건}` 을 써 보세요.

- 키는 단어 그 자체(문자열), 값은 그 단어의 길이(정수)입니다.
- 조건에 맞는 단어가 없으면 빈 딕셔너리 `{}` 를 반환합니다.
- 단어는 서로 다르다고 가정합니다.

## 제한 사항
- 0 ≤ len(words) ≤ 50, 각 단어는 영문 소문자 1~20자

## 입출력 예

| words | 반환값 |
|---|---|
| `["ai", "robot", "dog", "go"]` | `{'robot': 5, 'dog': 3}` |
| `[]` | `{}` |
| `["aaa", "bb"]` | `{'aaa': 3}` |
