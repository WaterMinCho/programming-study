# 0차시 · 사용법 익히기

실제 문제를 풀기 전에, 이 저장소에서 **문제를 받고 → 풀고 → 채점하는 흐름**을 한 번 연습하는 세트입니다.
문제는 아주 쉽습니다. 도구와 git 흐름에 익숙해지는 것이 목표입니다.

## 문제 유형 4가지

| 유형 | 어디에 답하나 | 어떻게 채점되나 |
|---|---|---|
| 객관식 · 출력 예측 · 단답 (퀴즈) | `quiz.py` 에 `Q1 = 3` 처럼 적기 | 정답과 **정확히** 일치해야 정답 |
| 빈칸 채우기 | `pNN.py` 의 `____` 자리만 채우기 | 빈칸 외 수정 금지 + 테스트 통과 |
| 반환값 | `pNN.py` 의 `solution` 함수 완성 | 반환값과 **자료형**까지 일치 |
| 출력 | `pNN.py` 에 프로그램 작성 | 출력이 글자 하나까지 일치 |

- 부분 점수는 없습니다. 테스트를 **전부** 통과해야 그 문제 점수를 받습니다(실제 평가와 동일).
- 출력 비교에서 줄 끝 공백과 맨 마지막 빈 줄만 무시합니다. 띄어쓰기·대소문자·문장부호는 그대로 맞아야 합니다.
- `input("안내 문구")` 의 안내 문구는 채점 출력에 포함되지 않으니 평소처럼 써도 됩니다.

## 진행 순서

```bash
python study.py init <내 깃허브 ID>   # 처음 한 번
python study.py start 0              # 문제 받기 → submissions/<ID>/s00/
# quiz.md 와 각 pNN/problem.md 를 읽고 submissions/<ID>/s00/ 안의 파일을 고칩니다
python study.py grade 0              # 채점
python study.py explain 0 Q1         # (다시 풀어 본 뒤) 해설 보기
```

실제 평가에서는 IDE 자동완성·검색을 쓸 수 없습니다. 퀴즈는 **코드를 실행하지 않고** 머릿속으로 풀어 보세요.
