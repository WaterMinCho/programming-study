# p15. 이메일 주소 뽑기 (빈칸 채우기 · 6점)

한 줄을 입력받아, 그 안의 이메일 주소를 모두 찾아 리스트로 출력하고 그 개수를 출력하는 프로그램입니다.
빈칸(`____`) 2곳을 채워 프로그램을 완성하세요.

```python
import re

text = input()
pattern = ____                    # 아이디@도메인 모양의 이메일 주소
mails = re.____(pattern, text)    # 매치되는 모든 문자열을 리스트로
print(mails)
print(len(mails))
```

이 문제에서 이메일 주소는 `아이디@도메인` 모양이고, 두 부분은 아래 규칙을 따릅니다.

- 아이디는 영문자·숫자·밑줄(`_`)·점(`.`)·하이픈(`-`)이 1개 이상 이어진 것입니다.
- 도메인은 아이디와 같은 종류의 글자가 1개 이상 이어진 뒤, 점(`.`) 하나와 영문자·숫자·밑줄 1개 이상으로 끝납니다. `rokey.kr` 과 `mail.rokey.co.kr` 은 도메인으로 인정됩니다.
- 문장 끝의 마침표는 주소에 넣지 않습니다. `write to a@b.kr.` 에서 찾아야 하는 주소는 `a@b.kr` 입니다.
- 아이디가 없는 `@rokey.kr` 과 도메인에 점이 없는 `kim@rokey` 는 이메일 주소로 치지 않습니다.

빈칸과 입력에 대한 조건은 아래와 같습니다.

- 첫 번째 빈칸에는 정규식 패턴 문자열, 두 번째 빈칸에는 re 모듈의 함수 이름이 들어갑니다. 역슬래시를 쓰려면 `r"..."` 로 적습니다.
- 입력은 영문자, 숫자, 공백, 문장부호로만 이루어집니다.
- 이메일 주소가 하나도 없으면 `[]` 와 `0` 을 출력합니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

| 입력 | 출력 |
|---|---|
| `send to help@rokey.kr or kim.lee@mail.rokey.co.kr` | `['help@rokey.kr', 'kim.lee@mail.rokey.co.kr']`<br>`2` |
| `my address is park-01@my-site.net.` | `['park-01@my-site.net']`<br>`1` |
| `no mail here` | `[]`<br>`0` |
