# 14차시 · 정규표현식

정규표현식(regular expression)은 "이런 모양의 문자열"을 기호로 적는 방법입니다.
파이썬에서는 표준 라이브러리 `re` 모듈로 사용합니다. 이 차시의 범위는 메타 문자의 뜻,
re 모듈의 검색 메서드 4가지, match 객체의 메서드 4가지, 컴파일 옵션 4가지, 역슬래시 문제입니다.
시험 전에 아래 표를 한 번 더 훑어 보세요.

주간 요약본은 정규표현식을 "정한 패턴으로 문자열을 검색하고, 일치 여부를 확인하고, 추출·변환하는 방법"이라고 적고,
쓰는 순서를 "`re` 모듈로 정규표현식을 컴파일한 뒤 모듈 안의 함수를 활용한다"고 적습니다.
강의 자료는 쓰임새로 데이터 검증(이메일, 전화번호), 텍스트 분석, 웹 스크래핑, 로그 파일 처리를 들고,
문법이 언어 사이에 비슷해 다른 언어에서도 응용할 수 있다고 설명합니다.

## 1. 메타 문자

`. ^ $ * + ? { } [ ] \ | ( )` 는 글자 그대로가 아니라 특별한 뜻으로 읽힙니다.
강의 자료는 메타 문자를 "원래 그 문자가 가진 뜻이 아닌 특별한 의미를 가진 문자"라고 정의합니다.
요약본은 "어떤 자료 구조나 특정 표식을 위해 쓰는 기호, 특수 문자"라고 적고 리스트의 `[]`, 튜플의 `()` 를 예로 듭니다.
위 목록에 없는 `@`, `:`, `;` 같은 글자는 메타 문자가 아니어서 정규식에 쓰면 그 글자와 매치됩니다.

| 기호 | 뜻 | 예 |
|---|---|---|
| `[abc]` | 대괄호 안의 글자 중 하나 | `[xyz]` 는 `sky` 와 매치(y가 있음), `dog` 와는 매치 안 됨 |
| `[a-z]`, `[0-9]` | 하이픈은 범위 | `[a-zA-Z]` 모든 알파벳, `[0-5]` = `[012345]` |
| `[^0-9]` | 대괄호 맨 앞의 `^` 는 부정(not) | 숫자가 아닌 글자 하나 |
| `.` | 줄바꿈 `\n` 을 뺀 아무 글자 하나 | `a.b` 는 `aab`, `a0b` 매치 / `ab` 는 매치 안 됨 |
| `[.]`, `[.+]` | 대괄호 안에서는 `.` 과 `+` 가 글자 그대로 읽힘 | `a[.]b` 는 `a.b` 만 매치, `[a-c.+]+` 는 `a+b.c` 를 한 덩어리로 매치 |
| `[\^]`, `[\w.-]` | 대괄호 안에서 메타 문자를 글자로 쓰려면 `\` 를 붙임. 맨 끝의 `-` 는 범위가 아니라 하이픈 글자 | `[\^]` 는 `^` 한 글자, `[\w.-]` 는 글자·숫자·밑줄·점·하이픈 중 하나 |
| `*` | 바로 앞 글자가 0번 이상 | `ca*t` → `ct`, `cat`, `caaat` |
| `+` | 바로 앞 글자가 1번 이상 | `ca+t` → `cat`, `caaat` / `ct` 는 안 됨 |
| `?` | 바로 앞 글자가 0번 또는 1번 = `{0,1}` | `ab?c` → `abc`, `ac` |
| `{m}` | 정확히 m번 | `ca{2}t` → `caat` 만 |
| `{m,n}` | m번 이상 n번 이하 | `ca{2,5}t` → `caat` … `caaaaat` |
| `{m,}` / `{,n}` | 생략한 쪽은 0 또는 무한대 | `{1,}` = `+`, `{0,}` = `*` |
| `^` | 문자열의 시작 | `^hello` 는 hello 로 시작해야 함 |
| `$` | 문자열의 끝 | `world$` 는 world 로 끝나야 함 |

자주 쓰는 문자 클래스는 역슬래시 표기가 따로 있습니다. 대문자는 소문자의 반대입니다.

| 표기 | 같은 뜻 | 의미 |
|---|---|---|
| `\d` | `[0-9]` | 숫자 |
| `\D` | `[^0-9]` | 숫자가 아닌 것 |
| `\s` | `[ \t\n\r\f\v]` | 공백 문자(스페이스, 탭, 줄바꿈 …) |
| `\S` | `[^ \t\n\r\f\v]` | 공백이 아닌 것 |
| `\w` | `[a-zA-Z0-9_]` | 글자 + 숫자 + 밑줄 |
| `\W` | `[^a-zA-Z0-9_]` | 글자·숫자·밑줄이 아닌 것 |

소괄호 `( )` 는 여러 글자를 한 덩어리로 묶습니다. 반복 메타 문자는 바로 앞 한 글자에 걸리지만, 괄호로 묶으면 덩어리 전체에 걸립니다.

| 패턴 | 반복되는 것 | `re.match(패턴, "ababab").group()` |
|---|---|---|
| `ab+` | `b` 한 글자 | `'ab'` |
| `(ab)+` | `ab` 덩어리 | `'ababab'` |

괄호 안의 `|` 는 "또는"입니다. 강의의 `re.VERBOSE` 예제에 나온 정규식 `&[#](0[0-7]+|[0-9]+|x[0-9a-fA-F]+);` 는
`&#` 뒤에 세 가지 모양(`0` 으로 시작하는 8진수, 10진수, `x` 로 시작하는 16진수) 가운데 하나가 오고 `;` 로 끝나는 문자열과 매치됩니다.
`&#123;` 과 `&#x4F;` 는 매치되고, `;` 가 없는 `&#12` 는 매치되지 않습니다.

## 2. re 모듈 사용 흐름

```python
import re

p = re.compile("[a-z]+")      # 패턴 객체 생성
m = p.match("python 3")       # 문자열 조사
if m:                         # 매치되면 match 객체, 아니면 None
    print("found:", m.group())
else:
    print("no match")
```

컴파일된 패턴 객체의 검색 메서드 4가지

| 메서드 | 하는 일 | 리턴 |
|---|---|---|
| `match()` | 문자열의 처음부터 매치되는지 조사 | match 객체 또는 `None` |
| `search()` | 문자열 전체를 뒤져 처음 매치되는 곳을 찾음 | match 객체 또는 `None` |
| `findall()` | 매치되는 모든 문자열 | 리스트 |
| `finditer()` | 매치되는 모든 결과 | 반복 가능한 객체(요소는 match 객체) |

```python
p = re.compile("[a-z]+")
p.match("3 python")      # None
p.search("3 python")     # <re.Match object; span=(2, 8), match='python'>
p.findall("life is too short")   # ['life', 'is', 'too', 'short']
for m in p.finditer("life is too short"):
    print(m.span())      # (0, 4) (5, 7) (8, 11) (12, 17)
```

match 객체의 메서드 4가지

| 메서드 | 리턴 | `p.search("3 python")` 의 경우 |
|---|---|---|
| `group()` | 매치된 문자열 | `'python'` |
| `start()` | 시작 인덱스 | `2` |
| `end()` | 끝 인덱스(매치 바로 다음 위치) | `8` |
| `span()` | `(시작, 끝)` 튜플 | `(2, 8)` |

`match()` 로 얻은 match 객체는 항상 처음부터 조사한 것이므로 `start()` 가 `0` 입니다.

축약형: `re.match("[a-z]+", "python")` 처럼 `re.함수(패턴, 문자열)` 로 컴파일과 검색을 한 번에
할 수 있습니다. 같은 패턴을 여러 번 쓸 때는 `re.compile` 로 패턴 객체를 한 번 만들어 두고 재사용합니다.

## 3. 컴파일 옵션 4가지

| 옵션 | 약어 | 효과 |
|---|---|---|
| `re.DOTALL` | `re.S` | `.` 이 줄바꿈 `\n` 과도 매치되게 한다 |
| `re.IGNORECASE` | `re.I` | 대소문자 구별 없이 매치한다 (`[a-z]+` 가 `PYTHON` 과도 매치) |
| `re.MULTILINE` | `re.M` | `^`, `$` 를 문자열 전체가 아니라 각 줄마다 적용한다 |
| `re.VERBOSE` | `re.X` | 정규식 안에 공백·줄바꿈·`#` 주석을 넣어 읽기 쉽게 쓸 수 있다 (`[ ]` 안의 공백은 유지) |

```python
data = """apple one
banana two
apple three"""
re.compile("^apple").findall(data)          # ['apple']            첫 줄만
re.compile("^apple", re.M).findall(data)    # ['apple', 'apple']   각 줄의 처음
```

요약본에는 아래 코드가 실려 있습니다. 옵션 없이 컴파일했으므로 첫 줄만 나옵니다.

```python
import re
p = re.compile("^python\s\w+")

data = """python one
life is too short
python two
you need python
python three"""

print(p.findall(data))    # ['python one']
```

`re.compile("^python\s\w+", re.MULTILINE)` 으로 바꾸면 `['python one', 'python two', 'python three']` 가 됩니다.
`you need python` 은 줄이 `python` 으로 시작하지 않아 어느 쪽에도 들어가지 않습니다.
`\s` 와 `\w` 는 파이썬 문자열의 이스케이프가 아니라서 `r` 없이 써도 결과가 같습니다. 직접 쓸 때는 `r"^python\s\w+"` 로 적습니다.

`re.VERBOSE` 로 컴파일하면 패턴 문자열 안의 공백·줄바꿈과 `#` 뒤의 주석이 지워집니다. 대괄호 안에 쓴 공백은 지워지지 않습니다.

```python
p = re.compile(r"""
    \d{3}   # 앞 세 자리
    -       # 하이픈
    \d{4}   # 뒤 네 자리
""", re.VERBOSE)
p.findall("tel 123-4567")                        # ['123-4567']
re.compile(r"\d \d", re.X).findall("1 2 34")     # ['34']    공백이 지워져 \d\d 와 같음
re.compile(r"\d[ ]\d", re.X).findall("1 2 34")   # ['1 2']   [ ] 안의 공백은 남음
```

## 4. 역슬래시 문제와 raw string

파일 안의 글자 그대로의 `\section` 을 찾고 싶다고 합시다.

- 정규식 `\section` 은 `\s`(공백 문자) + `ection` 으로 읽혀 버립니다.
- 정규식 엔진에는 `\\section` 을 줘야 하는데, 파이썬 문자열에서 `\` 하나를 쓰려면 또 `\\` 로
  써야 하므로 보통 문자열로는 `'\\\\section'`(역슬래시 4개)이 됩니다.
- 보통 문자열에 2개만 쓴 `'\\section'` 은 파이썬이 먼저 `\section` 으로 바꿔서 넘기므로, 엔진은 처음과 똑같이
  `\s` + `ection` 으로 읽습니다. `re.findall('\\section', r"\section 1 ection")` 의 결과는 `[' ection']` 입니다.
- 문자열 앞에 `r` 을 붙인 raw string 은 역슬래시를 그대로 전달하므로 `r'\\section'` 으로 끝납니다.
- 역슬래시가 없는 정규식이라면 `r` 이 있든 없든 같습니다. 패턴에 `\d`, `\w` 가 들어가면
  `r"..."` 로 쓰는 습관을 들이는 편이 안전합니다.

## 5. 강의 연습 문제에 나온 패턴 조합

| 하려는 일 | 패턴 | 쓰는 방법 |
|---|---|---|
| 숫자 덩어리를 모두 뽑기 | `\d+` | `re.findall(r"\d+", text)` |
| 문자열 전체의 형식 검사 | `^\d{3}-\d{4}$` | `re.match(패턴, text)` 결과를 `if` 로 검사 |
| 이메일 모양을 모두 뽑기 | `[\w.-]+@[\w.-]+\.\w+` | `re.findall(패턴, text)` |

이메일 패턴은 `[\w.-]+`(글자·숫자·밑줄·점·하이픈 1개 이상), `@`, 다시 `[\w.-]+`, 점 글자 `\.`, `\w+` 를 차례로 이어 붙인 것입니다.
대괄호 밖의 점은 `\.` 로 써야 점 글자와만 매치됩니다. `"mail kim.lee@rokey.co.kr."` 에서 찾으면 문장 끝 마침표를 뺀
`['kim.lee@rokey.co.kr']` 이 나옵니다. 마침표 뒤에 `\w+` 로 읽을 글자가 없기 때문입니다.

## 6. 과제에 나온 패턴 조합

| 하려는 일 | 패턴 | 쓰는 방법 |
|---|---|---|
| 자릿수가 섞인 전화번호를 모두 뽑기 | `\d{2,3}-\d{3,4}-\d{4}` | `re.findall(패턴, text)` |
| 연속된 대문자를 모두 뽑기 | `[A-Z]{2,}` | `re.findall(패턴, text)` |
| 특정 단어가 든 문장을 모두 뽑기 | `[^.]*Python[^.]*[.]` | `re.findall(패턴, text)` 뒤에 문장마다 `strip()` |
| 이메일 형식 검사 | `^[\w.-]+@[\w.-]+\.\w+$` | `re.match(패턴, text)` 결과를 `if` 로 검사 |
| 줄마다 `python` 으로 시작하는 부분 뽑기 | `^python\s\w+` | `re.compile(패턴, re.MULTILINE).findall(data)` |

- `"연락처: 010-1234-5678, 02-987-6543, 031-456-7890"` 에서 첫 패턴은 세 번호를 모두 찾습니다. `\d{3}-\d{4}-\d{4}` 로 자릿수를 고정하면 `010-1234-5678` 하나만 나옵니다.
- `"NASA is working on AI projects with IBM and Google."` 에서 `[A-Z]{2,}` 는 `['NASA', 'AI', 'IBM']` 을 찾습니다. `[A-Z]+` 로 쓰면 `Google` 의 `G` 까지 들어갑니다.
- `[^.]*Python[^.]*[.]` 는 마침표가 아닌 글자들 사이에 `Python` 이 있고 마침표로 끝나는 덩어리입니다. `"I love Python. Java is also popular. Python is great for AI."` 에서 `['I love Python.', ' Python is great for AI.']` 가 나오고, 두 번째 문장 앞의 공백은 `strip()` 으로 뗍니다.
- 이메일은 뽑을 때와 검사할 때 패턴의 몸통이 같습니다. 검사할 때는 `^` 와 `$` 를 붙여 문자열 전체가 그 모양인지 봅니다.

## 시험에서 헷갈리기 쉬운 포인트

- `match()` 는 처음부터, `search()` 는 아무 데나. `p.match("3 python")` 은 `None`,
  `p.search("3 python")` 은 매치. `print(m)` 에 `None` 이 들어가면 화면에도 `None` 이라는 네 글자가 찍힙니다.
- 매치 실패는 빈 문자열 `''` 이나 `False` 가 아니라 `None` 입니다. 그래서 `if m:` 으로 거릅니다.
- `findall()` 은 문자열 리스트, `finditer()` 는 match 객체들. `finditer` 결과에 `.group()` 을
  붙여야 문자열이 나오고, `findall` 결과에는 `.group()` 이 없습니다(오류).
- `span()` 은 튜플 `(시작, 끝)`. `end()` 는 매치된 마지막 글자의 인덱스가 아니라 그 다음 위치입니다.
  `"42 apples"` 에서 `apples` 의 span 은 `(3, 9)`.
- `*` 는 0번 이상, `+` 는 1번 이상, `?` 는 0~1번. `ca*t` 는 `ct` 와 매치되지만 `ca+t` 는 아닙니다.
- `{m,n}` 에서 `{1,}` 은 `+`, `{0,}` 은 `*`, `{0,1}` 은 `?` 와 같습니다.
- `.` 은 한 글자이고 `\n` 은 제외. `a.b` 는 `ab` 와 매치되지 않습니다. 대괄호 안의 `.` 은 그냥 점.
- `^` 는 놓인 자리에 따라 다르게 읽힙니다. 패턴 맨 앞이면 문자열의 시작, `[^…]` 처럼 대괄호 안 맨 앞이면 부정.
- 형식 검사는 `$` 까지 붙여야 합니다. `^\d{3}-\d{4}` 만으로는 `123-45678` 도 통과합니다.
- `\w` 에는 숫자와 밑줄도 포함됩니다. `\w+` 는 `ab12` 를 통째로 한 덩어리로 봅니다.
- `re.M` 은 `^`, `$` 에 관한 옵션이고, `.` 이 줄바꿈과 매치되게 하는 것은 `re.S`(DOTALL)입니다.
- `re.I` 는 `IGNORECASE`, `re.S` 는 `DOTALL`, `re.M` 은 `MULTILINE`, `re.X` 는 `VERBOSE`. 약어와
  전체 이름을 짝지어 둡니다.
- `print(m)` 의 출력 형식은 `<re.Match object; span=(0, 5), match='Hello'>` 입니다.
  `span=` 뒤는 튜플, `match=` 뒤는 작은따옴표 문자열입니다.
- 글자 그대로의 역슬래시를 찾을 때만 `\\\\` 또는 `r'\\'` 문제가 생깁니다. `\d`, `\s` 같은 문자 클래스는
  `r"\d"` 로 쓰면 됩니다.
- 반복 메타 문자는 바로 앞 한 글자에만 걸립니다. `colou?r` 에서 선택인 것은 `u` 뿐이라 `color`·`colour` 는
  매치되고 `colr` 는 매치되지 않습니다.
- `{m}` 은 정확히 m번. `\d{2}` 로 `12345` 를 `findall` 하면 `['12', '34']` 가 되고 남는 `5` 는 버려집니다.
  `match` 는 문자열 전체를 다 쓰지 않아도 처음 부분이 패턴과 맞으면 성공입니다(`"2024"` 에서 `20`).
- `\s` 는 공백 문자를 한 글자씩 셉니다. 공백이 두 개 연속이면 2개이고, 그만큼 뒤 단어의 `start()` 도 밀립니다.
- `re.S` 로 `.` 이 `\n` 과 매치되면 `group()` 안에 줄바꿈이 들어 있어 `print` 하면 두 줄로 출력됩니다.
- `[^a-z]+$` 를 `match` 로 쓰면 첫 글자부터 끝까지 소문자가 없어야 합니다. `x9` 는 `search` 로는 `9` 가
  매치되지만 `match` 로는 `None` 입니다.
- `re.X`(VERBOSE)로 컴파일하면 패턴 안의 공백이 지워집니다. `r"\d \d"` 는 `\d\d` 와 같아져 `4 2` 를 찾지 못하고,
  공백을 찾으려면 `r"\d[ ]\d"` 처럼 대괄호 안에 넣어야 합니다.
- 보통 문자열 `"\\word"` 는 엔진에 `\word` 로 전달되어 `\w` + `ord` 로 읽힙니다. `lord`, `sword` 안의 `word` 까지
  매치됩니다. 글자 그대로의 `\word` 를 찾는 패턴은 `r"\\word"` 또는 `"\\\\word"` 입니다.
- 대괄호 안의 `.` 과 `+` 는 글자로 읽히지만, 대괄호 밖의 점은 `\.` 로 이스케이프하지 않으면 아무 글자와 매치됩니다.
  `\w+@\w+.\w+` 는 `bad@site and` 를 통째로 잡습니다.
- 클래스 안에서 `re.match(self.pattern, text)` 로 검사하도록 만들어 두면, 자식 클래스가 클래스 변수 `pattern` 을
  다시 선언했을 때 자식의 패턴으로 검사합니다. 이때도 `match` 는 끝을 확인하지 않으므로 형식 검사 패턴에는 `$` 를 붙입니다.
- 정규표현식은 `import re` 로 불러옵니다. `regex`, `regular`, `pattern` 은 표준 라이브러리에 없는 이름입니다.
- `re.match(패턴, 문자열)` 같은 축약형도 match 객체나 `None` 을 돌려줍니다. 매치된 문자열은 `.group()` 으로 꺼냅니다.
- `(ab)+` 는 `ab` 덩어리를 반복하고 `ab+` 는 `b` 만 반복합니다. `ababa` 에 `match` 하면 앞의 것은 `abab`, 뒤의 것은 `ab` 입니다.
- `\w+` 는 쉼표, 느낌표, 공백에서 끊기고 그 글자들은 결과에 들어가지 않습니다. `"Hello, World!"` 에서 `['Hello', 'World']` 가 나옵니다.
- `^abc` 는 `abc` 로 시작하는 문자열, `abc$` 는 `abc` 로 끝나는 문자열과 매치되고, `^abc$` 는 문자열 전체가 `abc` 일 때만 매치됩니다. `[^abc]` 는 a, b, c 가 아닌 글자 하나와 매치됩니다.
- 요약본의 `re.compile("^python\s\w+")` 는 옵션이 없어서 여러 줄 문자열에서도 `['python one']` 만 찾습니다. 세 줄을 모두 찾으려면 `re.MULTILINE` 을 줍니다.
- `.*Python.*` 처럼 `.` 을 쓰면 마침표와도 매치되어 여러 문장이 한 덩어리로 잡힙니다. 문장 하나로 끊으려면 `[^.]*` 를 씁니다.
- 형식 검사를 `search` 로 하면서 `^` 를 빼면 문자열 중간의 맞는 부분을 찾아 통과시킵니다. `to user@example.com` 을 거르려면 `match` 를 쓰거나 `^` 를 붙입니다.
