# p06. 첫 숫자의 위치 (반환값 · 6점)

문자열 `text` 가 주어질 때, 처음 나오는 숫자 덩어리(연속된 숫자)의 `(시작 인덱스, 끝 인덱스)` 를
튜플로 **반환(return)** 하는 `solution` 함수를 완성하세요. 숫자가 없으면 `(-1, -1)` 을 반환합니다.

- 끝 인덱스는 match 객체의 `end()` 와 같은 값, 즉 마지막 숫자의 다음 위치입니다.
- 반환값은 튜플이어야 합니다. 리스트 `[3, 6]` 은 오답입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줍니다.

## 입출력 예

| text | 반환값 |
|---|---|
| `"abc123def"` | `(3, 6)` |
| `"7up"` | `(0, 1)` |
| `"none"` | `(-1, -1)` |
