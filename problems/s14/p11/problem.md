# p11. IP 주소 모양 검사 (반환값 · 6점)

문자열 `address` 가 주어질 때, `숫자.숫자.숫자.숫자` 모양(각 숫자는 1~3자리, 구분자는 점 `.`)에
정확히 맞으면 `True`, 아니면 `False` 를 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 문자열 전체가 그 모양이어야 합니다. 앞뒤에 공백이나 다른 글자가 붙어 있으면 `False` 입니다.
- 각 숫자의 값 범위(255 이하인지)는 검사하지 않습니다. 모양만 봅니다. `999.999.999.999` 는 `True` 입니다.
- 구분자는 반드시 점이어야 합니다. `192x168x0x1` 은 `False` 입니다.
- 반환값은 `True` 또는 `False`(bool)여야 합니다. match 객체나 `None` 을 그대로 반환하면 오답입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줍니다.

## 입출력 예

| address | 반환값 |
|---|---|
| `"192.168.0.1"` | `True` |
| `"999.999.999.999"` | `True` |
| `"192x168x0x1"` | `False` |
| `"1.2.3"` | `False` |
| `"1234.1.1.1"` | `False` |
