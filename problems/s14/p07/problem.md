# p07. 날짜 뽑기 (출력 · 6점)

한 줄을 입력받아, 그 안에 들어 있는 `숫자4자리-숫자2자리-숫자2자리` 형식(예: `2024-10-16`)의
날짜를 나온 순서대로 한 줄에 하나씩 출력하는 프로그램을 작성하세요.
그런 형식이 하나도 없으면 `no date` 를 한 번 출력합니다.

- 자릿수가 다르면(`2024-1-5`, `24-10-16`) 날짜로 치지 않습니다. 구분자가 `/` 이거나 없는 것(`2024/10/16`, `20241016`)도 날짜로 치지 않습니다.
- 날짜 모양의 앞뒤에 숫자나 하이픈이 바로 붙은 입력(`12024-10-16`, `2024-10-161`)은 주어지지 않습니다.
- 날짜가 실제로 존재하는지(13월 등)는 검사하지 않습니다. 형식만 봅니다.

## 입출력 예

입력
```
from 2024-10-16 to 2025-01-02
```
출력
```
2024-10-16
2025-01-02
```

입력
```
today is 2024-1-5
```
출력
```
no date
```
