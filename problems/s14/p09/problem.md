# p09. 아이디 검사기 (출력 · 8점)

첫 줄에 정수 `N` 이, 이어서 `N` 줄에 아이디 후보가 한 줄에 하나씩 입력됩니다.
각 아이디가 아래 규칙을 모두 만족하면 `OK`, 하나라도 어기면 `NO` 를 입력 순서대로 한 줄씩 출력하세요.

1. 첫 글자는 영문 소문자이다.
2. 둘째 글자부터는 영문 소문자·숫자·밑줄(`_`) 만 쓰며, 그 개수는 4개 이상 9개 이하이다.
   (즉 전체 길이는 5자 이상 10자 이하)
3. 숫자가 1개 이상 들어 있다.

- 대문자, 하이픈, 공백 등 다른 글자가 하나라도 있으면 `NO` 입니다.
- 입력 줄의 앞뒤에 공백은 없습니다.

## 입출력 예

입력
```
6
rokey1
abc
Rokey1
rokey_2024
rokeyrokey
a1234567890
```
출력
```
OK
NO
NO
OK
NO
NO
```

- `abc` 는 길이 부족, `Rokey1` 은 대문자로 시작, `rokeyrokey` 는 숫자 없음, `a1234567890` 은 11자라 `NO` 입니다.
