# p08. 득표 수 세기 (반환값 · 6점)

투표 용지에 적힌 후보 이름을 순서대로 담은 리스트 `votes` 가 주어질 때, 후보 이름을 키, 득표 수(정수)를 값으로 하는 딕셔너리를 **반환(return)** 하는 `solution` 함수를 완성하세요.

## 제한 사항

- `votes` 의 길이는 0 이상 100 이하이고, 각 요소는 빈 문자열이 아닌 문자열입니다.
- 딕셔너리의 키 순서는 그 후보가 `votes` 에 **처음 나타난 순서**와 같아야 합니다.
- `votes` 가 비어 있으면 빈 딕셔너리 `{}` 를 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 입출력 예

| votes | 반환값 |
|---|---|
| `["A", "B", "A", "C", "A"]` | `{'A': 3, 'B': 1, 'C': 1}` |
| `["b", "a", "b", "a"]` | `{'b': 2, 'a': 2}` |
| `[]` | `{}` |
