# p01. 짝수 합계 (빈칸 채우기 · 4점)

정수 `n` 을 입력받아 1 부터 `n` 까지의 정수 가운데 짝수만 더한 합을 출력하는 프로그램입니다. 빈칸(`____`) 2곳을 채워 프로그램을 완성하세요.

```python
n = int(input())
total = 0
for i in range(____):      # 1 부터 n 까지
    if i % 2 == 0:
        total ____ i
print("짝수 합:", total)
```

- `n` 은 0 이상 1000 이하의 정수입니다. `n` 이 1 이하이면 더할 짝수가 없으므로 합계는 0 이고 `짝수 합: 0` 이 출력됩니다.
- 출력 형식은 `짝수 합: 합계` 입니다(콜론 뒤 공백 한 칸).
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

| 입력 | 출력 |
|---|---|
| `10` | `짝수 합: 30` |
| `2` | `짝수 합: 2` |
| `1` | `짝수 합: 0` |
