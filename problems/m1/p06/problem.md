# p06. 점수 파일 정리 (출력 · 6점)

현재 폴더에 `scores.txt` 파일이 이미 있습니다. 한 줄에 `이름,점수` 형식(쉼표로 구분, 공백 없음)으로 적혀 있습니다. 이 파일을 읽어 각 줄을 `이름: 점수` 형식으로 한 줄씩 출력하고, 마지막 줄에 `합계: 점수합` 을 출력한 다음, `합계: 점수합` 한 줄을 `report.txt` 파일에 쓰는 프로그램을 작성하세요.

- 점수는 0 이상의 정수입니다. 빈 줄은 없으며, 마지막 줄 끝에는 줄바꿈이 있을 수도 있고 없을 수도 있습니다.
- 파일이 비어 있으면 `합계: 0` 만 출력하고 `report.txt` 에도 `합계: 0` 을 씁니다.
- 출력과 파일 내용 모두 콜론 뒤에 공백 한 칸이며, `report.txt` 의 줄 끝에는 줄바꿈 문자(`\n`)를 넣습니다.
- `report.txt` 는 쓰기 모드로 새로 만듭니다.
- 출력은 글자 하나까지 같아야 합니다.

## 입출력 예

`scores.txt`

```
민수,90
지영,85
```

출력

```
민수: 90
지영: 85
합계: 175
```

실행 후 `report.txt` 의 내용

```
합계: 175
```
