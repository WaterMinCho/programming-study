# p10. 가계부 파일 집계 (반환값 · 8점)

한 줄에 `항목,금액` 형식(쉼표로 구분, 공백 없음)으로 적힌 가계부 텍스트 파일의 경로 `path` 가 주어질 때, 항목을 키, 그 항목 금액의 합(정수)을 값으로 하는 딕셔너리를 **반환(return)** 하는 `solution` 함수를 완성하세요.

## 제한 사항

- 파일은 현재 폴더에 이미 만들어져 있습니다. 모든 줄은 쉼표가 정확히 하나 있는 `항목,금액` 모양이며 빈 줄은 없습니다. 마지막 줄 끝에는 줄바꿈이 있을 수도 있고 없을 수도 있습니다.
- 금액은 보통 정수(음수 포함)이지만, `만원`·`3.5` 처럼 `int()` 로 바꿀 수 **없는** 값이 적힌 줄이 섞여 있습니다. 그런 줄은 **통째로 건너뜁니다**(딕셔너리에 항목을 넣지 않습니다). `int()` 에서 발생하는 `ValueError` 를 처리하세요.
- 같은 항목이 여러 줄에 나오면 금액을 모두 더합니다. 키 순서는 유효한 줄에서 그 항목이 처음 나타난 순서입니다.
- 파일이 비어 있거나 유효한 줄이 없으면 빈 딕셔너리 `{}` 를 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 입출력 예

| 파일 내용 | 반환값 |
|---|---|
| `식비,8000`⏎`교통,1500`⏎`식비,12000`⏎ | `{'식비': 20000, '교통': 1500}` |
| `식비,8000`⏎`문화,만원`⏎`문화,15000` | `{'식비': 8000, '문화': 15000}` |
| `간식,1200`⏎`간식,-200`⏎`간식,3.5`⏎`간식,800`⏎ | `{'간식': 1800}` |
| (빈 파일) | `{}` |

(⏎ 는 줄바꿈을 뜻합니다)
