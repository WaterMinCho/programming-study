# p05. 머리글자 모으기 (반환값 · 6점)

문자열 `text` 가 주어질 때, 공백으로 구분된 각 단어의 **첫 글자**를 단어 순서대로 이어 붙인 문자열을 **반환(return)** 하는 `solution` 함수를 완성하세요.

## 제한 사항

- `text` 의 길이는 0 이상 100 이하입니다.
- 단어는 공백이 아닌 글자들의 묶음입니다. 단어 사이나 양 끝에 공백이 여러 개 있을 수 있습니다.
- 대소문자는 바꾸지 않고 그대로 씁니다.
- 단어가 하나도 없으면(빈 문자열이거나 공백뿐이면) 빈 문자열 `""` 을 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 입출력 예

| text | 반환값 |
|---|---|
| `"read only memory"` | `"rom"` |
| `"  Python  is fun "` | `"Pif"` |
| `"rokey"` | `"r"` |
| `""` | `""` |
