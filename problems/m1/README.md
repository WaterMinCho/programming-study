# 모의고사 1회 (1~16차시)

1~16차시 전 범위에서 고른 종합 모의고사입니다. 퀴즈 18문항(44점)과 코드 문제 10문제(56점), 총 100점이며 제한 시간은 실제 평가와 같은 120분입니다.
개념 정리는 각 차시 세트의 README.md 에 있으므로 여기서는 응시 요령만 적습니다.

## 시작하기

```bash
python study.py start m1     # 문제를 받는 순간부터 120분을 잽니다
python study.py grade m1     # 채점 (경과 시간이 함께 표시됩니다)
```

## 실전처럼 푸는 법

- 시간을 잽니다. `start` 를 실행한 뒤에는 중간에 쉬지 않고 한 번에 끝까지 풉니다. 막히는 문제는 표시만 해 두고 넘어간 뒤 마지막에 돌아옵니다.
- 퀴즈는 코드를 실행하지 않고 머릿속으로만 풉니다. 실제 평가에서는 IDE·자동완성·레퍼런스를 쓸 수 없습니다. 변수 값이 바뀌는 과정을 종이에 표로 적으며 따라갑니다.
- 코드 문제는 쓰기 전에 입출력 예를 손으로 한 번 따라가고, 다 쓴 뒤에는 경계값(0, 1, 빈 입력, 마지막 요소)을 넣어 머릿속으로 다시 실행합니다.

## 제출 전 형식 검토

부분 점수가 없으므로 답이 맞아도 형식이 다르면 0점입니다. 제출 전에 유형별로 아래 항목을 확인합니다.

| 유형 | 확인할 것 |
|---|---|
| 출력 예측 | 띄어쓰기 한 칸, 작은따옴표(`['a', 'b']`), 콜론 뒤 공백(`{'k': 1}`), `True`·`False`·`None` 의 대소문자, 줄 수 |
| 반환값 | `return` 으로 돌려주는지(`print` 만 하면 반환값은 `None`), 자료형(`3` 과 `3.0`, 문자열 `"3"` 과 정수 `3`) |
| 출력 | 예시와 글자 하나까지 같은지, 콜론과 쉼표 뒤의 공백, 줄 수 |
| 빈칸 채우기 | 빈칸이 아닌 줄을 고치거나 줄을 추가하지 않았는지 |

## 끝난 뒤 오답 정리

1. 틀린 문항은 해설을 보기 전에 한 번 더 풉니다. `python study.py explain m1 Q3` 처럼 해설은 그다음에 봅니다.
2. 틀린 이유를 '개념을 몰랐다', '코드 읽기에서 한 줄을 놓쳤다', '형식(띄어쓰기·자료형)에서 틀렸다' 중에서 골라 적습니다.
3. 개념이 원인이면 해당 차시 README.md 의 "시험에서 헷갈리기 쉬운 포인트"를 다시 읽고, 코드 읽기가 원인이면 그 코드를 종이에 한 줄씩 실행해 봅니다.
4. 틀린 문항을 고친 뒤 `python study.py grade m1` 을 다시 실행해 전부 통과하는지 확인합니다. 모의고사 결과는 적응형 학습의 문항 선택에 반영되지 않으므로, 약한 개념은 해당 차시 문항으로 다시 연습합니다.
