# p02. 재고 있는 상품 고르기 (빈칸 채우기 · 4점)

상품 이름을 키, 재고 수량을 값으로 갖는 딕셔너리 `stock` 을 받아, 재고가 1개 이상인 상품 이름만 딕셔너리에 적힌 순서대로 담은 리스트를 **반환(return)** 하는 함수 `in_stock` 입니다. 빈칸(`____`) 2곳을 채워 함수를 완성하세요.

```python
def in_stock(stock):
    names = []
    for name in stock.____():
        if stock[name] ____ 0:
            names.append(name)
    return names
```

- 첫 번째 빈칸은 딕셔너리의 키들을 돌려주는 메서드 이름, 두 번째 빈칸은 비교 연산자입니다.
- 수량은 0 이상의 정수입니다. 재고가 있는 상품이 없거나 `stock` 이 비어 있으면 빈 리스트 `[]` 를 반환합니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

| stock | 반환값 |
|---|---|
| `{"사과": 3, "배": 0, "감": 5}` | `['사과', '감']` |
| `{"a": 0, "b": 0}` | `[]` |
| `{}` | `[]` |
