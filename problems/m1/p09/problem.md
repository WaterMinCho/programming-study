# p09. 계좌 클래스와 잔액 부족 (출력 · 6점)

다음 조건에 맞는 `Account` 클래스를 완성하세요.

1. **생성자** — 예금주 `owner` 와 잔액 `balance` 를 받아 같은 이름의 인스턴스 변수에 저장합니다. `balance` 를 생략하면 0 입니다. 아무것도 출력하지 않습니다.
2. **`deposit(amount)`** — 잔액에 `amount` 를 더한 뒤 `입금 금액, 잔액 잔액` 을 출력합니다.
3. **`withdraw(amount)`** — `amount` 가 잔액보다 **크면** 잔액을 바꾸지 않고 `ValueError("잔액 부족")` 예외를 일으킵니다(출력 없음). 그렇지 않으면 잔액에서 빼고 `출금 금액, 잔액 잔액` 을 출력합니다. 잔액과 같은 금액은 출금할 수 있습니다.

- 클래스만 완성하면 됩니다. 채점할 때는 아래와 같은 테스트 코드가 객체를 만들어 메서드를 호출하고, 예외는 테스트 코드가 `try-except` 로 받아 출력합니다.
- 출력 형식은 쉼표 뒤 공백 한 칸, 그 밖의 띄어쓰기도 예시와 같아야 합니다.

## 테스트 코드와 출력 예

```python
a = Account("민수", 1000)
a.deposit(500)
a.withdraw(300)
```

```
입금 500, 잔액 1500
출금 300, 잔액 1200
```

```python
a = Account("민수", 1000)
try:
    a.withdraw(2000)
except ValueError as e:
    print("오류:", e)
print(a.balance)
```

```
오류: 잔액 부족
1000
```
