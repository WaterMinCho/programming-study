# p01. 로봇 클래스 사용하기 (빈칸 채우기 · 4점)

`Robot` 클래스를 정의하고, 객체를 하나 만들어 **속성을 출력**한 뒤 **메서드를 호출**하는 프로그램입니다.
빈칸(`____`) 3곳을 채워 프로그램을 완성하세요.

- `Robot` 클래스에는 멤버 변수 `model` 과 메서드 `beep` 이 있습니다.
- 객체 `robot` 을 만들고, `model` 값을 출력한 다음 `beep` 메서드를 호출합니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 출력 예

```
RK-11
삐빅
```

## 시작 코드

```python
class Robot:
    model = "RK-11"

        print("삐빅")

print(robot.____)
robot.beep()
```
