# p08. 계좌 입출금 (반환값 · 8점)

은행 계좌를 나타내는 `Account` 클래스와, 이 클래스를 사용하는 `solution` 함수를 완성하세요.

## Account 클래스

| 메서드 | 하는 일 |
|---|---|
| `__init__(balance)` | 잔액을 인스턴스 변수 `balance` 에 저장. 인수를 생략하면 잔액은 `0` (이미 작성되어 있습니다) |
| `deposit(amount)` | 잔액을 `amount` 만큼 늘린다. 반환값 없음 |
| `withdraw(amount)` | `amount` 가 잔액보다 크면 잔액을 바꾸지 않고 `False` 를 **반환**. 그렇지 않으면 잔액에서 `amount` 를 빼고 `True` 를 **반환** |

## solution 함수

`solution(start, amounts)` 는 잔액이 `start` 인 계좌를 하나 만들고, 리스트 `amounts` 의 값을 앞에서부터 차례로 처리합니다.

- 값이 **양수**이면 그만큼 입금(`deposit`)합니다.
- 값이 **음수**이면 그 절댓값만큼 출금(`withdraw`)을 시도합니다. (예: `-300` 이면 300 을 출금)
- 모두 처리한 뒤 `[최종 잔액, 출금에 실패한 횟수]` 를 리스트로 **반환**합니다.

- 시작 코드의 `pass` 는 아무 일도 하지 않는 자리 채움 문장이므로, 지우고 그 자리에 코드를 작성하세요.

## 제한 사항
- 0 ≤ `start` ≤ 100000
- `amounts` 의 길이는 0 이상 20 이하, 각 원소는 0 이 아닌 정수

## 입출력 예

| 호출 | 반환값 | 설명 |
|---|---|---|
| `solution(1000, [500, -300])` | `[1200, 0]` | 1000 → 1500 → 1200 |
| `solution(0, [-100])` | `[0, 1]` | 잔액이 모자라 출금 실패 |
| `solution(100, [-100, -1, 50, -50])` | `[0, 1]` | 잔액과 **같은** 금액은 출금 가능 |
| `Account().balance` | `0` | 인수 생략 시 잔액 0 |
| `Account(300).withdraw(500)` | `False` | |
| `Account(300).withdraw(300)` | `True` | |
