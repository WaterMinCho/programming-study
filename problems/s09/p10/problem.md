# p10. 여행 일정 (출력 · 6점)

여행 일정을 나타내는 `Trip` 클래스를 정의하세요.

1. **생성자** `Trip(city, days)` 는 도시 이름과 여행 일수를 받아 인스턴스 변수 `city`, `days` 에 저장하고, 숙박 일수 `nights` 를 **`days - 1`** 로 계산해 저장합니다.
2. **`label()`** 은 `도시 N박 M일` 형식의 문자열을 출력하지 않고 **반환(return)** 합니다.
3. **`extend(days)`** 는 여행을 `days` 일 늘립니다. `days` 와 `nights` 가 모두 그만큼 늘어납니다. 반환값은 없습니다.

- 클래스만 정의하면 됩니다. 채점할 때는 아래와 같은 테스트 코드가 객체를 만들어 메서드를 호출합니다.

## 테스트 코드와 출력 예

```python
t = Trip("부산", 3)
print(t.label())
print(t.nights)
```

```
부산 2박 3일
2
```

```python
t = Trip("부산", 3)
t.extend(2)
print(t.label())
print(t.days, t.nights)
```

```
부산 4박 5일
5 4
```

```python
t = Trip("제주", 2)
t.label()
t.extend(1)
```

```
(출력 없음)
```

- `label()` 은 문자열을 반환만 하므로, 세 번째 예처럼 `print` 없이 호출하면 아무것도 출력되지 않아야 합니다.
- 출력은 글자 하나까지 같아야 합니다. 도시 이름 뒤와 `박` 뒤에 공백이 한 칸씩 있고, 숫자와 `박`·`일` 사이에는 공백이 없습니다.

## 제한 사항
- `days` 는 1 이상 30 이하의 정수, `extend` 의 `days` 는 1 이상 10 이하의 정수
