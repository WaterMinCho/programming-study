# p02. 사각형의 넓이와 둘레 (반환값 · 4점)

가로(`width`)와 세로(`height`)를 가진 `Rect` 클래스가 있습니다. `__init__` 은 이미 작성되어 있습니다.
아래 두 메서드를 완성하세요.

| 메서드 | 하는 일 |
|---|---|
| `area()` | 넓이(가로 × 세로)를 **반환** |
| `perimeter()` | 둘레((가로 + 세로) × 2)를 **반환** |

- `print` 로 출력하는 것이 아니라 `return` 으로 돌려줘야 합니다.
- 클래스 이름, 메서드 이름, `__init__` 은 바꾸지 않습니다.

## 제한 사항
- `width`, `height` 는 0 이상 1000 이하의 정수

## 입출력 예

| 호출 | 반환값 |
|---|---|
| `Rect(3, 4).area()` | `12` |
| `Rect(3, 4).perimeter()` | `14` |
| `Rect(5, 5).area()` | `25` |

`Rect(3, 4).area()` 는 `r = Rect(3, 4)` 로 객체를 만든 뒤 `r.area()` 를 호출한 것과 같습니다.
