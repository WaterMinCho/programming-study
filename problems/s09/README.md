# 9차시 · 클래스(1)

변수(데이터)와 함수(기능)를 한 덩어리로 묶는 **클래스**를 처음 배우는 차시입니다.
용어를 묻는 객관식과, 클래스 코드를 눈으로 따라가며 실행하는 출력·빈칸 문제가 함께 나옵니다.

## 1. 절차적 프로그래밍 vs 객체 지향 프로그래밍

| | 절차적 프로그래밍(PP) | 객체 지향 프로그래밍(OOP) |
|---|---|---|
| 관점 | 할 일을 기능별로, 순서대로 처리 | 현실의 사물(객체)을 본떠서 구성 |
| 만드는 방식 | 명령을 차례대로 나열 | 속성(데이터)과 동작(기능)을 묶어 클래스로 제작 |
| 장점 | 컴퓨터의 처리 방식과 비슷해서 상대적으로 빠름 | 유지보수가 쉽고 코드를 다시 쓰기 좋음 |
| 단점 | 유지보수가 어렵고, 코드 순서가 바뀌면 같은 결과를 보장하지 못함 | 메모리를 많이 쓰고 상대적으로 느림 |

"순서가 바뀌면 결과가 달라질 수 있다", "빠르다" 는 **절차적** 쪽 설명입니다. 객관식에서 OOP 설명 사이에 섞여 나옵니다.

## 2. 클래스 · 객체 · 인스턴스

- **클래스(class)**: 분류, 틀, 설계도. 변수와 함수를 모아 둔 것입니다. (예: `로봇` 이라는 종류)
- **객체(object)**: 그 분류에 속하는 실체입니다. (예: 실습실 3번 자리의 로봇)
- **인스턴스(instance)**: 특정 클래스로 만들어져 메모리에 올라간 객체입니다. "`Robot` 클래스의 인스턴스"처럼 어느 클래스에서 나왔는지를 강조할 때 씁니다.
- **인스턴스화**: 클래스로 객체를 만드는 일입니다. 한 클래스로 객체를 여러 개 만들 수 있습니다.

## 3. 클래스 정의 문법

```python
class Robot:              # class 키워드 + 이름(대문자로 시작) + 콜론
    model = "RK-11"       # 멤버 변수: 속성(명사)

    def beep(self):       # 멤버 함수 = 메서드: 동작(동사). 첫 매개변수는 self
        print("삐빅")
```

- `class` 는 소문자입니다. 이름 뒤 콜론(`:`)을 빼면 문법 오류입니다.
- 들여쓰기가 된 부분까지가 클래스 정의입니다.
- 클래스 안에 메서드가 꼭 있어야 하는 것은 아닙니다. 변수만 있어도 되고, 내용이 없으면 `pass` 한 줄만 둡니다.

```python
class Phone:
    pass          # 아무 내용이 없는 클래스
```

## 4. 객체 생성과 멤버 접근

```python
r = Robot()        # 객체 이름 = 클래스 이름(인수)
print(r.model)     # 객체.멤버변수   → RK-11
r.beep()           # 객체.메서드()   → 삐빅
```

- 인수가 없어도 생성할 때 괄호는 씁니다.
- 멤버에 접근할 때는 접근 연산자 점(`.`)을 씁니다.
- `r = Robot` 처럼 괄호를 빼면 객체가 만들어지지 않고 클래스 자체에 이름만 하나 더 붙습니다.

## 5. 클래스 변수와 인스턴스 변수

| | 클래스 변수(클래스 멤버) | 인스턴스 변수(인스턴스 멤버) |
|---|---|---|
| 선언 위치 | 클래스 안, 메서드 **밖** | 클래스 안, 메서드 **안** |
| 선언 방법 | `변수 = 값` | `self.변수 = 값` |
| 소속 | 클래스에 하나 | 객체마다 따로 |
| 사용 | `클래스이름.변수` (객체로도 읽을 수 있음) | `객체.변수` (객체를 만들어야 사용 가능) |

```python
class Player:
    team = "ROKEY"                 # 클래스 변수

    def __init__(self, name):
        self.name = name           # 인스턴스 변수

p = Player("Mina")
print(Player.team)   # ROKEY
print(p.team)        # ROKEY  (객체에 team 이 없으면 클래스에서 찾습니다)
print(p.name)        # Mina
# print(Player.name) → 오류: name 은 객체마다 있는 변수라 클래스에는 없습니다
```

인스턴스 변수는 `self.변수 = 값` 이 **실행되는 순간** 만들어집니다. 일반 메서드 안에서 만든 변수는 그 메서드를 호출하기 전에는 존재하지 않습니다.

```python
class Cup:
    def fill(self, amount):
        self.amount = amount

c = Cup()
# print(c.amount) → 오류 (아직 fill 을 호출하지 않음)
c.fill(300)
print(c.amount)    # 300
```

## 6. self

- 메서드를 호출한 **그 객체 자신**을 가리킵니다. 즉 클래스의 인스턴스를 참조하는 변수입니다(객체가 저장된 위치 정보를 담고 있습니다).
- 메서드를 정의할 때 **첫 번째** 매개변수로 적습니다. 예약어는 아니고 관례로 쓰는 이름입니다.
- 호출할 때는 적지 않습니다. `c.fill(300)` 이라고 쓰면 `self` 에 `c` 가, `amount` 에 `300` 이 들어갑니다.
- 같은 클래스로 만든 여러 객체를 구분해 줍니다. `self.변수`, `self.메서드()` 로 그 객체의 멤버를 씁니다.

```python
class Basket:
    def __init__(self):
        self.items = []

    def put(self, x):
        self.items.append(x)

    def put_twice(self, x):
        self.put(x)        # 같은 객체의 다른 메서드 호출
        self.put(x)
```

- 호출한 메서드에 `return` 이 있으면 `first = self.add(n)` 처럼 반환값을 받아 쓸 수 있고, `if self.alive():` 처럼 조건 자리에 바로 쓸 수도 있습니다.
- 메서드 안에서 `self.` 없이 만든 변수는 그 메서드 안에서만 보이는 지역 변수입니다. 다른 메서드에서 같은 이름을 쓰면 NameError 입니다. 메서드끼리 값을 주고받는 통로는 `self.변수` 하나뿐입니다.

## 7. `__init__()` 초기화 메서드(생성자)

객체를 만들 때 **자동으로** 호출되어 멤버를 초기화합니다. 이름은 밑줄 두 개 + `init` + 밑줄 두 개입니다.

```python
class Pet:
    def __init__(self, age, name):
        self.age = age
        self.name = name

    def intro(self):
        print(str(self.age) + "살 " + self.name + "입니다.")

a = Pet(3, "보리")    # self 에 새 객체, age 에 3, name 에 "보리"
a.intro()             # 3살 보리입니다.
```

- 생성문의 인수는 `self` **다음** 매개변수부터 순서대로 전달됩니다. 개수가 맞지 않으면 오류입니다.
- 숫자와 문자열을 `+` 로 이으려면 `str()` 로 바꿔야 합니다. `print("나이", 3)` 처럼 쉼표로 나열하면 사이에 공백이 하나 들어갑니다.
- 매개변수 이름과 인스턴스 변수 이름이 같아도(`self.age = age`) 둘은 다른 변수입니다. `self.` 가 붙은 쪽이 객체에 저장되는 값이고, 붙지 않은 쪽은 그 메서드가 받은 인수입니다. 매개변수를 그대로 저장하지 않고 계산한 값(`self.nights = days - 1`)을 저장해도 됩니다.

## 8. 메서드의 디폴트 매개변수

함수에서 배운 디폴트 매개변수를 메서드에도 그대로 쓸 수 있습니다. `self` 뒤의 매개변수에 기본값을 줍니다.

```python
class Box:
    def size(self, w=2, h=5):
        self.area = w * h

b = Box()
b.size(3, 4)   # area = 12
b.size(3)      # h 는 기본값 5 → 15
b.size()       # 둘 다 기본값 → 10
```

## 9. 내장 클래스

- 파이썬이 미리 만들어 둔 클래스입니다: `int`, `float`, `str`, `list`, 딕셔너리(`dict`) 등. 우리가 `class` 로 직접 만든 것은 **사용자 정의 클래스**입니다.
- `na = 10` 은 `na = int(10)` 과 같은 일입니다. int 클래스의 객체 10 이 만들어지고 `na` 는 그 객체를 가리킵니다.
- `s = str("abc")` 로 만든 문자열 객체도 메서드를 가집니다. `s.capitalize()` 는 첫 글자를 대문자로 바꾼 **새 문자열** `"Abc"` 를 돌려줍니다(`s` 자체는 그대로 `"abc"`).

## 10. 객체를 리스트에 담고 함수에 넘기기

객체도 값이므로 리스트에 담거나 함수의 인수·반환값으로 쓸 수 있습니다.

```python
def top(players):              # Player 객체가 든 리스트를 받는 함수
    best = players[0]          # 첫 번째 객체를 일단 최고로 둔다
    for p in players:
        if p.score > best.score:
            best = p
    return best                # 이름이 아니라 객체를 반환

def reset(players):
    for p in players:
        p.score = 0            # 리스트 속 바로 그 객체의 값이 바뀐다
```

- `for p in players:` 의 `p` 는 리스트에 들어 있는 객체 그 자체입니다. `p.score = 0` 으로 바꾸면 밖에서 `a`, `b` 로 부르던 객체가 바뀝니다. 반대로 `p = Player(...)` 처럼 `p` 에 새 객체를 넣는 것은 지역 변수만 바꿀 뿐입니다.
- 최댓값을 찾을 때 `best = 0` 처럼 숫자로 시작하면 모든 값이 음수일 때 아무것도 뽑히지 않습니다. 첫 번째 원소를 초기값으로 두면 안전합니다.
- 함수가 객체를 반환하면 `top(players).name` 처럼 바로 멤버에 접근할 수 있습니다.

## 시험에서 헷갈리기 쉬운 포인트

- `__init__` 의 밑줄은 앞뒤로 두 개씩입니다. `_init_`, `__int__`, `init` 은 다른 이름의 메서드라서 자동으로 호출되지 않습니다.
- `self` 는 정의할 때 첫 번째 매개변수이고, 호출할 때는 쓰지 않습니다. 정의에서 `self` 를 빼먹으면 호출할 때 인수 개수 오류가 납니다.
- 메서드 안에서 `self.` 없이 `price = 100` 이라고 쓰면 그 메서드가 끝날 때 사라지는 지역 변수입니다. 객체에 남기려면 `self.price = 100` 으로 씁니다.
- 클래스를 정의하는 것만으로는 아무것도 실행되지 않습니다. `__init__` 안의 `print` 는 객체를 만들 때마다 한 번씩 실행됩니다.
- `b = a` 는 객체를 새로 만들지 않고 같은 객체에 이름을 하나 더 붙입니다. 새 객체는 `클래스이름()` 을 호출할 때만 생깁니다.
- 그래서 `c = a` 뒤에 `c.walk()` 를 호출하면 `a.steps` 도 함께 늘어나고, `c.name = "C"` 로 바꾸면 `a.name` 도 `C` 입니다. 새 객체 `b` 는 영향을 받지 않습니다.
- 메서드가 매개변수와 같은 이름의 속성을 다룰 때(`self.price = self.price - price`) `self.` 가 붙은 쪽만 객체의 값입니다. 출력 문제에서 두 값을 섞지 않도록 합니다.
- 같은 클래스로 만든 객체라도 인스턴스 변수는 객체마다 따로입니다. 한 객체의 리스트에 `append` 해도 다른 객체의 리스트는 그대로입니다.
- 클래스 변수는 `클래스이름.변수` 로 객체 없이도 읽을 수 있지만, 인스턴스 변수를 `클래스이름.변수` 로 읽으면 오류입니다.
- 값을 출력하는 메서드(`print`)와 반환하는 메서드(`return`)는 다릅니다. `return` 이 없는 메서드의 호출 결과를 `print` 하면 `None` 이 찍힙니다.
- 리스트를 `print` 하면 문자열 원소는 작은따옴표로 나옵니다: `['egg', 'milk']`.
- 강의 자료는 "클래스 이름은 대문자로 시작"이라고 정리하므로 객관식에서 이 문장은 옳은 설명으로 봅니다. 소문자로 시작해도 문법 오류는 아니지만, 대문자로 시작하는 것이 약속입니다.
- "클래스에는 반드시 메서드가 있어야 한다", "self 는 두 번째 매개변수다" 는 틀린 설명의 단골 보기입니다.
