# p09. 배달 로봇 (출력 · 8점)

배터리를 쓰며 앞으로 이동하는 `Robot` 클래스를 정의하세요.

1. **생성자** `Robot(name, battery)` — 이름과 배터리 양을 인스턴스 변수 `name`, `battery` 에 저장하고, 위치 `x` 를 `0` 으로 초기화합니다. `battery` 를 생략하면 `100` 입니다.
2. **`move(distance)`** — `distance` 칸 이동하려면 배터리가 `distance × 2` 만큼 필요합니다.
   - 배터리가 모자라면 이동하지 않고 `이름: 배터리 부족` 을 출력합니다.
   - 충분하면 `x` 를 `distance` 만큼 늘리고, 배터리를 `distance × 2` 만큼 줄인 뒤 `이름: N칸 이동` 을 출력합니다. (필요한 양과 남은 배터리가 **같으면** 이동할 수 있습니다)
3. **`status()`** — `이름 위치 x값 배터리 battery값` 형식으로 한 줄 출력합니다.

- 클래스만 정의하면 됩니다. 채점할 때는 아래와 같은 테스트 코드가 객체를 만들어 메서드를 호출합니다.

## 테스트 코드와 출력 예

```python
r = Robot("R1")
r.move(3)
r.status()
```

```
R1: 3칸 이동
R1 위치 3 배터리 94
```

```python
r = Robot("R2", 10)
r.move(6)
r.move(5)
r.move(2)
r.status()
```

```
R2: 배터리 부족
R2: 5칸 이동
R2: 배터리 부족
R2 위치 5 배터리 0
```

- 출력은 글자 하나까지 같아야 합니다. `R1:` 은 이름 바로 뒤에 콜론이 붙고, `3칸` 은 숫자와 `칸` 사이에 공백이 없습니다.

## 제한 사항
- `battery` 는 0 이상 1000 이하의 정수, `distance` 는 1 이상 100 이하의 정수
