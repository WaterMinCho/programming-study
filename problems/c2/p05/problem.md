# p05. 다이얼 자물쇠 (반환값 · 8점)

자리마다 `0` 부터 `9` 까지 돌릴 수 있는 `n` 자리 다이얼 자물쇠가 있습니다. 비밀번호에 대해 아래 힌트가 남아 있습니다.

- 모든 자리의 숫자를 더하면 `s` 가 됩니다.
- **이웃한 두 자리의 숫자는 서로 다릅니다.** (`0`, `1`, `1` 처럼 같은 숫자가 나란히 오지 않습니다.)

힌트를 모두 만족하는 비밀번호가 몇 가지인지 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 앞자리가 `0` 이어도 됩니다. 예를 들어 `n = 3` 이면 `0`, `1`, `0` 도 비밀번호 후보입니다.
- 이웃하지 않은 자리끼리는 숫자가 같아도 됩니다. `1`, `0`, `1` 은 후보입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줍니다.
- 반환값은 정수입니다. 조건을 만족하는 비밀번호가 없으면 `0` 을 반환합니다.

## 제한 사항
- 1 ≤ n ≤ 4
- 0 ≤ s ≤ 36

## 입출력 예

| n | s | 반환값 |
|---|---|---|
| 1 | 7 | `1` |
| 2 | 4 | `4` |
| 2 | 0 | `0` |
| 3 | 5 | `15` |
| 4 | 1 | `0` |

두 번째 예: 두 자리 합이 4 인 조합은 `0 4`, `1 3`, `2 2`, `3 1`, `4 0` 의 다섯 가지인데 `2 2` 는 이웃한 숫자가 같아 제외되어 `4` 가지입니다.

세 번째 예: 합이 0 인 조합은 `0 0` 하나뿐이고, 이웃한 숫자가 같아 제외되므로 답은 `0` 입니다.

다섯 번째 예: 네 자리 합이 1 이려면 한 자리만 `1` 이고 나머지가 `0` 이어야 하는데, 어떻게 놓아도 `0` 두 개가 나란히 오게 되어 조건을 만족하는 비밀번호가 없습니다.
