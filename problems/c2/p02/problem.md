# p02. 실행 취소와 다시 실행 (반환값 · 6점)

글자를 한 개씩 입력하는 아주 작은 편집기가 있습니다. 처음 문서는 빈 문자열이고, 명령 리스트 `commands` 를 앞에서부터 차례로 수행합니다.

| 명령 | 동작 |
|---|---|
| `"type X"` | 문서 끝에 글자 `X` 를 붙입니다. 이때 **다시 실행할 수 있는 글자는 모두 사라집니다.** |
| `"undo"` | 마지막에 입력한 글자를 문서에서 지웁니다. 지운 글자는 다시 실행할 수 있도록 보관합니다. 문서가 비어 있으면 아무 일도 하지 않습니다. |
| `"redo"` | 가장 최근에 `undo` 로 지운 글자를 문서 끝에 되살립니다. 되살릴 글자가 없으면 아무 일도 하지 않습니다. |

모든 명령을 수행한 뒤의 문서를 **문자열로 반환(return)** 하는 `solution` 함수를 완성하세요.

- `X` 는 공백이 아닌 글자 한 개(영문자, 숫자, 기호)입니다. `"type "` 가 다섯 글자이므로 명령 문자열의 인덱스 5 가 `X` 입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줍니다.
- 문서가 비어 있으면 빈 문자열 `""` 을 반환합니다. 리스트 `['h', '!']` 를 그대로 돌려주면 오답입니다.

## 제한 사항
- `commands` 의 길이는 0 이상 50,000 이하

## 입출력 예

| commands | 반환값 |
|---|---|
| `["type h", "type i", "undo", "type !", "redo"]` | `"h!"` |
| `["type a", "type b", "type c", "undo", "undo", "redo"]` | `"ab"` |
| `["undo", "redo", "type x"]` | `"x"` |
| `["type 7", "undo"]` | `""` |

첫 번째 예: `h` → `hi` → `undo` 로 `h` (지운 `i` 보관) → `type !` 로 `h!` 가 되면서 보관한 `i` 는 사라짐 → `redo` 는 되살릴 글자가 없어 그대로 `h!`.

두 번째 예: `abc` → `undo` 로 `ab` (보관: `c`) → `undo` 로 `a` (보관: `c`, `b`) → `redo` 는 **가장 최근에 지운** `b` 를 되살려 `ab` 가 됩니다. 먼저 지운 `c` 가 되살아나는 것이 아닙니다.
