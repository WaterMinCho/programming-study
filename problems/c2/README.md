# 코딩테스트 연습 Lv.2

프로그래머스 Lv.2 수준의 반환값 문제 6개입니다. 퀴즈는 없습니다.
Lv.1 과 다른 점은 "무엇을 세고 무엇을 저장할지"를 먼저 정해야 코드가 써진다는 것입니다.
문제를 읽고 바로 코드를 치기보다, 아래 세 가지를 종이에 적어 본 뒤 시작하세요.

## 문제 분해

문제를 "입력을 받는다 → 상태를 바꾼다 → 답을 만든다"의 세 토막으로 나눕니다.

- 상태가 무엇인지 적습니다. 로봇의 위치와 남은 배터리, 지금까지 입력한 글자들, 이름별 누적 금액처럼 **반복이 한 번 돌 때마다 바뀌는 값**이 상태입니다.
- 규칙을 조건문 한 줄씩으로 옮깁니다. "격자 밖이면 무시한다"는 `if row > 0:` 같은 경계 검사가 됩니다.
- 마지막에 요구하는 **자료형과 모양**을 확인합니다. `[행, 열]` 리스트인지, 문자열인지, 정수 하나인지에 따라 마지막 줄이 달라집니다.

## 자료구조 선택

| 필요한 일 | 고르는 것 | 쓰는 메서드 |
|---|---|---|
| 마지막에 넣은 것을 먼저 꺼낸다 (되돌리기) | 리스트를 스택으로 | `append()`, `pop()` |
| 먼저 넣은 것을 먼저 꺼낸다 (대기열) | 리스트를 큐로 | `append()`, `pop(0)` |
| 이름(키)별로 값을 모은다 | 딕셔너리 | `d.get(key, 0)`, `d.keys()` |
| 크기 순으로 줄 세운다 | 리스트 + 정렬 | 8차시 선택 정렬 |
| 중복 없이 모은다 | 세트 | `add()`, `&`, `\|`, `-` |

딕셔너리는 넣은 순서를 기억합니다. "처음 등장한 순서대로"라는 조건은 딕셔너리를 그대로 돌면 해결됩니다.

## 시간 복잡도 감각

- 반복문 하나가 n 번 돌면 n, 반복문 안에 반복문이 있으면 n × n 입니다. 파이썬은 1초에 대략 천만 번 정도의 간단한 연산을 처리합니다.
- n 이 1,000 이면 n × n 은 백만이라 이중 반복문도 괜찮습니다. n 이 100,000 이면 이중 반복문은 백억이 되어 끝나지 않습니다. 제한 사항의 n 을 보고 어느 쪽인지 먼저 판단하세요.
- 완전탐색은 "모든 경우를 다 만들어 본다"는 뜻이므로 경우의 수가 몇 개인지 먼저 셉니다. 네 자리 숫자는 만 가지, 다섯 자리는 십만 가지입니다.
- 그리디는 매 순간 가장 유리한 선택을 하고 뒤를 돌아보지 않는 방법입니다. 선택을 미룰수록 손해인 구조(갈 수 있는 가장 먼 충전소까지 가기)에서만 정답이 됩니다.
