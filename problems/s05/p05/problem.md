# p05. 홀수·짝수 구분하기 (출력 · 4점)

두 정수 `start`, `end` 를 입력받아, `start` 부터 `end` 까지(양 끝 포함)의 정수를 한 줄에 하나씩
`숫자 : 홀수` 또는 `숫자 : 짝수` 형식으로 출력하는 프로그램을 작성하세요.

- 숫자와 `:` 사이, `:` 와 글자 사이에 공백이 한 칸씩 있습니다.
- 입력을 받는 두 줄은 시작 코드에 주어져 있습니다. 그 아래에 코드를 작성하세요.

## 제한 사항
- 1 ≤ start ≤ end ≤ 100

## 입출력 예

입력

```
3
7
```

출력

```
3 : 홀수
4 : 짝수
5 : 홀수
6 : 짝수
7 : 홀수
```
