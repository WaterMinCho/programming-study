# p16. 홀수와 짝수 나눠 담기 (출력 · 6점)

정수 `n` 을 입력받아 1부터 `n` 까지(끝 포함)의 정수를 홀수는 리스트 `odds` 에, 짝수는 리스트 `evens` 에 작은 수부터 차례로
담은 뒤, 두 리스트를 아래 형식으로 출력하는 프로그램을 작성하세요.

```
홀수: [1, 3, 5]
짝수: [2, 4]
```

- 첫 줄에 홀수 리스트, 둘째 줄에 짝수 리스트를 출력합니다. `홀수:` 와 리스트 사이에는 공백이 한 칸 있습니다.
- 담을 값이 없으면 빈 리스트 `[]` 를 출력합니다.
- 리스트에 값을 추가할 때는 4차시에 배운 `append()` 를 사용합니다.
- 입력을 받는 줄은 시작 코드에 주어져 있습니다. 그 아래에 코드를 작성하세요.

## 제한 사항
- 1 ≤ n ≤ 30

## 입출력 예

입력

```
5
```

출력

```
홀수: [1, 3, 5]
짝수: [2, 4]
```

입력

```
1
```

출력

```
홀수: [1]
짝수: []
```
