# p06. 점수 합계 (빈칸 채우기 · 6점)

시험 점수를 한 줄에 하나씩 계속 입력받아 합계를 구하는 프로그램입니다.

- `-1` 이 입력되면 입력을 그만 받고, 그때까지의 합계를 `합계: 165` 와 같은 형식으로 출력한 뒤 끝냅니다.
- `-1` 이 아니면서 0 ~ 100 범위를 벗어난 값이 입력되면 `잘못된 점수` 를 출력하고, 합계에 더하지 않은 채 다음 입력을 받습니다.
- 0 이상 100 이하의 값은 합계에 더합니다.

빈칸(`____`) 세 곳을 채워 프로그램을 완성하세요.

- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 시작 코드

```python
total = 0
while ____:
    score = int(input())
    if score == -1:
        ____
    if score < 0 or score > 100:
        print("잘못된 점수")
        ____
    total += score
print("합계:", total)
```

## 입출력 예

입력

```
90
120
75
-1
```

출력

```
잘못된 점수
합계: 165
```

입력

```
-1
```

출력

```
합계: 0
```
