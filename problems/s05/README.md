# 5차시 · 반복문

같은 일을 여러 번 시키는 문법입니다. 시험에서는 몇 번 도는지, 언제 멈추는지, 돌 때마다 변수 값이 어떻게 바뀌는지를
손으로 따라갈 수 있어야 합니다. 이후 차시의 출력 문제·반환값 문제도 대부분 반복문을 바탕으로 합니다.

## 1. for: 값을 하나씩 꺼내며 반복

```python
snacks = ["쿠키", "젤리", "사탕"]
for snack in snacks:      # 값이 하나씩 snack 에 들어옴
    print(snack)          # 값의 개수만큼 실행
print("끝")               # 반복이 끝난 뒤 한 번만 실행
```

- 반복 횟수가 정해져 있을 때 씁니다. `in` 뒤에는 **시퀀스**(문자열·리스트·튜플처럼 순서와 길이가 있는 자료형)나 `range()` 가 옵니다.
- 리스트를 직접 적어도(`for n in [30, 10, 20]:`), 리스트가 담긴 변수를 적어도 됩니다. 값은 적힌 순서대로 30, 10, 20 이 나오고 크기순으로 정렬되지 않습니다.
- 문자열을 넣으면 글자를 하나씩 꺼냅니다. `for ch in "abc":` → `a`, `b`, `c`
- 슬라이싱한 부분만 돌 수도 있습니다. `for snack in snacks[1:3]:` → `젤리`, `사탕` (인덱스 1 부터 2 까지)
- 과제에 나온 `len()` 은 길이를 알려 주는 내장 함수입니다. `print(snack, len(snack))` → `쿠키 2`
- 정수는 시퀀스가 아니라서 `for x in 5:` 는 오류입니다. 5번 반복하려면 `range(5)` 를 씁니다.
- 들여쓴 줄(코드블록)만 반복됩니다. 들여쓰기는 공백 4칸 또는 탭 중 한 가지로 통일하고, `for` 줄 끝에는 콜론(`:`)을 붙입니다.

## 2. range(): 정수를 차례로 만들어 주는 내장 함수

| 형태 | 만들어지는 수 | 예 |
|---|---|---|
| `range(끝)` | 0 부터 끝 앞까지 | `range(4)` → 0, 1, 2, 3 |
| `range(시작, 끝)` | 시작부터 끝 앞까지 | `range(2, 6)` → 2, 3, 4, 5 |
| `range(시작, 끝, 증감)` | 시작부터 증감만큼씩 변하며 끝 앞까지 | `range(1, 10, 3)` → 1, 4, 7 / `range(5, 0, -2)` → 5, 3, 1 |

- **시작은 포함, 끝은 제외**입니다. 1부터 n까지는 `range(1, n + 1)` 로 적습니다.
- 무엇이 만들어지는지 궁금하면 `list(range(2, 6))` 처럼 리스트로 바꿔서 확인합니다 → `[2, 3, 4, 5]`
- `range` 로 인덱스를 만들어 리스트를 돌 수도 있습니다. 리스트 전체를 돌 때는 `range(len(snacks))` 로 0 부터 마지막 인덱스까지 만듭니다.

```python
for i in range(3):
    print(i + 1, snacks[i])    # 1 쿠키 / 2 젤리 / 3 사탕
```

## 3. while: 조건이 참인 동안 반복

```python
lap = 1
while lap <= 3:           # 매번 실행 전에 조건 검사
    print(lap, "바퀴째")
    lap = lap + 1         # 조건에 쓰는 변수를 바꿈
```

- 위 코드는 `for lap in range(1, 4):` 로 쓴 것과 같은 일을 합니다. for 가 대신 해 주던 초기값·조건·증가를 직접 써야 합니다.
- 조건이 처음부터 거짓이면 한 번도 실행하지 않습니다.
- "~할 때까지 반복" 은 반대 조건으로 씁니다. "exit 가 입력될 때까지" → `while command != "exit":`
- `while True:` 는 조건이 항상 참이라, 안에서 `break` 를 만날 때까지 끝없이 반복합니다.

for 를 while 로 바꿀 때는 `range` 에 적은 시작·끝·증감을 각각 한 줄로 옮깁니다.

```python
for num in range(2, 12, 3):    # 2, 5, 8, 11
    print(num)

num = 2                        # 시작
while num < 12:                # 끝 값 12 는 포함되지 않음 (num <= 11 과 같은 조건)
    print(num)
    num += 3                   # 증감
```

while 은 코드블록을 시작하기 전, 맨 위에서만 조건을 검사합니다. 코드블록 중간에 조건이 거짓으로 바뀌어도
그 바퀴의 남은 줄은 실행되고, 맨 위로 돌아간 뒤에 반복이 끝납니다.

```python
n = 3
while n != 0:
    n -= 1
    print(n)        # 2, 1, 0 (n 이 0 이 된 바퀴에서도 print 는 실행됨)
```

## 4. 복합 대입 연산자

대입 연산자의 왼쪽과 오른쪽에 같은 변수가 반복되면 연산과 대입을 합쳐 줄여 씁니다.

```
total = total + 5    →  total += 5
count = count - 1    →  count -= 1
word = word + "!"    →  word += "!"     # 문자열 이어 붙이기
```

## 5. continue 와 break

| 키워드 | 하는 일 |
|---|---|
| `continue` | 아래 남은 코드블록을 건너뛰고 반복의 처음으로 돌아갑니다(다음 반복 진행) |
| `break` | 반복문을 끝내고 반복문 바로 다음 코드부터 이어서 실행합니다 |

```python
for i in range(1, 8):
    if i == 6:
        break         # 반복 종료
    if i % 2 == 0:
        continue      # 짝수는 건너뜀
    print(i)          # 1, 3, 5
```

입력을 몇 번 받을지 모를 때는 `while True` + `break` 조합을 씁니다.

```python
while True:
    command = input()
    if command == "exit":
        break
    print("입력:", command)
print("종료합니다")
```

`continue` 아래에 있는 줄은 그 바퀴에서 실행되지 않습니다. 한 바퀴에 입력을 두 번 받는 반복에서 첫 입력이 틀렸을 때
`continue` 를 쓰면 두 번째 `input()` 은 건너뜁니다.

```python
while True:
    name = input()
    if name != "admin":
        print("다시 입력")
        continue          # 아래 input() 은 실행하지 않고 처음으로
    code = input()
    if code == "0000":
        break
```

## 6. 이중 for 와 print 의 end

for 안에 for 를 넣으면, 바깥이 한 번 돌 때 안쪽은 처음부터 끝까지 전부 돕니다.

```python
for i in range(1, 4):
    for j in range(i):
        print("#", end="")    # 줄을 바꾸지 않음
    print()                   # 줄바꿈
```

```
#
##
###
```

- `print(값, end="")` 는 출력 뒤에 줄바꿈 대신 `end` 에 적은 문자열을 붙입니다. 인수 없는 `print()` 는 줄바꿈만 합니다.
- `end=" "` 로 출력한 다음의 `print` 는 같은 줄에 이어서 나옵니다. `print(1, end=" ")` 뒤에 `print("끝")` 을 실행하면 `1 끝` 한 줄이 됩니다.
- 구구단처럼 "단 × 곱하는 수" 두 가지가 함께 변하는 문제는 이중 for 의 대표 예입니다.
- 주간 요약본 예제에는 `print(f"합계: {total}")` 처럼 문자열 앞에 `f` 를 붙인 f-string 이 나옵니다. `{ }` 자리에 변수 값이 들어간다고 읽으면 됩니다.

안쪽 for 에서 `break` 를 만나면 안쪽 for 만 끝납니다. 바깥 for 는 다음 값으로 넘어가 안쪽 for 를 처음부터 다시 돕니다.

```python
for i in range(1, 4):
    for j in range(1, 4):
        if j == i:
            break         # 안쪽 for 만 끝남
        print(i, j)       # 2 1 / 3 1 / 3 2
```

## 7. 자주 나오는 패턴

```python
# 누적 합: 밖에서 0 으로 초기화, 안에서 더하기
total = 0
for n in range(1, 11):
    total += n            # 55

# 개수 세기: 값이 아니라 1 을 더함
count = 0
for n in range(1, 11):
    if n % 3 == 0:
        count += 1        # 3

# 골라 담기: 밖에서 빈 리스트, 안에서 조건에 맞으면 append
evens = []
for n in range(1, 11):
    if n % 2 == 0:
        evens.append(n)   # [2, 4, 6, 8, 10]

# 처음 나오는 위치 찾기: 찾으면 순서를 적어 두고 break
scores = [72, 95, 88, 97]
position = 0              # 끝까지 못 찾으면 0 이 남음
for i in range(len(scores)):
    if scores[i] >= 90:
        position = i + 1  # 2 (인덱스 1 은 2번째)
        break             # break 가 없으면 뒤의 97 이 덮어써서 4 가 됨

# 반복문 안에서 리스트·딕셔너리 바꾸기 (4차시 내용과 함께 나옴)
left = {"빵": 1, "우유": 0}
picked = []
for name in ["우유", "빵", "빵"]:
    if left[name] == 0:
        continue          # 남은 것이 없으면 건너뜀
    left[name] -= 1
    picked.append(name)
print(picked, left)       # ['빵'] {'빵': 0, '우유': 0}
```

## 시험에서 헷갈리기 쉬운 포인트

- range 의 끝 값은 포함되지 않습니다. `range(1, 10)` 은 9 까지입니다. 10, 20, …, 50 을 만들려면 `range(10, 51, 10)` 처럼 끝 값을 50 보다 크게 적어야 합니다.
- `0 % 3 == 0` 은 참입니다. `range(0, 10)` 에서 3의 배수를 고르면 0, 3, 6, 9 로 0 도 함께 나옵니다.
- 들여쓰기가 곧 반복 범위입니다. 같은 `print` 라도 for 안에 있으면 매번, 밖에 있으면 한 번만 출력됩니다.
- `total = 0` 이 반복문 안에 있으면 매번 0 으로 돌아가 마지막 값만 남습니다.
- `total + n` 은 합계, `total + 1` 은 횟수입니다. 코드를 읽을 때 무엇을 더하는지 확인하세요.
- while 에서 값을 바꾸는 줄이 출력 전인지 후인지에 따라 결과가 한 칸씩 밀립니다. `continue` 아래에 두면 건너뛰어져 무한 반복이 될 수 있습니다.
- while 의 조건은 코드블록을 시작하기 전에만 검사합니다. 코드블록 중간에 끝낼 조건이 되어도 그 바퀴의 남은 줄은 실행됩니다. 그 자리에서 바로 멈추려면 `if` 와 `break` 를 씁니다.
- for 를 while 로 옮길 때 `<` 와 `<=` 를 구분합니다. `range(1, n + 1)` 은 `while i <= n:` 또는 `while i < n + 1:` 로 옮깁니다.
- continue 는 이번 한 번만 건너뛰고 계속, break 는 반복 자체를 끝냅니다. break 는 프로그램이 아니라 반복문만 끝내고, 이중 for 의 안쪽에서 쓰면 안쪽 반복문만 끝냅니다.
- 처음 하나만 찾을 때 `break` 를 빼먹으면 조건에 맞는 마지막 값이 남습니다.
- 반복이 끝난 뒤에도 변수는 남아 있습니다. `n` 을 1씩 키우는 `while n < 5:` 가 끝난 직후 `n` 은 5 이고, for 의 변수에는 마지막으로 꺼낸 값이 남습니다.
- 이중 for 에서 `print()` 가 안쪽 for 와 같은 깊이면 바깥이 한 번 돌 때마다, 바깥 for 와 같은 깊이면 맨 끝에 한 번만 줄이 바뀝니다.
- `print(2, "x", 3, "=", 6)` 은 값 사이에 공백이 한 칸씩 자동으로 들어가 `2 x 3 = 6` 이 됩니다. 문자열 안에 공백을 또 넣으면 두 칸이 됩니다.
- `for x in 5:` 는 오류이고, `=+` 는 복합 대입이 아닙니다(`+=` 가 맞음).
