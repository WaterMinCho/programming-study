# p14. 로그인 확인 (출력 · 8점)

등록된 아이디는 `rokey`, 비밀번호는 `ros2` 입니다. 로그인에 성공할 때까지 아래 순서를 되풀이하는 프로그램을 작성하세요.

1. 아이디를 한 줄 입력받습니다.
2. 아이디가 `rokey` 가 아니면 `없는 아이디` 를 출력하고 1번으로 돌아갑니다. 비밀번호는 입력받지 않습니다.
3. 아이디가 `rokey` 이면 비밀번호를 한 줄 입력받습니다.
4. 비밀번호가 `ros2` 가 아니면 `비밀번호 오류` 를 출력하고 1번으로 돌아가 아이디부터 다시 입력받습니다.
5. 비밀번호가 `ros2` 이면 반복을 끝냅니다.

반복이 끝나면 `로그인 성공` 을 출력하고, 그다음 줄에 아이디를 입력받은 횟수를 `시도 횟수: 3` 과 같은 형식으로 출력합니다.

- 대문자와 소문자는 서로 다른 글자입니다. (`Rokey` 는 없는 아이디)
- 로그인에 성공한 뒤에는 더 이상 입력을 받지 않습니다.
- 입력을 받을 때 안내 문구는 넣지 않아도 됩니다.

## 입출력 예

입력

```
guest
rokey
1234
rokey
ros2
```

출력

```
없는 아이디
비밀번호 오류
로그인 성공
시도 횟수: 3
```

첫 줄 `guest` 는 없는 아이디라서 비밀번호를 묻지 않고 다시 아이디를 받습니다. 둘째 줄 `rokey` 다음의 `1234` 는 틀린 비밀번호입니다.
넷째 줄부터 아이디와 비밀번호를 다시 받아 성공했고, 아이디를 세 번 입력받았으므로 시도 횟수는 3 입니다.

입력

```
rokey
ros2
```

출력

```
로그인 성공
시도 횟수: 1
```
