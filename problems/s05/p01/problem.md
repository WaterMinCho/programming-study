# p01. 번호 붙여 출력하기 (빈칸 채우기 · 4점)

분식집 메뉴 5개가 리스트 `menus` 에 들어 있습니다. 정수 `count` 를 입력받아, 앞에서부터 `count` 개의 메뉴를
`번호 메뉴이름` 형식으로 한 줄에 하나씩 출력하는 프로그램입니다. 번호는 1부터 시작합니다.
빈칸(`____`) 두 곳을 채워 프로그램을 완성하세요.

- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 시작 코드

```python
menus = ["김밥", "라면", "떡볶이", "순대", "튀김"]
count = int(input())
for i in range(____):
    print(i + 1, menus[____])
```

## 제한 사항
- 1 ≤ count ≤ 5

## 입출력 예

입력

```
3
```

출력

```
1 김밥
2 라면
3 떡볶이
```
