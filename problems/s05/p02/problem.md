# p02. 비밀번호 맞히기 (빈칸 채우기 · 4점)

올바른 비밀번호는 `python` 입니다. 비밀번호를 한 줄에 하나씩 입력받다가, 올바른 비밀번호가 입력되면 입력을 멈추고
몇 번째 입력에서 성공했는지 `N 번 만에 성공` 형식으로 출력하는 프로그램입니다.
빈칸(`____`)에 알맞은 조건식을 채워 프로그램을 완성하세요.

- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
- 대문자와 소문자는 서로 다른 글자입니다. (`Python` 은 틀린 비밀번호)
- 올바른 비밀번호가 입력된 뒤에는 더 이상 입력을 받지 않습니다.

## 시작 코드

```python
password = ""
tries = 0
while ____:
    password = input()
    tries += 1
print(tries, "번 만에 성공")
```

## 입출력 예

입력

```
abc
1234
python
```

출력

```
3 번 만에 성공
```

입력

```
python
```

출력

```
1 번 만에 성공
```
