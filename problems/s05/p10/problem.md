# p10. 글자 계단 (빈칸 채우기 · 8점)

문자열 `letters` 에 `"ROKEYCAMP"` 가 들어 있습니다. 정수 `n` 을 입력받아 글자 계단을 `n` 줄 출력하는 프로그램입니다.
첫째 줄에는 `letters` 의 첫 글자 1개, 둘째 줄에는 앞의 2개, 셋째 줄에는 앞의 3개 … 처럼 줄마다 글자가 하나씩 늘어나고,
글자 사이는 공백 한 칸으로 구분합니다.
빈칸(`____`) 세 곳을 채워 프로그램을 완성하세요.

- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.
- 줄 끝에 남는 공백은 채점에서 무시됩니다.

## 시작 코드

```python
letters = "ROKEYCAMP"
n = int(input())
for i in range(n):
    for j in range(____):
        print(letters[____], end=" ")
    ____
```

## 제한 사항
- 1 ≤ n ≤ 9

## 입출력 예

입력

```
4
```

출력

```
R
R O
R O K
R O K E
```
