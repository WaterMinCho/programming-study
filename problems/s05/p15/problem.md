# p15. 월드컵 개최 연도 (빈칸 채우기 · 4점)

월드컵은 4년에 한 번 열립니다. 2002년부터 2050년까지(2050년 포함) 월드컵이 열리는 연도를 한 줄에 하나씩 출력하는
프로그램입니다. 빈칸(`____`)을 채워 프로그램을 완성하세요.

- 빈칸만 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 시작 코드

```python
for year in range(____):
    print(year)
```

## 출력 예

```
2002
2006
2010
2014
2018
2022
2026
2030
2034
2038
2042
2046
2050
```
