# p03. 음료 찾기 (출력 · 4점)

자판기에 들어 있는 음료 이름이 리스트 `drinks` 에 순서대로 저장되어 있습니다. 찾을 음료 이름 `target` 을 입력받아
다음 규칙대로 출력하는 프로그램을 작성하세요.

1. `drinks` 의 음료 이름을 처음부터 끝까지 한 줄에 하나씩 출력합니다.
2. 방금 출력한 이름이 `target` 과 같으면 바로 다음 줄에 `찾았습니다!` 를 출력합니다.
3. 모든 음료를 출력한 뒤, 마지막 줄에 `끝` 을 한 번만 출력합니다.

- `target` 을 찾은 뒤에도 남은 음료는 끝까지 출력합니다.
- 리스트와 입력을 받는 줄은 시작 코드에 주어져 있습니다. 그 아래에 코드를 작성하세요.

## 입출력 예

입력

```
우유
```

출력

```
콜라
사이다
우유
찾았습니다!
커피
주스
끝
```

입력

```
녹차
```
