# p01. 정수 두 배 출력 (빈칸 채우기 · 4점)

한 줄을 입력받아 **정수**로 바꾼 뒤 두 배한 값을 출력하는 프로그램입니다. 정수로 바꿀 수 없는 입력이면 `숫자가 아닙니다` 를 출력합니다. 빈칸(`____`) 2곳을 채워 완성하세요.

```python
text = input()
try:
    n = ____(text)
    print(n * 2)
except ____:
    print("숫자가 아닙니다")
```

- 첫 번째 빈칸: 문자열을 정수로 바꾸는 내장 함수
- 두 번째 빈칸: 그 변환이 실패했을 때 발생하는 예외 이름
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

| 입력 | 출력 |
|---|---|
| `21` | `42` |
| `abc` | `숫자가 아닙니다` |
| `-5` | `-10` |
| `3.5` | `숫자가 아닙니다` |
