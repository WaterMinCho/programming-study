# p16. 아이디 가리기 (출력 · 6점)

아이디를 한 줄 입력받아, **첫 글자와 마지막 글자만 남기고** 가운데 글자를 모두 `*` 로 바꿔 출력하는 프로그램을 작성하세요.

- 가운데 글자 하나를 `*` 하나로 바꿉니다. 출력되는 글자 수는 입력한 아이디의 글자 수와 같습니다.
- 아이디가 두 글자 이하이면 가릴 글자가 없으므로 입력받은 아이디를 바꾸지 않고 출력합니다.
- 문자열은 `s[1] = "*"` 처럼 글자를 바꿔 넣을 수 없습니다. 인덱싱·슬라이싱으로 필요한 글자를 꺼내 새 문자열을 만드세요.

## 제한 사항
- 아이디는 길이 1 이상 20 이하이며, 영문 소문자와 숫자로만 이루어져 있습니다.

## 입출력 예

| 입력 | 출력 |
|---|---|
| `python` | `p****n` |
| `abc` | `a*c` |
| `ab` | `ab` |
| `a` | `a` |
