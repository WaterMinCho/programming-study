# p11. 설문 응답 정리 (출력 · 6점)

만족도 설문의 응답을 정리하는 프로그램을 작성하세요. 응답은 **1 이상 5 이하의 정수**여야 합니다.

**입력**

- 첫 줄에 응답 수 `n` (0 이상의 정수)
- 다음 `n` 줄에 응답이 한 줄에 하나씩 들어옵니다.

**처리** — 응답 한 줄마다 다음 순서로 확인합니다.

1. 정수로 바꿀 수 **없으면** `무시: 입력값 (숫자 아님)` 을 출력하고 그 줄은 끝냅니다. (`int()` 에서 발생하는 `ValueError` 를 처리하세요)
2. 정수이지만 1~5 를 **벗어나면** `무시: 입력값 (범위 밖)` 을 출력하고 그 줄은 끝냅니다.
3. 둘 다 정상이면 유효 응답으로 세고 합계에 더합니다.

**출력** — 모든 응답을 처리한 뒤 `유효 응답 K개` 와 `합계 S` 를 두 줄로 출력합니다.

- `입력값` 자리에는 입력된 문자열을 **그대로** 출력합니다.
- 출력은 글자 하나까지 같아야 합니다(띄어쓰기, 괄호 포함).

## 입출력 예

입력

```
5
4
abc
7
5
0
```

출력

```
무시: abc (숫자 아님)
무시: 7 (범위 밖)
무시: 0 (범위 밖)
유효 응답 2개
합계 9
```

입력

```
0
```

출력

```
유효 응답 0개
합계 0
```
