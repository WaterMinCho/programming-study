# p06. 정수가 나올 때까지 (출력 · 6점)

정수가 입력될 때까지 입력을 반복해서 받는 프로그램을 작성하세요.

1. 한 줄을 입력받아 정수로 바꿉니다.
2. 정수로 바꿀 수 **없으면** `정수를 입력하세요` 를 출력하고 다시 1 번으로 돌아갑니다.
3. 정수로 바꿀 수 **있으면** 그 수의 제곱을 출력하고 프로그램을 끝냅니다. (성공한 뒤에는 더 이상 입력을 받지 않습니다)

- `while True` 반복문 안에서 `try ... except ValueError` 와 `break` 를 사용하세요.
- 입력에는 올바른 정수가 반드시 한 번은 들어옵니다.

## 입출력 예

입력

```
abc
3.5
7
```

출력

```
정수를 입력하세요
정수를 입력하세요
49
```

입력

```
-4
```

출력

```
16
```
