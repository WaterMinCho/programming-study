# p10. 변환 실패는 기본값으로 (반환값 · 6점)

문자열 리스트 `values` 와 기본값 `default` 가 주어질 때, 각 문자열을 **정수**로 바꾼 리스트를 **반환(return)** 하는 `solution` 함수를 완성하세요. 정수로 바꿀 수 없는 문자열은 그 자리에 `default` 를 대신 넣습니다.

- 정수로 바꾸는 데 실패했는지는 `try ... except ValueError` 로 판단하세요.
- `default` 는 생략할 수 있으며, 생략하면 `0` 입니다. (시작 코드의 매개변수 선언을 그대로 둡니다)
- 반환 리스트의 길이는 `values` 와 같고, 순서도 같습니다. `values` 가 비어 있으면 빈 리스트 `[]` 를 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항
- `values` 의 길이는 0 이상 20 이하, 각 원소는 길이 0 이상 10 이하의 문자열입니다.
- `default` 는 정수 또는 문자열입니다. 주어진 값을 **그대로** 넣습니다.

## 입출력 예

| values | default | 반환값 |
|---|---|---|
| `["3", "x", "10"]` | (생략) | `[3, 0, 10]` |
| `["3", "x", "10"]` | `-1` | `[3, -1, 10]` |
| `["1", "a"]` | `"?"` | `[1, '?']` |
| `["7", "3.5", "", "-2"]` | `0` | `[7, 0, 0, -2]` |
