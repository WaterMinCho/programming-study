# p07. 나이 검사와 raise (빈칸 채우기 · 6점)

나이를 입력받아 검사하는 프로그램입니다. `check_age` 함수는 나이가 음수이면 `나이는 0 이상이어야 합니다` 라는 메시지를 담은 `ValueError` 예외를 **일부러 발생**시키고, 그렇지 않으면 나이를 그대로 반환합니다. 빈칸(`____`) 3곳을 채워 완성하세요.

```python
def check_age(age):
    if age < 0:
        ____ ValueError("나이는 0 이상이어야 합니다")
    return age

try:
    age = int(input())
    print("나이:", check_age(age))
except ____ as e:
    print("오류:", ____)
```

- 첫 번째 빈칸: 예외를 발생시키는 키워드
- 두 번째 빈칸: 잡을 예외의 이름
- 세 번째 빈칸: 예외에 담긴 메시지가 출력되도록 할 것
- 입력은 항상 정수입니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

| 입력 | 출력 |
|---|---|
| `25` | `나이: 25` |
| `-3` | `오류: 나이는 0 이상이어야 합니다` |
| `0` | `나이: 0` |
