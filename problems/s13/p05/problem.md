# p05. 날짜 나누기 (반환값 · 6점)

`"2026-10-16"` 처럼 `연-월-일` 형식의 문자열 `date` 가 주어질 때, 연·월·일을 **정수**로 바꿔 `[연, 월, 일]` 리스트로 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 반환하는 리스트의 세 값은 모두 **정수(int)** 여야 합니다. 문자열 `"10"` 이 아니라 숫자 `10` 입니다.
- 월·일이 `01` 처럼 0 으로 시작하면 정수로 바꾼 값은 `1` 입니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항
- `date` 는 항상 `숫자-숫자-숫자` 형식이며 연은 4자리, 월과 일은 2자리입니다.

## 입출력 예

| date | 반환값 |
|---|---|
| `"2026-10-16"` | `[2026, 10, 16]` |
| `"1996-01-24"` | `[1996, 1, 24]` |
| `"2000-12-01"` | `[2000, 12, 1]` |
