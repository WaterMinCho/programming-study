# p08. 변환 가능한 값의 합 (반환값 · 6점)

문자열들이 담긴 리스트 `items` 가 주어집니다. 각 문자열을 **정수**로 바꿔 보고,

- 바꿀 수 있는 값은 모두 더하고,
- 바꿀 수 없는 값은 **원래 문자열 그대로** 따로 모읍니다.

그리고 `[정수들의 합, 바꾸지 못한 문자열 리스트]` 를 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 정수로 바꾸는 데 실패했는지는 `try ... except ValueError` 로 판단하세요.
- 바꾸지 못한 문자열은 `items` 에 있던 순서대로 모읍니다.
- 모두 변환되면 두 번째 값은 빈 리스트 `[]`, `items` 가 비어 있으면 `[0, []]` 를 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항
- `items` 의 길이는 0 이상 20 이하, 각 원소는 길이 0 이상 10 이하의 문자열입니다.

## 입출력 예

| items | 반환값 | 설명 |
|---|---|---|
| `["10", "x", "25", "3.5"]` | `[35, ['x', '3.5']]` | `"3.5"` 는 정수로 바꿀 수 없음 |
| `["1", "2", "3"]` | `[6, []]` | |
| `["a", "b"]` | `[0, ['a', 'b']]` | |
| `["-7", "7", ""]` | `[0, ['']]` | 빈 문자열은 변환 실패 |
