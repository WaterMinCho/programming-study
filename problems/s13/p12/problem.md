# p12. 사탕 나누기와 finally (빈칸 채우기 · 6점)

사탕 개수와 사람 수를 두 줄로 입력받아 1인당 몇 개씩 돌아가는지(**정수 몫**) 출력하는 프로그램입니다. 사람 수가 `0` 이면 `사람 수가 0입니다` 를 출력합니다. 어느 경우든 `share` 함수는 마지막에 반드시 `나누기 끝` 을 출력합니다. 빈칸(`____`) 3곳을 채워 완성하세요.

```python
def share(candies, people):
    print("나누기 시작")
    try:
        each = candies ____ people
        print("1인당", each, "개")
    except ____:
        print("사람 수가 0입니다")
    ____:
        print("나누기 끝")

candies = int(input())
people = int(input())
share(candies, people)
print("프로그램 종료")
```

- 첫 번째 빈칸: 정수 몫을 구하는 연산자
- 두 번째 빈칸: 0 으로 나눌 때 발생하는 예외 이름
- 세 번째 빈칸: 예외 발생 여부와 상관없이 항상 실행되는 블록을 만드는 키워드
- 입력은 항상 0 이상의 정수 두 개입니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

입력

```
10
3
```

출력

```
나누기 시작
1인당 3 개
나누기 끝
프로그램 종료
```

입력

```
7
0
```

출력

```
나누기 시작
사람 수가 0입니다
나누기 끝
프로그램 종료
```
