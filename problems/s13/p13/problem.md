# p13. 점수 조회 (반환값 · 8점)

점수 리스트 `scores` 와 조회 요청 리스트 `queries` 가 주어집니다. `queries` 의 각 원소는 **문자열**이며, 조회하려는 **인덱스**를 뜻합니다. 요청마다 결과를 하나씩 만들어 리스트로 **반환(return)** 하는 `solution` 함수를 완성하세요.

요청 하나는 다음 순서로 처리합니다.

1. 문자열을 정수로 바꿀 수 **없으면** 결과는 문자열 `"번호 오류"` 입니다. (`int()` 의 `ValueError`)
2. 정수로 바꿨지만 `scores[번호]` 가 **범위를 벗어나면** 결과는 문자열 `"없는 번호"` 입니다. (`IndexError`)
3. 둘 다 정상이면 결과는 그 위치의 점수(정수)입니다.

- 번호는 **파이썬 인덱스 규칙**을 그대로 따릅니다. 음수 번호는 뒤에서부터 셉니다(예: `"-1"` 은 마지막 점수).
- 결과는 `queries` 와 같은 순서, 같은 개수입니다. `queries` 가 비어 있으면 `[]` 를 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 제한 사항
- `scores` 의 길이는 0 이상 10 이하, 각 원소는 0 이상 100 이하의 정수입니다.
- `queries` 의 길이는 0 이상 10 이하, 각 원소는 길이 0 이상 5 이하의 문자열입니다.

## 입출력 예

| scores | queries | 반환값 |
|---|---|---|
| `[80, 95, 70]` | `["1", "x", "5", "-1"]` | `[95, '번호 오류', '없는 번호', 70]` |
| `[80, 95, 70]` | `["0", "2", "3"]` | `[80, 70, '없는 번호']` |
| `[60]` | `["0", "1", "1.0", ""]` | `[60, '없는 번호', '번호 오류', '번호 오류']` |
| `[10, 20, 30, 40]` | `[]` | `[]` |
