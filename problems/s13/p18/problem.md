# p18. 인덱스로 원소 꺼내기 (빈칸 채우기 · 4점)

리스트 `numbers = [10, 20, 30]` 에서 입력받은 인덱스 위치의 원소를 출력하는 프로그램입니다. 범위를 벗어난 인덱스를 입력하면 `잘못된 인덱스입니다.` 를, 정수가 아닌 값을 입력하면 `숫자를 입력하세요.` 를 출력합니다. 빈칸(`____`) 3곳을 채워 완성하세요.

```python
numbers = [10, 20, 30]
try:
    idx = ____(input())
    print(numbers[idx])
except ____:
    print("잘못된 인덱스입니다.")
except ____:
    print("숫자를 입력하세요.")
```

- 첫 번째 빈칸: 입력받은 문자열을 정수로 바꾸는 내장 함수
- 두 번째 빈칸: 리스트의 범위를 벗어난 인덱스를 쓸 때 발생하는 예외 이름
- 세 번째 빈칸: 정수로 바꿀 수 없는 문자열을 바꾸려 할 때 발생하는 예외 이름
- 인덱스는 파이썬 규칙을 따릅니다. 음수 인덱스는 뒤에서부터 셉니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

| 입력 | 출력 |
|---|---|
| `1` | `20` |
| `3` | `잘못된 인덱스입니다.` |
| `abc` | `숫자를 입력하세요.` |
