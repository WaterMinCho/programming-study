# p02. 단어 수 세기 (반환값 · 4점)

문장 `sentence` 가 주어질 때, **공백을 기준으로 나눈 단어의 개수**를 정수로 **반환(return)** 하는 `solution` 함수를 완성하세요.

- 단어 사이에 공백이 여러 칸 있거나 문장 앞뒤에 공백이 있어도 단어 개수만 셉니다.
- 빈 문자열이면 `0` 을 반환합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. `print` 가 아니라 `return` 으로 돌려줘야 합니다.

## 제한 사항
- `sentence` 는 길이 0 이상 100 이하의 문자열이며, 영문자·숫자·공백으로만 이루어져 있습니다.

## 입출력 예

| sentence | 반환값 |
|---|---|
| `"python is fun"` | `3` |
| `"  hello   world  "` | `2` |
| `"rokey"` | `1` |
| `""` | `0` |
