# p03. 안전한 나눗셈 (출력 · 4점)

정수 두 개를 두 줄로 입력받아 첫 번째 수를 두 번째 수로 나눈 결과를 출력하는 프로그램을 작성하세요. 두 번째 수가 `0` 이면 나눌 수 없으므로 `0으로 나눌 수 없습니다` 를 출력합니다.

- 입력은 항상 정수 두 개이며, 한 줄에 하나씩 들어옵니다.
- 나눗셈은 `/` 연산자를 사용합니다. 결과는 나누어떨어지더라도 **실수**로 출력됩니다(예: `3.0`).
- 출력 형식은 `첫째수 / 둘째수 = 결과` 이며, `/` 와 `=` 앞뒤에 공백이 한 칸씩 있습니다.
- `try ... except` 로 `ZeroDivisionError` 를 처리하세요.

## 입출력 예

입력

```
10
4
```

출력

```
10 / 4 = 2.5
```

입력

```
7
0
```

출력

```
0으로 나눌 수 없습니다
```

- 출력은 글자 하나까지 같아야 합니다(띄어쓰기 포함).
