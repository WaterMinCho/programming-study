# p14. 출금 요청 처리 (출력 · 8점)

출금 함수 `withdraw` 와 시작 잔액 `balance = 10000` 이 주어져 있습니다. 출금 요청을 한 줄로 입력받아 차례로 처리하고 최종 잔액을 출력하는 프로그램을 작성하세요.

```python
def withdraw(balance, amount):
    if amount > balance:
        raise ValueError("잔액 부족")
    return balance - amount

balance = 10000
```

**입력** — 한 줄에 출금 요청들이 **공백으로 구분**되어 들어옵니다(1개 이상). 각 요청은 0 이상의 정수이거나, 정수로 바꿀 수 없는 문자열입니다.

**처리** — 요청 하나마다 다음 순서로 확인합니다.

1. 정수로 바꿀 수 **없으면** `금액 오류: 입력값` 을 출력하고 그 요청은 끝냅니다. (`int()` 의 `ValueError`)
2. 정수이면 `withdraw(balance, amount)` 를 호출합니다. 잔액이 부족하면 함수가 `ValueError` 를 발생시키므로, 이를 잡아 `출금 실패: 메시지` 를 출력합니다. 메시지는 예외에 담긴 것을 **그대로** 씁니다(`except ... as e`).
3. 출금에 성공하면 잔액을 갱신하고 `출금 금액, 잔액 남은잔액` 을 출력합니다.

**출력** — 모든 요청을 처리한 뒤 마지막 줄에 `최종 잔액: 잔액` 을 출력합니다.

- `withdraw` 함수는 **그대로 사용**합니다. 잔액 비교를 직접 다시 쓰지 마세요.
- 금액 변환 실패와 잔액 부족은 **둘 다 `ValueError`** 입니다. 어느 쪽에서 난 예외인지 구분되도록 코드를 구성해야 합니다.
- 출력은 글자 하나까지 같아야 합니다(쉼표·콜론·띄어쓰기 포함).

## 입출력 예

입력

```
3000 abc 8000 2000
```

출력

```
출금 3000, 잔액 7000
금액 오류: abc
출금 실패: 잔액 부족
출금 2000, 잔액 5000
최종 잔액: 5000
```

입력

```
10000 1
```

출력

```
출금 10000, 잔액 0
출금 실패: 잔액 부족
최종 잔액: 0
```
