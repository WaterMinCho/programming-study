# p09. 카페 주문 처리 (출력 · 8점)

가격표 `menu` 가 딕셔너리로 주어져 있습니다. 주문을 입력받아 처리하고 총액을 출력하는 프로그램을 작성하세요.

```python
menu = {"커피": 3000, "라떼": 4000, "케이크": 5500}
```

**입력**

- 첫 줄에 주문 수 `n` (0 이상의 정수)
- 다음 `n` 줄에 `메뉴이름 수량` 이 공백 하나로 구분되어 한 줄씩 들어옵니다. (항상 두 단어입니다)

**처리**: 각 주문 줄마다 다음 순서로 확인합니다.

1. 메뉴 이름이 `menu` 에 **없으면** `없는 메뉴: 이름` 을 출력하고 그 줄은 끝냅니다. (`menu[이름]` 에서 발생하는 `KeyError` 를 처리하세요)
2. 수량을 정수로 바꿀 수 **없으면** `수량 오류: 입력된수량` 을 출력하고 그 줄은 끝냅니다. (`ValueError` 를 처리하세요)
3. 둘 다 정상이면 `이름 x 수량 = 금액` 을 출력하고 금액(가격 × 수량)을 총액에 더합니다.

**출력**: 모든 주문을 처리한 뒤 마지막 줄에 `총액: 금액` 을 출력합니다.

- 한 줄에 오류는 최대 하나만 있습니다(메뉴와 수량이 동시에 잘못된 줄은 없습니다).
- 출력은 글자 하나까지 같아야 합니다(띄어쓰기, 콜론 포함).

## 입출력 예

입력

```
3
라떼 1
피자 2
커피 x
```

출력

```
라떼 x 1 = 4000
없는 메뉴: 피자
수량 오류: x
총액: 4000
```

입력

```
2
커피 2
케이크 1
```

출력

```
커피 x 2 = 6000
케이크 x 1 = 5500
총액: 11500
```
