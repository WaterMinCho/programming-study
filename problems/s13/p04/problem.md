# p04. 숫자 리스트와 제곱 (빈칸 채우기 · 4점)

공백으로 구분된 정수들을 한 줄로 입력받아, 정수 리스트와 각 수를 **제곱**한 리스트를 차례로 출력하는 프로그램입니다. 빈칸(`____`) 2곳을 채워 완성하세요.

```python
nums = list(map(____, input().split()))
squares = list(map(lambda x: ____, nums))
print(nums)
print(squares)
```

- 첫 번째 빈칸: `split()` 으로 나눈 문자열 조각 하나하나를 **정수**로 바꾸는 함수
- 두 번째 빈칸: `x` 의 제곱을 구하는 식
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

| 입력 | 출력 |
|---|---|
| `1 2 3` | `[1, 2, 3]`<br>`[1, 4, 9]` |
| `10 -2 5` | `[10, -2, 5]`<br>`[100, 4, 25]` |
| `7` | `[7]`<br>`[49]` |
