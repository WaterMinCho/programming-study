# p08. 입장권 요금 계산 (반환값 · 8점)

입장권을 나타내는 `Ticket` 클래스가 있습니다. 이를 **상속받는** 두 클래스와, 입장권 목록의 총 요금을 구하는 `solution` 함수를 완성하세요.

## Ticket 클래스 (이미 작성됨)

| 메서드 | 하는 일 |
|---|---|
| `__init__(price)` | 정가를 `price` 에 저장 |
| `cost()` | 실제 요금을 **반환**. 일반 입장권은 정가 그대로 |

## 완성할 클래스

| 클래스 | 설명 |
|---|---|
| `StudentTicket(Ticket)` | 학생권. `cost()` 를 재정의해 **정가의 절반**(`price // 2`, 소수점 버림)을 반환 |
| `SeniorTicket(Ticket)` | 경로권. `cost()` 를 재정의해 **정가의 70%**(`price * 7 // 10`, 소수점 버림)를 반환 |

- 두 클래스 모두 `__init__` 은 따로 만들지 않습니다(부모의 것을 그대로 씁니다).
- 요금은 표에 적힌 식처럼 정수 연산(`//`)으로 계산합니다. 실수 `0.7` 을 곱한 뒤 `int()` 로 바꾸면 일부 금액에서 1원이 모자라게 나옵니다.

## solution 함수

`solution(orders)` 의 `orders` 는 `[종류, 정가]` 리스트들의 리스트입니다. 종류에는 `"일반"`, `"학생"`, `"경로"` 가 있습니다.
각 항목마다 종류에 맞는 클래스(`Ticket`, `StudentTicket`, `SeniorTicket`)로 객체를 만들고 `cost()` 를 더해 **총 요금(정수)** 을 반환합니다.

- 시작 코드의 `pass` 는 아무 일도 하지 않는 자리 채움 문장이므로 지우고 코드를 작성하세요.

## 제한 사항
- `orders` 의 길이는 0 이상 20 이하, 정가는 0 이상 100000 이하의 정수

## 입출력 예

| 호출 | 반환값 | 설명 |
|---|---|---|
| `solution([["일반", 10000]])` | `10000` | |
| `solution([["일반", 10000], ["학생", 10000]])` | `15000` | 10000 + 5000 |
| `solution([["경로", 10000]])` | `7000` | |
| `solution([["학생", 9000], ["경로", 9000], ["일반", 9000]])` | `19800` | 4500 + 6300 + 9000 |
| `solution([])` | `0` | |
| `StudentTicket(9999).cost()` | `4999` | 소수점 버림 |
| `SeniorTicket(5000).price` | `5000` | 정가는 그대로 저장 |
