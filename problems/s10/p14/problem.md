# p14. 성적표와 장학생 (출력 · 8점)

수강생을 나타내는 `Student` 클래스와, 이를 **상속받는** `Scholar` 클래스를 정의하세요.

## Student 클래스

1. **생성자** `Student(name)`: 이름을 인스턴스 변수 `name` 에 저장하고, 과목별 점수를 담을 **빈 딕셔너리**를 인스턴스 변수 `scores` 에 저장합니다.
2. **`add(subject, score)`**: `scores` 에 과목 이름을 키, 점수를 값으로 저장합니다. 같은 과목을 다시 추가하면 점수를 덮어씁니다.
3. **`total()`**: 저장된 모든 점수의 합을 **반환**합니다. 과목이 하나도 없으면 `0` 을 반환합니다.
4. **`report()`**: `이름 총점 합계` 를 한 줄 출력합니다(공백 한 칸씩). 예) `Mina 총점 170`

## Scholar 클래스 (Student 상속)

1. **생성자** `Scholar(name, cutoff)`: 부모의 생성자로 `name` 과 `scores` 를 준비하고, 장학금 기준 점수를 인스턴스 변수 `cutoff` 에 저장합니다.
2. **`report()`**: 부모의 `report()` 가 출력하는 한 줄에 이어서, 총점이 `cutoff` **이상**이면 `장학금 대상`, 아니면 `장학금 제외` 를 한 줄 더 출력합니다(총 두 줄). 총점이 `cutoff` 와 **같으면** 대상입니다.
3. `add()` 와 `total()` 은 재정의하지 않습니다(부모의 것을 그대로 씁니다).

- 클래스만 정의하면 됩니다. 채점할 때는 아래와 같은 테스트 코드가 객체를 만들어 메서드를 호출합니다.

## 테스트 코드와 출력 예

```python
s = Student("Mina")
s.add("수학", 90)
s.add("영어", 80)
s.report()
```

```
Mina 총점 170
```

```python
k = Scholar("Hana", 180)
k.add("수학", 90)
k.add("영어", 90)
k.report()
```

```
Hana 총점 180
장학금 대상
```

```python
k = Scholar("Yun", 100)
k.report()
k.add("과학", 100)
k.report()
print(k.cutoff, k.name)
```

```
Yun 총점 0
장학금 제외
Yun 총점 100
장학금 대상
100 Yun
```

- 출력은 글자 하나까지 같아야 합니다.

## 제한 사항
- 점수와 `cutoff` 는 0 이상 1000 이하의 정수, 과목 수는 0 이상 10 이하
