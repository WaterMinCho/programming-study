# p13. 주차 요금 정산 (출력 · 8점)

주차장의 차량을 나타내는 `Car` 클래스와 이를 **상속받는** 두 클래스, 그리고 여러 차량의 요금을 한꺼번에 정산하는 함수 `settle` 을 작성하세요.

## Car 클래스

1. **생성자** `Car(plate, hours)` — 번호판과 주차 시간을 인스턴스 변수 `plate`, `hours` 에 저장합니다.
2. **`fee()`** — 요금 `hours × 1000` 을 **반환**합니다.

## Motorcycle 클래스 (Car 상속)

1. `__init__` 은 새로 만들지 않습니다(부모의 것을 그대로 씁니다).
2. **`fee()`** 를 재정의해 `hours × 500` 을 **반환**합니다.

## Truck 클래스 (Car 상속)

1. **생성자** `Truck(plate, hours, tons)` — 부모의 생성자로 `plate`, `hours` 를 저장하고, 적재 톤수를 인스턴스 변수 `tons` 에 저장합니다.
2. **`fee()`** 를 재정의해 `hours × 1000 + tons × 2000` 을 **반환**합니다.

## settle 함수

`settle(vehicles)` 의 `vehicles` 는 위 세 클래스의 객체가 섞여 있는 리스트입니다.

- 차량마다 `번호판 요금` 을 한 줄씩 출력합니다(공백 한 칸).
- 마지막에 `합계 총액` 을 한 줄 출력합니다. 리스트가 비어 있으면 `합계 0` 만 출력합니다.
- 각 차량의 요금은 그 객체의 `fee()` 로 구합니다. 클래스별로 계산식을 나눠 쓰지 않습니다.

## 테스트 코드와 출력 예

```python
settle([Car("11가1111", 3), Motorcycle("22나2222", 3), Truck("33다3333", 3, 2)])
```

```
11가1111 3000
22나2222 1500
33다3333 7000
합계 11500
```

```python
settle([])
```

```
합계 0
```

```python
t = Truck("44라4444", 0, 5)
print(t.plate, t.hours, t.tons)
print(t.fee())
```

```
44라4444 0 5
10000
```

- 출력은 글자 하나까지 같아야 합니다.

## 제한 사항
- `hours` 는 0 이상 24 이하의 정수, `tons` 는 1 이상 10 이하의 정수, 리스트 길이는 0 이상 10 이하
