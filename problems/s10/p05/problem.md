# p05. 관리자 급여 (반환값 · 6점)

사원을 나타내는 `Employee` 클래스가 있습니다. 이를 **상속받는** `Manager` 클래스의 메서드 세 개를 완성하세요. `Employee` 는 고치지 않습니다.

## Employee 클래스 (이미 작성됨)

| 메서드 | 하는 일 |
|---|---|
| `__init__(name, salary)` | 이름과 급여를 `name`, `salary` 에 저장 |
| `pay()` | `salary` 를 **반환** |
| `tag()` | `이름(사원)` 형식의 문자열을 **반환** |

## Manager 클래스 (완성할 것)

| 메서드 | 하는 일 |
|---|---|
| `__init__(name, salary, bonus)` | **부모의 `__init__`** 으로 `name`, `salary` 를 저장하고, `bonus` 를 인스턴스 변수 `bonus` 에 저장 |
| `pay()` | `salary + bonus` 를 **반환** (오버라이딩) |
| `tag()` | `이름(관리자)` 형식의 문자열을 **반환** (오버라이딩) |

- 시작 코드의 `pass` 는 "아무 일도 하지 않는다"는 뜻의 자리 채움 문장입니다. 지우고 코드를 작성하세요.
- `print` 로 출력하는 것이 아니라 `return` 으로 돌려줘야 합니다.

## 제한 사항
- `salary`, `bonus` 는 0 이상 100000 이하의 정수

## 입출력 예

| 호출 | 반환값 |
|---|---|
| `Manager("Kim", 3000, 500).pay()` | `3500` |
| `Manager("Kim", 3000, 500).tag()` | `'Kim(관리자)'` |
| `Manager("Kim", 3000, 500).name` | `'Kim'` |
| `Employee("Lee", 2000).pay()` | `2000` |
| `Employee("Lee", 2000).tag()` | `'Lee(사원)'` |
