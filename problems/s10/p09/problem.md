# p09. 전투 유닛과 치유사 (출력 · 8점)

게임 유닛을 나타내는 `Unit` 클래스와, 이를 **상속받는** `Healer` 클래스를 정의하세요.

## Unit 클래스

1. **생성자** `Unit(name, hp)`: 이름과 체력을 인스턴스 변수 `name`, `hp` 에 저장합니다.
2. **`status()`**: 아래 형식으로 두 줄 출력합니다. (콜론 뒤에 공백 한 칸)
   ```
   이름: 병사
   체력: 70
   ```
3. **`hit(damage)`**: 체력을 `damage` 만큼 줄입니다. 단, 체력은 `0` 아래로 내려가지 않습니다(모자라면 `0`). 그런 다음 `이름 피해 damage` 를 한 줄 출력합니다. 예) `병사 피해 30`

## Healer 클래스 (Unit 상속)

1. **생성자** `Healer(name, hp, mana)`: 부모의 생성자로 `name`, `hp` 를 저장하고, 마나를 인스턴스 변수 `mana` 에 저장합니다.
2. **`status()`**: 부모의 `status()` 가 출력하는 두 줄에 이어서 `마나: 값` 을 한 줄 더 출력합니다(총 세 줄).
3. **`heal(amount)`**: 마나가 `10` 미만이면 아무것도 바꾸지 않고 `마나 부족` 만 출력합니다. `10` 이상이면 체력을 `amount` 만큼 늘리고 마나를 `10` 줄인 뒤 `이름 회복 amount` 를 출력합니다. 예) `사제 회복 15` (마나가 **정확히 10** 이면 회복할 수 있습니다)
4. `hit()` 은 재정의하지 않습니다(부모의 것을 그대로 씁니다).

- 클래스만 정의하면 됩니다. 채점할 때는 아래와 같은 테스트 코드가 객체를 만들어 메서드를 호출합니다.

## 테스트 코드와 출력 예

```python
u = Unit("병사", 100)
u.hit(30)
u.status()
```

```
병사 피해 30
이름: 병사
체력: 70
```

```python
h = Healer("사제", 80, 25)
h.hit(10)
h.heal(15)
h.heal(15)
h.heal(15)
h.status()
```

```
사제 피해 10
사제 회복 15
사제 회복 15
마나 부족
이름: 사제
체력: 100
마나: 5
```

- 출력은 글자 하나까지 같아야 합니다. `병사 피해 30` 은 이름, `피해`, 숫자 사이에 공백이 하나씩 있습니다.

## 제한 사항
- `hp`, `mana` 는 0 이상 1000 이하의 정수, `damage`, `amount` 는 1 이상 1000 이하의 정수
