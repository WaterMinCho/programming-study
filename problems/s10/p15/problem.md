# p15. math 모듈 불러 쓰기 (빈칸 채우기 · 4점)

내장 라이브러리 `math` 모듈의 `factorial` 함수를 서로 다른 import 형태로 불러 쓰는 프로그램입니다.
`factorial(n)` 은 1부터 n까지의 곱을 돌려줍니다. 예) `factorial(4)` 는 `1 × 2 × 3 × 4 = 24`, `factorial(0)` 은 `1`

정수 `n` 을 입력받아 첫째 줄에 `n` 의 팩토리얼을, 둘째 줄에 `n - 1` 의 팩토리얼을 출력합니다.
빈칸(`____`) 3곳을 채워 프로그램을 완성하세요.

- 1번째 줄은 `math` 모듈에서 함수 하나를 가져옵니다. 5번째 줄이 모듈 이름 없이 `factorial(n)` 으로 호출하는 점을 보고 채웁니다.
- 2번째 줄은 `math` 모듈에 별칭 `m` 을 붙여 불러옵니다.
- 6번째 줄은 2번째 줄에서 붙인 별칭으로 `factorial` 을 호출합니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

```python
from math import ____
import math ____ m

n = int(input())

```
