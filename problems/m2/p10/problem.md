# p10. 후위 표기식 계산 (반환값 · 8점)

후위 표기식은 `3 4 +` 처럼 연산자를 두 수의 뒤에 적는 식입니다. 토큰이 공백으로 구분된 후위 표기식 문자열 `expr` 이 주어질 때, 스택으로 식을 계산한 결과를 **반환(return)** 하는 `solution` 함수를 완성하세요.

토큰을 앞에서부터 하나씩 아래 규칙으로 처리합니다.

- 토큰이 `+`, `-`, `*`, `/` 가운데 하나이면 스택에서 값을 두 번 꺼냅니다. 먼저 꺼낸 값이 `b`, 나중에 꺼낸 값이 `a` 일 때 `a 연산자 b` 를 계산해 결과를 스택에 넣습니다. `/` 는 몫을 구하는 `//` 로 계산합니다.
- 그 밖의 토큰은 `int()` 로 정수로 바꿔 스택에 넣습니다.
- 모든 토큰을 처리한 뒤 스택에 값이 한 개만 남아 있으면 그 값(정수)을 반환합니다.

계산할 수 없는 식은 아래 표의 문자열을 반환합니다.

| 상황 | 반환값 |
|---|---|
| 연산자가 아닌 토큰을 `int()` 로 바꿀 수 없다 (`x`, `3.5`, `+-` 등) | `"토큰 오류"` |
| 연산자를 처리하는데 스택에서 꺼낼 값이 모자란다 | `"식 오류"` |
| 0 으로 나눈다 | `"0 나눗셈"` |
| 모든 토큰을 처리한 뒤 스택에 남은 값이 한 개가 아니다 (0개 또는 2개 이상) | `"식 오류"` |

## 제한 사항

- `expr` 의 길이는 0 이상 100 이하이고, 토큰이 하나도 없는 빈 문자열에는 `"식 오류"` 를 반환합니다.
- 수 토큰은 0 이상의 정수입니다. 계산 도중의 값과 결과는 음수가 될 수 있지만, 음수를 나누거나 음수로 나누는 식은 주어지지 않습니다.
- 연산자를 만나면 값을 두 번 꺼낸 다음에 계산합니다. `0 /` 는 두 번째 값을 꺼낼 수 없으므로 `"0 나눗셈"` 이 아니라 `"식 오류"` 입니다.
- 오류가 여러 개 있는 식은 앞에서부터 처리하다가 **처음 만난 오류**의 문자열을 반환합니다. `1 0 / x` 는 `x` 를 보기 전에 0 으로 나누므로 `"0 나눗셈"` 입니다.
- 빈 리스트에서 `pop()` 을 하면 `IndexError` 가 발생합니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 입출력 예

| expr | 반환값 |
|---|---|
| `"3 4 +"` | `7` |
| `"5 1 2 + 4 * + 3 -"` | `14` |
| `"8 0 /"` | `"0 나눗셈"` |
| `"2 x +"` | `"토큰 오류"` |
| `"1 +"` | `"식 오류"` |

두 번째 예의 스택은 `[5]` → `[5, 1]` → `[5, 1, 2]` → `[5, 3]` → `[5, 3, 4]` → `[5, 12]` → `[17]` → `[17, 3]` → `[14]` 순서로 바뀝니다.
