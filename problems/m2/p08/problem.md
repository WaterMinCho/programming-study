# p08. 색상 코드 골라내기 (빈칸 채우기 · 6점)

공백으로 구분된 문자열들을 한 줄로 입력받아, `#` 뒤에 16진수 글자(`0`~`9`, `a`~`f`, `A`~`F`) 6개가 붙은 색상 코드만 골라 `#` 을 뺀 여섯 글자를 한 줄씩 출력하고, 마지막 줄에 고른 개수를 출력하는 프로그램입니다. 빈칸(`____`) 3곳을 채워 프로그램을 완성하세요.

```python
import re

p = re.compile(r"#[0-9a-f]{6}$", ____)    # 대문자 A~F 도 허용
codes = input().split()
count = 0
for code in codes:
    m = p.____(code)
    if m:
        print(m.group()[____])              # '#' 을 뺀 여섯 글자
        count += 1
print(count)
```

- 첫 번째 빈칸은 컴파일 옵션, 두 번째 빈칸은 패턴 객체의 검색 메서드 이름, 세 번째 빈칸은 슬라이싱 범위입니다.
- 문자열 전체가 `#` 과 16진수 글자 6개로 이루어져야 합니다. `#fff`(글자 수 부족), `#1234567`(글자 수 초과), `#GGGGGG`(16진수가 아닌 글자)는 출력하지 않습니다.
- `#` 앞에 다른 글자가 붙은 `x#000000` 도 출력하지 않습니다. 패턴 문자열은 고칠 수 없으므로 두 번째 빈칸의 메서드로 이 경우를 걸러 냅니다.
- 글자는 입력된 대소문자를 바꾸지 않고 출력합니다. 색상 코드가 없으면 `0` 만 출력합니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

입력

```
#12abEF #fff x#000000 #00ff7f
```

출력

```
12abEF
00ff7f
2
```

입력

```
red blue
```

출력

```
0
```
