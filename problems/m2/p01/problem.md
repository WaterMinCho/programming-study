# p01. 가장 큰 값과 가장 작은 값의 차 (빈칸 채우기 · 4점)

정수 리스트 `nums` 를 받아, 가장 큰 값에서 가장 작은 값을 뺀 결과를 **반환(return)** 하는 함수 `gap` 입니다. 빈칸(`____`) 2곳을 채워 함수를 완성하세요.

```python
def gap(nums):
    big = nums[0]
    small = nums[0]
    for n in nums:
        if n ____ big:
            big = n
        if n < small:
            small = ____
    return big - small
```

- 첫 번째 빈칸은 비교 연산자, 두 번째 빈칸은 변수 이름입니다.
- `nums` 의 길이는 1 이상 100 이하이고, 음수가 들어 있을 수 있습니다. 요소가 한 개이면 `0` 을 반환합니다.
- **빈칸만** 채웁니다. 다른 줄을 고치거나 줄을 추가하면 오답 처리됩니다.

## 입출력 예

| nums | 반환값 |
|---|---|
| `[3, 9, 4]` | `6` |
| `[5]` | `0` |
| `[-2, -8, -5]` | `6` |
