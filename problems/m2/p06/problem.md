# p06. 사물함 클래스 (출력 · 6점)

다음 조건에 맞는 `Locker` 클래스를 완성하세요.

1. 클래스 변수 `total` 을 둡니다. 처음 값은 0 이고, 지금까지 만든 `Locker` 객체의 수를 나타냅니다.
2. 생성자는 사물함 번호 `number` 와 사용자 이름 `owner` 를 받아 같은 이름의 인스턴스 변수에 저장하고, 클래스 변수 `total` 을 1 늘립니다. `owner` 를 생략하면 `"없음"` 입니다. 아무것도 출력하지 않습니다.
3. `info()` 는 `3번 사물함: 민수` 처럼 번호와 사용자 이름을 출력합니다.
4. `assign(name)` 은 `owner` 가 `"없음"` 일 때만 `owner` 를 `name` 으로 바꾸고 `7번 배정: 지영` 을 출력합니다. 이미 사용자가 있으면 `owner` 를 바꾸지 않고 `7번 사용 중` 을 출력합니다.

- 클래스만 완성하면 됩니다. 채점할 때는 아래와 같은 테스트 코드가 객체를 만들어 메서드를 호출합니다.
- `total` 은 `Locker.total` 로 읽었을 때와 객체로 읽었을 때(`a.total`) 모두 지금까지 만든 객체의 수여야 합니다.
- 번호 바로 뒤에 `번` 을 붙이고, 콜론 뒤에는 공백 한 칸을 둡니다. 그 밖의 띄어쓰기도 예시와 같아야 합니다.

## 테스트 코드와 출력 예

```python
a = Locker(3, "민수")
b = Locker(7)
a.info()
b.info()
print(Locker.total)
```

```
3번 사물함: 민수
7번 사물함: 없음
2
```

```python
b = Locker(7)
b.assign("지영")
b.assign("현우")
b.info()
```

```
7번 배정: 지영
7번 사용 중
7번 사물함: 지영
```
