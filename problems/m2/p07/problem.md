# p07. 파일의 n번째 줄 읽기 (반환값 · 6점)

한 줄에 정수가 하나씩 적힌 텍스트 파일의 경로 `path` 와 줄 번호 `n` 이 주어집니다. 그 파일의 `n` 번째 줄(첫 줄이 1번째)에 적힌 값을 **정수로 반환(return)** 하는 `solution` 함수를 완성하세요. 값을 읽을 수 없는 경우에는 아래 표의 문자열을 반환합니다.

| 상황 | 반환값 |
|---|---|
| `path` 의 파일이 없다 | `"파일 없음"` |
| 파일에 `n` 번째 줄이 없다 | `"줄 없음"` |
| `n` 번째 줄을 `int()` 로 바꿀 수 없다 | `"숫자 아님"` |

## 제한 사항

- `n` 은 1 이상 100 이하의 정수입니다.
- 없는 파일을 읽기 모드로 열면 `FileNotFoundError` 가 발생합니다. 강의 예제처럼 `except OSError` 로 받아도 됩니다.
- 빈 줄도 한 줄로 셉니다. 빈 줄과 `3.5`, `abc` 같은 줄은 `int()` 로 바꿀 수 없습니다.
- 줄에는 음의 정수가 적혀 있을 수 있고, 숫자 양옆에 공백이 붙어 있을 수 있습니다. `int()` 는 양옆의 공백과 줄바꿈을 무시하고 변환합니다.
- 마지막 줄 끝에는 줄바꿈이 있을 수도 있고 없을 수도 있습니다. 비어 있는 파일에는 줄이 없습니다.
- 함수 이름과 매개변수는 바꾸지 않습니다.

## 입출력 예

| 파일 | 호출 | 반환값 |
|---|---|---|
| `nums.txt` 의 내용이 `10`⏎`20`⏎`30`⏎ | `solution("nums.txt", 2)` | `20` |
| `nums.txt` 의 내용이 `10`⏎`20`⏎`30`⏎ | `solution("nums.txt", 4)` | `"줄 없음"` |
| `nums.txt` 의 내용이 `10`⏎`abc`⏎`30`⏎ | `solution("nums.txt", 2)` | `"숫자 아님"` |
| `none.txt` 라는 파일이 없음 | `solution("none.txt", 1)` | `"파일 없음"` |

(⏎ 는 줄바꿈을 뜻합니다)
