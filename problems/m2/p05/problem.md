# p05. 연속으로 겹친 값 건너뛰기 (반환값 · 6점)

리스트 `items` 의 값을 앞에서부터 하나씩 내놓되, **바로 앞의 값과 같은 값은 건너뛰는** 제너레이터 함수 `solution` 을 완성하세요. 값은 `return` 이 아니라 `yield` 로 하나씩 내놓습니다.

## 제한 사항

- `items` 의 길이는 0 이상 100 이하이고, 요소는 정수이거나 문자열입니다.
- 첫 번째 값은 항상 내놓습니다. 두 번째 값부터는 바로 앞 칸의 값과 다를 때만 내놓습니다.
- 떨어진 자리에 다시 나온 값은 건너뛰지 않습니다. `[1, 1, 2, 1]` 에서는 `1`, `2`, `1` 을 차례로 내놓습니다.
- `items` 가 비어 있으면 아무 값도 내놓지 않습니다.
- 채점할 때는 `list(solution(...))` 으로 내놓은 값을 모두 모으거나 `next(solution(...))` 로 첫 값을 꺼내 비교하고, `type(solution(...)).__name__` 이 `'generator'` 인지도 확인합니다. 리스트를 `return` 하면 오답 처리됩니다.
- 함수 이름과 매개변수는 바꾸지 않습니다. 시작 코드의 `pass` 는 아무 일도 하지 않는 자리 채움 문장이므로 지우고 코드를 작성하세요.

## 입출력 예

| 호출 | 결과 |
|---|---|
| `list(solution([1, 1, 2, 2, 2, 3, 1]))` | `[1, 2, 3, 1]` |
| `list(solution(["a", "a", "a"]))` | `['a']` |
| `list(solution([]))` | `[]` |
| `next(solution([7, 7, 8]))` | `7` |
