# w01. 상품 목록에 검색 붙이기

서버에서 받은 상품 목록을 화면에 보여 주는 작은 React 저장소를 고치는 미션입니다. 처음 15분 동안 받은 코드를 읽습니다. 이어지는 30분 동안 면접관이 하나씩 건네는 요구에 맞게 코드를 고칩니다. 웹 면접 준비에서 처음 푸는 워밍업 미션이라 파일이 적고 코드도 짧습니다.

토스증권의 2026년 공개 채용 공고를 보면 1차 면접은 라이브 코딩입니다. 미리 받은 코드베이스를 면접관과 함께 읽고 고칩니다. 이 미션은 그 형식을 따라 새로 지은 연습 문제이고 실제 출제 문제와는 관계가 없습니다.

## 어떤 앱인가요

쇼핑몰의 상품 목록 화면입니다. 화면을 열면 서버에서 상품 열 개를 받아 이름과 가격을 한 줄씩 보여 줍니다. 서버는 없고 `src/api.ts`의 가짜 함수가 서버 대신 응답합니다.

## 어떻게 실행하나요

[폴더 열기]를 누르거나 `submissions/<내 ID>/web/missions/w01/` 폴더를 에디터에서 여세요. 앱이 쓰는 패키지는 검사 도구를 설치할 때 스터디 저장소 맨 위 `node_modules` 폴더에 함께 들어갑니다. 검사 도구는 웹 홈의 [설치 관리]나 터미널의 `python study.py web install`로 설치합니다. 미션 폴더에서 `npm install`을 하지 마세요. 미션 폴더 안에 따로 설치하면 React가 두 벌 읽혀 `Invalid hook call` 오류가 날 수 있습니다. 에디터의 터미널에서 아래 명령을 실행하세요.

```
npm run dev      # http://localhost:5173 에서 앱이 열립니다
npm test         # 미션 폴더에 들어 있는 테스트를 실행합니다
```

프로그램 아래쪽의 [화면 띄우기]를 눌러도 `npm run dev`와 같은 서버가 뜨고 브라우저에 앱이 열립니다. 서버는 같은 자리의 [화면 끄기]를 누르거나 미션 화면을 떠나면 꺼집니다. [테스트 돌리기]는 `npm test`와 같은 테스트를 돌려 통과한 개수와 첫 실패를 보여 줍니다.

Windows의 PowerShell 터미널에서는 `npm run dev`가 "npm.ps1 파일을 로드할 수 없습니다"라는 오류로 막힐 수 있습니다. 그럴 때는 `npm.cmd run dev`와 `npm.cmd test`로 실행하거나 [화면 띄우기]와 [테스트 돌리기]를 쓰세요. PowerShell의 실행 정책은 바꾸지 않아도 됩니다.

## 파일은 어떻게 나뉘어 있나요

```
src/
  main.tsx                     앱 시작 파일 (StrictMode 사용)
  App.tsx                      상품 목록 state 를 가지고 화면을 그리는 최상위 컴포넌트
  api.ts                       가짜 서버 getProducts()
  types.ts                     Product 타입
  format.ts                    가격을 화면용 글자로 바꾸는 함수
  components/ProductList.tsx   상품 목록
  components/ProductItem.tsx   상품 한 줄
  App.test.tsx                 지금 통과하는 기존 테스트
  format.test.ts               format.ts 의 기존 테스트
```

## 가짜 서버는 어떻게 응답하나요

`getProducts()`는 인자를 받지 않습니다. 정해 둔 시간을 기다린 뒤 상품 열 개가 든 배열을 Promise로 돌려줍니다. `npm run dev`로 띄운 화면에서는 0.6초 뒤에 응답하고 테스트에서는 기다리지 않고 바로 응답합니다. 상품 하나는 `id`, `name`, `price`를 가집니다. `price`는 원 단위 정수입니다.
