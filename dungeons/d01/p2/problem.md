## 문제 설명

대상단의 낙타는 등 양쪽에 짐을 하나씩, 모두 두 개를 싣습니다. 낙타 한 마리가 버틸 수 있는 무게는 X입니다. 창고에 있는 짐의 무게 weights와 X가 주어질 때, 서로 다른 두 짐을 골라 한 낙타에 실을 수 있는 방법의 수를 return 하도록 solution 함수를 완성해 주세요.

두 짐 무게의 합이 X 이하이면 실을 수 있고, 고르는 순서만 다른 경우는 한 가지로 셉니다. 무게가 같은 짐이라도 창고의 다른 자리에 놓인 짐이면 서로 다른 짐으로 봅니다.

## 함수

```python
def solution(weights: list[int], X: int) -> int:
```

```javascript
function solution(weights, X) {}
```

## 제한사항

- 2 ≤ weights의 길이 ≤ 200,000
- 1 ≤ weights의 원소 ≤ 1,000,000,000
- 1 ≤ X ≤ 2,000,000,000
- 답은 최대 약 2×10^10이며 JavaScript의 Number로 정확히 나타낼 수 있습니다.

## 입출력 예

| weights | X | result |
|---|---|---|
| [5, 1, 3, 4] | 6 | 3 |
| [2, 2, 2] | 4 | 3 |
| [7, 8] | 10 | 0 |

## 입출력 예 설명

- 예 1: (1, 3), (1, 4), (1, 5)의 합이 6 이하입니다. (3, 4)는 합이 7이라 실을 수 없습니다.
- 예 2: 무게가 같은 짐 세 개에서 두 개를 고르는 방법 3가지의 합이 모두 4입니다. 같은 짐을 두 번 고를 수는 없습니다.
- 예 3: 두 짐의 합 15가 10보다 큽니다.
