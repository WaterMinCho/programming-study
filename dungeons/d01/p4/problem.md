## 문제 설명
시장 큰길에는 향신료 노점 n개가 한 줄로 서 있습니다. 노점은 저마다 향신료를 한 가지만 팝니다. 노점을 왼쪽부터 1번, 2번, … 순서로 부르고, 배열 stalls에는 그 순서대로 각 노점이 파는 향신료 이름이 적혀 있습니다. 손님의 주문서 order에는 필요한 향신료와 개수가 "향신료 개수" 꼴로 한 줄씩 적혀 있습니다.

손님은 이웃한 노점들을 끊김 없이 지나는 범위, 곧 연속한 노점 구간을 한 번 걸으며 노점마다 향신료를 한 개씩 살 수 있습니다. 구간 안에서 주문서의 향신료를 모두 적힌 개수 이상 살 수 있으면 그 구간은 주문을 채웁니다.

주문을 채울 수 있는 연속 구간 가운데 가장 짧은 구간의 길이(지나는 노점 수)를 return 하도록 solution 함수를 완성해 주세요. 주문을 채울 수 있는 구간이 없으면 0을 return 합니다.

## 함수
```python
def solution(stalls: list[str], order: list[str]) -> int:
```
```javascript
function solution(stalls, order) {}
```

## 제한사항
- 1 ≤ stalls의 길이 ≤ 200,000
- 1 ≤ order의 길이 ≤ 100,000이며, order에 적힌 향신료 이름은 서로 겹치지 않습니다.
- order의 원소는 "향신료 개수" 꼴이며, 향신료와 개수 사이에는 공백이 하나 있습니다. 개수는 1 이상 200,000 이하인 정수이며 앞에 0이 붙지 않습니다.
- 향신료 이름(stalls의 원소와 order의 향신료)은 알파벳 소문자와 밑줄(`_`)로만 이루어지고 길이는 1 이상 11 이하입니다.
- 주문서에 있지만 어느 노점에서도 팔지 않는 향신료가 있을 수 있습니다.

## 입출력 예
| stalls | order | result |
|---|---|---|
| ["salt", "cumin", "cumin", "pepper", "cumin", "salt", "cumin"] | ["cumin 2", "salt 1"] | 3 |
| ["mint", "anise", "anise", "mint"] | ["mint 1", "anise 1"] | 2 |
| ["salt", "salt"] | ["salt 3"] | 0 |

## 입출력 예 설명
- 예 1: cumin 2개와 salt 1개를 사려면 노점이 적어도 3곳 필요하고, 1~3번(salt, cumin, cumin)이 주문을 채웁니다. 4~6번(pepper, cumin, salt)처럼 길이가 3이어도 cumin이 1개뿐이면 주문을 채우지 못합니다.
- 예 2: 1~2번(mint, anise)이 길이 2로 주문을 채웁니다. 노점 한 곳에서는 향신료를 하나만 사므로 길이 1인 구간으로는 두 향신료를 살 수 없습니다.
- 예 3: salt를 파는 노점이 2곳뿐이라 salt 3개를 살 수 없으므로 0을 return 합니다.
