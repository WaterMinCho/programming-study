## 문제 설명

대상단은 오아시스 사이의 구간 n개를 차례로 지납니다. i번째 구간을 지나는 데 드는 연료는 fuel[i]이고 모두 양수입니다. 연속한 구간 몇 개를 묶어 하루 일정으로 삼으려면, 묶음의 연료 합이 L 이상 R 이하여야 합니다. 구간 하나만으로 이루어진 묶음도 하루 일정이 될 수 있습니다.

연료 배열 fuel과 두 정수 L, R이 주어질 때, 하루 일정으로 삼을 수 있는 묶음(연속한 구간들)의 수를 return 하도록 solution 함수를 완성해 주세요. 시작 구간이나 끝 구간이 다르면 서로 다른 묶음입니다.

## 함수

```python
def solution(fuel: list[int], L: int, R: int) -> int:
```

```javascript
function solution(fuel, L, R) {}
```

## 제한사항

- 1 ≤ fuel의 길이 ≤ 200,000
- 1 ≤ fuel의 원소 ≤ 10,000
- 1 ≤ L ≤ R ≤ 2,000,000,000
- return 하는 값은 최대 20,000,100,000이며 JavaScript의 Number로 정확히 나타낼 수 있습니다.

## 입출력 예

| fuel | L | R | result |
|---|---|---|---|
| [2, 1, 3, 2] | 3 | 5 | 4 |
| [5, 5, 5] | 5 | 5 | 3 |
| [1, 1, 1, 1] | 1 | 100 | 10 |

## 입출력 예 설명

- 예 1: [3], [2, 1], [1, 3], [3, 2]의 합이 각각 3, 3, 4, 5라서 모두 범위 안에 듭니다. [2]와 [1]은 합이 L보다 작고, [2, 1, 3]은 합이 6이라 R을 넘습니다.
- 예 2: 구간 하나짜리 묶음 3개만 합이 5입니다. 구간 두 개를 묶으면 합이 10이라 R을 넘습니다.
- 예 3: 길이 1인 묶음 4개, 길이 2인 묶음 3개, 길이 3인 묶음 2개, 길이 4인 묶음 1개가 모두 범위 안에 듭니다.
