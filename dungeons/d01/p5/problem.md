## 문제 설명

향신료 시장의 환전상은 하루 동안의 거래를 장부에 시간 순서대로 한 줄씩 적습니다. 배열 deltas에는 그 순서대로 거래마다의 손익이 적혀 있습니다. 이익은 양수, 손해는 음수, 변동이 없으면 0입니다.

감사 규정에 따라 연속한 기록 묶음 가운데 손익 합이 정확히 K인 묶음을 모두 찾아야 합니다. 연속한 기록 묶음은 장부에서 이웃한 기록을 끊김 없이 고른 것이고, 기록 하나만 고른 묶음도 됩니다. 묶음의 손익 합은 그 안에 든 손익을 모두 더한 값입니다.

손익 합이 정확히 K인 묶음의 수를 return 하도록 solution 함수를 완성해 주세요. 시작 기록이나 끝 기록이 다르면 서로 다른 묶음입니다.

## 함수

```python
def solution(deltas: list[int], K: int) -> int:
```

```javascript
function solution(deltas, K) {}
```

## 제한사항

- 1 ≤ deltas의 길이 ≤ 200,000
- −10,000 ≤ deltas의 원소 ≤ 10,000
- −2,000,000,000 ≤ K ≤ 2,000,000,000
- return 하는 값은 최대 20,000,100,000이며 JavaScript의 Number로 정확히 나타낼 수 있습니다.

## 입출력 예

| deltas | K | result |
|---|---|---|
| [3, -1, 2, -2, 1] | 2 | 3 |
| [0, 0, 0] | 0 | 6 |
| [1, 2, 3] | 3 | 2 |

## 입출력 예 설명

- 예 1: [3, -1], [2], [3, -1, 2, -2]의 합이 2입니다. 마지막 묶음처럼 합이 2를 넘었다가 손해로 다시 2가 되는 묶음도 셉니다.
- 예 2: 길이 1인 묶음 3개, 길이 2인 묶음 2개, 길이 3인 묶음 1개의 합이 모두 0입니다.
- 예 3: 합이 3인 묶음은 [1, 2]와 [3]입니다.
