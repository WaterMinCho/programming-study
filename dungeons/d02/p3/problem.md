## 문제 설명

용암 평원은 N개의 행과 M개의 열로 이루어진 격자이고, 관측소는 칸마다 쌓인 화산재의 양을 grid에 기록해 두었습니다. grid[i][j]는 위에서 i + 1번째 행, 왼쪽에서 j + 1번째 열에 있는 칸의 화산재 양입니다. 음수는 그 칸에서 바람에 쓸려 나간 양입니다.

관측소는 직사각형 구역의 화산재 양을 묻는 질의를 보냅니다. 질의 [r1, c1, r2, c2]는 왼쪽 위 칸이 r1번 행 c1번 열, 오른쪽 아래 칸이 r2번 행 c2번 열인 직사각형 안에 있는 모든 칸의 화산재 양을 더한 값을 묻습니다. 행과 열 번호는 1부터 셉니다.

격자 grid와 질의 목록 queries가 주어질 때, 질의마다 구한 합을 질의 순서대로 담은 배열을 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(grid: list[list[int]], queries: list[list[int]]) -> list[int]:
```

```javascript
function solution(grid, queries) {}
```

## 제한사항

- grid는 N개의 행으로 이루어지고 각 행의 길이는 M입니다.
- 1 ≤ N, 1 ≤ M, N × M ≤ 250,000
- −10,000 ≤ grid의 원소 ≤ 10,000
- 1 ≤ queries의 길이 ≤ 200,000
- queries의 원소 [r1, c1, r2, c2]는 1 ≤ r1 ≤ r2 ≤ N, 1 ≤ c1 ≤ c2 ≤ M을 만족합니다.

## 입출력 예

| grid | queries | result |
|---|---|---|
| [[1, 2, 3], [4, 5, 6], [7, 8, 9]] | [[1, 1, 2, 2], [2, 2, 3, 3], [1, 1, 3, 3], [3, 1, 3, 1]] | [12, 28, 45, 7] |
| [[-1, 2, -3, 4]] | [[1, 2, 1, 4], [1, 1, 1, 1]] | [3, -1] |

## 입출력 예 설명

- 예 1: 첫 질의 [1, 1, 2, 2]는 1번 행 1번 열부터 2번 행 2번 열까지의 네 칸을 묻습니다. 1 + 2 + 4 + 5 = 12입니다. 둘째 질의는 오른쪽 아래 네 칸이라 5 + 6 + 8 + 9 = 28이고, 셋째 질의는 격자 전체라 45입니다. 넷째 질의 [3, 1, 3, 1]은 3번 행 1번 열 한 칸만 묻고, 그 칸의 값은 7입니다.
- 예 2: 행이 하나뿐인 격자입니다. 첫 질의는 1번 행의 2번 열부터 4번 열까지라 2 − 3 + 4 = 3이고, 둘째 질의는 1번 행 1번 열 한 칸이라 −1입니다.
