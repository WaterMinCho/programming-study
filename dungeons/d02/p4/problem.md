## 문제 설명

용암 평원의 관측대는 이번에는 평원을 위아래로 N개의 행, 왼쪽에서 오른쪽으로 M개의 열이 있는 격자로 나누어 칸마다 온도를 기록합니다. 위에서 r번째 행, 왼쪽에서 c번째 열에 있는 칸을 (r, c)로 적고, r과 c는 모두 1부터 셉니다. 관측을 시작할 때 모든 칸의 온도는 0입니다.

분출이 한 번 일어나면 직사각형 모양 구역 안에 있는 모든 칸의 온도가 같은 값만큼 한 번에 바뀝니다. 분출 기록 events의 원소 [r1, c1, r2, c2, v]는 왼쪽 위 칸이 (r1, c1)이고 오른쪽 아래 칸이 (r2, c2)인 직사각형 안 모든 칸의 온도를 v만큼 바꿉니다. v가 음수이면 그 칸들의 온도가 그만큼 내려갑니다. 한 칸에 여러 분출이 겹치면 그 칸의 온도는 겹친 분출의 v가 모두 더해진 값이 됩니다.

격자의 행 수 N, 열 수 M, 분출 기록 events가 주어질 때, 기록된 분출이 모두 끝난 뒤 가장 높은 온도와 그 온도인 칸의 수를 [가장 높은 온도, 칸의 수] 순서로 담은 배열을 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(N: int, M: int, events: list[list[int]]) -> list[int]:
```

```javascript
function solution(N, M, events) {}
```

## 제한사항

- 1 ≤ N, 1 ≤ M, N × M ≤ 250,000
- events의 길이는 0 이상 250,000 이하이고, 각 원소는 정수 다섯 개를 담은 배열 [r1, c1, r2, c2, v]입니다.
- 1 ≤ r1 ≤ r2 ≤ N, 1 ≤ c1 ≤ c2 ≤ M
- −1,000 ≤ v ≤ 1,000

## 입출력 예

| N | M | events | result |
|---|---|---|---|
| 3 | 3 | [[1, 1, 2, 2, 2], [2, 2, 3, 3, 3], [1, 3, 1, 3, -1]] | [5, 1] |
| 2 | 2 | [[1, 1, 2, 2, 4], [1, 1, 1, 1, -4]] | [4, 3] |
| 1 | 3 | [[1, 1, 1, 3, -2]] | [-2, 3] |

## 입출력 예 설명

- 예 1: 첫 분출로 (1, 1)부터 (2, 2)까지 네 칸이 2가 되고, 둘째 분출로 (2, 2)부터 (3, 3)까지 네 칸에 3이 더해집니다. 셋째 분출은 (1, 3) 한 칸만 1 내립니다. 최종 온도를 행마다 적으면 [[2, 2, -1], [2, 5, 3], [0, 3, 3]]이고, 가장 높은 온도 5는 두 분출이 겹친 (2, 2) 한 칸에만 있으므로 답은 [5, 1]입니다.
- 예 2: 첫 분출로 네 칸이 모두 4가 되고, 둘째 분출이 (1, 1) 한 칸만 4 내려 0으로 되돌립니다. 최종 온도는 [[0, 4], [4, 4]]라 가장 높은 온도 4인 칸이 3개입니다.
- 예 3: 분출 하나가 세 칸을 모두 2 내려 최종 온도는 [[-2, -2, -2]]입니다. 모든 칸이 -2라 가장 높은 온도도 -2이고, 세 칸이 모두 그 온도이므로 답은 [-2, 3]입니다.
