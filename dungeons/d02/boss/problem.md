## 문제 설명

용암 평원의 관측대는 평원을 N행 M열의 격자로 나누어 봅니다. 위에서 i번째 행, 왼쪽에서 j번째 열에 있는 칸을 (i, j)로 나타내고, 행 번호와 열 번호는 1부터 셉니다. 관측을 시작할 때 모든 칸의 온도는 0입니다.

분출 기록 events의 각 원소 [r1, c1, r2, c2, v]는 왼쪽 위 칸이 (r1, c1)이고 오른쪽 아래 칸이 (r2, c2)인 직사각형 안 모든 칸의 온도를 v만큼 바꿉니다. v가 음수이면 그 직사각형 안 칸들의 온도가 그만큼 내려갑니다. 기록된 분출이 모두 끝난 뒤 온도가 T 이상인 칸을 용암 칸이라고 부릅니다.

용암의 열기는 둘레로 퍼지므로 대피 본부는 용암 칸 주변을 위험 칸으로 정합니다. 어떤 용암 칸과 행 번호의 차이가 d 이하이고 열 번호의 차이도 d 이하인 칸은 모두 위험 칸입니다. 용암 칸 자신도 위험 칸입니다. 위험 칸이 아닌 칸은 안전 칸입니다.

대피 본부는 질의 [r1, c1, r2, c2]마다 왼쪽 위 칸이 (r1, c1)이고 오른쪽 아래 칸이 (r2, c2)인 직사각형 안 안전 칸의 수를 묻습니다. 격자의 행 수 N과 열 수 M, 분출 기록 events, 기준 온도 T, 열기가 퍼지는 범위 d, 질의 목록 queries가 주어질 때, 질의마다 구한 안전 칸의 수를 질의 순서대로 담은 배열을 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(N: int, M: int, events: list[list[int]], T: int, d: int, queries: list[list[int]]) -> list[int]:
```

```javascript
function solution(N, M, events, T, d, queries) {}
```

## 제한사항

- 1 ≤ N, 1 ≤ M, N × M ≤ 250,000
- events의 길이는 0 이상 250,000 이하이고, 각 원소는 정수 다섯 개를 담은 배열 [r1, c1, r2, c2, v]이며 1 ≤ r1 ≤ r2 ≤ N, 1 ≤ c1 ≤ c2 ≤ M, −1,000 ≤ v ≤ 1,000을 만족합니다.
- −250,000,000 ≤ T ≤ 250,000,000
- 0 ≤ d ≤ 250,000
- 1 ≤ queries의 길이 ≤ 250,000
- queries의 각 원소는 정수 네 개를 담은 배열 [r1, c1, r2, c2]이며 1 ≤ r1 ≤ r2 ≤ N, 1 ≤ c1 ≤ c2 ≤ M을 만족합니다.

## 입출력 예

| N | M | events | T | d | queries | result |
|---|---|---|---|---|---|---|
| 3 | 4 | [[1, 1, 2, 3, 5], [2, 2, 3, 4, -3], [1, 4, 3, 4, 4]] | 5 | 1 | [[1, 1, 3, 4], [3, 2, 3, 4], [1, 4, 1, 4]] | [2, 2, 0] |
| 2 | 2 | [[1, 1, 1, 1, -1]] | 0 | 0 | [[1, 1, 2, 2]] | [1] |
| 1 | 6 | [[1, 3, 1, 3, 7]] | 7 | 1 | [[1, 1, 1, 6], [1, 5, 1, 6]] | [3, 2] |

## 입출력 예 설명

- 예 1: 세 분출이 끝난 뒤 온도는 1행이 [5, 5, 5, 4], 2행이 [5, 2, 2, 1], 3행이 [0, -3, -3, 1]입니다. 온도가 5 이상인 용암 칸은 (1, 1), (1, 2), (1, 3), (2, 1)입니다. d = 1이라 1행과 2행의 칸은 모두 어느 용암 칸과 행·열 번호의 차이가 1 이하여서 위험 칸이고, 3행에서는 (2, 1)과 이웃한 (3, 1), (3, 2)가 위험 칸입니다. 안전 칸은 (3, 3), (3, 4) 두 칸이라 첫째 질의의 답은 2, 3행 2열부터 4열까지를 묻는 둘째 질의의 답도 2입니다. 셋째 질의의 (1, 4)는 (1, 3) 바로 옆이라 위험 칸이므로 답은 0입니다.
- 예 2: 분출이 닿은 (1, 1)만 온도가 -1이고 나머지 세 칸은 0에 머물렀습니다. 기준 온도가 0이라 온도 0인 세 칸이 용암 칸입니다. d = 0이면 용암 칸 자신만 위험 칸이므로 안전 칸은 (1, 1) 하나이고 답은 [1]입니다.
- 예 3: 용암 칸은 (1, 3) 하나이고 d = 1이라 (1, 2), (1, 3), (1, 4)가 위험 칸입니다. 격자 밖은 따지지 않으므로 안전 칸은 (1, 1), (1, 5), (1, 6)이고, 전체를 묻는 첫째 질의의 답은 3, 5열과 6열을 묻는 둘째 질의의 답은 2입니다.
