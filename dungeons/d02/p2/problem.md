## 문제 설명

용암 평원의 관측대는 평원을 1번부터 n번까지 n개의 칸으로 나누어 칸마다 온도를 기록합니다. 관측을 시작할 때 모든 칸의 온도는 0입니다. 분출이 한 번 일어나면 한 칸, 또는 이어진 여러 칸의 온도가 같은 값만큼 한 번에 바뀝니다. 분출 기록 eruptions의 원소 [l, r, v]는 l번 칸부터 r번 칸까지의 온도를 v만큼 바꿉니다. v가 음수이면 l번부터 r번 칸의 온도가 그만큼 내려갑니다.

칸의 수 n, 분출 기록 eruptions, 기준 온도 T가 주어질 때, 기록된 분출이 모두 끝난 뒤 온도가 T 이상인 칸의 수를 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(n: int, eruptions: list[list[int]], T: int) -> int:
```

```javascript
function solution(n, eruptions, T) {}
```

## 제한사항

- 1 ≤ n ≤ 200,000
- eruptions의 길이는 0 이상 200,000 이하이고, 각 원소는 정수 세 개를 담은 배열 [l, r, v]입니다.
- 1 ≤ l ≤ r ≤ n
- −10,000 ≤ v ≤ 10,000
- −2,000,000,000 ≤ T ≤ 2,000,000,000

## 입출력 예

| n | eruptions | T | result |
|---|---|---|---|
| 5 | [[1, 3, 2], [2, 5, 3], [3, 3, -4]] | 3 | 3 |
| 4 | [[2, 2, -1]] | 0 | 3 |
| 3 | [] | 1 | 0 |

## 입출력 예 설명

- 예 1: 첫 분출로 1, 2, 3번 칸이 2가 되고, 둘째 분출로 2번부터 5번 칸에 3이 더해져 온도는 [2, 5, 5, 3, 3]이 됩니다. 셋째 분출은 3번 칸만 4 내려 최종 온도는 [2, 5, 1, 3, 3]이고, 3 이상인 칸은 2, 4, 5번의 세 칸입니다.
- 예 2: 최종 온도는 [0, -1, 0, 0]입니다. 분출이 닿지 않은 1, 3, 4번 칸도 온도가 0이라 기준 온도 0 이상이므로 답은 3입니다.
- 예 3: 분출이 하나도 없으면 모든 칸의 온도가 0에 머물러 1 이상인 칸이 없습니다.
