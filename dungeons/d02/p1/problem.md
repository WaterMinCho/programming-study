## 문제 설명

용암 평원에는 관측 칸 n개가 한 줄로 놓여 있습니다. 칸 번호는 1부터 세고, i번 칸의 온도 변화량은 temps의 i번째 원소입니다. 온도 변화량은 음수일 수 있습니다. 관측대장은 질의 [l, r]마다 l번 칸부터 r번 칸까지 온도 변화량을 모두 더한 값을 알고 싶어 합니다.

온도 변화량 temps와 질의 목록 queries가 주어질 때, 질의마다 구한 합을 질의 순서대로 담은 배열을 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(temps: list[int], queries: list[list[int]]) -> list[int]:
```

```javascript
function solution(temps, queries) {}
```

## 제한사항

- 1 ≤ temps의 길이 n ≤ 200,000
- -10,000 ≤ temps의 원소 ≤ 10,000
- 1 ≤ queries의 길이 ≤ 200,000
- queries의 원소는 정수 두 개 [l, r]로 이루어지며 1 ≤ l ≤ r ≤ n을 만족합니다.

## 입출력 예

| temps | queries | result |
|---|---|---|
| [3, -1, 4, 1, -5] | [[1, 3], [2, 5], [4, 4]] | [6, -1, 1] |
| [10] | [[1, 1], [1, 1]] | [10, 10] |
| [-2, -2, -2] | [[1, 3], [2, 3]] | [-6, -4] |

## 입출력 예 설명

- 예 1: 1번부터 3번 칸까지는 3 - 1 + 4 = 6, 2번부터 5번 칸까지는 -1 + 4 + 1 - 5 = -1이고, 4번 칸 하나의 값은 1입니다.
- 예 2: 칸이 하나뿐이고 같은 질의가 두 번 들어옵니다. 같은 질의가 여러 번 나오면 그때마다 답합니다.
- 예 3: 모든 칸이 -2라서 세 칸의 합은 -6, 두 칸의 합은 -4입니다.
