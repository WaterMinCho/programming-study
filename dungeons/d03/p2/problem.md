## 문제 설명

모래시계 탑 아래층 공방에는 모래시계를 만드는 연금로 n대가 있고, 모든 연금로는 0분에 동시에 켜집니다. i번 연금로의 정보는 furnaces[i] = [w, c]로 주어집니다. 이 연금로는 켜진 뒤 w분 동안 예열만 하고, 예열이 끝난 때부터 c분마다 모래시계를 하나씩 완성합니다. 그래서 첫 모래시계는 w + c분에, 두 번째 모래시계는 w + 2c분에 나오고, w가 0인 연금로는 c분에 첫 모래시계를 내놓습니다. 연금로는 한번 켜지면 쉬지 않으며, 서로 다른 연금로가 같은 분에 모래시계를 완성할 수도 있습니다.

탑지기가 모래시계 M개를 주문했습니다. 연금로의 정보 목록 furnaces와 주문 수 M이 주어질 때, 완성된 모래시계의 수가 처음으로 M개 이상이 되는 시각(분)을 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(furnaces: list[list[int]], M: int) -> int:
```

```javascript
function solution(furnaces, M) {}
```

## 제한사항

- 1 ≤ furnaces의 길이 ≤ 200,000
- furnaces의 원소 [w, c]는 0 ≤ w ≤ 1,000,000,000, 1 ≤ c ≤ 100,000을 만족합니다.
- 1 ≤ M ≤ 1,000,000,000
- return 하는 값은 최대 100,001,000,000,000이며 JavaScript의 Number로 정확히 나타낼 수 있습니다.

## 입출력 예

| furnaces | M | result |
|---|---|---|
| [[0, 3], [0, 5]] | 5 | 10 |
| [[4, 2], [0, 5]] | 4 | 10 |
| [[1000000000, 100000]] | 1000000000 | 100001000000000 |

## 입출력 예 설명

- 예 1: 두 연금로 모두 예열이 없습니다. 10분까지 첫 연금로는 3, 6, 9분에, 둘째 연금로는 5, 10분에 모래시계를 완성합니다. 9분까지 완성된 것은 3 + 1 = 4개이고, 10분에 둘째 연금로가 하나를 더 완성해 5개가 됩니다.
- 예 2: 첫 연금로는 4분까지 예열한 뒤 6, 8, 10분에 완성하고, 둘째 연금로는 5, 10분에 완성합니다. 9분까지는 5, 6, 8분에 나온 3개뿐이고, 10분에 두 연금로가 동시에 하나씩 완성해 5개가 되면서 처음으로 4개 이상이 됩니다.
- 예 3: 연금로 한 대가 10억 분 동안 예열한 뒤 10만 분마다 하나씩 만듭니다. 10억 개를 만들려면 예열 10^9분에 10^5 × 10^9 = 10^14분을 더한 100,001,000,000,000분이 걸립니다.
