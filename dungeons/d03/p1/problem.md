## 문제 설명

모래시계 탑의 기록관에는 사건이 일어난 시각을 적은 기록이 정리되지 않은 채 쌓여 있습니다. 시각은 0 이상의 정수로 적고, 같은 시각에 여러 사건이 일어났을 수도 있습니다. 기록관을 찾은 사람들은 시각 a부터 시각 b까지 일어난 사건이 몇 개인지 묻습니다. 이 물음을 질의라 부르고 [a, b]로 적습니다.

사건의 시각 목록 times와 질의 목록 queries가 주어질 때, 질의 [a, b]마다 시각이 a 이상 b 이하인 사건의 수를 구해 질의 순서대로 담은 배열을 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(times: list[int], queries: list[list[int]]) -> list[int]:
```

```javascript
function solution(times, queries) {}
```

## 제한사항

- 1 ≤ times의 길이 ≤ 200,000
- 0 ≤ times의 원소 ≤ 1,000,000,000
- 1 ≤ queries의 길이 ≤ 200,000
- queries의 원소는 정수 두 개 [a, b]로 이루어지며 0 ≤ a ≤ b ≤ 1,000,000,000을 만족합니다.

## 입출력 예

| times | queries | result |
|---|---|---|
| [5, 1, 9, 5, 3] | [[1, 5], [6, 8], [5, 5], [0, 100]] | [4, 0, 2, 5] |
| [7] | [[8, 9], [0, 6], [7, 7]] | [0, 0, 1] |

## 입출력 예 설명

- 예 1: 시각을 작은 것부터 늘어놓으면 1, 3, 5, 5, 9입니다. [1, 5]에는 1, 3, 5, 5 네 개가 들고, [6, 8]에는 아무 사건도 들지 않습니다. [5, 5]에는 시각 5에 일어난 사건 두 개가 들고, [0, 100]에는 다섯 개가 모두 듭니다.
- 예 2: 시각 7에 일어난 사건만 있습니다. [8, 9]는 그 시각보다 뒤, [0, 6]은 앞이라 0개이고 [7, 7]에는 1개가 듭니다.
