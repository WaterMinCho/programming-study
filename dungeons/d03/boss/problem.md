## 문제 설명

모래시계 탑 꼭대기에도 한 줄로 곧게 뻗은 회랑이 있습니다. 회랑의 자리는 입구에서 잰 거리인 위치로 나타내고, 입구를 왼쪽 끝에 두고 보면 위치가 클수록 오른쪽에 있습니다. 이 회랑에는 받침대가 없는 대신 수정을 놓을 수 있는 구역들이 정해져 있으며, 그 목록이 zones에 담겨 있습니다. zones[i] = [l, r]이면 i번 구역에서는 위치가 l 이상 r 이하인 정수 위치 어디에나 수정을 놓을 수 있습니다. 구역끼리는 겹치지 않고, l이 작은 구역부터 차례로 주어집니다.

탑지기는 수정 K개를 구역 안의 서로 다른 정수 위치에 하나씩 놓으려 합니다. 위치가 a와 b인 두 수정 사이의 거리는 |a - b|입니다. 수정끼리 가까우면 공명이 일어나므로, 탑지기는 가장 가까운 두 수정 사이의 거리가 가능한 한 커지도록 놓으려 합니다. 그렇게 놓았을 때 가장 가까운 두 수정 사이의 거리를 D라 하겠습니다.

가장 가까운 거리가 D가 되게 놓는 방법 가운데 가장 오른쪽 수정의 위치가 가장 작은 방법을 골라, [D, 그 방법에서 가장 오른쪽 수정의 위치]를 return 하도록 solution 함수를 완성해 주세요.

## 함수

```python
def solution(zones: list[list[int]], K: int) -> list[int]:
```

```javascript
function solution(zones, K) {}
```

## 제한사항

- 1 ≤ zones의 길이 ≤ 100,000
- zones의 원소 [l, r]은 0 ≤ l ≤ r ≤ 1,000,000,000,000을 만족합니다.
- 서로 다른 두 구역이 같은 정수 위치를 함께 포함하는 일은 없습니다.
- zones는 l의 오름차순으로 정렬되어 있습니다.
- 2 ≤ K ≤ 1,000,000,000
- 모든 구역에 들어 있는 정수 위치의 수를 합하면 K 이상입니다.

## 입출력 예

| zones | K | result |
|---|---|---|
| [[0, 3], [20, 29]] | 5 | [3, 26] |
| [[0, 2], [5, 5], [10, 12]] | 4 | [2, 10] |
| [[0, 1000000000000]] | 3 | [500000000000, 1000000000000] |

## 입출력 예 설명

- 예 1: 0, 3, 20, 23, 26에 놓으면 가장 가까운 거리가 3입니다. 모든 수정 사이를 4 이상으로 두려면 [0, 3]에는 하나만 놓을 수 있고, [20, 29]에는 20, 24, 28처럼 세 개까지만 놓을 수 있어서 다섯 개를 놓지 못합니다. 거리 3을 지킬 때도 [0, 3]에는 두 개까지만 들어가므로 [20, 29]에 세 개 이상을 놓아야 하고, 그 세 번째 수정은 20에서 3씩 두 번 떨어진 26보다 왼쪽에 올 수 없습니다. 그래서 가장 오른쪽 수정의 위치는 26입니다.
- 예 2: 0, 2, 5, 10에 놓으면 가장 가까운 거리가 2입니다. 모든 수정 사이를 3 이상으로 두려면 세 구역에 하나씩만 놓을 수 있어서 네 개를 놓지 못합니다. 거리 2를 지킬 때 [0, 2]와 [5, 5]에는 합해서 세 개까지만 들어가므로 네 번째 수정은 [10, 12]에 놓이고, 가장 오른쪽 수정의 위치는 10입니다.
- 예 3: 수정 세 개를 놓으면 가장 왼쪽 수정과 가장 오른쪽 수정 사이에 간격이 두 개 생기고, 두 수정 사이는 10^12보다 멀 수 없습니다. 그래서 가장 가까운 거리는 5×10^11을 넘지 못하며, 0, 5×10^11, 10^12에 놓으면 이 거리가 됩니다. 이 거리를 지키면 가장 오른쪽 수정은 10^12에만 놓일 수 있습니다.
