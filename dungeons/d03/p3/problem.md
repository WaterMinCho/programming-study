## 문제 설명

모래시계 탑의 회랑은 한 줄로 곧게 뻗어 있고, 회랑의 자리는 입구에서 잰 거리인 위치로 나타냅니다. 회랑에는 수정을 올릴 수 있는 빈 받침대 n개가 있으며, i번 받침대의 위치는 stands[i]입니다. 회랑에는 이미 수정이 놓인 자리도 있고, 그 위치들은 fixed에 담겨 있습니다. 이미 놓인 수정은 옮길 수 없습니다. 탑지기는 빈 받침대 가운데 K개를 골라 고른 받침대마다 수정을 하나씩 올리려 합니다.

수정끼리 가까우면 공명이 일어납니다. 그래서 탑지기는 이미 놓인 수정과 새로 올린 수정을 모두 합쳐, 가장 가까운 두 수정 사이의 거리가 가능한 한 커지도록 받침대를 고르려 합니다. 위치가 a와 b인 두 수정 사이의 거리는 |a - b|입니다. 받침대를 가장 잘 골랐을 때 가장 가까운 두 수정 사이의 거리를 return 하도록 solution 함수를 완성해 주세요.

stands와 fixed는 오름차순으로 주어집니다. 같은 위치에 받침대가 둘 이상 있을 수 있고, 받침대가 이미 놓인 수정과 같은 위치에 있거나 이미 놓인 수정 둘이 같은 위치에 있을 수도 있습니다. 같은 위치에 있는 두 수정 사이의 거리는 0입니다.

## 함수

```python
def solution(stands: list[int], fixed: list[int], K: int) -> int:
```

```javascript
function solution(stands, fixed, K) {}
```

## 제한사항

- 1 ≤ stands의 길이 ≤ 200,000
- 1 ≤ K ≤ stands의 길이
- 0 ≤ fixed의 길이 ≤ 200,000이고, fixed의 길이 + K ≥ 2입니다.
- 0 ≤ stands와 fixed의 원소 ≤ 1,000,000,000
- stands와 fixed는 오름차순으로 정렬되어 있습니다.

## 입출력 예

| stands | fixed | K | result |
|---|---|---|---|
| [0, 3, 6, 7, 10] | [] | 3 | 4 |
| [1, 4, 9, 12] | [6] | 2 | 5 |
| [2, 3, 8] | [0, 5, 6] | 1 | 1 |

## 입출력 예 설명

- 예 1: 이미 놓인 수정이 없으므로 받침대 세 곳을 고릅니다. 0, 6, 10에 올리면 수정 사이의 거리가 6과 4라 가장 가까운 거리는 4입니다. 세 수정이 모두 5 이상 떨어지려면 양 끝 수정 사이가 10 이상이어야 하므로 0과 10에 올려야 하고, 가운데 수정은 두 수정에서 모두 5 이상 떨어진 위치 5에 있어야 합니다. 그런데 5에는 받침대가 없습니다.
- 예 2: 6에 수정이 이미 놓여 있고 받침대 두 곳을 더 고릅니다. 1과 12에 올리면 수정은 1, 6, 12에 있고, 가장 가까운 거리는 1과 6 사이의 5입니다. 모든 수정 사이를 6 이상으로 만들려면 새 수정 두 개가 모두 6에서 6 이상 떨어져야 하는데, 위치가 0 이하이거나 12 이상인 받침대는 12에만 있어서 두 개를 올릴 수 없습니다.
- 예 3: 이미 놓인 수정 5와 6 사이의 거리가 1이므로 어느 받침대를 골라도 가장 가까운 거리는 1보다 커질 수 없습니다. 2에 올리면 수정은 0, 2, 5, 6에 있고, 가장 가까운 거리는 5와 6 사이의 1입니다.
