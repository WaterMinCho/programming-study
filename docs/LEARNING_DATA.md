# 풀이 데이터를 보관하고 공유합니다

파이썬과 AI 비전 개론 홈의 [학습 데이터]에서 과목별로 추가 수집을 시작할 수 있습니다. 기본 설정은 수집하지 않음입니다. 수집과 공유에 참여하지 않아도 학습·채점·풀이 제출을 사용할 수 있습니다.

## 이 기기에 보관합니다

[동의하고 수집 시작]을 누른 뒤의 기록을 보관합니다. 기존 풀이를 가져오거나 과거에 없던 값을 채우지 않습니다.

아래 표는 AI 비전 개론의 수집 항목입니다.

| 기록 | 포함하는 내용 |
|---|---|
| 연습 묶음 | 모드, 실제 선택한 문항 목록, 묶음 생성 시드, 규칙 판 |
| 연습 문항 | 서비스가 처음 반환한 지문, 빈칸 형식, 보기 순서, 문항 판, 개념 태그 |
| 연습 답 | 맞힌 답을 포함한 입력값, 채점 결과, 응답 시간, 확신 여부, 묶음 안 첫 답인지 여부 |
| 다시 풀기 | 묶음 안 재시도, 모르겠어요, 내 답도 맞음 처리의 별도 기록 |
| 학습 활동 | 읽기, 다시 보기, 짐작, 떠올리기, 세 단계 확인 물음, 돌려 가며 빈칸 |
| 모의고사 | 시작, 서비스가 반환한 문항, 최종 제출한 답과 문항별 판정, 회차 소요 시간, 자동 제출 여부 |
| 희망 직무 | 직접 고른 목표 또는 미선택, 선택 시각·선택 번호, 당시 로드맵 내용의 SHA-256과 갱신일 |

[학습 데이터]에서 수집에 동의한 뒤 희망 직무를 고르고 [희망 직무 저장]을 누릅니다. 로드맵의 여섯 직무 중 하나를 고르거나 미선택으로 저장할 수 있습니다. 선택은 본인이 밝힌 진로 목표이며 능력 등급이나 직무 적합도 판정에 쓰지 않습니다. 선택하지 않아도 수집과 학습을 계속할 수 있습니다.

각 이벤트의 `data.goal`에 그때 저장한 목표와 로드맵 판을 복사합니다. 직무나 로드맵이 바뀌어도 과거 답을 다시 분류하지 않습니다. 같은 직무를 다시 저장하면 그때의 로드맵 판과 새 선택 번호를 기록합니다. 수집 중단과 재동의 때는 현재 목표를 미선택으로 초기화합니다. 이전 선택을 다시 적용하려면 직접 저장해야 합니다. 이 기능 이전의 기록에는 목표를 채워 넣지 않습니다.

로드맵 판은 JSON의 키 순서·들여쓰기·줄 끝을 정규화한 내용으로 계산합니다. Windows와 macOS에서 줄 끝만 달라졌을 때 같은 판의 풀이가 서로 다른 집단으로 나뉘지 않게 합니다.

학습 활동의 입력 답은 화면에서 채점·저장한 경우에 남습니다. 읽기 전용 노트의 확인 물음은 수집하지 않습니다. 짐작은 정오답으로 채점하지 않으며 모델 학습의 정답 자료로 바로 쓰지 않습니다. 연습의 해설은 채점 뒤 반환했다는 사실을 남깁니다. 실제로 읽었는지, 주의를 기울였는지까지 측정하지 않습니다.

서비스의 문항 반환 기록은 재조회·화면 복원 때문에 같은 문항을 중복 집계하지 않습니다. 실제 화면 노출 횟수와 시선 기록을 의미하지 않습니다. 연습 시간은 현재 앱이 전달한 초 단위 값이며 순수 집중 시간을 보장하지 않습니다. 모의고사에는 문항별 응답 시간을 새로 추정하지 않습니다. 시험 도중 수정하는 모든 글자도 수집하지 않습니다. 수집 동의 전에 입력한 모의고사 초안은 이후 제출하더라도 추가 답안으로 복사하지 않습니다. 중단 뒤 다시 동의한 경우에도 이전 동의 기간의 입력값을 가져오지 않습니다.

기록에는 고유번호와 순서를 붙입니다. 문항 판 해시는 지문·채점 조건·보기 순서·생성 시드·관련 실행 코드 판과 허용 답 사전 판을 포함합니다. 지문과 보기 스냅샷에는 채점용 정답표를 넣지 않습니다. 저장 시각에는 시간대를 포함하고, 기존 학습 기록의 시각은 `source_at`에 따로 보관합니다.

추가 파일은 `~/.rokey-study/ai/<내 ID>/learning-data.sqlite3`에 있습니다. `STUDY_AI_HOME`을 지정했다면 그 폴더를 따릅니다. 공개 저장소 안의 경로에는 새로 수집할 수 없습니다. 기존 `submissions/<내 ID>/ai/record.json`과 진도·복습 계산은 바꾸지 않습니다.

추가 저장에 실패해도 기존 학습은 계속할 수 있습니다. 관리 화면과 과목 홈에서 실패를 알립니다. 실패한 구간의 입력값을 과거 제출 기록으로 추정해 복원하지 않습니다. 파일·잠금·저장 공간 문제를 해결한 뒤 다시 확인해 주세요.

## 파이썬 입력과 채점을 보관합니다

파이썬 수집은 AI 개론과 별도로 동의합니다. `~/.rokey-study/python/<내 ID>/learning-data.sqlite3`에 저장하며 `STUDY_PYTHON_HOME`으로 위치를 바꿀 수 있습니다. 기존 `profile.json`, `quiz.py`, 코드 답안과 GitHub 제출은 유지합니다.

수집 중 프로그램에서 실제로 바꿔 저장한 퀴즈·코드 입력, 입력 당시 목표와 시각, 문항·채점 조건의 판, 채점 결과와 재시도를 보관합니다. 화면에 실제 선택한 문항만 표시 기록을 남기며 회차 전체를 읽었다고 처리하지 않습니다. 같은 입력을 그대로 저장하거나 채점을 반복한 경우에는 답 기록을 늘리지 않습니다. 시작 코드와 빈 답은 오답 학습 자료로 만들지 않습니다.

동의 전에 저장한 답, 이전 동의 기간의 답, 외부 편집기에서 바꿔 일치하지 않는 답은 새 답 기록으로 가져오지 않습니다. 채점 중 입력이 바뀌어도 이전 판정을 새 입력에 붙이지 않습니다. 외부 편집기의 입력 시각·읽은 시간·응답 시간·확신은 추정하지 않습니다. 기존 기록을 활용할 때는 [공통 학습 자료 준비](LEARNING_STARTER.md) 도구에서 소유자의 동의를 별도로 확인합니다.

## 중단하거나 파일로 내보냅니다

[수집 중단]은 이후의 추가 저장을 멈춥니다. 이미 모은 기록은 삭제하기 전까지 남습니다. [파일로 내보내기]는 JSONL 파일을 만들고 다시 읽어 확인합니다. 기본은 입력 답안 제외이며, [내보낼 때 입력 답안 포함]을 선택하면 입력값도 들어갑니다. 기존 파일을 덮어쓰거나 공개 저장소 안에 내보내지 않습니다.

가명 구분값은 이 기기의 추가 데이터마다 생성합니다. GitHub ID와 이름을 내보내기 항목에 넣지 않지만 가명 자료를 완전한 익명 자료로 취급하지 않습니다. 입력 답안에 개인정보를 적었다면 답안 포함 내보내기·전송 전에 확인해 주세요.

[추가 데이터 삭제]는 이 기기의 추가 수집 파일을 지우고 수집을 중단합니다. 기존 진도와 제출 기록, 이미 내보낸 파일, 서버에 보낸 기록은 남습니다. 서버 삭제에 필요한 연결 인증도 남깁니다. 다시 수집을 시작하면 새 가명 구분값을 만듭니다.

터미널에서도 관리할 수 있습니다.

```sh
python study.py ai-data status
python study.py ai-data enable --agree
python study.py ai-data disable
python study.py ai-data export --out /저장소밖경로/learning-data.jsonl
python study.py ai-data delete --agree
python study.py python-data status
python study.py python-data enable --agree
python study.py python-data export --out /저장소밖경로/python-learning-data.jsonl
```

다른 ID는 `--user <ID>`로 지정합니다. 입력 답안까지 내보낼 때만 `--include-answers`를 붙입니다. Windows에서는 `C:\Users\내이름\Downloads\learning-data.jsonl`처럼 실제 경로를 지정합니다.

## 수집 서버에 보냅니다

운영자가 발급한 개인 초대 코드와 HTTPS 서버 주소가 필요합니다. [동의하고 서버에 보내기]를 누를 때만 전송합니다. 자동 전송이나 모델 학습은 실행하지 않습니다. 수집 동의와 서버 전송 동의는 별개입니다. 입력 답안 전송은 기본으로 꺼져 있습니다.

인증 값은 같은 로컬 폴더의 `learning-data-sharing.json`에 보관하며 GitHub 제출·데이터 내보내기에 포함하지 않습니다. 운영체제 계정의 파일 접근 권한으로 보호하며 별도로 암호화한 파일은 아닙니다. 인증 값과 초대 코드는 공유 문서·공개 이슈·화면 캡처에 넣지 마세요.

서버가 저장 확인을 보내면 마지막 전송 순서를 보관합니다. 응답이 끊기면 다음 전송에서 다시 보내며, 서버는 같은 고유번호의 같은 기록을 한 번만 저장합니다. 같은 번호의 내용이 달라지면 덮어쓰지 않고 요청을 거절합니다. 전송 후에는 입력 답안 포함 설정을 바꾸지 않습니다. 바꾸려면 기존 서버 데이터를 삭제하고 새로 등록합니다.

[서버의 내 풀이 삭제]는 서버의 해당 가명 참가자 풀이를 지우고 업로드 인증을 폐기합니다. 중복 전송을 막기 위한 최소 등록·철회 정보는 남습니다. 학습용으로 이미 내보낸 파일과 백업의 삭제는 운영자에게 요청해야 합니다. 재참여할 때는 로컬 추가 데이터도 삭제한 뒤 새 초대 코드를 받습니다.

앱과 서버는 `ai`와 `python`을 별도 과목으로 다룹니다. 파이썬의 기존 기록을 자동으로 업로드하지 않습니다. 서버 배포 운영과 데이터 준비는 WaterMinCho가 맡으며 팀원 딥러닝 미션에 넘기지 않습니다.

서버 설치와 수강생 확대는 [수집 서버 운영](LEARNING_SERVER.md), 프로그램 담당과 세 팀원의 개발 분담은 [딥러닝 미션](LEARNING_MISSIONS.md)을 참고하세요.
