# 제목과 설명 사이를 띄웁니다

세로 간격은 `gui/theme.py`의 `GAP`에서 고릅니다. 같은 제목과 설명은 `kit.heading()`으로 묶습니다. 설명을 숨기면 그 자리에 간격도 남기지 않습니다.

| 이어지는 요소 | 간격 | 적용 위치 |
|---|---:|---|
| 목록 제목과 짧은 보조 설명 | 8px | 단원·문항 목록, 다음 행동 카드의 분류 이름 |
| 제목과 그 제목을 설명하는 글 | 12px | 과목 소개, 구역 소개, 카드, 대화상자, 노트 제목 |
| 본문 문단 | 16px | 노트와 해설의 문단 |
| 설명과 다음 목록·입력 영역 | 24px | 과목 홈의 목록, 대화상자의 입력 영역 |
| 카드 안의 내용 묶음 | 24px | 지표, 소개 글, 기술 목록 |
| 서로 다른 구역 | 48px | 과목 홈과 학습 현황 |

보통 글자에서 제목은 28px에 줄 높이 36px, 본문은 17px에 줄 높이 28px입니다. 가장 큰 글자는 본문 21px에 줄 높이 36px입니다. 제목과 설명 사이는 12px를 유지합니다. 줄바꿈한 글의 높이를 먼저 확보하고 다음 내용을 24px 띄웁니다. 두 줄 목록은 최소 80px를 확보합니다. 설명이 여러 줄이면 목록 높이도 늘어납니다.

화면 설정의 글자 크기 선택 단추 셋은 같은 글꼴·크기·굵기·높이로 표시합니다. 폭은 가장 긴 단추 글자에 맞춥니다. 크기를 줄였다가 키우거나 설정을 다시 열어도 같은 기준을 적용합니다. 선택한 항목은 배경색으로 구분합니다.

기본 목록·체크박스에도 공통 글꼴 역할을 지정합니다. 화면 설정을 바꾸면 목록의 선택과 입력을 유지하며 같은 역할의 글자가 함께 커지고 작아집니다. 긴 목록 제목은 툴팁에서도 전체 내용을 확인할 수 있게 합니다.

행간을 대조할 때는 같은 글꼴·크기·아이콘을 쓴 기본 목록과 비교합니다. 실제 캡처에서도 두 글줄 사이의 간격을 확인합니다.

가로 도구 모음과 선택지 사이에는 내용에 맞는 간격을 씁니다. 제목·설명 규칙을 모든 배치 숫자에 적용하지 않습니다. 오답 결과처럼 한 문단이 표의 한 줄을 대신하는 곳은 기존 문단 간격을 유지합니다.

그림 넘김 단추는 글자에 필요한 폭을 유지합니다. 한 줄에 들어가지 않으면 다음 줄로 넘깁니다. 카운터는 가장 긴 장 번호의 폭을 확보합니다. 재생 단추는 재생·멈춤 문구 중 넓은 쪽에 맞춥니다. 크게 보기는 넘김 줄에 자리가 있을 때 함께 놓고, 공간이 부족하면 그림 설명 아래에 놓습니다. 장을 바꿔도 넘김 단추의 위치는 유지합니다.

화면을 바꾸면 offscreen에서 실제 창 크기 760×480, 1024×700, 1280×800을 확인합니다. 가장 큰 글자와 밝은·어두운 테마에서 제목·설명 간격, 줄바꿈, 단추의 글자 폭을 확인합니다. 제출 안내를 갱신할 때 입력 내용·선택 영역·초점·스크롤 위치도 대조합니다.

Windows 창 검사는 `QT_QPA_PLATFORM=windows`에서 별도로 수행합니다. 요청한 창 크기와 실제 크기, 화면의 작업 영역, 글자 크기와 배율을 기록합니다. 실행 환경의 화면이 작아 창 크기를 줄인 결과를 프로그램의 배치 실패로 판정하지 않습니다. 배율을 바꿔 확인할 때 `QT_SCALE_FACTOR`로 시험한 값과 Windows의 표시 설정을 구분합니다.

창이 작은 경우에는 스크롤로 각 단추를 보이게 한 뒤 글자와 클릭 영역 전체가 들어오는지 확인합니다. Windows가 그린 창의 캡처와 위젯 캡처도 대조합니다. 운영체제·Qt 버전·테마·실제 창 크기를 함께 남기며 호스팅 실행 환경의 확인 결과를 사용자 기기의 검증으로 확대하지 않습니다.

빈 화면과 기록이 쌓인 화면을 모두 확인합니다. 그래프의 권장 너비를 작은 창의 최소 너비로 강제하지 않습니다. 나란한 카드가 들어가지 않으면 세로로 배치하고, 창을 넓히면 다시 나란히 놓습니다. 화면 첫 진입과 왕복, 글자 확대 뒤 축소에서도 가용 폭을 다시 계산합니다.

## 학습 본문을 넉넉하게 읽습니다

AI 비전 개론의 설명·보기·입력에는 메뉴보다 큰 읽기용 글자를 씁니다. 보통은 22px·줄 높이 40px, 기본 설정인 크게는 24px·44px, 더 크게는 26px·48px입니다. 학습 제목은 30~34px, 활동 제목은 24~28px입니다. 코드도 20~24px와 줄 높이 32~40px로 키웁니다. 그림 캡션은 18~22px이며 그림 속 글자도 본문 크기에 맞춰 함께 확대합니다.

학습 본문과 연습 문항의 읽기 너비는 1200px에서 시작하고 큰 창에서는 1600px까지 넓어집니다. 작은 창에서는 실제 가용 폭을 따릅니다. 카드 안쪽은 32px, 문단 사이는 24px, 단계 안의 서로 다른 글·그림·물음 묶음 사이는 48px를 둡니다. 제목과 바로 아래 설명 사이는 학습 화면에서 16px입니다. 이 학습 범위의 값은 위의 일반 화면 간격과 구분합니다.

전체 노트·노트 보기·세 수준 설명에도 같은 글자와 문단 기준을 적용합니다. 그림이 커져 한 화면에 다 들어오지 않으면 스크롤로 그림과 조작부에 각각 접근할 수 있게 합니다. 그림 비율과 코드 글자 크기는 유지하고, 긴 코드는 줄바꿈이나 가로 스크롤로 끝까지 볼 수 있게 합니다.

## 창의 가로 공간을 사용합니다

왼쪽 과목 메뉴의 아이콘은 같은 크기와 열에 놓고, 메뉴 이름과 구역 이름은 같은 세로선에서 시작합니다. 선택 표시는 배경과 왼쪽 선으로 함께 제공합니다. 글자와 아이콘을 따로 가운데 정렬하되 단추의 클릭 영역은 한 덩어리로 유지합니다. 좁은 창의 과목 선택란은 같은 순서와 현재 선택을 유지합니다.

첫 화면과 과목 홈은 1600px까지 넓어집니다. 웹 학습과 연습 카드도 창의 남는 폭을 사용합니다. 편집기 옆의 설명은 편집기와 나란히 놓인 칸의 가용 폭을 따르며 본문 글자가 커지면 읽기 폭의 상한도 늘어납니다. 작은 창에서 이 수치를 최소 폭으로 강제하지 않습니다.

여러 열 표의 항목을 온전히 읽을 폭이 부족하면 열별 설명으로 바꿉니다. 열 제목 아래에 원래 첫 열의 항목 이름과 해당 값을 함께 표시합니다. 창을 넓히면 원래 비교 표로 돌아옵니다. 글자 크기와 값의 관계는 유지합니다.

## 학습 활동과 그림 조작을 구분합니다

떠올리기와 왜일까요는 32px 안쪽 여백과 24px 간격을 가진 활동 영역으로 묶습니다. 제목은 `learn_activity`로 표시합니다. 라벨·라디오 버튼·체크박스는 본문의 전체 높이 대신 첫 글줄의 중심에 맞춥니다. 인라인 강조는 글꼴 크기·줄 높이·기준선을 바꾸지 않습니다.

같은 줄에 놓인 숫자와 설명은 글자 기준선을 맞춥니다. 체크 항목 오른쪽의 시간·메모도 첫 글줄을 따릅니다. 제목과 설명을 함께 표시하는 목록의 상태 점은 두 줄 묶음의 가운데에 둡니다. 이 배치는 첫 글줄에 맞추는 문항 표시와 구분합니다.

그림 넘김 줄과 하단 도구는 각 줄 안에서 세로 가운데를 맞춥니다. 줄이 바뀌면 새 줄의 높이를 따로 계산합니다. 입력 칸은 초점·정답·오답 테두리가 두꺼워져도 바깥 높이를 유지합니다. 글자 크기를 바꾼 뒤에도 같은 기준으로 다시 배치합니다.

정렬 검사는 위젯 상자의 좌표와 캡처에 그려진 첫 글줄을 함께 대조합니다. 짧은 글과 여러 줄 글, 표시가 숨겨진 상태, 글자 크기 전환을 확인합니다. 가는 숫자 획을 빈 줄로 오인하지 않는지도 대조합니다. 숨겨진 입력부의 배치가 다른 화면의 최소 크기를 늘리지 않게 합니다.

그림 넘김은 별도 테두리 영역에 두고 재생은 강조 테두리와 글자색으로 구분합니다. 학습 단계의 다음·채점 행동을 화면의 주 버튼으로 유지합니다. 한 장 그림에는 재생 조작을 보이지 않습니다. 학습 그림은 가로세로 비율을 유지하며 글자 설정에 따라 커집니다. 가장 큰 글자에서 본문 폭까지 넓히되 원본 폭의 1.5배를 상한으로 둡니다. 원본보다 크게 그린 결과의 글자도 확인합니다.

GIF 조작부의 제목·장 번호·이전 장·다음 장·크게 보기는 같은 글자 크기를 씁니다. 같은 줄의 단추 높이도 맞추고 줄이 바뀌면 그 줄 안에서 정렬합니다. 조작부 높이는 실제 줄 수에 맞춥니다. 재생은 삼각형, 일시 정지는 두 막대 아이콘으로 표시합니다. 아이콘 단추에는 현재 할 동작을 툴팁과 접근성 이름으로 제공하며 키보드 조작과 두 테마의 색을 확인합니다.

하단 알림은 제출할 변경이나 받을 자료가 있을 때만 띄웁니다. 내용 끝에는 상태와 무관한 스크롤 여백을 두어 알림의 출현·소멸로 읽던 위치가 바뀌지 않게 합니다. 키보드로 내용 안의 동작에 초점을 옮기면 알림 위까지 보이게 합니다.

알림의 줄바꿈은 실제 문장과 단추에 필요한 폭으로 정합니다. 한 줄에 들어가는 알림을 창 너비만으로 두 줄로 나누지 않습니다. 배경 전송 상태를 갱신할 때는 편집 중인 희망 직무·입력·선택 항목을 다시 채우지 않습니다.

Windows에서 학습 그림을 확인할 때는 본문과 확대창을 따로 봅니다. 확대창의 가로·세로 스크롤을 양끝까지 옮겨 원본 끝부분에 닿는지 확인하고, 크게 보기·닫기·단계 이동 단추를 실제로 누릅니다. 원본 그림의 비율과 적용된 최대 글자 크기, 실제 창 크기를 함께 기록합니다.

AI의 개론·응용 전환은 같은 홈의 탭으로 구분합니다. 과정 제목과 설명을 탭 아래에 두고 학습 목록·문제집·다음 행동을 선택한 과정으로 맞춥니다. 같은 차시 번호에는 과정 이름을 붙이고 마지막으로 선택한 과정을 보존합니다.

심화 팝업은 화면 안에 들어오는 크기로 열고 긴 내용은 내부에서 스크롤합니다. 닫기는 본문 밖에 두어 항상 도달할 수 있게 합니다. 원래 단계와 읽던 위치·입력은 유지합니다. 새 부품은 부모 레이아웃에 붙인 뒤 표시 상태를 반영해 별도 창이나 초점 이동이 생기지 않게 합니다.

팝업을 다시 열 때도 현재 부모 창과 모니터의 작업 영역에 크기·위치를 맞춥니다. Esc로 닫은 뒤 열었던 단추로 초점을 돌립니다. GIF의 재생을 예약한 뒤 화면 밖으로 나가면 실제로 보일 때까지 기다립니다. 예약 이후 움직임 줄이기를 켜도 재생을 시작하지 않습니다.

선택형 연구 참여는 사용 목적을 설명하고 프로그램 이용에 필수인 약관처럼 부르지 않습니다. 동의 항목은 짧게 쓰되 보관 위치를 항목 가까이에 표시합니다. 전송 항목·사용 목적·보관 기간·철회 방법은 본문에서 확인할 수 있게 합니다.

첫 화면의 AI 활동 그래프와 최근 채점에는 개론·응용 기록을 함께 표시합니다. 진도·복습·오답과 이어갈 위치는 선택한 과정으로 유지하고 과정 이름을 붙입니다. 단원 읽기도 포함한 합계는 `기록된 활동`으로 표시합니다.

## 검토 근거를 기록합니다

2026년 11월 11일 [Qt의 배치 정렬 설명](https://doc.qt.io/qt-6/qboxlayout.html#addWidget)과 [글꼴 측정 문서](https://doc.qt.io/qt-6/qfontmetricsf.html)를 대조했습니다. 상자의 아랫변 정렬과 글자의 기준선 정렬을 구분하고, 측정한 글꼴 값은 실제 캡처와 비교합니다.

2026년 11월 11일 [W3C의 모달 대화상자 지침](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)과 [Qt QDialog 문서](https://doc.qt.io/qt-6/qdialog.html)를 대조했습니다. 열기·닫기·키보드 초점의 기대 동작을 네이티브 창에서 확인하며, 웹용 속성을 Qt 위젯에 그대로 적용하지 않습니다. 자동 재생의 멈춤·수동 조작은 [W3C의 움직이는 내용 제어 설명](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide.html)을 참고합니다.

[Mayer의 멀티미디어 학습 연구 요약][mayer]을 참고해 관련 그림과 설명을 가까이 두고 학습자가 장면을 멈추거나 다시 보는 길을 유지합니다. 빠르고 복잡한 설명과 학습자의 사전 지식에 따라 적용 조건이 달라집니다. 현재 그림의 속도나 배치만으로 이해·기억 향상을 확인했다고 쓰지 않습니다.

화면 문구는 [토스의 라이팅 운영 사례](https://toss.tech/article/1st_uxwriter)와 [NHS의 글쓰기 지침](https://service-manual.nhs.uk/content/how-we-write)을 참고합니다. 반복해서 쓸 기준을 문서·검사기에 반영하고, 추상적인 평가 대신 실제 동작과 집계 대상을 씁니다. 낯선 용어는 먼저 설명하며 한국어 문맥은 별도로 읽어 확인합니다.
