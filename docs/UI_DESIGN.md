# 제목과 설명 사이를 띄웁니다

세로 간격은 `gui/theme.py`의 `GAP`에서 고릅니다. 같은 제목과 설명은 `kit.heading()`으로 묶습니다. 설명을 숨기면 그 자리에 간격도 남기지 않습니다.

| 이어지는 요소 | 간격 | 적용 위치 |
|---|---:|---|
| 목록 제목과 짧은 보조 설명 | 8px | 단원·문항 목록, 다음 행동 카드의 분류 이름 |
| 제목과 그 제목을 설명하는 글 | 12px | 과목 소개, 구역 소개, 카드, 대화상자, 노트 제목 |
| 본문 문단 | 16px | 노트와 해설의 문단 |
| 설명과 다음 목록·입력 영역 | 24px | 과목 홈의 목록, 대화상자의 입력 영역 |
| 카드 안의 내용 묶음 | 24px | 지표, 소개 글, 기술 목록 |
| 서로 다른 구역 | 48px | 과목 홈과 학습 현황 |

보통 글자에서 제목은 28px에 줄 높이 36px, 본문은 17px에 줄 높이 28px입니다. 가장 큰 글자는 본문 21px에 줄 높이 36px입니다. 제목과 설명 사이는 12px를 유지합니다. 줄바꿈한 글의 높이를 먼저 확보하고 다음 내용을 24px 띄웁니다. 두 줄 목록은 최소 80px를 확보합니다. 설명이 여러 줄이면 목록 높이도 늘어납니다.

가로 도구 모음과 선택지 사이에는 내용에 맞는 간격을 씁니다. 제목·설명 규칙을 모든 배치 숫자에 적용하지 않습니다. 오답 결과처럼 한 문단이 표의 한 줄을 대신하는 곳은 기존 문단 간격을 유지합니다.

그림 넘김 단추는 글자에 필요한 폭을 유지합니다. 한 줄에 들어가지 않으면 다음 줄로 넘깁니다. 카운터는 가장 긴 장 번호의 폭을 확보합니다. 재생 단추는 재생·멈춤 문구 중 넓은 쪽에 맞춥니다. 크게 보기는 넘김 줄에 자리가 있을 때 함께 놓고, 공간이 부족하면 그림 설명 아래에 놓습니다. 장을 바꿔도 넘김 단추의 위치는 유지합니다.

화면을 바꾸면 offscreen에서 실제 창 크기 760×480, 1024×700, 1280×800을 확인합니다. 가장 큰 글자와 밝은·어두운 테마에서 제목·설명 간격, 줄바꿈, 단추의 글자 폭을 확인합니다. 제출 안내를 갱신할 때 입력 내용·선택 영역·초점·스크롤 위치도 대조합니다.

Windows 창 검사는 `QT_QPA_PLATFORM=windows`에서 별도로 수행합니다. 요청한 창 크기와 실제 크기, 화면의 작업 영역, 글자 크기와 배율을 기록합니다. 실행 환경의 화면이 작아 창 크기를 줄인 결과를 프로그램의 배치 실패로 판정하지 않습니다. 배율을 바꿔 확인할 때 `QT_SCALE_FACTOR`로 시험한 값과 Windows의 표시 설정을 구분합니다.

창이 작은 경우에는 스크롤로 각 단추를 보이게 한 뒤 글자와 클릭 영역 전체가 들어오는지 확인합니다. Windows가 그린 창의 캡처와 위젯 캡처도 대조합니다. 운영체제·Qt 판·테마·실제 창 크기를 함께 남기며 호스팅 실행 환경의 확인 결과를 사용자 기기의 검증으로 확대하지 않습니다.

## 학습 본문을 넉넉하게 읽습니다

AI 비전 개론의 설명·보기·입력에는 메뉴보다 큰 읽기용 글자를 씁니다. 보통은 20px·줄 높이 36px, 기본 설정인 크게는 22px·40px, 더 크게는 24px·44px입니다. 코드도 18~22px와 줄 높이 30~36px로 키웁니다. 그림 캡션은 16~20px이며 그림 속 글자도 본문 크기에 맞춰 함께 확대합니다.

학습 본문과 연습 문항의 읽기 너비는 1200px에서 시작하고 큰 창에서는 1600px까지 넓어집니다. 작은 창에서는 실제 가용 폭을 따릅니다. 카드 안쪽은 32px, 문단 사이는 24px, 단계 안의 서로 다른 글·그림·물음 묶음 사이는 48px를 둡니다. 제목과 바로 아래 설명 사이는 학습 화면에서 16px입니다. 이 학습 범위의 값은 위의 일반 화면 간격과 구분합니다.

전체 노트·노트 보기·세 수준 설명에도 같은 글자와 문단 기준을 적용합니다. 그림이 커져 한 화면에 다 들어오지 않으면 스크롤로 그림과 조작부에 각각 접근할 수 있게 합니다. 그림 비율과 코드 글자 크기는 유지하고, 긴 코드는 줄바꿈이나 가로 스크롤로 끝까지 볼 수 있게 합니다.

## 창의 가로 공간을 사용합니다

첫 화면과 과목 홈은 1600px까지 넓어집니다. 웹 학습과 연습 카드도 창의 남는 폭을 사용합니다. 편집기 옆의 설명은 편집기와 나란히 놓인 칸의 가용 폭을 따르며 본문 글자가 커지면 읽기 폭의 상한도 늘어납니다. 작은 창에서 이 수치를 최소 폭으로 강제하지 않습니다.

여러 열 표의 항목을 온전히 읽을 폭이 부족하면 열별 설명으로 바꿉니다. 열 제목 아래에 원래 첫 열의 항목 이름과 해당 값을 함께 표시합니다. 창을 넓히면 원래 비교 표로 돌아옵니다. 글자 크기와 값의 관계는 유지합니다.
