# 수집 범위와 전체 배포 조건을 확인합니다

일반 수강생 배포는 [첫 실행 동의·비공개 자동 전송](LEARNING_PRIVACY.md)과 [별도 비공개 파일 제출](API_SUBMISSIONS.md)을 사용합니다. 개인 초대 파일은 기본 배포에 필요하지 않습니다. 이 문서의 초대 발급 절차는 운영자용 시범 방식입니다.

[풀이 데이터 안내](LEARNING_DATA.md) · [서버 운영](LEARNING_SERVER.md) · [시범 운영](LEARNING_PILOT.md)

수집 대상은 파이썬과 AI 개론·응용입니다. 현재 기록으로 정오답 예측 실습을 시작할 수 있지만, 추천 효과를 평가하는 데 필요한 정보가 모두 준비된 상태는 아닙니다. 이름·이메일을 모델 입력에 더하는 방식으로 해결하지 않습니다.

## 이미 보관하는 기록과 연결할 기록을 구분합니다

| 알고 싶은 내용 | 현재 기록과 남은 조건 |
|---|---|
| 어떤 문제를 어떻게 풀었나요? | 가명·과목·과정·문항 판·개념·순서·정오답·재시도를 보관합니다. 입력 답안 본문은 기본 서버 전송에서 제외합니다. |
| 답하기 전에 무엇을 알고 있었나요? | 파이썬은 관찰한 예측 시각을 사용합니다. AI는 같은 문항 판·풀이 위치의 반환 시각을 연결합니다. 없는 시각을 추정하지 않습니다. |
| 왜 이 문제를 받았나요? | AI 연습의 실제 후보 묶음·예비 후보·선정 목록·규칙 판·시드를 보관합니다. 파이썬의 전체 후보 목록은 아직 기록하지 않습니다. |
| 추천이 학습에 도움이 됐나요? | 아직 추천 모델을 앱에 연결하지 않았습니다. 연결할 때 실제 후보·정책/모델 판·선정 시각과 고유번호·실제 선택 확률을 남기고 이후 복습 결과와 연결합니다. |
| 같은 사람이 다른 PC에서도 풀었나요? | 기기별 가명을 자동으로 합치지 않습니다. AI와 파이썬도 별도 가명입니다. 과목을 합친 개인별 분석은 별도 연결 절차가 생기기 전에는 하지 않습니다. |
| 모르는 값은 어떻게 처리하나요? | 시각·응답 시간·확신·후보 확률의 미확인을 0으로 바꾸지 않습니다. 현재 공통 입력 판은 4이며 이전 자료를 덮어쓰지 않습니다. |

문항의 고유번호와 정확한 제시 판을 함께 보관합니다. 실행 코드나 보기 순서가 바뀌면 같은 문제 번호의 판도 바뀔 수 있습니다. 모델 번호표를 만들 때 서로 다른 판을 자동으로 합치거나 평가 자료의 새 문항을 학습에서 본 것으로 처리하지 않습니다.

모델 연결 때는 선택한 문제만 기록하지 않습니다. 실제로 고를 수 있었던 후보와 선정 규칙도 함께 남깁니다. 정답 가능성 80%와 그 문제를 뽑을 확률 80%는 서로 다른 값입니다. 선택 확률을 모르면 후보 수의 역수로 채우지 않습니다. 추천 뒤 맞혔다는 사실만으로 추천의 학습 효과를 단정하지 않습니다. 날짜를 띄운 복습과 비교 조건을 따로 정합니다.

## 참가자는 첫 실행에서 수집 여부를 선택합니다

일반 수강생은 clone한 뒤 start 파일을 실행하고 동의 여부를 선택합니다. 동의하면 새 기록을 기본 서버에 비공개로 자동 전송합니다. 회원가입·개인 초대·서버 관리 계정은 필요하지 않습니다. 모델 실습에는 별도로 준비한 같은 판의 비공개 자료를 사용하며 운영 DB·인증 키에 접근하지 않습니다.

실제 참가자 사용은 동의 선택·등록·전송·같은 기록 재전송·철회·오류 후 재시도를 각자의 PC에서 확인합니다. 운영자의 합성 시험과 구분하며 앱을 설치한 사람 수를 서버 수집 참가자 수로 세지 않습니다.

## 무료 서버의 운영 한계를 확인합니다

2026년 11월 12일 확인한 PythonAnywhere 무료 계정은 저장 공간 512MiB, 웹 워커 1개이며 한 달마다 운영 기간을 연장합니다. 새 무료 계정에는 예약 작업이 없어 자동 백업을 등록한 상태로 안내하지 않습니다. [공식 무료 계정 기능](https://help.pythonanywhere.com/pages/FreeAccountsFeatures/)과 [SQLite 운영상 제약](https://www.pythonanywhere.com/forums/topic/35474/)을 따릅니다.

같은 날 실제 HTTPS 서버에서 시험 기록 2건의 저장·재전송·삭제와 DB 무결성을 확인했습니다. DB와 인증 키를 백업해 운영자 기기로 내려받고 SHA-256과 새 경로 복구를 확인했습니다. 실제 참가자 계정과 풀이 기록은 0건이며 네 명의 PC에서 사용을 마쳤다는 결과는 아닙니다. 운영 만료일은 관리 화면에서 2026년 12월 11일로 연장했습니다.

로컬 macOS SQLite에서 합성 가명 100개가 8개 작업으로 10,000건을 저장하고 같은 기록 10,000건을 다시 보냈습니다. 중복 없이 10,000건을 보관했고 DB는 약 11.2MiB였습니다. 공개 AI 문항 184개의 스냅샷을 사용한 직접 저장 검사이며 PythonAnywhere HTTP 처리량이나 실제 학생 100명의 사용 결과가 아닙니다.

이 표본 비율로 100명이 하루 30문제를 30일 풀고 문제당 반환·답 기록만 2건씩 남긴다고 가정하면 DB는 약 202MiB입니다. 읽기·선정 후보·파이썬 기록·백업·코드 갱신에 따른 증가는 제외했습니다. DB 사본을 같은 호스팅에 누적하면 무료 용량을 빠르게 소모할 수 있습니다. 이 계산을 보존 가능 기간이나 최대 참가자 수로 사용하지 않습니다.

| 확대 전 확인 | 완료를 판단하는 방법 |
|---|---|
| 네 명의 실제 사용 | 각 PC의 저장 건수와 서버 수신·재시도 결과를 대조합니다. 합성 계정과 구분합니다. |
| 외부 저장 사본 | DB와 인증 키를 함께 백업하고 운영자 기기에서 해시·새 경로 복구를 확인합니다. 삭제·철회 요청도 복구 전에 반영합니다. |
| 용량과 장애 대응 | 실제 하루 증가량·전송 실패·잠금 발생을 확인합니다. DB·백업·내보내기·배포 파일을 합쳐 계산합니다. |
| 지속 운영용 저장소 | 실제 증가량과 오류를 보고 네트워크 파일 시스템의 SQLite 잠금 문제·예약 백업 부재를 해결할 운영 환경을 정합니다. |

전송 실패 때는 로컬 기록을 보존하고 다음 요청에서 다시 보냅니다. 앱 삭제·기기 고장 전에 서버로 보내지 않은 기록까지 복구할 수 있다는 뜻은 아닙니다.
