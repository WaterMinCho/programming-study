# Git 사용 안내 · 프로그램 설치와 모델 개발

<a id="git-사용-목적에-맞는-안내를-고릅니다"></a>

[학습 시작](LEARNER_START.md) · [스터디 개발 시작](STUDY_START.md)

일반 수강생은 프로그램과 새 문제를 받을 때 Git을 사용합니다. 새 기기에서 프로그램을 처음 열 때 GitHub 계정으로 [본인 확인](DEVICE_IDENTITY.md)을 합니다. 풀이 파일은 비공개 서버로 보내므로 공통 저장소의 쓰기 권한이나 풀이 PR은 필요하지 않습니다.

- [SourceTree 또는 터미널로 프로그램 받기](../gui/README.md#처음-설치할-때)
- [새 자료 받기](../gui/README.md#프로그램과-문제-업데이트)
- [비공개 풀이 제출과 실패 후 재시도](API_SUBMISSIONS.md)

모델 개발 스터디원은 본인 계정으로 공통 프로젝트를 fork한 뒤 작업 브랜치에서 코드를 만듭니다. 본인 폴더의 코드·설명을 Stage → Commit → Push하고 공통 main으로 개발 PR을 보냅니다.

- [fork에서 첫 PR까지 SourceTree·터미널 안내](LEARNING_WORKFLOW.md)
- [PR 제목·본문·검사 규칙](PR_GUIDE.md)
- [코드 검토와 피드백 반영](LEARNING_REVIEW.md)

GitHub 권한 오류는 모델 개발용 fork의 원격 주소와 로그인 계정을 확인합니다. 일반 수강생의 서버 제출 실패는 위의 비공개 제출 안내를 따릅니다.
