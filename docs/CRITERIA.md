# 평가·선별 기준

맞춤 학습 엔진(`adaptive.py`)이 사람마다 다음 회차를 어떻게 정하는지, 무엇을 근거로 "숙달"이라고 판정하는지 정리합니다.
숫자는 모두 상수로 두어 운영하면서 바꿀 수 있습니다.

## 1. 단위

- **단원** = 차시 세트(`s01`~`s16`). 새 차시가 추가되면 자동으로 단원이 됩니다.
- **레벨** = 문항 난이도 1·2·3. Bloom 분류를 단순화한 것으로, 1 = 기억·이해(용어, 기본 문법), 2 = 적용(코드 읽기, 작은 구현), 3 = 분석·종합(함정, 여러 개념 결합).
- **문항 유형** = 퀴즈(객관식·출력 예측·단답)와 코드(빈칸·반환값·출력). 실제 평가 유형과 같습니다.
- **중요도** = 세트 `meta.json` 의 `priority`(기본 1.0). 상속·GUI·예외 처리·정규표현식 단원은 1.5.

## 2. 출발점: 진단 테스트

단원마다 레벨1 퀴즈 2문항(총 32문항). 둘 다 맞히면 그 단원은 레벨2부터, 아니면 레벨1부터 시작합니다.
점수가 아니라 **배치**가 목적이라 짧고 쉬운 문항으로만 구성합니다.

## 3. 숙달 판정 (mastery learning)

레벨마다 **첫 시도** 결과의 최근 4개만 봅니다(고친 뒤 다시 채점한 결과는 연습일 뿐 판정에 쓰지 않습니다).

| 판정 | 조건 |
|---|---|
| 레벨 통과 → 다음 레벨 | 최근 2문항 모두 정답, 또는 최근 4문항 중 3개 이상 정답 |
| 재도전(같은 레벨, 다른 문항) | 최근 3문항 이상에서 정답률 50% 미만 |
| 유지 | 그 사이 |
| 단원 **숙달** | 레벨1·2 통과 |
| 단원 **완료** | 레벨3까지 통과 |

숙달 뒤에도 복습 문항을 틀리면 최근 4개 창이 바뀌어 **다시 "진행 중"으로 내려옵니다**(Khan Academy 의 숙달 도전처럼, 한 번 숙달해도 틀리면 내려갑니다).
어떤 레벨에 문항이 없으면 그 레벨은 건너뜁니다.

## 4. 회차 구성 (interleaving)

매 회차는 **전 단원을 섞은 미니 모의고사**입니다. 단원을 가중 추첨해 문항을 하나씩 뽑습니다.

| 단원 상태 | 추첨 가중치 |
|---|---|
| 미진단 | 3.0 |
| 진행 중 | (4 − 레벨) + (재도전이면 +2) + (1 − 정답률) |
| 숙달 | 0.5 + 0.25 × 안 본 회차 수(최대 4) |
| 완료 | 0.3 + 0.15 × 안 본 회차 수(최대 4) |

- 가중치에 단원 **중요도**를 곱합니다.
- 한 단원이 회차의 1/4 을 넘지 않습니다.
- 코드 문제가 약 40%, 나머지는 퀴즈(실제 평가 비율).
- 문항은 그 단원의 **현재 레벨**에서 안 풀어 본 것 우선. 숙달 단원의 복습은 숙달 단원이 절반을 넘으면 레벨3으로 올립니다.
- 숙달 단원의 가중치가 "안 본 회차 수"에 비례해 커지는 것은 **간격 반복**(Leitner·SM-2 계열) 원리입니다. 오래 안 본 단원일수록 다시 나옵니다.

## 5. 오답 재출제 (spaced retrieval)

첫 시도에 틀렸고 아직 다른 회차에서 맞히지 못한 문항은 **2회차 이상 지난 뒤** 다시 냅니다(회차당 최대 2문항).
틀린 직후 바로 다시 푸는 것보다 간격을 두고 다시 꺼내는 쪽이 기억에 오래 남는다는 인출 연습 연구를 따른 것입니다.

## 6. 문항 수 (필요 기반)

회차 문항 수는 8~18개이며 그 사람의 필요로 정합니다.

- 보강할 단원마다 1.5~2.5문항(재도전 2.5, 레벨1 2.0, 레벨2 1.5), 숙달 단원 0.5, 완료 단원 0.25 를 더해 반올림.
- 직전 회차 득점률이 50% 미만이면 25% 줄이고 12문항을 넘지 않게(짧게 끊어 자주 피드백).
- 90% 이상이면 2문항 더.

## 7. 시험 준비도 (0~100)

단원 준비도의 **중요도 가중 평균**. 현황판과 가이드에 표시됩니다.

| 단원 상태 | 단원 준비도 |
|---|---|
| 완료(레벨3 통과) | 100 |
| 숙달 | 85 |
| 레벨2 진행 | 55 + 25 × 정답률 |
| 레벨1 진행 | 20 + 25 × 정답률 |
| 미진단 | 0 |

## 8. 끝

모든 단원이 숙달되면 실전 모의고사 `m1`, `m2`(각 120분·100점)를 권합니다. 계속하면 심화(레벨3) 회차가 이어지고, 모든 단원이 완료되면 회차 생성이 멈춥니다.

## 9. 아직 넣지 않은 것

- **문항 난이도 보정(IRT·Elo)**: 전원의 첫 시도 결과가 쌓이면 문항별 실제 정답률을 계산해, 흔들리는 사람에게는 쉬운 문항부터, 잘하는 사람에게는 변별력 큰 문항을 먼저 줄 수 있습니다. 지금은 데이터가 없어 레벨(출제자 판단)만 씁니다. `profile.json` 이 PR 로 모이면 바로 계산할 수 있는 구조입니다.
- **확신도 표시**: 답과 함께 확신도를 적게 하는 방식은 실제 평가 형식과 달라 넣지 않았습니다.
