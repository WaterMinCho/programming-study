# 이 기기에서 처음 한 번 본인 확인

모든 학습자는 기기마다 처음 한 번 GitHub 계정을 확인합니다. 이미 학습한 기기에서도 처음 확인할 때 기존 답안과 진도는 유지합니다.

프로그램을 열면 업데이트를 먼저 확인합니다. 처음 인증할 기기에서는 다음 순서로 진행합니다.

1. 프로그램에서 [GitHub에서 확인하기]를 누릅니다.
2. 열린 GitHub 화면에서 본인 계정으로 로그인합니다.
3. 프로그램에 표시된 확인 코드를 입력하고 계정 소유 확인을 마칩니다.
4. 프로그램으로 돌아옵니다. 학습 기록 제공 여부를 아직 정하지 않았다면 이때 선택합니다.

GitHub 확인 코드는 [확인 코드 복사]로 복사할 수 있습니다. 코드가 만료되면 [새 코드 받기]를 누르세요. 다른 계정으로 확인하려면 첫 화면의 [설정]에서 [본인 확인 다시 하기]를 누릅니다.

## 보관하는 정보

이름·이메일·프로필 사진·GitHub 계정 번호 원문·GitHub 토큰은 저장하지 않습니다. 서버는 계정 번호와 서버 비밀키로 계정 확인값(HMAC)을 만들고 확인에 사용한 GitHub 권한을 해제합니다. 로그인 이름이 바뀌어도 계정 번호가 같으면 같은 확인값이 나옵니다.

처음 인증을 마치면 서버가 발급한 기기 키를 이 컴퓨터에 보관합니다. 다음 실행부터는 이 키로 자동 확인합니다. 서버에는 키의 해시만 보관합니다. 새 컴퓨터에서는 GitHub에서 다시 확인합니다. 기기 키를 복사하거나 다른 사람에게 전달하지 마세요.

자동 확인 중 연결이 잠시 끊겨도 이미 받은 문제를 풀고 이 컴퓨터에서 채점할 수 있습니다. 서버가 기기 키를 거부하거나(401 또는 403) 기기에 저장한 인증 정보를 읽을 수 없으면 GitHub에서 다시 확인합니다.

계정 확인값은 연구 참가자의 가명 ID나 풀이 데이터와 연결하지 않습니다. [연구용 학습 기록 제공](LEARNING_PRIVACY.md)은 별도로 선택하며, 동의하지 않아도 학습과 로컬 채점을 이용할 수 있습니다.

## 스터디원의 수집 통계

본인 확인된 기기가 스터디원으로 확인되면 [학습 현황]에 수집 통계를 표시합니다. 제목 옆의 날짜와 시각은 서버에서 통계를 집계한 한국 시간입니다. [새로고침]을 누르면 다시 조회합니다. 기간은 1일·1주·15일·30일이며 오늘을 포함합니다. 1일은 시간별, 나머지는 날짜별로 표시합니다.

기간을 고르면 열어 본 문항·문제 열기·기록된 입력 변경·채점이 함께 바뀝니다. 각 숫자 옆의 정보 버튼에서 집계 기준을 확인할 수 있습니다.

[전체 누적]에서는 누적 채점, 수집 기록, 인증 계정, 첫 실행 확인 기기를 카드로 볼 수 있습니다. 큰 숫자는 처음부터 쌓인 합계이고, 그 아래 작은 숫자는 선택한 기간의 건수입니다. 한 문항을 열고 답을 적어 채점하면 수집 기록이 여러 건 생길 수 있으므로 카드의 숫자는 서로 더하지 않습니다.

- **열어 본 문항**은 선택 기간에 열기 기록이 남은 서로 다른 문항 수입니다. 여러 사람이 같은 문항을 열어도 한 문항으로 셉니다.
- **문제 열기**는 프로그램이 문항을 보여 주며 남긴 기록 수입니다. 같은 기록의 재전송은 한 번만 셉니다.
- **기록된 입력 변경**은 바뀐 답을 저장한 횟수입니다. 타수나 같은 값의 재저장은 세지 않습니다. 과거 AI 입력은 미측정이며 새 계측으로 기록한 횟수만 표시합니다.
- **채점**은 답을 적거나 보기를 고른 뒤 채점까지 마친 문항 수입니다.

그래프는 채점을 먼저 보여 주며 문제 열기·입력 변경으로 바꿀 수 있습니다. 막대에 마우스를 올리거나 그래프에 초점을 옮긴 뒤 좌우 방향키를 누르면 해당 시점의 수치를 확인할 수 있습니다. 작은 창에서는 요약을 두 열로 나누고 그래프와 과목별 합계를 세로로 배치합니다. 선택 기간에 채점한 기록 중 지문·개념·문항 버전·출제 난이도·순서와 시각이 남은 수, 파이썬 입력과 연결된 수를 아래에서 확인할 수 있습니다.

답을 쓰거나 보기를 고르고 채점까지 마친 문항 하나를 풀이 1건으로 셉니다. 오답과 부분 정답도 포함합니다. 같은 문항을 다시 풀고 채점하면 1건을 더 셉니다. 문제 열기, 답안 입력만 한 경우, 미응답, [모르겠어요], 같은 기록이나 파일의 재전송은 제외합니다.

그래프는 한국 시간 기준입니다. 풀이 시각을 모르는 옛 AI 판정은 누적에만 포함합니다. 옛 연습·모의고사 오답 중 답을 적었는지 확인할 수 없는 기록은 ‘응답 여부 미확인’으로 따로 표시합니다. 서버가 채점 풀이 통계를 제공하지 않으면 풀이 수는 대시(–)로 표시합니다.

- **인증 계정 수**는 계정 확인값으로 중복을 제외한 GitHub 계정 수입니다. 한 사람이 계정 두 개를 쓰면 두 개로 셉니다.
- **첫 실행 확인 기기 수**는 처음 인증을 마친 기기를 셉니다. 기기에서 무작위로 만든 코드로 중복을 제외합니다. 같은 계정을 두 컴퓨터에서 인증하면 계정 한 개, 기기 두 대입니다. 프로그램을 다시 받아도 기기 코드가 남아 있으면 한 대입니다. 코드를 지우거나 다른 운영체제 사용자 계정에서 실행하면 새 기기로 집계될 수 있습니다.

선택 기간의 계정 수와 기기 수는 각각 그 기간에 처음 인증한 건수입니다. 통계 도입 전에 설치한 수는 추정해 더하지 않습니다. 실제 사람 수와 프로그램 다운로드 횟수는 집계하지 않습니다.

통계에는 답안 본문이나 개인별 기록을 표시하지 않습니다. 서버는 통계를 요청한 기기의 팀원 권한을 확인합니다. 팀 명단이 바뀌면 기존 팀 권한을 해제하고, 일반 학습자의 기기 키는 그대로 유지합니다. 스터디원 표시는 통계 조회와 [다른 서버 연결]에 사용합니다. 운영자의 서버 관리 권한은 별도로 관리합니다.
