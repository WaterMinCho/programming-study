# 이 기기에서 처음 한 번 본인 확인

프로그램을 열면 업데이트를 먼저 확인합니다. 이 기기에서 본인 확인을 한 적이 없다면 GitHub 확인 창을 표시합니다. 이미 학습한 사용자도 처음 표시될 때 한 번 확인합니다. 기존 답안과 진도는 유지합니다.

1. 프로그램에서 [GitHub에서 확인하기]를 누릅니다.
2. 열린 GitHub 화면에서 본인 계정으로 로그인합니다.
3. 프로그램에 표시된 확인 코드를 입력하고 계정 소유 확인을 마칩니다.
4. 프로그램으로 돌아옵니다. 학습 기록 제공 여부를 아직 정하지 않았다면 이때 선택합니다.

GitHub 확인 코드는 [확인 코드 복사]로 복사할 수 있습니다. 코드가 만료되면 다시 확인합니다. 다른 계정으로 확인하려면 [화면 설정]의 [본인 확인 다시 하기]를 누릅니다.

## 보관하는 정보

실명·이메일·프로필 사진과 GitHub 계정 번호·GitHub 토큰은 저장하지 않습니다. 서버는 계정 번호를 일시적으로 대조하고 확인에 사용한 GitHub 권한을 해제합니다. 다음 실행에는 계정 정보가 없는 기기 확인 결과를 사용합니다. 학습 기록 제공 여부는 별도 동의 화면에서 선택합니다.

기기에는 임의 기기 코드와 확인 결과를 보관합니다. 스터디원에게 발급하는 기기 키는 통계 조회에만 사용하며 서버에는 그 키의 해시만 보관합니다. 기기 인증 값을 다른 사람에게 전달하지 마세요.

## 스터디원의 수집 통계

본인 확인된 기기가 스터디원으로 확인되면 [학습 현황]에 수집 통계를 표시합니다. 기간은 1일·1주·15일·30일이며 오늘을 포함합니다. 1일은 시간별, 나머지는 날짜별로 표시합니다.

전체 수집 기록에는 보관 중인 파이썬·AI 개론·응용 기록을 합산합니다. 재전송은 중복 합산하지 않고 합성 기록은 제외합니다. 기록에 저장된 시각을 한국 시간으로 바꾸어 집계하며, 시각을 확인할 수 없는 옛 기록은 전체 합계에만 넣습니다. 사람 수·문항 수·모델 학습에 사용할 수 있는 답안 수와는 구분합니다.

[첫 실행 확인 기기]는 임의 기기 코드로 중복을 제외한 등록 건수입니다. 같은 사람이 컴퓨터 두 대를 사용하면 두 대로 집계됩니다. 기존 기기 코드가 남아 있으면 프로그램 폴더만 다시 받아도 중복 등록하지 않습니다. 기기 코드를 지우거나 다른 운영체제 사용자 계정에서 실행하면 별도 등록이 될 수 있습니다. 통계 기능을 도입하기 전의 설치 인원을 추정해 더하지 않습니다.

통계에는 답안 본문이나 개인별 기록을 표시하지 않습니다. 기기 키와 팀원 권한은 서버에서 확인하며, 화면을 직접 수정해도 다른 권한으로 통계 API를 호출할 수 없습니다.
