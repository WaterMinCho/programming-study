# 이 기기에서 처음 한 번 본인 확인

모든 학습자는 기기마다 처음 한 번 GitHub 계정을 확인합니다. 이미 학습한 기기에서도 처음 확인할 때 기존 답안과 진도는 유지합니다.

프로그램을 열면 업데이트를 먼저 확인합니다. 처음 인증할 기기에서는 다음 순서로 진행합니다.

1. 프로그램에서 [GitHub에서 확인하기]를 누릅니다.
2. 열린 GitHub 화면에서 본인 계정으로 로그인합니다.
3. 프로그램에 표시된 확인 코드를 입력하고 계정 소유 확인을 마칩니다.
4. 프로그램으로 돌아옵니다. 학습 기록 제공 여부를 아직 정하지 않았다면 이때 선택합니다.

GitHub 확인 코드는 [확인 코드 복사]로 복사할 수 있습니다. 코드가 만료되면 다시 확인합니다. 다른 계정으로 확인하려면 [화면 설정]의 [본인 확인 다시 하기]를 누릅니다.

## 보관하는 정보

이름·이메일·프로필 사진·GitHub 계정 번호 원문·GitHub 토큰은 저장하지 않습니다. 서버는 계정 번호와 서버 비밀키로 계정 확인값(HMAC)을 만들고 확인에 사용한 GitHub 권한을 해제합니다. 로그인 이름이 바뀌어도 계정 번호가 같으면 같은 확인값이 나옵니다.

처음 인증을 마치면 프로그램이 발급한 기기 키를 이 컴퓨터에 보관합니다. 다음 실행부터는 이 키로 자동 확인합니다. 서버에는 키의 해시만 보관합니다. 기기 키를 다른 사람에게 전달하지 마세요.

자동 확인 중 연결이 잠시 끊겨도 이미 받은 문제를 풀고 이 컴퓨터에서 채점할 수 있습니다. 기기 키를 확인한 서버가 인증을 거부한 경우(401 또는 403)에만 GitHub에서 다시 확인합니다.

계정 확인값은 연구 참가자의 가명 ID나 풀이 데이터와 연결하지 않습니다. [연구용 학습 기록 제공](LEARNING_PRIVACY.md)은 별도로 선택하며, 동의하지 않아도 학습과 로컬 채점을 이용할 수 있습니다.

## 스터디원의 수집 통계

본인 확인된 기기가 스터디원으로 확인되면 [학습 현황]에 수집 통계를 표시합니다. 기간은 1일·1주·15일·30일이며 오늘을 포함합니다. 1일은 시간별, 나머지는 날짜별로 표시합니다.

전체 수집 기록에는 보관 중인 파이썬·AI 개론·응용 기록을 합산합니다. 재전송은 중복 합산하지 않고 합성 기록은 제외합니다. 기록에 저장된 시각을 한국 시간으로 바꾸어 집계하며, 시각을 확인할 수 없는 옛 기록은 전체 합계에만 넣습니다. 사람 수·문항 수·모델 학습에 사용할 수 있는 답안 수와는 구분합니다.

- **인증 계정 수**는 계정 확인값으로 중복을 제외한 GitHub 계정 수입니다. 한 사람이 계정 두 개를 쓰면 두 개로 셉니다.
- **첫 실행 확인 기기 수**는 처음 인증을 마친 기기를 셉니다. 기기에서 무작위로 만든 코드로 중복을 제외합니다. 같은 계정을 두 컴퓨터에서 인증하면 계정 한 개, 기기 두 대입니다. 프로그램을 다시 받아도 기기 코드가 남아 있으면 한 대입니다. 코드를 지우거나 다른 운영체제 사용자 계정에서 실행하면 새 기기로 집계될 수 있습니다.

선택 기간의 계정 수와 기기 수는 각각 그 기간에 처음 인증한 건수입니다. 통계 도입 전에 설치한 수는 추정해 더하지 않습니다. 실제 사람 수와 프로그램 다운로드 횟수는 집계하지 않습니다.

통계에는 답안 본문이나 개인별 기록을 표시하지 않습니다. 서버는 통계를 요청한 기기의 팀원 권한을 확인합니다. 팀 명단이 바뀌면 기존 팀 권한을 해제하고, 일반 학습자의 기기 키는 그대로 유지합니다.
