# 프로그램 안내 문서를 찾습니다

[처음 안내로 돌아갑니다](../README.md)

처음 설치할 때는 [프로그램 준비](../gui/README.md#최초-한번-준비해야할-것)를 읽습니다. 모델 스터디에 참여하는 팀원은 [개인 저장소부터 첫 PR까지](LEARNING_WORKFLOW.md)를 먼저 따라 합니다.

## 바뀐 점

- 체크 표시와 보조 설명, 그림 조작부, 숫자 옆 설명의 정렬을 조정했습니다. 확인한 화면과 조건은 [화면 정렬 점검 범위](UI_ALIGNMENT_AUDIT.md)에서 볼 수 있습니다.
- GIF의 장 번호와 단추 글자 크기를 맞추고 재생·일시 정지를 아이콘으로 표시합니다. 아이콘 위에 마우스를 올리면 할 동작을 확인할 수 있습니다.

- 풀이 수집부터 세 모델의 학습·비교·추천까지 [전체 흐름과 팀원 미션](LEARNING_MISSIONS.md)을 그림으로 정리했습니다. 공통 첫 실습, 개인 산출물, PR 피드백 반영 방법도 확인할 수 있습니다.

- 파이썬 홈에서도 [학습 데이터]를 관리합니다. 기존 풀이 기록은 소유자의 동의를 확인한 뒤 [공통 학습 자료와 입력 예제](LEARNING_STARTER.md)로 바꿔 세 팀원의 모델 개발에 사용할 수 있습니다.

- AI 홈의 [학습 데이터]에서 풀이 기록을 관리합니다. 배포 시 수집에 동의한 참가자의 새 풀이 과정을 이 기기에 모으고, 전송 버튼으로 초대받은 비공개 서버에 보냅니다. 기존 풀이 제출과 진도에는 영향을 주지 않습니다. [수집 안내](LEARNING_DATA.md)와 [프로그램 담당 및 세 팀원의 모델 개발 분담](LEARNING_MISSIONS.md)을 참고하세요.
- AI 개론에서 1~17차시, 상황별 코드 연습과 모의고사 3회를 풉니다. 단계 왕복 시 입력 초안과 읽던 위치를 복원하고, 오늘 마친 문항은 당일 자동 복습의 보충 문항으로 다시 채우지 않습니다. 쓰는 법은 [AI 개론](../ai/README.md#ai-개론응용)에 있습니다.
- 첫 화면에 오답 노트 줄이 생겼고, 공부 트랙과 최근 7일 학습은 위아래로 놓여 가로 폭을 다 씁니다. 오답 노트의 왼쪽 목록은 '틀린 문항', '미응답 문항', '다시 맞힌 문항'으로 나뉘고 이름 줄을 눌러 접고 폅니다. 자세한 내용은 [파이썬 스터디 풀기](../problems/README.md#파이썬-스터디-풀기)에 있습니다.
- 첫 화면과 웹 면접 준비 화면을 새로 그렸습니다. 글자를 키우고, 주요 동작을 구분하고, 목록은 줄을 눌러 엽니다. 첫 화면 맨 위의 '이어서 할 일' 카드에서 하던 일을 바로 이어 합니다. 자세한 내용은 [켜기와 첫 화면](../gui/README.md#켜기와-첫-화면)에 있습니다.
- 2026년 10월 판부터 첫 화면이 생겼습니다. 예전 홈 화면은 첫 화면의 공부 트랙에서 파이썬 스터디 줄을 누르면 나오고, 새로 생긴 알고리즘 여행은 알고리즘 여행 줄로 들어갑니다.

- 이번 판을 받은 뒤 처음 제출하기 전에 프로그램을 한 번 껐다 켜 주세요. 켜 둔 예전 프로그램으로 제출하면 다른 컴퓨터에서 올린 알고리즘 여행 기록이 그 PR 에서 빠질 수 있습니다.
- [문제 받기]가 파이썬 스터디 기록과 알고리즘 여행 기록을 따로 맞춥니다. 한 컴퓨터에서 회차를 풀어 제출하고 다른 컴퓨터에서 알고리즘 여행 문제를 풀었다면, 그 컴퓨터에서 받을 때 회차 기록을 가져오고 알고리즘 여행 기록은 지우지 않습니다.

## 폴더와 차시별 복습 자료

회차는 여러 차시를 섞어서 냅니다. 차시별로 복습하려면 `problems/s03/README.md` 처럼 차시 폴더의 `README.md` 를 엽니다. 개념 정리와 시험에서 헷갈리는 부분이 적혀 있습니다.

| 폴더                                      | 내용                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `problems/s01` ~ `s21`                    | 1~21차시. 파이썬 소개, 프로그래밍 기초, 조건문, 리스트와 딕셔너리, 반복문, 함수 1·2, 자료구조와 알고리즘, 클래스 1·2, GUI, 파일 처리, 예외·문자열·람다·map, 정규표현식, 고급 함수, 알고리즘 1·2, Pandas·NumPy·Matplotlib, statsmodels·scikit-learn·SciPy, Seaborn·OpenCV, 파이썬 활용 심화. 18~20차시는 패키지를 다루는 차시라 객관식과 단답만 있습니다. 20차시의 캐스케이드 분류기 이후와 21차시는 시험 범위가 아니라서 회차에 나오지 않습니다 |
