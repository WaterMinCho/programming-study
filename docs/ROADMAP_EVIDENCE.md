# 직무 로드맵의 요구와 교과를 대조합니다

2026년 11월 8일에 네이버랩스와 레인보우로보틱스의 공식 공고 13건을 읽고 기존 여섯 직무의 학습 항목을 대조했습니다. 직무마다 필요한 작업을 확인하려고 고른 표본입니다. 전체 채용 시장의 비율이나 신입 채용 순위를 계산한 자료는 아닙니다. 점핏·원티드에서 공고를 찾았던 10월 20일 조사와 이번 대조를 합산하지 않습니다.

네이버랩스의 목록에 ‘무관’이 표시돼도 세부 공고에는 학위나 경력 조건이 있습니다. 레인보우 Vision AI는 목록에는 경력, 본문에는 신입 지원 가능이라고 적혀 있습니다. 양팔로봇 AI/SW의 학위와 연차를 나열한 문장도 조합이 명확하지 않습니다. 지원 전에는 해당 공고의 원문 조건을 다시 확인하세요. ‘경력 무관’을 학사 신입이 제한 없이 지원할 수 있다는 뜻으로 바꾸지 않습니다.

다른 기업의 채용 페이지에서는 접근 오류나 상세 내용 누락이 있어 이번 근거에 넣지 않았습니다. 읽지 못한 공고를 채용 추세의 근거로 세지 않습니다. 공고별 요약과 확인 날짜는 [근거 목록](roadmap/hiring-20261108.json)에 보존했습니다.

## 수업에 포함된 범위를 표시합니다

로드맵 상자의 색과 짧은 글자로 ROKEY 11기 교과와의 관계를 함께 표시합니다. 공식 교과별 커리큘럼의 차시별 제목과 세부 내용을 대조합니다. 프로젝트 이름이나 상위 교과 이름만으로 세부 도구를 배운다고 표시하지 않습니다.

| 라벨 | 판단하는 범위 |
| --- | --- |
| 11기 수업 | 해당 주제나 도구가 공식 교과 목차에 명시돼 있습니다. 실무 숙련을 보장하지 않습니다. |
| 11기 일부 | 관련 기초는 다루지만 상자의 전체 내용이나 실무 적용까지 확인되지 않았습니다. |
| 추가 학습 | 확인한 공식 교과 목차에 항목이 없습니다. 수업에서 언급하지 않는다고 단정하지는 않습니다. |
| 확인 대기 | 프로젝트 이름 등만으로 포함 여부를 정할 수 없습니다. |

회색 상자는 같은 자리에 고를 수 있는 도구입니다. 도구 선택과 교과 포함 여부는 별도로 읽습니다. 개별 상자의 `course`에는 판단 범위와 근거를 보존합니다.

## 직무마다 확인할 결과를 남깁니다

| 목표 직무 | 실습에서 남길 결과 |
| --- | --- |
| 로봇 SW·제어 | 좌표·통신·제어 조건을 정하고 장치 오류를 재현한 로그, 수정과 재검증 |
| 자율주행 로봇 | 위치 추정·경로 계획의 설정, 주행 실패 감지와 복구, 같은 경로의 비교 기록 |
| 비전 AI | 분할을 고정한 학습·검증, 실패 사례, 체크포인트와 실제 배포 장치의 측정 조건 |
| 현장·통합 | 설치·점검 절차, 장애 재현과 조치, 고객에게 전달할 기술 문서 |
| Physical AI | 데이터·시드·학습 설정, 정책 평가, 시뮬레이션과 실제 장치의 차이 |
| 로봇 관제 | API·DB·실시간 상태 처리, 연결이 끊겼을 때의 복구와 운영 로그 |

이 결과 목록은 공고를 바탕으로 구성한 학습 제안입니다. 특정 회사의 공식 평가표가 아닙니다. 관련 수업을 마친 뒤 직접 구현·측정하며 부족한 부분을 확인합니다. 모델 추천을 위한 실험은 Python과 AI 개론의 기록을 분리해 진행합니다.

파이썬이나 AI의 [학습 데이터]에서 기록 수집을 켠 동안 [희망 직무 저장]을 누르면 이후 수집하는 풀이에 선택 시점과 로드맵 버전을 함께 남깁니다. 이 선택은 목표를 나타내며 실력 등급이나 채용 적합도를 뜻하지 않습니다. 목표를 바꾸기 전의 풀이는 당시 목표로 유지합니다.
