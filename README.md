# <img src="docs/img/icon.png" width="36" alt=""> 프로그래밍 스터디

프로그래밍 공부와 코딩 테스트 준비를 같이 하려고 만든 프로그램입니다. 실행하면 창이 열리고 문제 풀이, 채점, 해설 확인, 제출을 그 안에서 합니다. 첫 화면에서 파이썬 스터디, 알고리즘 여행, AI를 골라 들어갑니다. AI 홈에서 개론·응용을 나눠 봅니다.

파이썬 스터디에는 ROKEY 11기 파이썬 교과목 평가(10/16)를 준비하며 만든 파이썬 문제가 들어 있습니다. 알고리즘 여행은 코딩 테스트에 자주 나오는 알고리즘을 주제별로 16묶음으로 나눈 문제 모음이고, 한 묶음을 던전이라고 부릅니다. 프로그래머스처럼 `solution` 함수를 Python 이나 JavaScript 로 완성해 풉니다. AI 개론은 학습 단원을 읽고 빈칸·고르기 문제로 개념과 코드를 익히는 트랙입니다.

웹 면접 준비는 현재 진입을 중지했습니다. 기존 안내는 [웹 면접 준비](web/README.md)에서 확인합니다.

## [풀이 기록으로 추천 모델을 만듭니다](learning_server/README.md#풀이-기록으로-추천-모델을-만듭니다)

[수집하는 항목과 전체 배포 전 확인할 조건](docs/LEARNING_READINESS.md)을 확인할 수 있습니다.

풀이 기록을 모으고, 각자 모델을 만들어 같은 자료로 비교합니다. 모델 학습과 추천 연결은 앞으로 진행합니다.

팀원은 [각자 fork에서 첫 PR까지](docs/LEARNING_WORKFLOW.md)를 먼저 읽습니다. [담당별 미션](docs/LEARNING_MISSIONS.md)에서 세 모델의 차이를, [모델 개발 로드맵](docs/LEARNING_ROADMAP.md)에서 남길 산출물과 다음 학습을 확인합니다.

PR 등록·CI 결과·새 리뷰는 [Slack 알림](docs/SLACK_NOTIFICATIONS.md)에서 바로가기로 확인할 수 있습니다.

프로그램 코드(`study.py`, `adaptive.py`, `session.py`, `gitflow.py`, `bootstrap.py`, `mdlite.py`, `gui/`, `journey/`, `webprep/`, `tools/`, `tests/`)는 [GPL-3.0](LICENSE)입니다. 화면에 쓰는 PyQt6 가 GPL-3.0 이라 같은 조건을 따릅니다.

`gui/fonts/` 의 글꼴은 SIL OFL 1.1 을 따릅니다. 화면 글꼴은 [나눔고딕](gui/fonts/OFL.txt), 코드 글꼴은 [D2Coding](gui/fonts/OFL-D2Coding.md)입니다.

`problems/`, `dungeons/`, `web/` 의 문제, 해설, 개념 정리, 그림, 미션 템플릿 코드는 이 스터디의 학습 자료이고 GPL 적용 대상이 아닙니다. 다른 곳에 옮겨 쓰려면 스터디장에게 문의해 주세요.
