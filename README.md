# <img src="docs/img/icon.png" width="36" alt=""> 프로그래밍 스터디

프로그래밍 공부와 코딩 테스트 준비를 같이 하려고 만든 프로그램입니다. 실행하면 창이 열리고 문제 풀이, 채점, 해설 확인, 제출을 그 안에서 합니다. 첫 화면에서 파이썬 스터디, 알고리즘 여행, AI 비전 개론을 골라 들어갑니다.

파이썬 스터디에는 ROKEY 11기 파이썬 교과목 평가(10/16)를 준비하며 만든 파이썬 문제가 들어 있습니다. 알고리즘 여행은 코딩 테스트에 자주 나오는 알고리즘을 주제별로 16묶음으로 나눈 문제 모음이고, 한 묶음을 던전이라고 부릅니다. 프로그래머스처럼 `solution` 함수를 Python 이나 JavaScript 로 완성해 풉니다. AI 비전 개론은 학습 단원을 읽고 빈칸·고르기 문제로 개념과 코드를 익히는 트랙입니다.

웹 면접 준비는 현재 화면과 터미널의 진입을 중지했습니다. 기존 코드·학습 자료·기록은 보존합니다. 개발자가 다시 열 때는 `study.py`의 `ENTRY_TRACKS`에서 `"web"` 줄의 주석을 해제합니다. 아래 웹 트랙 안내는 복원 후 사용할 기존 기능을 설명합니다.

## 바뀐 점

- 풀이 수집부터 세 모델의 학습·비교·추천까지 [전체 흐름과 팀원 미션](docs/LEARNING_MISSIONS.md)을 그림으로 정리했습니다. 공통 첫 실습, 개인 산출물, PR 피드백 반영 방법도 확인할 수 있습니다.

- 파이썬 홈에서도 [학습 데이터]를 관리합니다. 기존 풀이 기록은 소유자의 동의를 확인한 뒤 [공통 학습 자료와 입력 예제](docs/LEARNING_STARTER.md)로 바꿔 세 팀원의 모델 개발에 사용할 수 있습니다.

- AI 비전 개론 홈에 [학습 데이터]가 생겼습니다. 동의한 뒤 풀이 과정을 이 기기에 모으고, 원하면 초대받은 비공개 서버로 보냅니다. 기존 풀이 제출과 진도에는 영향을 주지 않습니다. [수집 안내](docs/LEARNING_DATA.md)와 [프로그램 담당 및 세 팀원의 모델 개발 분담](docs/LEARNING_MISSIONS.md)을 참고하세요.
- AI 비전 개론에서 1~17차시, 상황별 코드 연습과 모의고사 3회를 풉니다. 단계 왕복 시 입력 초안과 읽던 위치를 복원하고, 오늘 마친 문항은 당일 자동 복습의 보충 문항으로 다시 채우지 않습니다. 쓰는 법은 [AI 비전 개론](#ai-비전-개론)에 있습니다.
- 첫 화면에 오답 노트 줄이 생겼고, 공부 트랙과 최근 7일 학습은 위아래로 놓여 가로 폭을 다 씁니다. 오답 노트의 왼쪽 목록은 '틀린 문항', '미응답 문항', '다시 맞힌 문항'으로 나뉘고 이름 줄을 눌러 접고 폅니다. 자세한 내용은 [파이썬 스터디 풀기](#파이썬-스터디-풀기)에 있습니다.
- 첫 화면과 웹 면접 준비 화면을 새로 그렸습니다. 글자를 키우고, 주요 동작을 구분하고, 목록은 줄을 눌러 엽니다. 첫 화면 맨 위의 '이어서 할 일' 카드에서 하던 일을 바로 이어 합니다. 자세한 내용은 [켜기와 첫 화면](#켜기와-첫-화면)에 있습니다.
- 2026년 10월 판부터 첫 화면이 생겼습니다. 예전 홈 화면은 첫 화면의 공부 트랙에서 파이썬 스터디 줄을 누르면 나오고, 새로 생긴 알고리즘 여행은 알고리즘 여행 줄로 들어갑니다.

## 학습 로드맵

ROKEY 11기 교과와 공식 채용 공고를 대조해 여섯 직무의 학습 순서를 그렸습니다. 각 상자에는 **11기 수업·11기 일부·추가 학습·확인 대기**를 표시합니다. 수업에 포함됐다는 표시와 실무 역량을 갖췄다는 판단은 구분합니다.

![여섯 길과 모든 길에 필요한 것](docs/roadmap/intro.png)

### 그림 읽는 법

가운데 선을 따라 위에서 아래로 배우고, 양옆에서 세부 주제를 확인합니다. 회색 상자는 같은 자리에 고를 수 있는 도구입니다. 교과 포함 여부는 상자의 짧은 글자와 귀퉁이 색을 함께 읽습니다.

| 표시 | 뜻                                                                   |
| ---- | -------------------------------------------------------------------- |
| 보라·11기 수업 | 공식 교과 목차에 해당 주제나 도구가 있습니다 |
| 파랑·11기 일부 | 관련 기초는 배우며 상자 전체 내용은 더 익힙니다 |
| 주황·추가 학습 | 확인한 교과 목차에 없어 별도로 익힙니다 |
| 회색·확인 대기 | 프로젝트 이름만으로 포함 여부를 정하지 않습니다 |

하늘색 꼬리표가 붙은 상자는 이 프로그램에서 연습합니다. 흰 글상자에는 실습에서 확인할 결과와 공고의 조건을 적었습니다. 선택할 도구나 추가 전문 분야까지 모두 배운 뒤 지원해야 한다는 뜻은 아닙니다.

### 이 프로그램에서 연습할 수 있는 부분

- 파이썬 스터디에서는 모든 길에 필요한 Python과 자료구조·알고리즘 기초를 풀고, 비전 AI 길의 NumPy·pandas·Matplotlib과 현장·통합 엔지니어 길의 파일 처리·정규표현식도 함께 다룹니다.
- 알고리즘 여행은 모든 길의 코딩 테스트에 나오는 알고리즘을 Python과 JavaScript로 연습하는 트랙입니다. 지금은 던전 1~3(해시·투 포인터, 누적합·차분, 이분 탐색)을 풀 수 있고, 자율주행 로봇 길에 나오는 다익스트라·우선순위 큐는 나머지 던전과 함께 차례로 출제됩니다.
- 웹 면접 준비는 로봇 관제 개발자 길의 JavaScript, TypeScript, React, 브라우저 동작을 라이브 코딩 미션과 꼬리 질문으로 연습하는 트랙입니다. 지금은 미션 w01·w03 과 주제 1·3·6·7·11 이 출제되어 있습니다.

AI 비전 개론에서는 데이터·배치·모델·손실·갱신·평가와 전이 학습을 그림과 문제로 익힙니다. C++·ROS2의 실물 로봇 실습과 모델 학습은 앱 밖에서 진행합니다.

파이썬과 AI 비전 개론의 [학습 데이터]에서 희망 직무를 선택할 수 있습니다. 선택은 건너뛸 수 있으며 풀이 당시 목표와 로드맵 버전을 함께 저장합니다. 목표를 바꿔도 이전 풀이의 분류는 바꾸지 않습니다. [수집 안내](docs/LEARNING_DATA.md)를 확인하세요.

### 그림의 근거

교과 표시는 11기 공식 교과별 커리큘럼과 Life Guide를 대조했습니다. 2026년 11월 8일에는 네이버랩스·레인보우로보틱스 공식 공고 13건의 필수·우대·학위·경력을 구분해 학습 순서를 보완했습니다. 전체 시장의 채용 비율이나 순위를 나타내는 조사는 아닙니다. 공고 목록과 교과 판정 기준은 [로드맵 근거](docs/ROADMAP_EVIDENCE.md)에 있습니다.

로드맵을 고칠 때는 `tools/roadmap/roadmap.json`을 수정하고 `tools/roadmap/draw.py`로 그림을 다시 생성합니다. 10월 20일 공고 집계는 당시 판의 기록으로 남기고 현재 채용 수치로 표시하지 않습니다.

파이썬 스터디 화면은 시험과 비슷하게 맞췄습니다. 왼쪽에 문항 목록, 가운데에 문제, 오른쪽에 답안이 있습니다. 코드를 적는 칸은 프로그래머스 편집기처럼 남색 바탕이고, 예약어와 문자열 같은 파이썬 문법에 따라 글자색이 달라집니다. 괄호와 따옴표는 자동으로 닫히고 자동완성은 없습니다. 복사, 붙여넣기, 우클릭 메뉴도 막아 두었습니다.

## 최초 한번 준비해야할 것

- 파이썬 3.10~3.14(64비트)가 필요합니다. 새로 설치한다면 [3.14](https://www.python.org/downloads/latest/python3.14/)를 고릅니다. 3.15 에는 PyQt6 가 아직 설치되지 않습니다. 이미 설치돼 있으면 아래 1번처럼 터미널을 열고 `python --version` 으로 버전을 확인합니다.
- git 도 필요합니다. Windows 는 [Git for Windows](https://git-scm.com/download/win)를 설치합니다.
- 알고리즘 여행을 JavaScript로 풀려면 Node.js 20 이상도 설치합니다. [설치 방법](#nodejs-설치)을 참고하세요. Python으로만 풀 때는 Node.js가 필요하지 않습니다.
- 깃허브 ID 를 스터디장에게 알려 주고, GitHub 알림이나 메일로 온 저장소 초대를 수락합니다.

그다음 저장소를 받아 실행합니다. 터미널에서 쓰던 예전 버전을 받아 둔 폴더가 있으면 새로 받지 않고 [안 될 때](#안-될-때)의 네 줄 명령으로 새 버전을 받은 뒤 3번부터 합니다.

1. 프로그램을 둘 폴더를 탐색기로 열고 주소 칸에 `cmd` 를 입력한 뒤 Enter 를 누릅니다. 그 폴더에서 터미널(검은 창)이 열립니다. macOS 는 터미널 앱을 엽니다.
2. 아래 명령을 입력합니다. `programming-study` 폴더가 생깁니다.

   ```bash
   git clone https://github.com/WaterMinCho/programming-study.git
   ```

3. `programming-study` 폴더의 `start.pyw`(macOS 는 `ROKEY.app`)를 더블클릭합니다. 검은 창 없이 프로그램 창이 열립니다. Windows 탐색기에 확장자가 보이지 않아 `start` 가 두 개로 보이면 종류가 'Python File (no console)'인 파일을 엽니다. 톱니바퀴 아이콘의 `start.bat` 을 열어도 검은 창이 잠깐 떴다가 닫히고 프로그램 창만 남습니다.
4. 처음 실행하면 '프로그래밍 스터디 준비' 창이 설치할지 묻습니다. [설치]를 누르면 화면을 그리는 PyQt6 를 `~/.rokey-study/venv` 에 설치하는데, 내려받는 양이 85MB 쯤이고 설치하면 250MB 쯤 됩니다. 수업 때 PyQt6 를 설치했다면 묻지 않습니다.
5. 프로그램 창이 열리면 깃허브 ID(github.com/ 뒤에 나오는 이름)를 입력하고 [시작]을 누릅니다. 첫 화면이 열립니다.
6. 첫 화면의 공부 트랙에서 파이썬 스터디 줄을 누르고, 파이썬 스터디 홈의 [진단 테스트 시작]을 누릅니다. 단원마다 2문항씩 42문항이고 40분쯤 걸립니다. 모르는 문항은 비워 두고 제출해도 됩니다. 알고리즘 여행은 진단 테스트 없이 바로 시작합니다.

그래도 창이 열리지 않으면 Windows 는 터미널에서 `python study.py` 를 실행하고, macOS 는 `start.command` 를 더블클릭합니다. 이때는 검은 창이 먼저 열리고 이어서 프로그램 창이 열리며, 검은 창을 닫으면 프로그램도 닫힙니다. 설치도 검은 창에서 묻습니다. "설치할까요? [y/N]"이 나오면 `y` 를 입력하고 Enter 를 누릅니다. 준비 창을 띄울 수 없는 파이썬(Homebrew 파이썬 등)에서는 처음 설치할 때 프로그램이 `start.bat` 이나 `start.command` 를 대신 엽니다.

Sourcetree 같은 앱으로 받은 폴더에서는 macOS 가 `ROKEY.app` 을 확인되지 않은 앱으로 막습니다. 그때는 `start.command` 로 켜거나 터미널에서 `python3 study.py` 를 실행합니다.

이 문서에 나오는 터미널 명령은 `start.bat` 이 있는 폴더에서 입력합니다. 탐색기로 그 폴더를 열고 주소 칸에 `cmd` 를 입력하면 터미널이 열립니다. `python` 이 실행되지 않으면 Windows 는 `py`, macOS 는 `python3` 로 바꿔 입력합니다(예: `py study.py update`).

## 켜기와 첫 화면

다음부터는 `start.pyw` 나 `start.bat`(macOS 는 `ROKEY.app`)을 더블클릭해 켭니다. 열리지 않으면 Windows 는 터미널에서 `python study.py` 로, macOS 는 `start.command` 로 켭니다. 켤 때마다 새 문제와 프로그램 새 버전을 받아 오고, 첫 화면의 [새 문제 받기]나 파이썬 스터디 홈의 [문제 받기]를 눌러도 똑같이 받습니다. 프로그램이 바뀌었으면 '프로그램 갱신' 창이 뜨고, [다시 시작]을 누르면 새 버전으로 다시 열립니다.

켜면 학습 현황이 열립니다. 이어서 할 일, 과목별 학습, 오답 노트, 최근 7일 기록을 확인합니다. 넓은 창은 왼쪽 과목 메뉴를, 좁은 창은 위쪽 선택란을 사용합니다.

- 이어서 할 일은 저장한 학습 위치와 복습 상태를 바탕으로 다음 행동을 안내합니다. 버튼을 누르면 해당 학습이나 문제 화면으로 갑니다.
- 과목별 학습에는 파이썬 스터디, 알고리즘 여행, AI 비전 개론이 있습니다. 과목마다 진행 상태와 다음 할 일을 확인하고 눌러 들어갑니다. 웹 면접 준비는 과목 메뉴와 이어서 할 일에서 제외했습니다.
- 오답 노트에서는 틀린 문항·미응답 문항·다시 맞힌 문항을 구분해 살펴봅니다.
- 최근 7일 기록은 날짜별 학습 횟수와 최근 채점을 보여 줍니다. 파이썬은 회차를 한 번 채점하면 문항 수와 관계없이 채점 한 번으로 셉니다. 읽기 완료와 복습 기준 충족은 구분합니다.
- 하단의 제출 안내는 제출하지 않은 변경이나 받을 자료가 있을 때 나타납니다. 풀이 제출과 비공개 학습 데이터 전송은 각각 선택합니다.

파이썬 스터디 홈의 왼쪽 위 [처음으로]와 던전 지도·AI 비전 개론 홈의 [← 처음 화면]을 누르면 첫 화면으로 돌아옵니다.

![홈 화면](docs/img/home.png)

- 답은 적는 대로 저장됩니다. 창을 닫아도 다음에 이어서 풉니다.

## 알고리즘 여행

### 던전 지도

첫 화면의 공부 트랙에서 알고리즘 여행 줄을 누르면 던전 지도가 열립니다. 맨 위 '이어서 할 일' 카드에는 첫 화면의 이어서 할 일과 같은 문제가 나옵니다. [문제 풀기]를 누르면 그 문제가 바로 열립니다. 가장 최근에 연 문제를 아직 통과하지 않았으면 그 문제가 나오고 그 밖에는 권장 순서의 다음 문제가 나옵니다.

카드 아래 왼쪽 지도에는 던전 16개가 권장 순서대로 길로 이어져 있습니다. 원 안의 숫자는 던전 번호이고 원 아래 글은 던전 이름입니다. 원 색의 뜻은 지도 아래에 있습니다. 원이나 이름을 누르면 오른쪽에 그 던전의 문제 목록이 나옵니다. 목록 아래에는 던전 소개와 익히는 기술이 있습니다. 지도를 누른 뒤에는 화살표로 옆 던전을 고를 수 있고 Enter 를 누르면 그 던전의 첫 문제 줄로 갑니다. 던전은 순서와 상관없이 모두 열려 있습니다. 지금은 던전 1~3 이 출제되어 있고, 나머지는 '준비 중'으로 보이다가 출제되면 [새 문제 받기]로 들어옵니다.

던전 하나는 기초, 중급, 보스 문제로 이뤄지고, 선택 문제가 있는 던전도 있습니다.

- 기초 문제는 중급을 풀기 전에 손에 익히는 준비 문제라서 건너뛰어도 됩니다. 중급 문제의 [문제] 탭 맨 위에 "준비 문제 1-1 장부 정산"처럼 연결된 앞 문제(대개 기초 문제)가 나옵니다.
- 그 던전의 중급 문제를 모두 통과하면 보스 문제가 열립니다. 잠긴 보스 줄은 앞에 자물쇠가 붙고 눌리지 않습니다. 둘째 줄에 여는 조건과 지금 통과한 수가 나옵니다.
- 보스를 통과하면 그 던전을 클리어합니다. 지도의 원이 초록으로 바뀌고, 보스에서 새로 익힌 기술이 목록 아래에 나옵니다.
- 선택 문제는 보스와 상관없이 따로 연습하는 문제입니다. 보스 잠금과 첫 화면 알고리즘 여행 줄의 '다음은 …'(다음에 풀 문제)에 들어가지 않습니다.

문제 줄의 둘째 줄에 있는 `S3 / Lv2` 같은 글자는 난이도이고, 앞은 백준 티어, 뒤는 프로그래머스 레벨입니다. 줄 끝에는 기초, 중급, 선택, 보스가 나옵니다. 줄을 한 번 누르거나 키보드로 고른 뒤 Enter 를 누르면 문제 화면이 열립니다.

### 언어 고르기

지도와 문제 화면 오른쪽 위의 [Python], [JavaScript]로 풀 언어를 고릅니다. 고른 언어는 이 컴퓨터에 기억되어 다음에 켜도 이어집니다. 코드는 언어마다 따로 저장되어서 언어를 바꿔도 다른 언어로 쓰던 코드가 지워지지 않습니다. 한 언어로 통과하면 그 문제를 통과한 것이고, 같은 문제를 두 언어로 모두 풀어 볼 수도 있습니다.

JavaScript 는 Node.js 가 있어야 고를 수 있습니다. Node.js 를 찾지 못하면 'Node.js 찾기' 창이 뜨고 Python 으로 계속 풉니다. 그동안 지도에는 Node.js 가 필요하다는 주의 띠와 [Node 찾기]가 보이고 문제 화면에는 언어 단추 옆에 'Node.js 필요'가 보입니다. 설치 방법은 아래 [Node.js 설치](#nodejs-설치)에 있습니다.

### 문제 화면

왼쪽 카드에는 [문제], [힌트], [해설] 탭이 있고 오른쪽에는 코드 칸과 그 아래 결과 카드가 있습니다. 위쪽 [← 알고리즘 여행]을 누르면 지도로 돌아갑니다. 두 칸 사이나 코드 칸과 결과 카드 사이의 손잡이를 끌어 크기를 바꿀 수 있습니다. 앱을 다시 켜도 바꾼 크기로 열립니다. 손잡이를 두 번 누르면 처음 크기로 돌아갑니다.

- 위쪽 문제 이름 옆에 역할(기초, 중급, 선택, 보스)과 번호가 나옵니다. [문제] 탭 맨 위에는 난이도와 고른 언어의 시간 제한이 있습니다. 중급 문제는 그 아래에 준비 문제가 나옵니다. 준비 문제 이름을 누르면 그 문제가 열립니다.
- 문제를 열면 바로 코드 칸에 쓸 수 있습니다. 코드 칸에서 Esc 를 누르면 탭으로 나갑니다. 찾기 막대가 떠 있을 때는 Esc 가 막대를 닫습니다.
- 코드는 적는 대로 저장되고 위쪽에 '저장했습니다'가 나옵니다. Ctrl+S(맥은 Cmd+S)를 누르면 바로 저장합니다. 저장하지 못하면 코드 칸 위에 빨간 띠가 뜹니다. 다른 프로그램이 풀이 파일을 열고 있다면 닫으세요. [코드 되돌리기]를 누르면 처음 받은 코드로 돌아갑니다.
- 이 화면에서는 복사와 붙여넣기가 됩니다. 앞 던전에서 직접 만든 자료구조 코드를 뒤 던전에서 다시 쓸 수 있게 열어 두었습니다. 파이썬 스터디의 회차 화면은 지금처럼 막혀 있습니다.
- 줄 번호, 찾기(Ctrl+F), 주석(Ctrl+/)은 파이썬 스터디의 코드 칸과 같게 동작하고, 맥은 Ctrl 대신 Cmd 를 누릅니다. JavaScript 에서는 Ctrl+/ 가 줄 앞에 `// ` 를 붙입니다.
- 보스 문제는 [문제] 탭 맨 위에 "이 던전의 3-1~3-3에서 익힌 기술을 함께 씁니다." 같은 줄이 나옵니다.
- 같은 실행 안에서 다른 문제를 갔다 오면 보던 탭과 읽던 자리로 돌아옵니다.

### 코드 실행과 채점

- [코드 실행]은 입출력 예와 내가 추가한 테스트를 돌리고, 테스트마다 입력값, 기댓값, 실행 결과, 출력을 보여 줍니다. 테스트 하나를 10초까지 기다리고 기록하지 않습니다. Ctrl+Enter(맥은 Cmd+Enter)로도 실행합니다.
- [테스트 추가]로 내 테스트를 20개까지 더합니다. 값은 파이썬이나 JSON 문법(`["a", "b"]`, `3`, `True`)으로 적고, [예시에서 가져오기]에서 입출력 예를 고르면 그 값을 채운 줄이 하나 생겨서 조금 고쳐 경계 사례(빈 목록, 가장 큰 값처럼 실수하기 쉬운 입력)를 만들 수 있습니다. 틀린 칸은 테두리가 빨갛게 바뀌고 창 아래에 까닭이 한 줄로 나옵니다. 추가한 테스트는 Python 과 JavaScript 가 같이 씁니다.
- [채점하기]는 숨은 테스트까지 돌려 정확성과 효율성 점수를 매기고 기록합니다. Ctrl+Shift+Enter(맥은 Cmd+Shift+Enter)로도 채점합니다. 정확성 테스트는 입출력 예, 경계 사례, 작은 무작위 입력이고, 효율성 테스트는 시간 제한 안에 끝나야 하는 큰 입력입니다. 테스트마다 "테스트 3 〉 통과 (0.42ms, 15.3MB)" 같은 줄이 하나씩 붙고, 100점이면 통과입니다.
- 결과 카드 맨 위에 "테스트 3개 중 2개 통과", "100점 중 41.5점" 같은 결과와 막대가 나오고 그 아래에 테스트 줄이 이어집니다. 실행하는 동안에도 맨 위 줄은 그 자리에 있고 테스트 줄만 늘어납니다.
- 아직 실행하지 않은 문제는 결과 카드가 접혀 있어 코드 칸이 깁니다. 처음 [코드 실행]이나 [채점하기]를 누르면 펼쳐집니다.
- 처음 통과하면 결과 카드에 [해설 보기]가 나옵니다. 그 던전의 보스가 열리면 [보스 풀기]도 나옵니다.
- 실행이나 채점이 오래 걸리면 [중지]를 누릅니다. 중지한 채점은 기록하지 않습니다.
- 채점 결과는 이 컴퓨터에만 기록됩니다. GitHub 에 올리는 것은 첫 화면의 [풀이 제출]로 따로 합니다.

배점, 시간 제한, 통과 판정은 [docs/CRITERIA.md](docs/CRITERIA.md)의 '알고리즘 여행'에 있습니다.

### 힌트와 해설

- [힌트] 탭에서 [힌트 1 보기]부터 한 단계씩 엽니다. 뒤 단계일수록 풀이에 가까운 내용이 나오고, 연 단계는 기록에 남습니다.
- 해설은 그 문제를 한 언어로라도 통과하면 열립니다. 해설에는 풀이 설명과 그림, 고른 언어의 기준 풀이, 더 풀어 볼 실제 문제(백준, 프로그래머스)가 들어 있고, 보스 해설에는 어느 부분을 어느 문제에서 익혔는지 정리한 '보스에 쓰인 기술' 표가 더 있습니다. 해설 끝에는 다음에 풀 문제가 나옵니다. 칸이 좁아 그림이 줄어 보이면 [크게 보기]나 그림을 눌러 원래 크기로 봅니다.
- 통과하기 전에 해설을 보려면 [해설] 탭의 [해설 먼저 보기]를 누릅니다. 확인 창에서 [해설 열기]를 누르면 해설이 열리고 기록에 '해설 보고 풂'으로 남으며, 그 뒤에 통과하면 지도에 '해설 보고 통과'로 나옵니다.
- 해설이 열린 문제를 채점하면 실패한 정확성 테스트 줄 끝에 그 테스트가 확인하는 경계 사례가 적힙니다. 테스트의 입력값과 기댓값은 해설이 열린 뒤에도 보여 주지 않습니다.

### 생성 입력 캐시

생성기로 만드는 테스트 입력(효율성 테스트의 큰 입력, 정확성 테스트의 작은 무작위 입력 묶음)은 처음 채점할 때 이 컴퓨터에서 만들고, `~/.rokey-study/journey-cache/`(Windows 는 `C:\Users\<사용자 이름>\.rokey-study\journey-cache`)에 보관해 두었다가 다음 채점부터 다시 씁니다. 그래서 문제마다 첫 채점은 입력을 만드느라 더 오래 걸립니다. 보관한 입력이 모두 합쳐 1GB 를 넘으면 오래 쓰지 않은 것부터 지웁니다.

보관한 입력이 1MB 를 넘으면 지도 오른쪽 위에 [캐시 비우기]가 나옵니다. 누르면 지금 크기가 적힌 확인 창이 뜹니다. [지우기]를 누르면 보관한 입력을 모두 지웁니다. 지워도 코드와 기록은 남고, 다음 채점 때 입력을 다시 만듭니다.

### 기록

알고리즘 여행의 코드와 기록은 `submissions/<내 ID>/journey/` 에 저장됩니다. 코드는 문제와 언어마다 `d01/p1.py`, `d01/p1.js` 같은 파일이고 시작 코드를 고쳤을 때만 생깁니다. 채점, 연 힌트, 통과 전에 연 해설은 `progress.json` 에 쌓이고 [코드 실행]은 쌓이지 않습니다. 고른 언어와 마지막으로 연 문제는 이 파일이 아니라 컴퓨터마다 따로 기억합니다.

## 웹 면접 준비

프론트엔드 채용의 라이브 코딩과 직무 면접을 연습하는 트랙입니다. 라이브 코딩은 면접 전에 작은 React + TypeScript 코드베이스를 받아 읽고, 면접 시간에 면접관이 하나씩 건네는 요구를 그 코드 위에서 고치는 전형입니다. 직무 면접에서는 답에 나온 낱말을 붙잡아 원리까지 한 단계씩 더 묻는데, 그런 질문 묶음을 이 프로그램에서는 꼬리 질문 사슬이라고 부릅니다. 트랙은 라이브 코딩 미션, 꼬리 질문 사슬, 두 가지에 필요한 개념을 채우는 학습 노트로 이루어집니다. 토스증권 2026년 공고에 적힌 전형 형식을 따라 새로 지은 연습 문제이고, 실제 출제 문제와는 관계가 없습니다.

첫 화면의 공부 트랙에서 웹 면접 준비 줄을 누르면 웹 홈이 열립니다. 위 막대에 검사 도구 상태와 [설치 관리]가 보이고, 그 아래에 이어서 할 일 카드, 오늘 복습, 라이브 코딩 미션, 꼬리 질문, 학습 노트 목록이 이어집니다. 목록의 줄을 누르면 그 화면으로 바로 가고, 이어서 할 일 카드의 파란 단추는 지금 하던 미션이나 오늘 복습을 엽니다. 둘 다 없으면 권장 순서에서 다음에 할 학습 노트, 미션, 사슬을 엽니다. 지금은 미션 w01(상품 목록에 검색 붙이기)과 w03(거래내역 불러오기), 주제 1·3·6·7·11 의 사슬, 학습 노트 l01·l03·l06·l07·l11·l20·l21 이 출제되어 있습니다. 나머지는 목록 끝의 [준비 중 N개 보기]를 누르면 이름이 보이고, 출제되면 [새 문제 받기]로 들어옵니다.

창 없이 풀 때는 터미널 명령 `python study.py web …` 을 씁니다. 명령 목록은 `python study.py web --help` 로 보고, 다른 터미널 명령과 같이 `start.bat` 이 있는 폴더에서 입력합니다. 화면과 명령은 같은 기록(`record.json`)을 쓰므로 섞어 써도 됩니다.

### 준비하기

꼬리 질문 사슬과 학습 노트는 Python 만 있으면 됩니다. 라이브 코딩 미션은 Node.js 22.12 이상과 검사 도구가 있어야 합니다. 검사 도구는 미션의 단계 검사를 돌리는 vitest, jsdom, React, Testing Library 묶음이고, 웹 홈 위 막대의 [설치 관리]를 누르면 설치 상태를 보여 주는 창이 열리고, 무엇을 어디에 설치하는지는 그 창의 [자세히]에 있습니다. [설치하기]를 누르면 저장소 맨 위 `package.json` 에 적힌 판이 저장소 맨 위 `node_modules` 폴더에 설치되고, 진행 중에는 설치 로그의 끝 몇 줄이 창에 보입니다. 설치한 크기는 약 80MB 이고 저장소에는 올라가지 않습니다. 인터넷은 처음 설치할 때 한 번 필요하고, 그 뒤 검사는 인터넷 없이 돕니다. 설치한 뒤에는 같은 창의 [자세히] 안에 [다시 설치하기]와 [지우기]가 있습니다. 검사 도구 없이 미션을 받으려 하면 설치할지 묻고, 그냥 받으면 코드를 읽고 고칠 수는 있지만 [검사하기]는 설치한 뒤에 됩니다.

터미널에서는 아래 명령이 같은 일을 합니다.

```bash
python study.py web status       # 찾은 Node.js 판, 검사 도구 설치 여부, 미션·사슬·학습 노트 현황, 오늘 복습
python study.py web install      # 검사 도구 설치. 무엇을 어디에 설치하는지 보여 주고 "설치할까요? (y/n)" 를 묻습니다
python study.py web uninstall    # 검사 도구 지우기
```

`install --yes` 는 묻지 않고 설치합니다. 설치는 10분 안에 끝나야 하고, 진행 내용은 `~/.rokey-study/web/install.log` 에 남습니다. 실패하면 창과 터미널 모두에 이유와 로그 위치가 나옵니다. 저장소의 패키지 목록이 바뀌면 웹 홈 위 막대에 '검사 도구 다시 설치 필요'가, `status` 에 "패키지 목록이 바뀌었습니다" 가 나오고, [설치 관리]의 [다시 설치하기]나 `install` 을 한 번 더 실행하면 됩니다.

Node.js 는 알고리즘 여행과 같은 자리에서 찾되 22.12 이상인 판만 받고, 알고리즘 여행의 'Node.js 찾기' 창에서 고른 위치도 같이 봅니다. 프로그램을 켤 때 한 번 찾고, 찾은 판은 [설치 관리] 창의 [자세히]에 보입니다. nvm 이나 nvm-windows 로 여러 판을 두었다면 기본 판을 22.12 이상으로 두거나, 환경 변수 `STUDY_NODE` 에 node 실행 파일 경로를 적습니다. 설치 방법은 아래 [Node.js 설치](#nodejs-설치)에 있습니다.

### 라이브 코딩 미션

미션은 시작 전, 진행 중(읽는 중과 실전 중), 끝남 상태를 지납니다. 웹 홈의 미션 목록에서 줄을 누르면 미션 화면이 열립니다. 위 막대에 남은 시간이, 그 아래에 단계 표시(끝난 단계는 체크, 지금 단계는 파란 원, 넘어간 단계는 주황 줄, 열리지 않은 단계는 번호만)가 보이고, 왼쪽 카드에는 읽기 안내나 지금 요구가, 오른쪽 카드에는 미션 정보나 검사 결과가 나옵니다. 시계는 모두 기록된 시각으로 계산해서 프로그램을 껐다 켜도 이어 흐르고, 일시정지는 없습니다.

1. [미션 받기]를 누르면 미션 코드가 `submissions/<내 ID>/web/missions/w03/` 에 복사되고 읽기 시간(w03 은 20분)이 시작됩니다. [폴더 열기]를 누르면 그 폴더가 Cursor 나 VS Code(없으면 탐색기)로 열립니다. 읽기 안내대로 에디터의 터미널에서 `npm run dev` 와 `npm test` 를 돌려 봅니다. 아래 막대의 [화면 띄우기]를 누르면 `npm run dev` 와 같은 서버가 떠서 브라우저에 앱이 열리고, [화면 끄기]를 누르거나 미션 화면을 떠나거나 프로그램을 닫으면 서버가 꺼집니다. [테스트 돌리기]는 `npm test` 와 같은 테스트를 돌려 통과한 개수를 위 막대의 미션 이름 오른쪽에 적고, 실패가 있으면 첫 실패 문구를 창으로 보여 줍니다. 두 단추는 미션을 받고 검사 도구를 설치한 뒤에 켜집니다. 패키지는 저장소 맨 위에 설치되어 있으니 미션 폴더에서 `npm install` 을 하지 않습니다. 따로 설치하면 React 가 두 벌 읽혀 `Invalid hook call` 오류가 날 수 있어서 검사 전에 경고가 나옵니다. 읽기 시간이 끝나면 시계가 빨갛게 지난 시간을 셉니다.
2. 오른쪽 카드의 '에디터의 AI 자동완성을 껐습니다'에 표시하고(기록만 합니다) [실전 시작]을 누르면 실전 시간(w03 은 45분)이 시작되고 0단계가 열립니다. 읽기 시간이 남아 있어도 시작할 수 있습니다.
3. 0단계는 받은 코드를 목표 시간(w03 은 3분) 동안 설명하는 단계입니다. 자동 검사가 없고, 목표 시간이 지나면 점검 항목이 열립니다. 말한 항목에 표시하고 [설명 끝내기]를 누르면 1단계 요구가 열립니다.
4. 1단계부터는 왼쪽에 면접관의 요구, 검사가 확인하는 내용, 목표 시간 막대가 나옵니다. 코드를 고친 뒤 [검사하기]를 누르면 1단계부터 지금 단계까지의 검사가 모두 돌고, 오른쪽에 통과한 검사 수와 검사마다 통과·실패가 나옵니다. 실패한 검사의 영어 원문은 [원문 보기]로 펼칩니다. 지금 단계의 검사를 모두 통과하면 다음 요구가 열립니다. 앞 단계 검사가 깨지면 깨진 단계가 나오지만 진행을 막지는 않습니다. 단계에 따라 통과한 뒤 면접관이 이어서 묻는 질문이 나오는데, 30초 시계 안에 소리 내어 답하고 말한 항목에 표시한 뒤 [답을 마쳤습니다]를 누릅니다.
5. [힌트 듣기]는 언제든 누를 수 있고 누른 시각이 기록에 남습니다. [이 단계 건너뛰기]는 그 단계의 목표 시간이 지나면 켜지고, 넘어간 단계로 기록됩니다. [안내 다시 보기]로 읽기 안내를 다시 볼 수 있습니다.
6. 모든 단계를 통과하거나 [실전 끝내기]를 누르면 끝납니다. 왼쪽 카드의 해설, 내 코드와 비교, 스스로 점검 탭에 단계별 결과와 해설, 내 코드와 모범 답안의 차이, 템플릿과 모범 답안의 차이, 스스로 점검 항목이 나옵니다. 요구에 나오지 않은 버그를 숨긴 미션은 이때 숨긴 검사를 한 번 돌립니다. 스스로 점검 항목은 표시하면 바로 기록에 남습니다. 끝난 미션을 다시 열면 같은 해설이 보입니다.
7. 오른쪽 카드의 '이어서 할 일'에서 이 미션의 꼬리 질문 줄을 누르면 그 미션의 꼬리 질문 사슬이 열리고, 학습 노트 줄을 누르면 묶인 학습 노트를 읽습니다. 꼬리 질문은 미션을 끝내기 전에는 열리지 않습니다. 처음부터 다시 풀려면 아래 막대 왼쪽의 [다시 하기]를 누릅니다. 내 폴더가 템플릿으로 덮어써지고 기록은 새 시도로 나뉘므로, 지난 코드를 남기려면 그 전에 [풀이 제출]로 올려 둡니다.

실전 시간이 지나도 시계는 멈추지 않고 넘긴 시간을 빨갛게 따로 셉니다. 읽기 시간과 면접 시간을 어떻게 쓸지는 학습 노트 l21(라이브 코딩 60분 운영표)에 있습니다.

Windows 의 VS Code·Cursor 터미널은 기본이 PowerShell 이라서 `npm run dev` 가 "npm.ps1 파일을 로드할 수 없습니다" 오류로 막힐 수 있습니다. PowerShell 은 `npm` 을 스크립트 파일 npm.ps1 로 찾는데, Windows 의 기본 실행 정책이 스크립트 실행을 막기 때문입니다. `npm.cmd run dev`, `npm.cmd test` 로 입력하거나 [화면 띄우기]와 [테스트 돌리기]를 쓰면 되고, `Set-ExecutionPolicy` 로 실행 정책을 바꾸지 않아도 됩니다. 두 단추는 npm 을 거치지 않고 `npm run dev` 가 부르는 개발 서버 vite 와 `npm test` 가 부르는 vitest 를 node 로 바로 실행합니다.

터미널에서는 `python study.py web get w03`(받기, 처음부터 다시 하려면 `--again`), `start w03`, `check w03`(0단계면 점검 항목 표시, 그 뒤는 단계 검사), `hint w03`, `skip w03`, `finish w03`, `dev w03`(화면 띄우기, Ctrl+C 로 끄기), `test w03`(테스트 돌리기) 이 같은 일을 합니다. 통과 뒤 질문에 답하지 못하고 넘어갔으면 `answer w03` 으로 다시 답합니다. 묻는 자리에 답을 미리 적어 둘 수도 있어서 `start w03 --no-ai yes`, `check w03 --said 1,3`, `answer w03 --said 1,2`, `finish w03 --self 1,2` 처럼 적으면 묻지 않습니다. 터미널에서는 0단계 목표 시간이 지나기 전에도 `check w03` 으로 점검 항목에 표시하고 1단계로 넘어갈 수 있습니다.

### 꼬리 질문 사슬

웹 홈의 오늘 복습이나 꼬리 질문 목록에서 사슬 줄을 누르면 그 사슬이 열립니다. 주제 칩을 누르면 그 주제의 사슬 목록으로 바뀝니다. 사슬 화면에는 면접관 질문이 크게 나오고, 그 아래에 면접관이 보여 주는 코드와 말한 내용을 적는 칸이 있습니다. 사슬 소개는 [배경 보기]를 누르면 코드 위에 펼쳐집니다.

1. 질문마다 답 시간(대개 60초)이 막대로 차오르는 동안 소리 내어 답하고 [답 확인]을 누릅니다. 시간이 지나도 막지 않고 넘긴 초만 빨갛게 세어 기록합니다. 모르겠으면 [모르겠습니다]를 누릅니다. 말한 내용을 적는 칸은 선택이고 500자까지입니다.
2. 답에서 짚어야 할 내용이 목록으로 나옵니다. 필수 꼬리표가 붙은 항목은 답에 꼭 들어가야 하는 내용이고, 보충 항목은 더 말하면 좋은 내용입니다. 말한 항목에 표시합니다. 이 사슬을 전에 풀었다면 그때 적은 답과 항목마다 그때 표시했는지가 함께 보입니다.
3. 필수 항목을 빠뜨리면 그 질문에서 꺼낼 수 있는 말을 적은 '막히면' 안내와 '막힌 곳에서 아는 데까지 말했습니다' 표시가 나옵니다. 이 표시는 판정에 들어가지 않습니다. 사슬 끝 화면에 표시한 질문 수가 나오고, 웹 홈 꼬리 질문 목록 아래에 표시한 비율이 나옵니다.
4. [다음 질문]을 누르면 그 질문의 판정이 기록되고 다음 질문이 나옵니다. 적어 둔 내용은 다음 복습 때 지난 답으로 보입니다. 적은 내용은 [풀이 제출]하면 공개 저장소에 올라가니 그 점을 생각해 적습니다.
5. 마지막 질문에서 [사슬 끝내기]를 누르면 통과한 질문 수와 다음 복습 날짜, 질문별 판정(통과·부분·막힘), 약한 답 예시와 이어서 답한 예가 나오고, 맨 아래 학습 노트 줄을 누르면 그 사슬의 원리가 적힌 절로 갑니다. [한 번 더 풀기]로 같은 사슬을 바로 다시 풀 수 있습니다.

터미널에서는 `python study.py web drill 3-A` 처럼 사슬 id 를 적으면 그 사슬을 풀고, id 를 비우면 오늘 복습 목록의 첫 사슬을 풉니다. 질문마다 답한 뒤 Enter 를 누르고(모르겠으면 `m`), 말한 항목의 번호를 띄어쓰기로 적습니다. 사슬 id 는 `status` 의 주제 목록에 나옵니다.

## AI 비전 개론

ROKEY AI 비전 개론 강의(17차시)의 개념과 코드를 익히는 트랙입니다. 차시마다 학습 단원을 읽고, 그 단원에서 나온 빈칸·고르기 문제를 풉니다. 맞힌 문항도 며칠 간격을 두고 다시 나옵니다. 하루에 몇 단원, 몇 문항을 풀라는 목표는 없고 문제집을 원하는 만큼 풉니다. PyTorch 는 설치하지 않으며 코드는 실행하지 않고 빈칸과 고르기로만 묻습니다. 1~17차시와 상황별 코드 연습, 모의고사 3회가 공개되어 있습니다.

15차시에서는 이미지 크기를 맞추는 여러 설정과 검증 결과로 모델 상태를 골라 복원하는 방법을 비교합니다. 설명에 필요한 조건·코드·그림을 같은 단원에 두어 외부 노트북 번호를 몰라도 따라갈 수 있게 했습니다.

16차시에는 숫자 이미지의 CNN 모양·hook·Dropout·증강과 모델 선택을 연결하는 단원을 더했습니다. 17차시에는 토큰화에서 Trainer 학습과 검증 모델 선택, accuracy·F1 계산까지 이어지는 단원을 더했습니다. 두 단원은 그림 9장과 새 고정 문항 10개, 참거짓 16개, 수치를 바꿔 내는 계산 문제 2종으로 연습합니다. 예시 수치와 모델을 실행해 측정한 결과는 구분합니다.

첫 화면의 AI 비전 개론 카드를 누르면 홈이 열립니다. [학습·사용 안내]는 실제 화면에 번호와 테두리를 표시한 안내 팝업입니다. [이전]·[다음]으로 넘기며 따라 하고, 작은 글씨는 [크게 보기]로 확인합니다. 학습 단원을 읽고 [연습 시작]으로 문제를 푼 뒤, 문제집의 복습을 따로 진행할 수 있습니다.

- 이어서 할 일은 마지막으로 중단한 학습 단계나 미완료 풀이 묶음으로 돌아갑니다. 단원 연습 묶음을 끝내면 같은 차시의 다음 단원, 마지막 단원까지 끝내면 다음 차시의 첫 단원을 안내합니다. 최근 수업 날짜나 복습 일정이 이 대상을 바꾸지 않습니다. 단원 연습 완료와 모든 문항 숙달은 구분합니다.
- 학습 단원 목록의 차시 줄에는 읽은 단원 수가 나오고, 누르면 차시 화면이 열립니다. 단원 줄에는 읽기·단원 연습·복습 확인을 나누어 표시합니다. 아래 막대의 [이 차시 풀기]는 홈의 차시 문제집과 같습니다. 위 막대의 [전체 노트]는 차시의 모든 단원을 정답을 편 채로 다시 읽는 화면이고, [외울 것]은 단원마다의 외울 것 질문을 모아 답을 가린 채 보여 줍니다.
- 「문제집」 제목 아래에 복습 확인의 기준이 나옵니다. 섞어 풀기는 읽은 단원의 문항을 차시를 섞어 20문항씩 내고 복습 문항이 앞에 나옵니다. '1차시 문제집' 같은 차시 문제집은 단원을 읽지 않아도 그 차시의 모든 문항을 20문항씩 냅니다. 줄마다 복습 확인 묶음 수와 복습 문항 수가 나오고, 같은 문제집을 몇 번이든 다시 풀어도 됩니다. 오답 노트 줄을 누르면 공유 오답 노트가 AI 비전 개론 칩으로 열립니다.
- 상황별 코드 목록에는 여러 차시에서 나온 코드를 '학습 루프' 같은 상황 하나로 모은 단원이 나옵니다. 줄에는 몇 차시 뒤에 읽기를 권하는지가 나오지만 그 차시를 읽기 전에도 열 수 있습니다. 단원을 읽으면 그 단원 문항이 섞어 풀기와 복습에 나오고, 권하는 차시의 문제집에도 섞여 나옵니다. 학습 루프·평가·회귀·이진 분류·다중 분류·CNN·파일 데이터·전이 학습의 여덟 단원이 공개되어 있습니다.

학습 화면은 입력 준비, 예측, 손실, 기울기, 갱신과 별도 평가를 그림으로 연결합니다. 단원 처음과 마지막에는 전체 흐름을 펴서 보여주고, 중간에는 현재 연결 과정을 표시하며 [전체 흐름 보기]로 펼칩니다. 마지막에는 이 과정이 필요한 이유를 다시 생각해 볼 수 있습니다.

10~17차시 첫 단원의 마지막에는 앞뒤 차시를 잇는 그림이 있습니다. 같은 분류 예에서 입력·특징·점수의 모양과 배치 수를 따라가며, 이번에 바꾸는 것과 유지하는 것을 구분합니다. 차시 본문의 실험과 구별한 설명용 예이며, 사진에서 문장으로 입력이 바뀌어도 점수·손실·갱신의 관계를 이어 봅니다.

여러 차시와 공식 학습 예제에서 반복하는 핵심어는 형광펜과 볼드로, 긴 핵심 원리는 밑줄로 표시합니다. 색만으로 뜻을 구분하지 않으며 코드와 수식의 글자 위치는 유지합니다.

두 코드를 나란히 보며 다른 줄을 확인하고, 코드 빈칸을 한 자리씩 채워 보는 단계도 있습니다. 한 자리씩 채울 때는 답 확인 뒤 정답과 그 자리에 연결된 해설을 보여 줍니다. 틀린 자리는 세 자리 뒤에 다시 나옵니다. 이 단계의 답은 복습 상자에 반영하지 않습니다.

읽기 마침, 단원 연습 마침, 복습 확인은 서로 다른 기록입니다. 복습 확인은 예정된 복습에서 서로 다른 날의 첫 답을 세 번 연속 맞힌 문항 묶음 수입니다. 단원을 읽은 날은 제외합니다. 같은 내용을 묻는 여러 형태는 한 묶음으로 세며, 이미 풀어본 형태가 모두 기준을 충족해야 그 묶음을 확인한 것으로 셉니다. 기준을 충족한 묶음이 없으면 복습 확인 전으로 표시합니다.

### AI 비전 개론 모의고사

모의고사는 3회이며 각 30문항·60분입니다. 1회는 1~12차시, 2·3회는 1~17차시를 다룹니다. 시작 전에는 범위를 확인하고 [시작]을 누릅니다. 제출한 뒤 정답과 해설을 확인합니다. 중간에 나가도 시간은 계속 흐르며 홈의 모의고사 목록에서 이어 풉니다.

### 학습 단원

학습 본문과 입력은 보통에서 22px·줄 높이 40px, 크게에서 24px·44px, 더 크게에서 26px·48px로 표시합니다. 읽기 영역은 큰 창에서 1600px까지 넓어지고 문단과 그림·물음 사이를 띄웠습니다. 좁은 표는 열 제목과 항목별 값을 세로로 나누어 보여 줍니다. 작은 창에서는 화면 폭에 맞추며, 그림 속 글자도 본문 크기와 함께 커집니다. 전체 노트와 세 단계 설명에도 같은 기준을 적용합니다.

단원은 설명·그림·확인 물음을 단계별로 보여 줍니다. 위 막대 아래의 단계 표시에서 지금 단계가 파란 원으로 보이고, 아래 막대의 [이전]·[다음]이나 ←·→ 키로 넘깁니다. 입력 칸이나 그림을 고른 동안에는 ←·→ 가 그쪽에서 쓰이므로 Alt+←·→ 로 넘깁니다. 수업에서 들은 단원은 위 막대의 [외울 것으로]를 눌러 마지막 단계로 바로 갈 수 있습니다.

- 첫 단계 「먼저 풀어 보기」는 설명을 읽기 전에 짐작으로 고르는 문항입니다. 보기를 고르면 바로 기록되고 몇 단계에서 답을 확인하는지 나옵니다. 그 단계를 떠나기 전까지는 다른 보기로 바꿀 수 있습니다. 채점하지 않고, 고른 답과 정답은 뒤 단계의 「짐작 확인」에 나옵니다.
- 그림이 움직이는 그림이면 1장에서 멈춘 채 열리고, [처음]·[이전 장]·[재생]·[다음 장]으로 넘깁니다. 지금 장의 설명이 그림 바로 아래에 나오고 장을 넘기면 같이 바뀝니다. 그림을 누른 뒤에는 ←·→ 로도 장을 넘기고, Alt+←·→ 는 단계를 넘깁니다.
- 그림의 [크게 보기]를 누르면 확대창이 열립니다. 작은 창에서 한 번에 보이지 않는 부분은 가로·세로 스크롤로 확인하고 [닫기]로 학습 화면에 돌아옵니다.
- 그림을 읽지 못하면 저장된 캡션·대체 내용·장별 설명을 표시합니다. [다시 시도]는 같은 자리에서 그림 파일만 다시 읽습니다. 학습 단계나 답안은 다시 열지 않으며 파일이 계속 없거나 손상됐으면 설명과 안내를 유지합니다.
- 「떠올리기」는 빈칸 하나를 적고 [확인]을 누르면 바로 맞고 틀림, 정답, 까닭이 나옵니다. 칸이 비어 있으면 채점하지 않습니다. 틀려도 다음 단계로 넘어갈 수 있고 복습 날짜에는 들어가지 않습니다.
- 「왜일까요?」는 질문을 읽고 답을 충분히 생각한 뒤 펼쳐보세요. [답 보기]를 누르면 이유를 확인할 수 있습니다.
- 어려운 개념이 나오는 단계 끝에는 「세 단계로 다시 보기」가 접혀 있습니다. 펴면 같은 개념을 초급 수준은 숫자와 그림으로, 중급 수준은 계산과 식으로, 심화 수준은 정의와 코드로 차례로 설명합니다. 수준마다 확인 물음에 답을 적고 [확인]을 누르면 떠올리기처럼 바로 맞고 틀림이 나옵니다. 결과는 떠올리기처럼 기록되고 복습 날짜에는 들어가지 않습니다. 전체 노트와 [노트 보기] 창에서도 접혀 있고, 펴면 입력 칸 대신 확인 물음의 정답과 까닭이 나옵니다.
- 확인한 원리와 조건은 본문과 해설에서 바로 설명합니다. 자료의 오류를 대조한 기록은 학습 화면의 별도 정정 상자로 표시하지 않습니다. 「보충 설명」은 필요한 배경을, 「심화」는 더 깊은 내용을 다룹니다. 「2026 흐름 · 시험 범위 밖」은 접혀 있습니다.
- 마지막 단계 「외울 것」은 질문 목록입니다. 질문을 읽고 답을 충분히 생각한 뒤 펼쳐보세요. 이 단계를 열기만 해서는 완료되지 않습니다. [연습 시작]을 누르면 읽기 기록을 남기고 해당 단원의 연습을 엽니다. 연습 묶음을 끝내면 다음 단원을 안내합니다.

읽다가 나가면 [이어서 학습]으로 보던 단원과 단계로 돌아갑니다. 같은 실행에서 같은 단원을 왕복하면 떠올리기 입력, 그림 장, 펼친 설명과 읽던 위치를 복원합니다. 프로그램을 다시 켜도 학습 단계는 남고, 미완료 연습 묶음은 같은 문항·보기·입력으로 이어집니다. 학습 본문의 모든 입력과 스크롤을 재시작 뒤까지 저장하는 기능은 아닙니다. 자료가 바뀌어 이전 문항과 맞지 않으면 옛 묶음을 그대로 재생하지 않습니다.

### 연습

연습 화면은 한 번에 한 문항을 보여 줍니다. 위 막대 오른쪽에 몇 번째 문항인지가, 카드 맨 위에 차시와 문항 꼴 꼬리표가 나오고, 상황별 코드 문항은 차시 대신 '학습 루프' 같은 상황 이름이 나옵니다. 묶음 제목이 차시를 말하는 차시 문제집과 단원 연습에서는 그 차시 문항에 차시 꼬리표를 붙이지 않습니다. 빈칸이 둘 이상이면 지문과 입력 칸에 ①② 번호가 붙고, 코드 안의 빈칸은 코드 줄 사이에 입력 칸이 놓입니다. Tab 으로 다음 칸에 갑니다. 하나만 고르는 보기는 둥근 표시, 여럿 고르는 보기는 네모 표시입니다. 시험처럼 복사와 붙여넣기는 막혀 있고, 글을 끌어다 놓아도 칸에 들어가지 않습니다.

- 답을 적거나 고른 뒤 [확실함]이나 [긴가민가]를 누릅니다. 이 두 단추가 답을 내는 단추이고, 묶음 첫 문항 아래에도 이 안내가 나옵니다. Ctrl+Enter(맥은 Cmd+Enter)는 [확실함], Ctrl+Shift+Enter 는 [긴가민가]입니다. 모르면 [모르겠어요]를 누르면 '모르는 문항으로 넘겼습니다'와 정답이 나옵니다.
- 답하면 카드 맨 위에 '맞았습니다', '일부 맞았습니다', '틀렸습니다'와 정답이 나오고 칸 테두리 색이 바뀝니다. 빈칸이 둘 이상이면 칸마다 '맞음'·'틀림'이 붙고, 코드 안 빈칸은 코드 아래 한 줄에 번호마다 나옵니다. 고르기는 보기마다 '정답'·'내 답' 꼬리표와 그 보기가 왜 맞거나 틀린지 한 줄이 붙습니다. 옳지 않은 것을 고르는 문항은 정답 줄 대신 '옳지 않은 문장' 줄이 나옵니다. 보기가 코드인 상황별 코드 문항은 정답 줄을 따로 쓰지 않고 보기의 '정답'·'내 답' 꼬리표로 보여 주며, 순서 고르기 보기에는 까닭 줄이 붙지 않고 해설이 순서를 설명합니다. 그 아래에 해설과 관련 학습 노트의 위치가 나옵니다. 노트 위치를 누르면 해당 단계를 엽니다.
- [확실함]을 누르고 틀리면 '확실하다고 했지만 틀렸습니다'가 나오고, 그 문항은 다음 날과 7일 뒤에 다시 나옵니다.
- 틀린 문항은 세 문항 뒤에 다시 나오고, 두 번 이어 맞히면 그 묶음에서 빠집니다. 다시 들어간 문항은 판정 아래에 몇 문항 뒤에 나오는지 적혀 있고, 그만큼 위 막대의 전체 문항 수가 늘어납니다.
- [노트 보기]는 그 문항의 근거가 된 학습 단계를 창으로 엽니다. 창을 닫아야 연습으로 돌아갑니다. 창 안의 떠올리기와 왜일까요는 답이 펴진 채로 나오고 기록에 남지 않습니다.
- 빈칸 답이 채점에서 틀렸지만 같은 뜻이라고 생각하면 [내 답도 맞음]을 누릅니다. 그 답은 맞은 것으로 바뀌고, 출제자가 모아 보고 받을 답에 더할지 정합니다.

묶음이 끝나면 이번 묶음의 첫 답에 맞힌 수, 새로 복습 확인 묶음 수, 다음 복습 날짜가 나옵니다. 오늘 새로 접한 문항은 이 묶음에서 마친 수를, 이전 학습일에도 풀었던 문항은 이번 첫 답에 맞힌 수를 따로 표시합니다. 단원을 읽은 날 틀린 문항이 있으면 그 문항은 오답 노트에 넣지 않았다는 줄도 나옵니다. 단원을 읽은 뒤 연 연습이면 [다음 단원]이(안 읽은 단원이 없으면 [섞어 풀기]가), 그 밖에는 [한 번 더]가 나옵니다. 자동 복습을 마쳤으면 다음 복습일과 홈으로 가는 단추를 보여 줍니다. 차시 문제집과 섞어 풀기에서는 계속 연습할 수 있습니다.

### 복습 확인

- 단원을 읽은 날에 맞힌 문항은 다음 날 다시 나옵니다. 그 뒤로는 맞힐 때마다 다음 복습까지의 간격이 1일, 2일, 4일, 7일, 14일로 늘고, 틀리면 다음 날로 돌아옵니다.
- 같은 날 두 번째로 맞히거나 복습 날짜 전에 맞힌 답은 간격을 늘리지 않습니다. 날짜가 되면 다시 확인합니다.
- 단원을 읽은 날을 제외하고 예정된 복습에서 서로 다른 세 날의 첫 답을 연속으로 맞히면 복습 확인 기준을 충족합니다. 같은 내용을 묻는 여러 형태는 한 묶음으로 셉니다. 기준을 충족한 뒤에도 7일, 14일 간격으로 나옵니다.
- 날짜는 새벽 4시에 바뀝니다. 밤 12시 전후에 푼 문항은 같은 날로 셉니다.
- 11월 25일부터 12월 1일까지는 그동안 연 문항이 모두 한 번씩 고르게 나뉘어 나옵니다.

### 오답 노트

그 문항의 단원을 읽은 날이 아닌 날에 그날 처음 낸 답이 틀린 문항이 오답 노트의 AI 비전 개론 칩에 차시별로 모이고, 상황별 코드 문항은 '상황별 코드' 묶음에 모입니다. 단원을 읽은 날 틀린 문항은 넣지 않고 다음 날 복습에서 다시 냅니다. 그날 [확실함]으로 틀린 문항은 넣습니다. [모르겠어요]를 누른 문항은 '미응답 문항'에, 그 뒤 다른 날 맞힌 문항은 '다시 맞힌 문항'에 들어가고 또 다른 날 한 번 더 맞히면 목록에서 빠집니다. 문항 줄에는 문항 꼴과 문제 첫머리가 나오고, 오른쪽 칸에 근거, 문제, 내 답이 나옵니다. [해설 보기]로 정답과 해설을 펴고 [다시 풀기]를 누르면 그 문항과 같은 갈래 문항으로 연습이 열립니다.

### 기록

연습의 답, 읽은 단원, 짐작과 떠올리기 결과는 `submissions/<내 ID>/ai/record.json` 에 쌓이고 [풀이 제출]을 누르면 같이 올라갑니다. 맞힌 답의 글은 남기지 않습니다. 단원에서 보던 단계는 저장소에 올리지 않는 `~/.rokey-study/ai/<내 ID>/state.json` 에 둡니다. 복습 날짜와 복습 확인 수는 기록에서 그때그때 계산하고 따로 저장하지 않습니다. 계산 규칙은 [docs/CRITERIA.md](docs/CRITERIA.md)의 'AI 비전 개론'에 있습니다.

## Node.js 설치

알고리즘 여행을 JavaScript 로 풀 때와 웹 면접 준비의 라이브 코딩 미션을 풀 때 필요합니다. 알고리즘 여행은 Node.js 20 이상, 웹 면접 준비의 미션은 22.12 이상이 있어야 합니다. 꼬리 질문 사슬과 학습 노트는 Node.js 없이 풉니다.

1. 터미널에서 `node --version` 을 입력합니다. `v22.23.2` 처럼 22.12 이상이 나오면 설치하지 않아도 됩니다. `v20.10.0` 처럼 20 이상 22.12 미만이면 알고리즘 여행만 됩니다.
2. 명령을 찾지 못하거나 판이 낮으면 [nodejs.org](https://nodejs.org) 에서 LTS 버전(오래 지원하는 안정판)을 내려받아 설치합니다. Windows 는 `.msi`, macOS 는 `.pkg` 설치 파일을 받아 기본값으로 설치합니다.
3. 알고리즘 여행에서 [JavaScript]를 누릅니다. 프로그램을 켜 둔 채로 설치했다면 이때 뜨는 'Node.js 찾기' 창의 [다시 찾기]를 누르거나 프로그램을 껐다 켭니다. 웹 면접 준비는 프로그램을 켤 때 찾은 판을 [설치 관리] 창의 [자세히]에서 보여 주고, 켜 둔 채로 설치했다면 껐다 켭니다.

프로그램은 PATH 에 등록된 폴더와 아래 폴더에서 node 를 찾습니다. Windows 는 기본 설치 폴더와 nvm-windows, Volta, Scoop 이 설치하는 폴더를 보고, macOS 는 기본 설치 폴더와 Homebrew, nvm, Volta, fnm 이 설치하는 폴더를 봅니다. macOS 에서 [다시 찾기]를 누르면 로그인 셸 설정(`.zprofile`, `.bash_profile`)에 넣은 PATH 도 살핍니다. 그래도 찾지 못하면 같은 창의 [직접 고르기]를 누르고 node 실행 파일을 고릅니다. 위치는 터미널에서 `where node`(macOS 는 `which node`)를 입력하면 나옵니다. 고른 위치는 이 컴퓨터에 기억되고 웹 면접 준비도 그 위치를 같이 봅니다. 웹 면접 준비의 화면과 터미널 명령은 이 창을 띄우지 않으므로, 같은 자리에서 찾지 못하면 환경 변수 `STUDY_NODE` 에 node 실행 파일 경로를 적어 둡니다.

## 문제를 고르는 방식

- 진단 테스트로 단원(차시)마다 출발 레벨을 정합니다. 레벨은 1 기본, 2 응용, 3 심화입니다.
- 회차마다 전 단원에서 15~30문항을 섞어 냅니다. 약한 단원이 더 자주 나오고, 틀린 문항은 2회차 뒤에 다시 나옵니다.
- 한 레벨에서 푼 문항이 2~3개면 전부 맞혀야 하고, 4개 이상이면 최근 4문항 중 3문항 이상을 맞혀야 다음 레벨로 올라갑니다.
- 레벨2를 통과한 단원을 숙달로 칩니다. 홈과 결과 화면에는 숙달한 단원 수를 보여 줍니다.
- 클래스 1·2, GUI, 예외 처리, 정규표현식 단원(9·10·11·13·14차시)은 추첨 가중치가 1.5배라 더 자주 나옵니다.

규칙과 숫자 전체는 [docs/CRITERIA.md](docs/CRITERIA.md)에 있습니다.

## 모의고사 보기

실전 모의고사는 3회(`m1`, `m2`, `m3`)가 있고 각각 120분, 100점입니다. `m1` 과 `m2` 는 1~16차시, `m3` 은 1~21차시에서 냅니다. `m3` 의 Q17, Q18, p02, p10 은 시험 범위 밖인 21차시 문항입니다. 화면이 아니라 터미널에서 봅니다. 전 단원을 숙달한 뒤에 보기를 권하지만 그 전에도 받을 수 있습니다. 아래는 1회 기준이고, 2회와 3회는 `m1` 자리에 `m2`, `m3` 을 씁니다.

1. `python study.py start m1` 을 실행합니다. 이때부터 120분을 잽니다. 남은 시간은 보여 주지 않으니 시계를 봅니다.
2. 문제지는 `problems/m1/quiz.md` 와 `problems/m1/p01/problem.md` 같은 파일이고, 답은 `submissions/<내 ID>/m1/` 의 `quiz.py` 와 `p01.py` 같은 파일에 적습니다. 파일은 메모장 같은 편집기로 엽니다.
3. `quiz.py` 는 화면과 달리 파이썬 값으로 적습니다. 객관식은 숫자(`Q1 = 3`), 출력 예측과 단답은 따옴표로 감싼 글자(`Q17 = "답"`), 여러 줄 출력은 `"""` 로 감쌉니다. 같은 안내가 `quiz.py` 맨 위에도 적혀 있습니다.
4. `python study.py grade m1` 로 채점합니다. 틀린 문항의 해설은 `python study.py explain m1 Q3` 처럼 봅니다.
5. 프로그램의 [제출(PR 올리기)]를 누르면 모의고사 풀이도 같이 올라갑니다.

## 안 될 때

### 창이 열리지 않을 때

창이 열리지 않고 오류만 나오면 터미널에서 `python study.py update` 를 실행해 새 버전을 받은 뒤 다시 켭니다. `update` 가 오류로 끝나면 바로 아래의 네 줄을 입력합니다.

`start.pyw` 나 `ROKEY.app` 으로 켰을 때 프로그램 오류로 창을 열지 못하면 알림 창이 뜨고, 오류 내용은 알림에 적힌 `~/.rokey-study/launch.log` 파일에 남습니다. 터미널에서 `python study.py` 로 켜면(macOS 는 `start.command`) 같은 오류가 검은 창에 나옵니다.

### 예전 버전을 받아 뒀거나 문제 받기가 계속 오류로 끝날 때

터미널에서 쓰던 예전 버전을 받아 뒀거나(폴더에 `start.bat` 이 없습니다), 프로그램을 켤 때마다 "문제를 받다가 오류가 났습니다"가 나오면 `programming-study` 폴더에서 아래 네 줄을 따옴표까지 똑같이 차례로 입력한 뒤 프로그램을 켭니다.

```bash
git fetch origin main
git reset -q FETCH_HEAD
git checkout -q -- ":(top)" ":(top,exclude)submissions"
git clean -fdq ":(top)problems"
```

새로 clone 하지 않아도 되고, 풀이 폴더(`submissions`)는 바뀌지 않아서 풀던 기록이 새 프로그램에서 이어집니다.

### ID 를 잘못 넣었을 때

프로그램을 끄고 `submissions/<잘못 넣은 ID>` 폴더 이름을 맞는 ID 로 바꾼 뒤, 터미널에서 `python study.py init <맞는 ID>` 를 실행합니다. 다시 켜면 풀던 기록이 이름을 바꾼 폴더에서 이어집니다. 잘못된 ID 로 이미 제출했다면 그 PR 은 스터디장에게 닫아 달라고 하세요.

### 제출이 안 될 때

프로그램이 띄운 안내마다 확인할 것을 [docs/GIT_GUIDE.md](docs/GIT_GUIDE.md#제출이-안-될-때)에 적어 두었습니다.

### 알고리즘 여행 줄에 기록을 읽을 수 없다고 나올 때

`submissions/<내 ID>/journey/progress.json` 을 읽지 못하면 첫 화면의 공부 트랙 아래에 이유가 나오고 알고리즘 여행 줄이 눌리지 않습니다. 파이썬 스터디 회차는 계속 풀 수 있지만, 이 파일을 고칠 때까지 프로그램을 켤 때와 [새 문제 받기]를 누를 때는 "알고리즘 여행 기록 파일(journey/progress.json)을 읽을 수 없어 멈췄습니다."가 나오며 문제를 받지 않고, [풀이 제출]은 "읽을 수 없는 풀이 파일이 있어 올리지 않았습니다"가 나오며 올리지 않습니다. 이 파일은 채점, 힌트, 해설 기록을 담은 JSON 파일이라, 메모장 같은 편집기로 열어 오류 문구가 가리키는 곳(JSON 형식이 깨졌으면 '4번째 줄 3번째 글자 근처'처럼 자리가 나옵니다)을 고친 뒤 프로그램을 다시 켭니다. 고치기 어려우면 그 문구를 적어 아래 '사용이 불편하거나 오류가 납니다' 이슈로 알려 주세요.

### 그 밖에 불편하거나 이상할 때

저장소의 Issues → New issue 에서 양식을 골라 적습니다.

| 양식                            | 적을 것                                                                                            |
| ------------------------------- | -------------------------------------------------------------------------------------------------- |
| 사용이 불편하거나 오류가 납니다 | 프로그램이 안 되거나 설명이 헷갈릴 때 씁니다. 오류 창이 뜨면 [오류 내용 복사]를 눌러 붙여 넣습니다 |
| 문제나 정답이 이상합니다        | 문항 ID(예: `s03_Q4`, 알고리즘 여행은 `1-3`)와 무엇이 이상한지 적습니다                            |
| 문제를 더 만들어 주세요         | 더 연습하고 싶은 단원이나 개념을 적습니다                                                          |

이슈를 쓰면 스터디장에게 알림이 가고, 처리되면 이슈가 닫히면서 알림이 옵니다.

## 터미널 명령

창 없이 풀려면 `go` 를 씁니다. 답은 `submissions/<내 ID>/<회차>/` 의 `quiz.py` 와 `.py` 파일에 직접 적습니다. 알고리즘 여행은 창에서 풀고, 웹 면접 준비는 창에서도 풀고 아래 `web` 명령으로도 풉니다. 명령마다 `--user <ID>` 를 붙이면 다른 ID 의 기록을 씁니다.

`go` 는 적어 둔 답을 채점해 첫 제출로 기록합니다(채점 전에 한 번 묻습니다). 화면에서 풀던 회차에 쓰면 쓰다 만 답까지 기록되므로, 화면으로 풀 때는 화면의 [회차 제출]만 씁니다. 터미널 모드는 빈 문항을 오답으로 넘기지 않아서, 모든 문항에 답을 적어야 회차가 끝나고 다음 회차가 나옵니다.

| 명령                             | 하는 일                                                                            |
| -------------------------------- | ---------------------------------------------------------------------------------- |
| `python study.py`                | 창 열기. 진행 상황과 오류가 이 터미널에 나옵니다                                   |
| `python study.py update`         | 새 버전과 새 문제 받기 (창이 열리지 않을 때)                                       |
| `python study.py go`             | 다음 할 일 이어 가기 (진단, 풀기, 채점, 다음 회차)                                 |
| `python study.py me`             | 단원별 숙달도와 약한 개념                                                          |
| `python study.py explain s03_Q4` | 정답과 해설                                                                        |
| `python study.py grade r02`      | 2회차(`r02`) 다시 채점                                                             |
| `python study.py start m1`       | 실전 모의고사(120분). 채점은 `grade m1`. 2회는 `m2`, 3회는 `m3`                    |
| `python study.py start c1`       | 코딩테스트 연습 Lv.1. 채점은 `grade c1`. Lv.2 는 `c2`                              |
| `python study.py web status`     | 웹 면접 준비 현황: Node.js 와 검사 도구, 미션·사슬·학습 노트, 오늘 복습, 다음 추천 |
| `python study.py web install`    | 미션 검사 도구 설치 (처음 한 번, 인터넷 필요). 지우기는 `web uninstall`            |
| `python study.py web get w03`    | 미션 코드를 내 폴더로 복사하고 읽기 시간 시작. 처음부터 다시 하려면 `--again`      |
| `python study.py web start w03`  | 실전 시작. 0단계(코드 설명)가 열립니다                                             |
| `python study.py web check w03`  | 0단계면 점검 항목 표시, 그 뒤는 단계 검사                                          |
| `python study.py web answer w03` | 통과 뒤 질문에 답하지 못하고 넘어갔으면 그 질문에 다시 답하기                      |
| `python study.py web hint w03`   | 면접관 힌트 듣기                                                                   |
| `python study.py web skip w03`   | 목표 시간이 지난 단계 넘어가기                                                     |
| `python study.py web finish w03` | 미션 끝내기: 해설, 모범 답안 비교, 스스로 점검                                     |
